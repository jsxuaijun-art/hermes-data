# 通用话术模块 · 客户维护与跟进话术

> 来源：代帐促单培训材料。覆盖客户分类ABCD、跟进频率、二次跟进、续费、到账后、日常维护。

## 一、客户分类管理（ABCD）

| 分类 | 决策人 | 代账需求 | 成交时间 | 表现状态 |
|------|--------|---------|---------|---------|
| A | 是 | 是 | 3天内 | 主动询问价格、套餐、合作方式；已定成交时间但出差；确定成交但考虑套餐（新户未找代账/切户1个内到期且不满前公司/转介绍户） |
| B | 是 | 是 | 两周内 | 询问价格、套餐、售后、优惠、财务服务等细节 |
| C | 是 | 是 | 1个月内 | 主动问服务问题（会计专业度）、拿我们与竞对比较、咨询记账报税信息（成本票） |
| D | 是/否 | 是 | 不确定 | 了解产品服务但不接受邀约、推脱 |

## 二、客户跟进技巧

### 1) 未成交 A 类（准则：快、准、狠）
**电话跟进：** ①反对意见解决要及时，第一时间邀约，自己不能解决的问题立马明确10分钟后回复或现场配合；②结合客户性格用不同方式邀约（性格软的主动做决定、多次邀约让客户不好意思拒绝）；③利用报税节点、优惠节点邀约（最好见效）；④明确下一次具体沟通时间。
**线下跟进：** ①马上加微信（答应加了没加上，10分钟后再次致电确认）；②发公司介绍图片、资质、视频、账本账套给客户；③评论客户朋友圈、嘘寒问暖、转发客户公司业务介绍。
**联系频率：** 每天联系。**误区：** 不能拖，容易被同行签走。

### 2) 未成交 B 类（准则：自信、分析）
**电话跟进：** ①了解关键需求点（重视价格还是服务）及担心点，沟通解决及时邀约；②做好和同行效果对比，突出我们如何更好满足需求；③强化模式和收费方式能满足需求；④明确下次沟通时间。
**联系频率：** 2-3天一次。**误区：** 没信心或盲目相信客户。

### 3) 未成交 C 类（准则：循序渐进，让客户对公司及收费模式产生认同）
**电话跟进：** ①明确需求及我们如何满足；②介绍服务优势、收费和维护模式及对客户好处；③用各种案例、政策推动客户重视合规做账报税；④明确下次沟通时间。
**联系频率：** 每2-3天一次。**误区：** 放弃。

### 4) 未成交 D 类（准则：放长线，培养正确的财税意识及认同）
**电话跟进：** ①新户探寻客户财税意识、强化合规理念和正确流程；切户客户探寻原财税公司是否按合规做账、客户满意程度，针对性强化沟通不满的点；②探寻客户对公司财税的想法、什么时候准备合作/换公司、原因是否可引导；③不能短期解决的，加微信保持联系。
**线下跟进：** ①关注客户朋友圈保持联系留印象；②发公司资料和行业信息加深认同；③关注客户与前公司合作是否有不愉快。
**联系频率：** 半个月左右一次，节日多问候。**误区：** 花太多时间。

## 三、二次跟进技巧

### 1) 二次跟进前的准备
- **心态准备：** 不跟进客户，一天后数据回到公海就归大家所有，之前沟通化为乌有。继续跟进会出现3种情况：成交/拒绝/再次出现异议——被拒绝就当多一次演练，再次出现异议就离成交更近一步。
- **思路准备（3逻辑）：** ①让客户知道产品是他需要的、能解决问题；②让客户知道产品是好的、我们服务不错；③让客户知道为什么要现在买、现在参加对客户有什么好处（制造急迫感）。
- **话术准备：** ①讲过哪些内容？哪些是重点？哪些能促动客户？②客户会提什么问题，先找解决方法？③什么优惠政策能吸引客户？

### 2) 二次跟进的时间安排
- 约访时间准时拨打（客户比较有空，也显示重视尊重）
- 根据行业性质安排（如餐饮行业下午2-3点半较空闲）
- **黄金时间点：上午10:30-11:30、下午15:00-17:00**

## 四、续费话术

**当合作只剩3个月就要开始做续费动作。模板：卡准时间 + 成果汇报 + 财务规划 + 奖励机制。**
> 刘总，咱们目前每个月的代账都在正常开展，上半年的财务数据我做了个汇总，我稍等发您。目前会计在做下个阶段的财务规划，我这边刚查到咱们的合作只剩下3个月了，我们现在刚好有活动，这个月有个续费活动，老客户续费只要如何如何就可以怎样怎样，这个月刚好还有6个名额，我给您争取了一个。您什么时候方便，我们详细聊一聊。

## 五、到账后的话术（打款之后，合作才开始）

> ①王总款已收到，咱们的合作才刚刚开始，希望你能在未来的一年里，亲自验证今天你没选错！
> ②王总，款已收到，不过我还是要提醒一下，后面我跟你联系的频率可能会更高，因为接下来才是真正为你解决财税问题的阶段，你千万别嫌麻烦，毕竟我们都是为了更好的结果。
> ③王总，款已收到。在这么乱的市场，最可贵的是一份信任和用心，今天你把信任交给我，今后我把用心还给你。感谢信任，未来我们共同期待！

## 六、日常维护话术

**①客户说"你辛苦了"：** 千万别说"都是我们应该做的"（既否定自己功劳，又聊死天）。要把话接过来：
> 张总，只要你满意了，我们再辛苦都值得。我唯一担心的就是哪里没有做好，影响了你们的体验，看来我们这次做得还不错。

**②客户说"感觉你很专业"：** 不管夸什么，都要把客户带上：
> 专业的人也要遇到您这样的老板，您这么懂财税的老板不多了。

**③客户说"谢谢"（5个版本）：**
> 1) 张总，您就别跟我客气了，我们做的是代理记账，交的是生意伙伴，以后您有任何事情随时来找我，我一定让您知道，"靠谱"这俩字不是说出来的，是做出来的。
> 2) 张总，实话跟您说，您给我了一份信任，我也还您十分责任，起码让您在财税上能睡得安稳。
> 3) 您太客气了张总，像您这么大气又爽快的老板真的不多见。您放心，以后有任何需要随时来找我，我随叫随到。
> 4) 张总，您太客气了，这次合作只是一个开始，我们的服务永无止境，期待后续的愉快合作！
> 5) 哎呀张总您太客气了，该谢谢的是我，毕竟专业也要遇到懂行的人，遇到您这种企业做得大还这么谦虚的老板，是我们的荣幸。
