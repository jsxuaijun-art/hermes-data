# 价格谈判核心逻辑：服务费 = 买断工作时间

## 一句话版

> 服务费买的是会计的工作时间——时间花在开票上，做账时间就少，风险就多了。

## 完整论述版

一个人的时间是有限的。服务费相当于买断了一定的工作时间。

总的工作时间就这么多——

- 花在开发票这些不需要专业的事情上（而且是做在明面上的，让你有感觉的，让大家开心的事情）
- 那么用来做账的时间就少了
- **做账是看不见的无形服务，做多做少花多少时间根本不知道**
- 现在税务大数据监管这么严格，风险也就来了

上帝对每个人都公平——一天24小时，能用来工作的时间就那点。大家都是靠出卖时间来赚钱的。

同行说"我们免费帮你开票"——你要知道：开发票没有技术含量，只是耗时间。他把分配给你的时间花在开票上了，分给认真做账的时间还剩多少？

**做账才是真正的专业，而且是看不见的无形服务。**

## 配套杀伤链

1. 服务费=买断时间 → 2. 时间总量固定 → 3. 低价同行时间花在开票上（明面上让你开心） → 4. 做账是看不见的无形服务 → 5. 你做账时间少 → 6. 大数据监管下风险大 → 7. 先比资质专业再比价格（高认知做法）

## 数据版（把「24小时」升级成算术——阶段三/七/八通用）

> 客户觉得「几百块凭什么不能一对一」时，用数据把「时间/成本/规模」量化讲透。

- 代账会计月成本约 8000–10000 元（苏州/上海，含社保）
- 基础档收费 300–3000 元/户 → 人均需服务 **25–40 户**才能覆盖成本＋合理利润
- 单客户月均只能分到 **4–6 小时**（160工时÷30户）；全职会计同口径约 **176 小时/月**
- 结论：几百块买的是「每月几小时的标准化处理」，不是月薪万元、全天在岗的全职会计——
  这是**规模摊薄**的行业共性，不是哪家机构偷懒，任何机构都突破不了。
- 客户若认同一对一服务的价值，正确路径是**升级档位**，不是让基础档降价。

## 官方定义（法理锚，客户质疑「你凭什么」时用）

**结论先行：** 代理记账的官方定义 = 「代理记账机构接受委托办理会计业务」，出自
《代理记账管理办法》（财政部令98号，2019年修改）第二条；上位法是《会计法》授权
「不具备设置条件的单位，委托经批准设立从事代理记账业务的中介机构代理记账」。

**两条核心条文：**
- 《代理记账管理办法》（财政部令98号）第2条：代理记账是指代理记账机构接受委托办理会计业务。
- 《会计法》（2024修正）第34条：各单位应依会计业务需要，采取四种方式之一组织会计工作——
  ①设会计机构 ②设会计岗位并指定主管 ③委托代理记账机构 ④财政部规定的其他方式。

**四个关键边界（实务常踩）：**
| 维度 | 官方规定 | 出处 |
|------|----------|------|
| 执业主体 | 必须是机构（持许可证，或会计师事务及其分所）；个人不得从事 | 办法第3、26条 |
| 谁必须委托 | 未设会计机构或会计人员的单位，应委托代理记账（强制） | 办法第10条 |
| 可办业务范围 | 审原始凭证/填制记账凭证/登记账簿/编报告；对外提供报告；向税务提供资料；其他委托业务 | 办法第11条 |
| 资格准入 | 依法设立企业；专职从业人员≥3名；主管具会计师以上资格或从业≥3年且专职；有健全规范 | 办法第4条 |

## 代理记账 vs 全职会计（对比表）

| 对比项 | 代理记账（基础档） | 全职会计 |
|--------|--------------------|----------|
| 用工形态 | 机构承接，一对多 | 企业自聘，一对少（1–2家） |
| 月成本 | 300–3,000 元 | 8,000–10,000 元 |
| 服务深度 | 标准做账＋申报 | 深度对接、随叫随到 |
| 提醒方式 | 申报期前统一提醒一次 | 逐笔、每日主动盯节点 |
| 适合对象 | 小微、初创、票据规范 | 业务复杂、需专人陪护 |

## 科技现实（防「别家能用AI免费盯」的反击）

- RPA、财税软件、票税接口 → 减少重复录入、自动取数，提升**批量处理效率**；
- 「理解业务实质、判断票据合规、税务风险筹划、一对一沟通」→ 仍高度依赖人；
- 当前同行任何技术都做不到把人工环节降到免费提供「专属一对一提醒」；AI辅助能提效，
  远未到替代人力的临界点。**做这些都要花时间，大家成本都差不多。**
- 现实提醒：向客户催资料/沟通合规，是代账履行做账前置义务，绝非无事生非；部分低价营销
  从业者「不要求或不处理资料」，正是为省时间多服务几家企业——这才是税务风险与合规隐患的来源。

## 客户常见误解 + 四大应对原则

**误解：**「我花几百块请了你们，就等于请了个全天候、随叫随到的专属会计。」

**四大应对原则：**
1. **边界书面化** —— 服务范围、双方义务写进合同（告知书/条款见 `references/02-首次接触/建群开场白_完整流程.md` 附录）
2. **预期话术化** —— 统一话术讲清「做什么／不做什么／为什么」★
3. **服务分层化** —— 用价格区分服务深度，让客户自选，而非被动被比价
4. **自动化补提醒** —— 企微推送＋线上票据交接单，近零成本覆盖「一对一提醒」体验缺口
