# 案例：贸易公司→生产企业转型（含业务过渡）

> 来源：2026年7月 · 服饰贸易公司综合服务方案
> 关键特征：无经营壳公司 · 小股东15%股权转让 · 地址迁移 · 贸易转生产 · 同控制人业务过渡
> 关联主体：另一家内衣贸易公司（存货1,200万、年销售2,500万）

---

## 一、项目背景

XX服饰贸易有限公司（以下简称"目标公司"）目前无实际经营，股东结构中含有小股东拟退出。同一实控人名下另有一家内衣贸易公司，有实际业务（存货约1,200万元、年销售约2,500万元）。客户希望：

1. 小股东15%股权转让（预计个税约4,000元）
2. 注册地址迁移
3. 公司从贸易→生产制造转型（名称+经营范围+行业代码）
4. 变更完成后，逐步将内衣公司业务过渡到目标公司

## 二、操作里程碑

```
第1阶段（5~10个工作日）：股权转让
  → 核实财务报表 → 签协议 → 申报个税 → 工商变更

第2阶段（5~15个工作日）：地址迁移
  → 新地址证明 → 工商地址变更 → 税务登记更新
  ⚠ 跨区迁移需先清税（迁出地查账5~10天）

第3阶段（5~10个工作日）：行业转型
  → 名称变更（去"贸易"） → 经营范围增加生产类 → 行业代码调整
  → 生产资质（环评/消防）备案

第4阶段（6~12个月）：业务过渡
  → 并行期（1~3月）：新公司先做贸易，搭建供应链
  → 试产期（4~6月）：小批量生产，逐步分流订单
  → 主导期（7~12月）：新公司成为主要经营主体
```

## 三、关键税务处理

### 3.1 股权转让个税

无经营公司的股权转让，定价依据为净资产或注册资本。计算公式：
> 个人所得税 = (转让收入 - 原始出资成本 - 合理税费) × 20%

**风险提示：** 转让价格明显偏低且无正当理由的，税务机关有权按净资产核定。

### 3.2 业务过渡的税务安排

| 过渡环节 | 推荐处理方式 | 不推荐的方式 |
|----------|-------------|------------|
| 存货转移 | 正常销售开票 OR 委托代销 | 按账面价值直接划转（视同销售） |
| 客户切换 | 新公司直接签约 | 旧合同不变只改开票主体（三流不一致） |
| 供应商切换 | 新公司重新签采购合同 | — |
| 关联交易 | 独立交易原则，定价不偏离市场价 | 转移利润定价（纳税调整风险） |

### 3.3 行业变更的税务影响

贸易→生产转型后，税务上需关注：
- 行业代码变更（影响税负率比对模型）
- 增值税发票额度重新核定
- 如符合制造业条件，可关注相关税收优惠

## 四、报价模型参考

| 服务项目 | 报价 | 说明 |
|----------|------|------|
| 股权转让代办 | 2,500 | 协议+税务申报+工商变更 |
| 地址变更代办 | 1,500 | 含迁入迁出 |
| 名称变更代办 | 1,000 | 核准+申请+换照 |
| 经营范围变更 | 1,000 | 含行业代码调整 |
| 生产资质咨询 | 1,500 | 环评/消防/许可指引 |
| 业务过渡方案设计 | 3,000 | 含存货转移+客户切换+关联交易 |
| 合规账首年 | 25,000 | 变更后全年（参照商贸公司存货密集型定价） |
| **全套优惠价** | **32,000** | 以上7项打包 |

## 五、风险补丁清单

| 风险 | 触发条件 | 应对 |
|------|---------|------|
| 股权转让价偏低被核定 | 税局认为价格<净资产 | 提前准备财务报表作定价依据 |
| 跨区迁移触发清税查账 | 迁出地要求查账 | 确保历史零申报正常 |
| 生产资质审批延误 | 环评/消防未通过 | 变更前先咨询当地环保部门 |
| 存货转移被视同销售 | 不开票直接划转 | 采用销售开票或委托代销模式 |
| 关联交易被纳税调整 | 定价明显偏离市场 | 保留市场可比价格依据 |

## 六、话术要点

> 「这家公司现在是个壳，股权转让的时候税务局会看净资产。虽然没经营，但注册资本认缴了多少、实缴了多少、资产负债情况，都要提前拉出来看看。」

> 「贸易转生产不只是改经营范围。行业代码一变，税务局对你的税负率预期也会变。」

> 「内衣公司的货不能直接搬过去——要不开票卖过去，要不委托代销。直接划转税务局不认，算视同销售，税一分不能少。」
