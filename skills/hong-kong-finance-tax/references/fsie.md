# 香港 FSIE 分析框架

FSIE 属于高变化专题，正式结论必须核验当前 IRD / 政府官方规则和适用生效日期。

## 1. 先识别
- Income type
- Source
- Recipient entity
- Group structure
- Receipt / deemed receipt facts
- Tax period

## 2. 再分析
- 是否进入当前 FSIE 适用范围
- 是否存在适用豁免或排除
- Economic substance（如适用）
- Participation exemption（如适用）
- Nexus / IP-related rules（如适用）
- Anti-abuse / documentation

## 3. 输出
- In scope / out of scope / Needs Verification
- Required facts
- Evidence
- Potential risk
- Recommended action
- Effective Date / Review Tier
