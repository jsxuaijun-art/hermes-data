# 苏州地区股权转让实操辅导

> ⚠️ **本技能为江敏内部工具**，不直接对外。用于在服务客户时快速查资料、提高效率和服务质量。
>
> **反白嫖边界：** 以下内容skill会主动识别并向你提问，由你决定公开程度：
> - 税负测算的具体数字（差异率、核定价格、经典测算）
> - 窗口审核的"潜规则"（哪些模糊地带可控、哪些一定卡）
> - 协议审查意见（具体条款修改建议）
> - 特殊案例处理经验（非标情形）

## 二、核心知识：苏州三地窗口差异对比

> 💡 **核心认知：** 苏州各分局股权转让窗口的材料要求和审核口径**存在实质性差异**。同样一笔股权转让，在吴中木渎和在园区，材料清单和审核时间可能完全不同。

**关键差异点说明：**
- **高新区**区分三种业务类型（近亲属/无增值性资产/非即时办结），每种的材料清单不同
- **高新区**要求2019年以前成立的企业提供最近一次股权转让的旧协议+旧章程+承诺书+完税证明
- **吴中木渎**短信通知中有"转让时点一般为签约时间"这一实操口径，其他分局不一定明说
- **工业园区**：申报表类（《财产和行为税纳税申报表》+《个人股东股权转让情况报告》）由盈信现场填，客户只备自备文件；**协议签订日至递交须在15个工作日内**；股权原值资料按"取得方式"分6类选报；个税走自然人电子税务局**网页端**自行申报。完整必报/选报清单见 `references/园区-股权转让办理材料清单.md`

## 三、高新区特色：三类型分类体系（最详细）

高新区税务局将股权转让分为三种类型，**每种的资料要求和办理时效不同**：

### 类型A：近亲属关系类 → 即时办结

**适用条件：** 继承或将股权转让给配偶、父母、子女、祖父母、外祖父母、孙子女、外孙子女、兄弟姐妹、直接抚养/赡养人

**所需资料：**
1. 《个人所得税自行纳税申报表（A表）》或《个人所得税扣缴申报表》
2. 股权转让合同（协议）
3. 股权转让双方身份证明
4. **具有法律效力的身份关系证明**（户口簿、结婚证、抚养赡养关系证明等）
5. 被投资企业最新章程（章程修正案）或股东会决议
6. 纳税人或扣缴义务人的书面承诺
7. 经办人身份证明+授权委托书（非本人办理时）

**时效：** 资料齐全 → 即时办结

### 类型B：无增值性资产类（≤200万）→ 即时办结

**适用条件：**
- 被转让企业（不含房地产开发企业）在转让上一年末及转让时**均无**房屋、土地使用权、知识产权、探矿权、采矿权、股权等资产
- 转让价格**不低于**对应权益份额账面净资产
- 转让价格**≤200万元**

**所需资料：**
1. 《个人所得税自行纳税申报表（A表）》或《个人所得税扣缴申报表》
2. 股权转让合同（协议）
3. 股权转让双方身份证明
4. 被投资企业最新章程或股东会决议（含利润分配方式；2019年前成立的企业需提供最近一次股转资料）
5. 纳税人或扣缴义务人的书面承诺
6. 上一年度及上一月末的财务报表
7. 股权原值证明资料（如需扣除原值）
8. 经办人身份证明+授权委托书（非本人办理时）

**时效：** 资料齐全 → 即时办结

### 类型C：非即时办结事项

**适用条件（符合任一）：**
- C：不符合即时办结条件的股权转让
- D：上一月末财务报表的资产总额/增值性资产/净资产，与上年度年末增减变化**20%及以上**
- E：前期股权转让办理中止或作废，又重新申请的

**所需资料（基础）：**
1-9项同类型B基础资料

**附加资料（条件触发）：**
- 第10项：土地使用权/房屋/知识产权/探矿权/采矿权/股权等资产占总资产**超过20%** → 提供**具有法定资质中介机构出具的资产评估报告**
- 第11项：计税依据明显偏低但有正当理由 → 提供相关证明材料

**时效：** 移交属地税源管理机构审核，时长取决于复杂程度，**建议在申报期限内尽早申报**

## 四、税务处理核心知识点

### 4.1 个人所得税

| 项目 | 内容 |
|------|------|
| 纳税人 | 股权转让方（个人） |
| 扣缴义务人 | 股权受让方 |
| 申报时间 | 协议签订后5个工作日内报告；次月15日内申报纳税 |
| 税率 | 20%（财产转让所得） |
| 应纳税所得额 | 转让收入 - 股权原值 - 合理税费 |
| 核心法规 | 国家税务总局公告2014年第67号 |

**转让收入明显偏低的认定情形（67号公告 第十二条，共六项）：**
1. 申报的股权转让收入**低于股权对应的净资产份额**——其中被投资企业拥有土地使用权、房屋、房地产企业未销售房产、知识产权、探矿权、采矿权、股权等资产的，低于**净资产公允价值份额**即算偏低
2. 低于**初始投资成本**，或低于取得该股权所支付的价款及相关税费
3. 低于相同或类似条件下**同一企业同一股东或其他股东**的股权转让收入
4. 低于相同或类似条件下**同类行业**企业的股权转让收入
5. **不具合理性的无偿让渡**股权或股份（不是所有0元都安全）
6. 主管税务机关认定的其他情形

**关键推论——净资产为负时的零元转让（2026.6.4实战案例）：**

当公司净资产为负时，零元转让**不构成"计税依据明显偏低"**，因为：

```
净资产 = 资产合计 - 负债合计
净资产份额 = -75,466.28
转让价格 0  >  净资产份额 -75,466.28
→ 不低于净资产份额
→ 不启动核定征收
→ 个税 = 0 ✅
```

**⚠️ 但是！如果公司有房产/土地/知识产权：**
- 必须出具资产评估报告
- 评估后房产升值可能把净资产"翻正"
- 净资产变正 → 零元转让低于净资产份额 → 核定征收 → 需要交个税

**评估前后的对比：**

| 状态 | 净资产 | 零元转让结果 |
|------|--------|-------------|
| 评估前账面 | -7.55万 | 不核定，个税=0 ✅ |
| 评估后（房产升值30万） | +22.45万 | 核定收入22.45万，个税≈4.49万 ❌ |

**实操口诀：** 净资产为负≠个税归零，房产评估是变数。先看评估结果再定价，别急着签协议。

**有正当理由的低价转让（67号公告 第十三条，共四项，缺一不可对号）：**

4. 转让双方能提供有效证据证明其合理性的其他合理情形

### 4.4 ⭐ 定价前第一问：转让方与受让方是什么关系？（67号公告13条的落地动作）

> **为什么这是"第一问"而不是"顺便问一句"**：因为关系直接决定三件事——**①低价合不合法 ②走不走类型A即时办结 ③要交什么证明材料**。关系没问清就报价、就签协议，后面全是返工。

**必问三句（一次问完，别拆成三轮）：**
1. **转给谁？** 是个人还是公司？个人的话，跟你（转让方）是什么关系？
2. **具体是哪一种？** 配偶／父母／子女／祖父母／外祖父母／孙子女／外孙子女／兄弟姐妹／抚养人／赡养人——**要客户自己说出具体称谓**，不接受"亲戚""家里人"这种回答
3. **有没有证明文件？** 结婚证、户口簿（能体现关系的页）、出生医学证明、抚养/赡养关系证明。**没有证明 = 不能按近亲属办**，窗口只认文件不认口头

**关系判定的四分法：**

```
┌──────────────┬────────────────────────────┬──────────────────────────────┐
│  关系类型     │  税务后果                    │  材料/路径                    │
├──────────────┼────────────────────────────┼──────────────────────────────┤
│ 夫妻          │ 低价/平价/0元 有正当理由      │ 结婚证；类型A 即时办结         │
│ 其他法定近亲   │ 同上                        │ 户口簿/出生证明；类型A          │
│ 抚养/赡养人    │ 同上（须"直接"抚养或赡养）     │ 抚养赡养关系证明；类型A         │
│ 不在名单的亲友 │ **无正当理由** → 低于净资产即核定│ 只能按净资产定价或另找正当理由   │
└──────────────┴────────────────────────────┴──────────────────────────────┘
```

**夫妻场景要额外盯的三点（实战最常踩）：**
- **夫妻间转让≠随便定价**：价格可以是0或平价（13条2项），但**协议要写清、身份关系证明要附**，否则窗口按无正当理由核定
- **夫妻共同财产**：股权登记在一方名下但属婚后共同财产的，转让时通常需配偶书面同意；离婚析产式转让要同时备**离婚协议/判决书 + 财产分割约定**，且分割本身与"转让"在税务上要分开说清
- **受让方原值承接（15条3项 + 16条）**：无偿受让且符合13条2项的，**受让方原值 = 取得时的合理税费 + 原持有人的股权原值**——不是0。这条不写清，下次再转让时客户会以为原值是0、税负算错

**若客户答"没关系但要低价转"：** 不要顺着压价。给两条路——①按净资产份额定价（多数情况税负可接受）；②找13条其他项（政策调整影响经营、员工内部转让等）并备证据。**硬压价＝核定征收，补税+滞纳金，客户以为省钱实际多花。**

## 五、实操流程辅导

### ⭐ 首要原则：以表单替代一问一答（江姐偏好）

> **江姐明确要求：** 别在对话里逐个盘问客户信息。直接甩一份信息采集表过去，让客户一次填好发回来，你再读取。
>
> 理由：① 客户不用被你追着问，体验好；② 信息一次到齐，效率高；③ 避免反复追问的「审问感」。
>
> **操作：** 客户一提股转需求 → 直接生成 `股权转让信息采集表.docx` 到桌面 → 客户填好发回 → 你读取后出方案+材料清单。
>
> 采集表生成脚本：本技能 `scripts/gen-equity-info-form.py`，每次使用时直接运行即可。
>
> **⚠️ 2026.6.4 血的教训——两套财务报表必须同时索要：**
> 上次我只问了上年度末的财务报表，被客户反问"为什么不要最近一期？不重要吗？"——非常尴尬。
>
> **正确姿势：** 出采集表时就已经包含"上年度末净资产 + 最近一个月末净资产"两个字段。
> 原因：① 税务局窗口要求交两套（上年末+上月）；② 两期比较才能判断资产结构变化是否超过20%；③ 最近一期的利润表可以判断这期间是否有新增亏损或盈利，直接影响净值。
>
> **口诀：** 出表即出两期，不问第二遍。

### 5.0 两阶段报告流程（徐总 2026.11 定 · 标准做法）

> 股转出报告一律走"**初步 → 正式**"两阶段：先出初稿+待补清单，客户补齐后再出正式版。客户体验与专业性兼顾，不做一次性憋大报告。

**阶段一（初步）**：客户上传**财务报表 + 科目余额表** → 读取分析：
- 必做【科目余额表4项体检】：借贷是否平／应收是否挂贷方／本年利润是否结转未分配／长投是否标标的（详见实战经验-窗口口径；多数代账客户账上都有这些问题，先查出来防窗口退回，也是续费卖点）
- 输出**初步分析结果**，必须包含：① 我的疑问  ② 还需补充/提供的哪些信息和材料
- **立即出具《股权转让税务处理分析报告（初步版）》**，并单列"待客户再次补充的文件/信息"，典型必问项：
  · **股权怎么转**——原股东持有的X万股权（对应X%）以X万元价格转让给新股东（转让份额、定价、受让方）
  · **此前是否发生过股权转让**（历次沿革，尤其2019年前成立企业，要追历次不是只问最近一次）
  · 两期报表（上年末+最近一月末）是否已齐
  · 利润分配方式（实缴/认缴，章程/决议须注明）
  · 意向成交价 vs 净资产（是否触发核定）
  · 转让方/受让方身份与关系（近亲属/境外/法人）
  · 公司是否持有房产/土地/知识产权/对外持股（长投）→ 决定评估触发

**阶段二（正式/完整版）**：客户补齐上述材料 → 出**完整/正式版《股权转让税务处理分析报告》**，并**一并列举客户须完全准备提供的文件和信息完整清单**（含园区/属地窗口必报+选报清单，见 references/园区-股权转让办理材料清单.md）。

### 5.2 材料准备要点

**财务报表注意事项：**
- 需要**上一年度**（汇算清缴年报） + **转让前一个月**的财务报表
- ⚠️ **2026.6.4教训：必须同时索要两期，不要只问上年末不问最近一期**
- 最近一期利润表：用来判断转让前这段时间是否有新增亏损或盈利，直接影响净值
- 采集表v2.0新增字段：资产合计、负债合计、未分配利润、利润总额——这些是核税关键参数，一次性问全
- 高新区要求在转让时点及上一年末均无特定资产方可适用类型B
- 资产结构变化超过20% → 自动转入非即时办结

**章程/股东会决议注意事项：**
- 必须注明**利润分配方式**（按实缴比例或按认缴比例）
- 高新区"章程修正案"与"股东会决议"**二者有一样即可**
- 2019年以前成立的企业若有历史股权转让，需提供最近一次股转的旧协议+旧章程+承诺书+完税证明

**股权原值证明：**
- 注册资本已到位：验资报告或实收资本入账会计凭证
- 资金未到位：资金未到位声明
- 转让方非原始股东：前次受让凭证或成本证明

**⚠️ 历次股权转让的文件核查（2026.10.27 案例沉淀）：**
- **不是只问"最近一次"，要追"历次"**：公司历史上每一次股权转让的旧协议+旧章程（章程修正案）+完税证明/申报记录，都要让客户找齐。高新区尤其硬性（2019年前成立企业提供最近一次旧协议+旧章程+承诺书+完税证明），但即使不要求，也主动追问历次沿革——漏一次历史股转，窗口可能退回，也可能被认定计税依据问题。
- **主动核实股权沿革**：不要只听客户说"转给谁谁"，要按时间倒序把每一次股转的对手方、价格、计税依据、完税情况列出来。

**⚠️ 长期股权投资 / 控股子公司的核查（2026.10.27 案例沉淀）：**
- **账上有"长期股权投资"就必须问清楚投的是什么**：不要只看科目余额就完事，要问清：投资标的是哪家公司、**持股比例**、是**控股还是参股**、是否纳入合并。
- **若是控股子公司 → 必须索取该子公司的：**
  1. 子公司**名称 + 持股比例**
  2. 子公司**财务报表（资产负债表+利润表）**，看清其**盈亏状况**
- **为什么必须看子公司财报**：
  - 控股子公司的盈亏直接影响被投资企业"长期股权投资"的价值，进而影响被转让企业**净资产核定**与**转让定价合理性**判断（子公司亏损→母公司长投减值→净资产可能被"压低"→零元/低价转让空间随之变化；子公司盈利→长投增值→评估"翻正"风险）。
  - 若子公司亏损严重，母公司长期股权投资已发生减值，需判断账面是否计提减值、是否触发"转让价格低于净资产份额"的核定。
- **口诀：账上有长投→问清投的谁、持股多少、盈亏如何；控股子公司→看它的财报，别只看母公司账面。**

**⚠️ 两期财务数据原则（2026.10.30 徐总定，长期执行）：**
- 股转测算必须有"上年度末 + 最近一月末"两期报表。**缺任一期时，优先 A 方案：请客户补齐资料再算**，绝不用科目余额表倒推年初数或估算硬填——年内增资、红字调整、期间结转会让倒推严重失真（实测：倒推出的年初资产与权益严重矛盾）。
- 客户催得急、只能先出过渡版（B）：仅填报可核实的那一期，缺项**一律红字标注【待补：需XXXX年度报表】**，并在结论里明确"两期对比项无法判定"。
- **铁律：宁可交一份"缺项标红＋待补清单明确"的报告，也不交一份"数字齐全但来源不可靠"的报告。**

**⚠️ 拿到科目余额表先做 4 项体检（2026.10.30 案例）：**
1. **借贷是否平衡**：资产−负债 应等于所有者权益；不等即为账务/数据问题，先查再算（本案差 12,923.26）。
2. **应收账款是否出现贷方余额**：应收出现贷方属异常，疑预收未重分类或错账（本案贷方 230,387）。
3. **"本年利润"是否已结转"未分配利润"**：未结转会导致资产负债表"未分配利润"为空、累计亏损挂在损益科目（本案 89.6 万挂账）。
4. **长期股权投资等对外投资科目名是否写明标的**：只写"XX"的必须追问投资对象、持股比例、是否控股。
> 月度科目余额表的"期初"是月初、不是年初；年初数只能用"期末−本年借累计+本年贷累计"逐科目还原，且必须与正式报表交叉验证，不可直接当上年度末填表。

**⭐ 把 4 项体检做成标准服务动作（2026.10.30 徐总要求执行）：**
- 股转前先出一页《账务体检结论》，随采集表/方案一起交客户。
- 理由：多数代账客户账上都有这几类问题，替客户先查出来，① 防股转申报被窗口退回；② 是续费/涨价时"别人只报税、我们还查账"的现成卖点。
- 输出固定四行：借贷是否平／应收是否挂贷方／本年利润是否结转／长投是否标标的，每行给结论+建议动作。
- **模板见 `templates/账务体检结论模板.docx`（一页纸，含四项体检表、综合结论、客户配合事项、签署确认），直接改数即可用。**
- **产品化与报价：** 口径见 `references/年度账务体检-产品与报价口径.md`（三档报价建议＋抵扣机制＋纪律边界）；对客户/内部评审用一页说明见 `templates/年度账务体检-产品与报价建议.docx`。两者均为**建议稿，报价待徐总/江姐定**，对外以《合规账服务方案》为准。

| 11 | 违约金、补偿金、后续款没并进收入 | 67号第8、9条：各种名目的款项和后续收入都要并入，协议写"另行补偿"不顶用 | 按含税总对价倒算，别只看转让价款 |
| 12 | 多次取得同一公司股权，转让时原值乱取 | 67号第18条必须用**加权平均法**；取"最早一笔"或"最低一笔"都会被调 | 拉全历次取得成本，加权平均算原值 |
| 13 | 近亲属无偿受让后，把原值当成0 | 67号第15条(3)+16条：受让方原值=取得时合理税费+原持有人原值，不是0 | 在协议/备忘里明确承接原值，避免下次转让多缴 |
| 14 | 把"低价就安全"或"0元就免税"当通则 | 只有13条四项之一才算正当理由，其余低于净资产即核定 | 先对号入座，再定价 |
| 15 | 协议签完才想起来报告义务 | 67号第6条：扣缴义务人须在协议签订后**5个工作日内**报告；第20条六种情形次月15日内申报 | 签字当天就排申报节奏 |
| 16 | 非货币支付、名画抵债等情形漏判 | 67号第3条的"股权转让"含7类：出售/公司回购/首发配售/司法强制过户/以股权对外投资或非货币交易/以股权抵债/其他 | 先判断是否属"转让"，再谈税 |

## 九之二、67号公告条文速查（文件级索引，用于给客户/窗口"引条文"时）

> 来源：用户提供的《股权转让所得个人所得税管理办法（试行）》全文（税总2014年67号公告，2015-1-1施行）。下面只列**实操会用到的条文**，条文原意已核对；引给客户或窗口时按条号说，比说"税务局规定"有力。

### 9.2.1 总则（第1—6条）

| 条 | 要点 | 实操用法 |
|---|---|---|
| 2 | 适用对象＝**自然人股东**投资于中国境内企业/组织的股权；**不含个人独资企业、合伙企业** | 客户是合伙企业份额转让→不适用本办法（按"经营所得"或财产转让另行判断） |
| 3 | "股权转让"含**七类**：①出售 ②公司回购 ③首发时老股东一并发售 ④司法/行政强制过户 ⑤**以股权对外投资或其他非货币性交易** ⑥**以股权抵偿债务** ⑦其他转移 | 客户说"不是卖，是抵债/换股/被法院判走"→仍是转让，照样申报 |
| 4 | 应纳税所得额＝转让收入−股权原值−合理费用；合理费用＝转让时按规定支付的有关税费 | 印花税、评估费等可扣；个人消费性支出不可扣 |
| 5 | 纳税人＝转让方；**扣缴义务人＝受让方** | 受让方是公司也要代扣，很多客户以为只有公司股东才缴 |
| 6 | 扣缴义务人须在协议签订后**5个工作日内**报告主管税务机关；被投资企业须详细记录股东持股成本、如实提供信息 | 报告≠申报，两步都要做，别以为报了就不用申报 |

### 9.2.2 收入确认与核定（第7—14条）

| 条 | 要点 |
|---|---|
| 7 | 收入＝现金＋实物＋有价证券＋**其他形式经济利益** |
| 8 | **违约金、补偿金及其他名目的款项、资产、权益，一律并入收入** |
| 9 | 合同约定的**后续收入**，满足条件取得时也作收入 |
| 10 | 收入按**公平交易原则**确定 |
| 11 | 可核定收入的四种情形：①申报收入明显偏低且无正当理由 ②逾期不申报 ③无法/拒不提供收入资料 ④其他 |
| 12 | **明显偏低六项**（见 4.1，含净资产份额、公允价值份额、初始投资成本、同企业其他股东价、同类行业价、无合理性无偿让渡） |
| 13 | **正当理由四项**（见 4.1/4.4，核心是配偶父母子女等法定近亲属＋继承＋员工内部转让＋其他有效证据） |
| 14 | **核定顺序（依次）**：①**净资产核定法**（每股净资产或对应净资产份额）②类比法（同企业其他股东价／同类行业价）③其他合理方法。**触发评估的两个口子**：土地使用权/房屋/未售房产/知识产权/探矿权/采矿权/股权等资产**占总资产超20%**；以及**6个月内再次转让**且净资产无重大变化→可参照上次评估报告 |

> **窗口话术**：窗口说"必须出评估报告"，依据就是第14条(一)的20%口径；说"按净资产核定"，依据是第11条+第12条(一)。客户争"我这是双方自愿的价格"，回答口径是第10条公平交易原则＋第12条列举情形，不是"税务局不讲理"。

### 9.2.3 股权原值（第15—18条）

| 条 | 要点 |
|---|---|
| 15 | 原值确认五法：①现金出资＝实付价款＋直接相关合理税费 ②非货币出资＝税务机关认可/核定的入股价格＋合理税费 ③**无偿让渡且属13条2项的＝取得时合理税费＋原持有人原值** ④资本公积/盈余公积/未分配利润转增股本且已缴个税的＝转增额＋相关税费 ⑤其他按"避免重复征税"原则由税务机关确认 |
| 16 | 转让人被核定收入并已缴个税的，**受让方原值＝取得时合理税费＋被核定的转让收入** |
| 17 | 无完整准确的原值凭证 → **由税务机关核定原值**（不是按0，也不是按客户报的） |
| 18 | 多次取得同一企业股权，转让部分时用**加权平均法** |

### 9.2.4 申报与征管（第19—31条）

| 条 | 要点 |
|---|---|
| 19 | 纳税地点＝**被投资企业所在地**税务机关（不是股东户籍地） |
| 20 | 应**次月15日内**申报的六种情形：①已付或部分付款 ②协议已签订生效 ③受让方已实际行使股东权利 ④有关部门判决/登记/公告生效 ⑤第3条第4—7项行为已完成 ⑥其他有证据表明股权已转移 |
| 21 | 报送资料：①转让合同 ②双方身份证明 ③需评估的附评估报告 ④偏低但有正当理由的证明材料 ⑤税务机关要求的其他 |
| 22 | **被投资企业义务**：董事会/股东会结束后**5个工作日内**报决议、会议纪要；股东变动**次月15日内**报《个人所得税基础信息表（A表）》＋股东变更情况说明 |
| 23 | 外币结算 → 按结算当日人民币汇率中间价折算 |
| 24—26 | 与工商部门信息交换共享；建立**电子台账、链条式动态管理**（每次转让的收入和原值会被逻辑比对）；加强日常管理与税务检查、各税种协同 |
| 27 | 逾期申报/报送 → 按《税收征管法》及实施细则处理（滞纳金、罚款） |
| 28 | 各地可政府购买服务，引入中介做评估 |
| 29 | **不适用**：个人在沪深交易所转让上市公司股票、转让限售股及其他特别规定的股权转让 |
| 30 | 各省/计划单列市税务局可制定具体实施办法 → **这就是苏州各分局口径差异的法规依据**（高新区三类型分类即本地实施办法的落地） |
| 31 | 2015-1-1施行；同时废止国税函〔2009〕285号、总局公告2010年第27号 |

> **⭐ 第30条是给客户的定心丸**：客户问"为什么别的区只要两样材料、你们这里要五样"，答案就是总局授权各省制定实施办法，苏州各分局的口径差异有法规出处（配套 2.2 材料清单对比表使用）。
