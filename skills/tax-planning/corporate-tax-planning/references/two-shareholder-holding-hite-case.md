# 案例：两股东投资控股 + 高企项目公司架构方案

## 客户背景

- 类型：软件技术研发公司，后期计划申报高新技术企业
- 股东：A股东（业务）55% + B股东（技术）45%
- 需求：设立一个投资公司 → 再投下面具体项目公司
- 后续：可能引进外部投资人 + 员工持股平台
- 目标主体：XX科技有限公司（高企申报载体）

## 核心方案

### 推荐架构

```
第一层：XX投资管理有限公司（有限责任公司，注册资本认缴100-500万）
  A股东 55% + B股东 45%
  ↓ 100%控股
第二层：XX科技有限公司（高企申报主体，独立法人）
       项目公司B、项目公司C（按需设立）
补充：员工持股平台（有限合伙，GP=1%/LP=99%）
     外部投资人（增资进入投资公司层）
```

### 投资主体选择结论

| 维度 | 有限责任公司 | 有限合伙企业 |
|------|------------|------------|
| 高企申报资格 | ✅ 可以 | ❌ 不能 |
| 股东责任 | 有限责任 | GP无限连带 |
| 引外部投资人 | 容易 | 困难 |
| 分红税务 | 居民企业间免税(企所税26条) | 穿透征税 |

**决定性因素：高企认定只有有限责任公司可以申报。**

### 高企财务准备要点

```
研发费用占比：
  收入<5,000万 → ≥5%
  5,000万≤收入<2亿 → ≥4%
  收入≥2亿 → ≥3%

研发费用辅助账科目：
  管理费用-研发费用-人员人工费用
  管理费用-研发费用-直接投入费用
  管理费用-研发费用-折旧摊销费用
  管理费用-研发费用-设计试验费
  管理费用-研发费用-其他相关费用（≤总额10%）

其他条件：
  高新产品收入 ≥ 60%
  科技人员 ≥ 10%
  知识产权（软著/专利）充足
```

## 关键教训

1. **合伙账不能申报高企** — 如果A/B以"合伙企业"形式经营，不能申报高企，也享受不了软件即征即退。必须走有限责任公司路径。

2. **投资公司的税务定位** — 项目公司分红到投资公司免税（企业所得税法第26条），投资公司再分给股东个人才需交20%个税。双重征税只发生在个人层面。

3. **员工持股平台 ≠ 投资主体** — 有限合伙适合做下层激励平台（GP控制+LP收益），但不能作为上层投资主体（不能申报高企、引投资人困难）。

4. **软件公司双税优惠** — 高企所得税15% + 软件产品即征即退（增值税13%征超过3%退），可叠加享受。

5. **架构图必须极简** — 本案例用户三次说"看不清/看不懂"。教训：框内不写注册地、注册资本等次要信息；字体≥20px；层级≤3层；默认出最简版，用户要求再补充。

6. **用PIL替代Graphviz** — Graphviz布局不可控、中文字体依赖严重。PIL/Pillow绘图字体精准、布局可控，客户更容易接受。
