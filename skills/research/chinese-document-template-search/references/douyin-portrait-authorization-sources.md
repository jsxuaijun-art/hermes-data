# 抖音肖像权授权书检索实测（2026-08）

## 案例背景

用户要求"搜索"抖音肖像权授权书模版，结构要求：一.授权人信息表格；二.授权内容；三.授权期限。
**纠正教训**：首轮搜索后助手擅自制作了 Word 成品，用户明确纠正：
"我是让你搜索，没有让你制作。如果搜索不到，你再问我要不要制作。"
——此后所有"搜索/查找"类请求必须交付搜索结果，制作需先征求同意。

## 正确工作流（已固化进 SKILL.md）

1. 多引擎并行搜：360 so.com + 搜狗 sogou.com（requests+bs4 直抓均可）
2. 收集真实来源：标题 + 落地链接 + 可读性判断
3. 360 文库详情页 meta description 含文档**开头骨架**（足以判断结构是否符合要求）
4. 搜狗网页版摘要可还原**完整条款骨架**（授权期限、权利和义务等条款名都能看到）
5. 汇报：按相关度排序的真实来源表（链接 + 结构摘录 + 可获取性），明确哪些能读全文、哪些只有骨架
6. 给用户选项：A. 深入某篇（按场景选最贴近的）/ B. 按真实结构制作成品 —— **问，别自己做主**

## 通用结构知识（供制作/核对用）

肖像权授权书标准三段结构：
- 一、授权人（及被授权人）信息表格：姓名/身份证/电话/地址；公司则含法定代表人
- 二、授权内容：授权素材范围（照片/视频/形象/声音）+ 用途勾选（短视频/直播/广告/物料）+ 使用规范（不得歪曲丑化）
- 三、授权期限：起止日期 + 期满后停止使用/下架
常加：四、其他约定（有偿/无偿、禁止转授权、一式两份、争议管辖）+ 双方签署区。
