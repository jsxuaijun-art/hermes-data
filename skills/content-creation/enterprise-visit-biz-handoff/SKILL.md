# 参访考察 → 业务衔接方法论（通用版）

通用方法论，不限行业。财税行业专业版见 skill `enterprise-visit-biz-handoff-tax`（财税映射表 + 合规红线更强）。

## 触发场景

用户说「我去参观了X企业/进厂考察/要去名企参访/标杆游学归来，想写文案/拍视频/发内容，最好能顺带带出我的业务」时加载本 skill。

## 核心立意原则

**向大企业学习是一种幸运**——所有参访类内容的情感底色（黄金三秒开场定调）。
在此基础上，用「参观中看到的细节」当切入口，让业务从前台体验里"自然长出来"，**绝不硬广**。

反模式（掉粉/违规）：
- ❌ 开头就自家推销（"我们公司专业XX 20年"）
- ❌ 借大企业抬自己，夸大自家能力
- ❌ 通篇捧场无观点、无水花

---

## 产出两种版本（并存交付，按需选用）

### 版本A：纯学习视角（价值人设型）
1. **起手**：亮出"有机会向大企业学习是一种幸运"（谦逊真诚，黄金三秒）
2. **公司简介**：简洁介绍参访对象（成立年份/创始人/规模/专利/市场）
3. **参观过程体会**：讲现场真实看到、感受到的细节（画面感）
4. **学到了什么**：落到自己身上，产出价值观/方法论，不主动卖货

适用：养粉/立人设期，或想建立"爱学习、有格局"的个人IP。

### 版本B：业务衔接版（转化型，主推）
立意 = **用参访中看到的细节当切入口**，让业务从参观里长出来。核心用「三细节切入法」。

1. **起手（幸运 + 点出职业）**：先亮谦逊态度，再自然带出"我是做XX的，别人看热闹我看它的底层"——以专业反差立人设
2. **公司简介**：简洁介绍参访对象（为后面埋业务钩子选材）
3. **参观体会 → 拆三个细节**：挑3个"能挂到业务知识点"的观察点，逐层拆解
4. **落到业务 + CTA承接**：把三个细节的启示引到"目标客户也缺的能力"，自然导入自己的服务，配完整转化链路

---

## 核心方法论一：三细节切入法（版本B引擎）

从参访对象身上挑 **3 个"看得见"的细节**，分别翻译成能挂载业务的知识点。每个细节 = 台前台后双解读。

通用映射框架（挂载你的业务所服务的需求）：

| 参观看到的台前现象 | 台后的专业解读方向 | 挂载业务的方式 |
|------------------|------------------|--------------|
| 极致流程/标准化 | 效率/质量/复制的底层 | 你的服务能帮客户达到同样水准 |
| 大手笔投入(研发/设备/人才) | 投入产出、账怎么算、值不值 | 你的服务帮客户算清投入产出 |
| 高毛利/高周转/强现金流 | 商业模式的护城河在哪 | 你的服务帮客户搭这种护城河 |
| 快速扩张/并购/上市 | 扩张背后的筹谋与风险 | 你的服务帮客户在扩张前想清楚 |
| 主动收缩/砍业务线 | 取舍与聚焦的决策智慧 | 你的服务帮客户做理性决策 |
| 全球化/出海布局 | 跨市场、跨文化的打法 | 你的服务帮客户少踩坑 |
| 供应链/生态/伙伴管理 | 上下游整合与协同 | 你的服务帮客户管好这层关系 |
| 人才培养/组织/文化 | 人的复用、价值观的底盘 | 你的服务帮客户建组织能力 |

> 原理：外行看热闹，内行看门道。前 2 个细节讲"我看懂了什么"，第 3 个顺势引到"这种底层能力，你的客户也缺/也得学"，业务就有落点。

## 核心方法论二：业务锚点定位

每个参访对象，先回答：**"我从它身上，最能引到我自己哪一项服务？"**
- 选锚点 = 选参访中"最好拆、最能让目标客户共鸣"的一两个细节
- 一个参访对象配 **1 个主锚点**（太散失焦）
- 锚点用一句话浓缩：如"账本里的大智慧""跑得快要先想得清""极致标准化是护城河"

## 核心方法论三：转化链路设计

业务版必须配完整承接，形成私域闭环：
- **评论区置顶**：让观众报"行业+阶段/痛点"，引导互动（合规）
- **私信收暗号**：观众回关键词 → 触发自动回复 → 转人工跟进
- **CTA三连**：收藏(怕忘)/评论(报行业)/私信(承接转化)——命中平台最高权重行为(收藏/评论/复访)，克制泛赞

## 创作执行流程

1. 先问清：参访对象 + 你的业务领域 + 目标客户是谁
2. （可选）爬虫skill实时搜证参访对象公开资料（成立/创始人/营收/专利/市场/上市）——**用客观数据不编造**
3. 定位 1 个业务锚点
4. 按版本A 或 版本B 出稿；要转化加转化链路
5. 双交付：纯学习版(人设) + 业务衔接版(转化)，让用户按账号阶段选用
6. 交付 .docx 到桌面，按短视频skill的「脚本速览表+标题三件套+标签+完整文案+拍摄速查表」规范

## 内容安全红线（通用）

- 参访对象数据（营收/专利/规模）只用公开可查来源，不确定写"市场口径"或留实地确认
- 实地口径与公开资料不符，以现场为准，回来修订
- 业务衔接不得夸大自身能力到失实（广告法/误导红线）
- 谦逊基调不能丢：是"向强者学习"，不是"点评教大企业做事"（引反噬）
- 行业专用合规红线（如财税、医疗、法律）见对应专业版 skill
