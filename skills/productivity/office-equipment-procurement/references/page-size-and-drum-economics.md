# 幅面（A5）折算 与 成像鼓经济学

> 来源：2026-10 盈信打印机采购会话。针对"几乎全打 A5 凭证纸"的高印量场景，
> 计算碳粉 / 成像鼓的真实单页成本。这套口径通用：既用于自家买机，也用于对外谈外包价。

## 核心区分：粉按面积、鼓按张数（两笔账，不能混）

- **碳粉耗量 ∝ 打印覆盖面积。** A5 = 半张 A4 面积 → 一盒粉在 A5 上可打的
  张数翻倍（例：W1810A 标称 1500 页 A4 ≈ 3000 张 A5）。
- **成像鼓磨损 ∝ 物理过机张数。** 每一张纸过机 = 鼓转一圈，与幅面无关。
  A5 面积小、成像区磨损略缓，实际寿命可能到 1.2~1.5 万物理张，
  但**不能按"半张 A5"摊鼓成本**——过一张就是一张。
- 算单页成本必须先拆两笔：粉按面积折算、鼓按物理张数。**幅面折算只对碳粉成立。**

## 换鼓频次是真金白银（最常被漏算的一项）

- 月印 6,400 张、鼓寿命 ~1.2 万物理张 → **每 1.5~2 个月换一次鼓，年约 6.4 个**。
- 金额：原装鼓 ~¥430/个 → 年 ~¥2,800；兼容鼓 ~¥180/个 → 年 ~¥1,150。
- 鼓粉分离机型选型时，"鼓"跟"粉"一样是经常性耗材，必须进年度预算，别只谈粉盒。

## 实案：HP LaserJet M323dnw / 323sdnw（2026-10 询价）

- 定位：A4 黑白激光多功能一体机（打印 / 复印 / 扫描），**鼓粉分离**。
- 耗材：
  - W1810A 碳粉盒（标称 ~1500 页 A4）；另有 W1810X 大容量（~3000 页 A4）。
  - W1816A 成像鼓（~10000 页 A4）。
- 价格（2026-10 电商实测 + 估价，原装价为京东/官方口径估值）：
  - 兼容粉 ¥40~129（格之格类，实测 ¥39.6 / ¥41.2 / ¥51.65 / ¥68 都有）；原装粉 ~¥210~270。
  - 兼容鼓 ~¥180（淘宝特价秒杀价）；原装鼓 ~¥380~480。
- 年耗材测算（7.7 万张 / 年、90% A5、鼓按 1.2 万物理张、碳粉按面积翻倍）：

  | 搭配 | 单张 A5 成本 | 年耗材 |
  |---|---|---|
  | 全原装（标配粉） | ~¥0.11 | ~¥8,700 |
  | 原装粉 + 兼容鼓 | ~¥0.09 | ~¥7,100 |
  | 兼容粉 + 兼容鼓 | ~¥0.035 | ~¥2,700 |
  | 加粉 + 兼容鼓 | ~¥0.022 | ~¥1,700 |

## 结论 / 边界（说给用户听）

1. **高印量下"原装耗材"是不可承受的**（原装 vs 兼容/加粉差 4~5 倍）。
   预算这个量级的客户，买这台机 = 必须接受兼容 / 加粉路线；若坚持原装，直接把结论改成"买它不划算"。
2. **自购自印全成本 ≈ 耗材 + 纸 + 机器摊 >= 按张付费外包。**
   实测：兼容路线耗材 ~¥2,700 + A5 纸 ~¥1,500~2,700 + 机摊 ≈ ¥4,500~5,500/年，
   ≥ 全程 0.03 元/张外包 ~¥2,310/年（含纸含服务）。**印证 SKILL 原则 6**：
   在当前 0.03 元/张全包价下，按张付费反而更省；买机若不是为复印 / 扫描 / 随打随有的便利，
   纯为省钱不成立。这一句要诚实告诉用户。
3. **"鼓按张数磨损"是谈外包价时的通用口径**：A5 省碳粉、不省鼓——过了 1 张就是 1 张。
   对外谈判（A5 折半、一口价）同用此口径，别承诺"A5 就只算半张的全成本"。
