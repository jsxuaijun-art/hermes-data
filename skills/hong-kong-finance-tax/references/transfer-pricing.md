# 香港关联交易与 Transfer Pricing 分析框架

## 1. 识别
- Related parties
- Controlled transactions
- Goods / services / royalty / interest / guarantee / financing
- Amount and currency
- Contract terms

## 2. 功能风险资产
- Functions performed
- Assets used
- Risks assumed / controlled
- Decision makers

## 3. 分析
- Arm's length support
- Pricing method
- Comparable evidence
- Local documentation obligations（按当前规则核验）
- Counterparty-country TP
- DTA / WHT / PE interaction

## 4. 输出
- Risk level
- Evidence gap
- Documentation needed
- Adjustment exposure
- Review Tier
