# 公司注销 / 企业市场退出 全流程与政策

财税服务（代理记账/公司注册注销）从业者的核心业务线。本 skill 提供注销全流程、税务销户政策、衔接顺序与市场行情的完整框架。政策依据含 2024-2026 最新文件。

## 总体顺序（法定衔接）

```
股东会解散决议 → 成立清算组(15日内) → 清算组备案/公告(10日内)
→ 债权人公告(60日内,公告期45日) → 开展清算(清税)
→ 税务注销取得《清税证明》(工商注销之前!) → 工商注销《注销核准通知书》
→ 社保注销(工商注销后30日内) → 银行销户 → 印章缴销
```

**铁律："先税后工再银"**
- 税务注销必须**早于**工商注销——持《清税证明》才能办工商注销（《税收征收管理法》§16；被吊销执照的自吊销之日起15日内申报税务注销）。
- 银行销基本户须凭**工商注销证明**；先销一般/专用/临时存款户，资金转入基本户后再销基本户；须先完成税务注销。
- 社保注销在**工商注销（企业注销登记）之日起30日内**，须先结清社保欠费。

## 三条注销路径怎么选

| 路径 | 条件 | 动作 |
|---|---|---|
| **免办清税证明** | ①未办理过涉税事宜；②办过涉税事宜但未领用发票(含代开)、无欠税滞纳金罚款；③公告届满前已办结缴销发票结清税款 | 直接向市场监管部门简易注销，不跑税务局 |
| **即办/承诺制容缺** | 未领票无欠税罚款主动清税；或未处税务检查状态+无欠税+已缴销专票税控，且属A/B级信用、M级(母A)、行业领军人才企业、定期定额个体户、未达增值税起征点、汇总缴纳的分支机构 | 税务机关**即时出具清税文书**，资料不齐可先承诺后补 |
| **一般注销** | 有欠税滞纳金罚款、处稽查状态、发票税控未缴销、经营异常/严重违法失信、非正常户（须先解非解除+补申报）、被调查期间 | 出具《税务事项通知书》告知未结事项，办结后办理 |

- 时限：一般纳税人税务注销**10个工作日**，小规模**5个工作日**；涉嫌偷逃骗抗税/虚开/需纳税调整**时限中止**。
- 简易注销公示期（市场监管程序）：按 45 号文压缩为 **20 天**。

## 税务注销时税务机关查什么（预检）

1. 有无未办结涉税事项（未申报/未缴款/未办结）。
2. 账务与清算所得：企业所得税就**清算所得**申报缴纳；未办**土地增值税清算**须先办；出口企业**结清出口退(免)税**。
3. 发票与税控设备：缴销发票和其他税务证件、注销防伪税控信息。
4. 欠税欠费：结清应纳税款、多退免税款、**滞纳金和罚款**。
5. 异常状态：**非正常户**须先解除+补办申报；被特别纳税调查期间原则上不予注销；是否处**税务检查/稽查**状态。
6. 社保及银税划缴：已登记社保费信息的须办注销；**银税三方(委托)划缴协议在税务注销办结后自动终止**（无需单独申请）。

## 最新政策文件（引用依据）

- **税总发〔2018〕149号**：推清税证明免办/承诺制容缺/即时办结。
- **税总发〔2019〕64号**：扩大即办范围（其第一条第3项已废止——见下）。
- **国市监注发〔2021〕45号**：简易注销公示期 45→20 天；拓展适用范围；个体工商户免承诺书免公示。
- **市场监管总局等六部门 2025年第52号公告**《企业注销指引（2025年修订）》：现行总纲。
- **税务总局+最高法 2025年第24号公告**《关于企业破产程序中若干税费征管事项的公告》（2025-11-27）：破产企业**持终结破产程序裁定书即申请税务注销、即时出具清税文书并核销"死欠"**；重整/和解中未获清偿的滞纳金罚款**不影响注销**；**废止**64号文第一条三3项和2019年48号文第四条。

## Pitfalls

1. **2025年24号公告已改规则**：引用 64号文第一条第3项（破产即时核销死欠）会成为过时依据，破产税务注销以 2025年24号公告为准。
2. **税务注销是"卡脖子"环节**：税务不清 → 工商不给注销 → 银行不销基本户。实务上税务注销15-45天、工商公示20-45天、全程正常约2-4个月；异常公司 6个月-1年。
3. **非正常户必须先解非**：直接申报税务注销会被拒，须先补办申报、解除非正常状态。
4. **简易注销≠免税务责任**：全体投资人书面承诺承担真实性法律责任；隐瞒真实情况弄虚作假将被撤销注销+列入严重违法失信名单。
5. **银税三方划缴协议自动终止**，无需单独去银行/税务局申请终止——别为客户白跑一趟。

## 清税前科目体检（12大雷区）—— 客户咨询/获客诊断

老板咨询注销时的核心诊断层。**流程**决定走哪条路径，**科目体检**决定清税能否顺利通过、要补多少税。二者缺一不可。

**核心5雷区**（决定注销能否过审的命门）：

| 科目 | 核心风险 | 税务处理口径 | 红线 |
|---|---|---|---|
| **应收账款过大** | 收不回仍挂账→虚增清算所得 | 坏账核销须凭**25号公告证据**：破产裁定/清算文件、生效判决/仲裁+强制执行终止、账龄超3年+催收记录、不可抗力证明 | 无证据硬核销→税局不认，100万挂账视同利润补税 |
| **存货过大** | 账实不符/长期不卖→注销重点审查，最高可罚5倍 | 三选一：变现(交增值税)/分配股东(视同销售按组成计税价)/报废(非正常损失进项转出) | 管理不善致存货损失→**进项税额必须转出** |
| **未分配利润高** | 清算分配→自然人股东涉20%个税 | 清算所得先缴企税，剩余财产分配对自然人股东补个税 | 不能靠注销规避个税，税局按清算分配核定 |
| **股东/关联借款** | 股东借款不还→视同分红 | 注销前结清或作分配处理 | 12月底前未还的股东借款视同利润分配 |
| **固定资产** | 变卖/分配未缴增值税 | 对外处置交增值税，清算确认所得 | — |
| **应交税费** | 贷方余额=未缴税、借方=留抵 | 贷方须结清税款；借方留抵可申请退税或结转 | 贷方余额未清→**拿不到清税证明** |

**补充雷区**（易被忽略但老板高频问，2026.8.6新增）——客户问"现金多怎么办/应付有余额怎么办"时的口径：

| 科目 | 风险 / 处理口径 |
|---|---|
| **货币资金(现金+银行存款+其他货币资金)** | 余额较大属清算财产，须分配；分配环节股东补个税。**现金异常巨量且无业务支撑→先自查是否私户收款未入账**（账外经营嫌疑）🔴 |
| **应付账款(无法清偿)** | 注销前尽量清偿；**确实无需支付的应付转营业外收入缴25%企税**；长期挂账无法清偿被税局按营业外收入核定补税 🟡 |
| **预收账款/合同负债** | 已履约的确认收入缴税；未履约的退款冲销；长挂不处理→税局疑隐匿收入 🟡 |
| **长期资产(长期待摊/在建/无形资产/商誉/长投)** | 可处置变现或核销；**长期股权投资不清理→注销受阻(有子公司须先注销子公司)** 🟡 |
| **应付职工薪酬** | 欠付工资/社保→清算须优先清偿，注销前结清 🟡 |

**关键动作时机**：应收/存货处理要在**决定注销前半年**布局（该起诉的起诉、该核销的核销、该卖的卖），别等到了清税窗口才手忙脚乱。证据链+账实一致是清税双保险。

存货视同销售计税价依据：《增值税暂行条例实施细则》第四条第七款（剩余财产向股东分配属抵偿投资→视同销售）、第十六条（按最近时期同类平均价→其他纳税人同类价→组成计税价=成本×(1+成本利润率)，消费应税货物另加消费税）。

### 清算所得计算核心公式（财税〔2009〕60号 —— 清税环节的"命门"）

依据《财政部 国家税务总局关于企业清算业务企业所得税处理若干问题的通知》（财税〔2009〕60号），企业清算的所得税处理包括6项：全部资产按可变现价值或交易价格确认转让所得或损失、确认债权清理/债务清偿所得或损失、对预提待摊费用处理、弥补亏损确定清算所得、计算缴纳清算所得税、确定可分配剩余财产。

**① 清算所得 = 全部资产可变现价值/交易价格 − 资产计税基础 − 清算费用 − 相关税费 + 债务清偿损益**

**② 剩余财产 = 全部资产可变现价值/交易价格 − 清算费用 − 职工工资/社保/法定补偿金 − 清算所得税 − 以前年度欠税 − 清偿债务**

**③ 股东分配个税（60号第五条，关键！）**
- 股东分得剩余资产中，**相当于累计未分配利润和累计盈余公积×持股比例的部分 → 确认为股息所得**（对自然人股东按"利息股息红利所得"20%征个税）
- 剩余资产减股息后的余额，**超过或低于股东投资成本的部分 → 确认为投资转让所得或损失**
- 股东分得资产按可变现价值或实际交易价格确定计税基础

> ⚠️ 这就是"注销≠逃税"的根源：未分配利润越高，清算分配时股东要补的股息个税越多（20%）。老板想靠注销"抹掉"账上利润/往来款，在60号面前行不通。实务红线：**清算前处理利润分配/股东借款，比清算后补税划算得多。**

## 清税雷区解析引擎（科目余额表/报表 → 自动诊断）

当客户已提供**科目余额表/资产负债表/利润表**（.xlsx）时，用解析引擎自动识别11类雷区并生成《注销雷区诊断报告》Word 到桌面，而非逐项人工核对。

**脚本：`scripts/qingshui_risk_engine.py`** — openpyxl+xlrd 解析 + 雷区规则匹配 + 清算所得税测算 + docx 输出。用法：
```
python3 scripts/qingshui_risk_engine.py --科目余额表 路径.xlsx --自动诊断
python3 scripts/qingshui_risk_engine.py --资产负债表 a.xlsx --利润表 b.xlsx
python3 scripts/qingshui_risk_engine.py --科目余额表 a.xlsx --资产负债表 b.xlsx --自动诊断
# 多文件自动分流：文件名含"科目余额表"→科目表；否则→财务报表
```

**格式支持（2026.8.6 真实客户适配）**：
- 科目余额表：.xlsx（openpyxl）+ .xls 老格式（xlrd），双层合并表头（科目编码|名称|期初余额|本期发生额|本年累计|期末余额 + 借方/贷方子行）
- 财务报表：.xlsx + .xls（资产负债表左右双栏取期末：左A/C、右E/G；利润表取本年累计）
- ⚠️ 必须排除现金流量表 sheet（行名会误匹配雷区关键词）
- 自动分流：命令行多个文件时按文件名含"科目余额表"自动路由

**数据源策略（关键）**：
- **清算所得税测算**：优先用资产负债表权威期末总额（bs参数），科目余额表兜底。因为科目余额表明细借贷净额（如应付账款-1287万）≠报表总额（2312万），存在暂估/预付冲抵，测算必须用报表口径。
- **雷区诊断**：科目余额表看明细净额（能发现暂估748万、股东借款等异常），报表补充总资产。
- 调用：`calc_qingshui_tax(pool, bs=bs_pl)` 传 bs 权威源。

**能力**：
- 自动定位科目余额表表头，识别科目编码→顶级科目(编码4位)的期末借贷净额
- 兼容资产负债表/利润表（xlsx/xls）
- 12条雷区规则按关键词匹配科目（应收/其他应收/存货/未分配利润/股东借款/固定资产/货币资金/应付/预收/长资/应交税费/应付职工薪酬）
- **清算所得税测算（财税〔2009〕60号）**：自动算出清算所得、清算所得税(25%)、剩余财产、股东股息个税(20%)、转让个税、**注销合计涉税**。公式：①清算所得=可变现价值−计税基础−清算费用−税费+债务清偿损益；②清算所得税=清算所得×25%；③剩余财产=可变现价值−清算费用−工资社保−清算所得税−欠税−清偿债务；④股息=(未分配利润+盈余公积)→20%个税；⑤转让=剩余财产−股息−投资成本→20%个税。
- 自动产出引流文案钩子
- Word报告四板块：诊断结论→清算所得税测算→各雷区处理建议→引流文案钩子

**⚠️ 测算假设**：可变现价值按账面净值×折扣率(默认100%)估算，相关税费/增值税未计；可传参覆盖：`calc_qingshui_tax(pool, discount_rate=0.8, liq_cost=XXX, bs=bs_pl)`。实际以处置价格和税局核定为准——报告已注明。

**docx 字体坑（已踩过）**：python-docx 对 run 设中文字体不能直接 `r._element.rPr.rFonts.set()` —— 新 run 的 `rPr` 是 None 会报 `'NoneType' object has no attribute 'set'`。正确写法用 `r._element.get_or_add_rPr()` + `makeelement(qn('w:rFonts'))` 再 append + `rf.set(qn('w:eastAsia'), 字体)`。见脚本内 `set_ea()` 函数。
**P() 颜色坑**：gen_docx 内 `P(t, s=10.5, c=None, b=False)` 签名——第二参数是字号s、第三是颜色c。传颜色必须用关键字 `c=(0xCC,0x00,0x00), b=True`，别用位置参数把颜色tuple塞进字号位置（会报 `int() ... not 'tuple'`）。

**真实报表格式坑（客户实盘，2026.8.6踩过）**：
1. **老式 .xls 财务报表**（会计软件导出）须用 `xlrd` 读（openpyxl 读不了 xls）。报表目录常用 `D:\360MoveData\...\Desktop\` —— WSL 里转 `/mnt/d/360MoveData/...`。
2. **资产负债表是左右双栏**：左栏 [A名称|B行次|C期末|D年初]、右栏 [E负债名|F行次|G期末|H年初]。**必须读 C 列和 G 列（期末）**，`取最后非零数字列` 会取到 H（年初数）——报表导入公司真实文件后这个坑必炸。
3. **科目余额表常为双层合并表头**：R4 合并且是 `科目编码|科目名称|期初余额|本期发生额|本年累计|期末余额`，R5 才是 `借方|贷方×5` 子行。借贷列必须从**子行 R5** 识别（表头行无"借方/贷方"字样），科目名称/编码从 R4。data_start = R6。
4. **`_find_header_row` 会误中 R1 标题行**（"科目余额表"四个字含"科目"+"余额"）。必须优先找含"科目名称/科目编码"且其后行出现"借方/贷方"子行的行。
5. **现金流量表行名会误匹配雷区关键词**：如"销售产成品收到的现金"命中"存货"、"支付其他与经营活动有关的现金"命中"货币资金"。解析 xls 时必须**跳过现金流量表 sheet**（只处理"资产负债表"和"利润表"）。
6. **"库存"关键词坑**：存货雷区若含关键词"库存"，会把"库存现金"匹配进来导致存货误报。存货关键词应为 `存货/库存商品/原材料/在产品/生产成本/产成品`（去掉裸"库存"）。

**引擎数据源优先级**：诊断 pool 合并顺序必须是 **`subjects`（科目余额表）覆盖 `bs_pl`（报表）**——单元级科目余额表比报表行的汇总数更细准（如应付账款明细差、应交税费借贷）。若反过来 bs_pl 覆盖 subjects，会出现"资产负债表'应付账款'2312万 被覆盖成 科目余额表明细差-1287万"之类的串值。xls 双栏解析是本 skill 里**最经客户实盘验证**的路径（对应苏州ZP节能案例）；xlsx 双栏报表的 `max(non_zero)` 取值是**未经实盘验证的启发式**，若遇 xlsx 报表先人工核对再信诊断。
