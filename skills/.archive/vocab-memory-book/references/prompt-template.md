# 🎯 目标
生成一份「高考英语词汇默写本」Word文档，基于艾宾浩斯遗忘曲线 + 词根词缀记忆法，从源词汇表（约3875词）自动分组，输出为格式精美的 .docx 文档。

---

# 📦 输入数据
## 词汇源文件
当前源文件为 Word 文档（.docx），内含表格，每行三列：单词、音标、释义。
直接从 python-docx 读取表格，跳过首行表头。

## 词频数据
英文词频库 en_50k.txt（14K+词条），格式：`word frequency_count`
用于计算「写作指数」（1~5星）。

# 🏗 设计思想（必读）

## 核心设计理念：按天编排（v4 关键创新）
**文档按日历天排列，不是按组打包。** 这是与旧版 v1~v3 最本质的区别。

### 为什么必须按天编排？
按组打包时，学生必须自己在一堆页码里翻来翻去找今天该做哪几页——体验极差。**按天编排**后，学生翻到 DAY N，从上到下做完即可，不需要算进度。

### 学习计划索引
文档开头前置一张 107 天一览表（学习计划索引），列出每天的新学组和复习组。

### 日程算法
```python
N = 78 组（28 词根 + 50 基础）
复习偏移量: [1, 3, 6, 14, 29] → 英→中, 中→英, 音标, 高频词, 终测

对每天 day (1 到 107):
  新组: 如果 day ≤ N，则学新组
  复习: 遍历所有组，检查 day 是否等于 学习日 + offset
```
**⚠️ 最容易犯的错误**：直接按组循环输出，忽略每日交叉。必须用 schedule 数组先构建每一天的任务列表，再按天输出。

## 核心记忆理论：艾宾浩斯六轮复习
| 轮次 | 天数 | 形式 |
|:--:|:--:|:--|
| ① 学习 | 学习日 | 单栏卡片（含词根拆解） |
| ② 复习 | +1天 | 六栏表格：英文→写中文 |
| ③ 复习 | +3天 | 六栏表格：中文→写英文 |
| ④ 复习 | +6天 | 六栏表格：音标→写单词+释义 |
| ⑤ 复习 | +14天 | 六栏表格：仅高频词 |
| ⑥ 终测 | +29天 | 六栏表格：奇偶交替 |

## 分组策略
- **词根词汇（Part 1）**：通过词根库检测，匹配到的归入Part 1
- **基础词汇（Part 2）**：未匹配的归入「基础词汇」
- **每组50词**，组内乱序

### 词根检测方法
使用Membean词根库（约260个词根），按长度降序排列，对每个单词进行子串匹配。
长度≤2的词根在短词（≤4字母）中跳过，避免误匹配。

## 文档结构（v4 按天编排）
```
封面 → 使用说明 → 学习计划索引（107天）→ 正文（DAY 1→2→…→107）
```

# 📐 排版规格

## 六栏复习表列宽
| 列 | 宽度 |
|:--:|:--:|
| #（序号） | **0.2cm**（绝对最小值） |
| 第2列（提示） | 3.56cm |
| 第3列（填空**留白**） | **5.24cm** |
| #（序号） | 0.2cm |
| 第5列（提示） | 3.56cm |
| 第6列（填空**留白**） | 5.24cm |

**填空格不留任何占位虚线**，单元格完全留白。

## 行高
- 表头行：400 dxa
- 数据行：**600 dxa**（25行填满一页）

## 学习卡
每词一卡片，2×2表格，**卡片之间无空行**。
- 中文释义必须用深色（`#2C3E50`），不得用 `#BBBBBB`
- 释义后不留填空虚线

## 音标填空列（仅第④轮）
```
英[＿＿＿＿]  ← 一行
中[＿＿＿＿]  ← 换行
```
**其他复习列的空格绝对不可出现任何字符/虚线。**

# 🔧 技术要点
- 使用 python-docx
- 日程交叉算法：双循环（每天→每组）检查到期复习
- Part 1→Part 2 分割点在 Day 28/29 之间
- 学习卡紧凑排列：`card_learn()` 末尾不可有 `doc.add_paragraph()`
- 所有填空格不写任何 run 内容，只留空白单元格
