# 案例：合伙企业股票减持 · 少计投资收益

## 一、基本信息

| 字段 | 内容 |
|---|---|
| 案号/编号 | CASE-2026-001 |
| 结案日期 | 2026-09 |
| 行业 | 半导体设备及电子产品的销售与技术服务 |
| 纳税人类型 | 法人企业（有限责任公司），某有限合伙企业17%出资合伙人 |
| 涉案税种 | 企业所得税 |
| 涉案期间 | 2023年度 |
| 金额区间 | 中等（数十万元级；本案例补税 510,000 元） |
| 案源类型 | 推送（《税务事项通知书（风险提示专用）》——合伙企业股票减持风险） |
| 我方介入时点 | 选案阶段（风险提示后、检查前，自查自纠） |

## 二、案情摘要

A公司（有限责任公司）2021年6月向B有限合伙企业（以下简称"B企业"）投资 5,100,000 元，占出资比例17%。2023年3月收回投资本金 5,100,000 元；2023年5月收到B企业转付款项 2,040,000 元。税务机关通过"合伙企业股票减持"风险画像锁定该笔款项，风险提示要求 A公司 自查。

## 三、税务机关的认定

- **初始认定**：A公司作为法人合伙人，自B企业（有限合伙）取得的 2,040,000 元属于其分得的所得（股票减持收益穿透），应并入2023年度应纳税所得额，但未并入申报，存在少计投资收益、少缴企业所得税风险。涉补税 510,000 元（25%）。
- **认定依据**：合伙企业"先分后税"；法人合伙人缴企业所得税并不可享受居民企业间股息红利免税。

## 四、争议焦点

1. **款项性质**：2023年5月收到的 2,040,000 元，究是"收回投资本金"还是"分利（投资收益）"？——这是全案命门。
2. **是否适用股息红利免税**：该笔所得能否按《企业所得税法》第26条主张免税。
3. **是否构成不缴税的抗辩**：企业能否以"对方未办股权（合伙份额）变更登记、公示系统仍显示为投资人"为由主张不计所得。

## 五、我方主张与论证路径

| 争点 | 我方主张 | 论证要点 | 引用的依据 |
|---|---|---|---|
| 款项性质 | 2,040,000 元属分利（投资收益），非收回本金（本金已全额收回） | 结合银行流水时间线：本金已返还完毕后仍收到该款，性质为所得分配 | 财税〔2008〕159号 第2、3条 |
| 是否适用免税 | 不适用居民企业间股息红利免税 | B企业系合伙企业，非居民企业；款项非"直接投资于其他居民企业"取得的投资收益 | 《企业所得税法》第26条＋实施条例第83条 |
| 股权变更登记抗辩 | 不成立；先分后税以所得实质归属为准，不以份额变更登记为前提 | 产权/登记未变更不影响所得已实现的税务处理 | 财税〔2008〕159号 先分后税原则 |
| 处理路径 | 主动自查、确认补缴，争取不予/减轻处罚 | 选案阶段主动纠错＝无主观故意最强证据；行政处罚法第33条 | 《行政处罚法》第33条 |

## 六、提交的文书与证据

- 文书：税收风险自查报告 ×1
- 关键证据：银行转账回单（本金返还与转付款项分列）、合伙协议（出资比例）、信息公示系统截图（投资人登记现状）

> 本案例真正管用的，是把银行流水的时间线摆出来——证明"本金已收回、该笔 2,040,000 元是额外的所得"，一锤定音。

## 七、沟通过程

环节在自查报告阶段，尚未进入正式检查对话。税务机关以风险提示形式要求自查，我方选择"确认风险、主动补缴"路径，将税款 510,000 元及滞纳金纳入申报，意在把案件消灭在立案/检查之前。

## 八、结果

| 项目 | 初始认定 | 最终结果（本案为自查确认补缴） |
|---|---|---|
| 定性 | 少计投资收益 | 自查确认少计投资收益 |
| 补税金额 | 510,000 元 | 510,000 元（2023年度企业所得税） |
| 滞纳金 | 万分之五/日 | 按实际滞纳天数申报 |
| 罚款 | —（选案阶段，自查路径回避偷税定性） | 争取不予/减轻处罚 |
| 合计 | — | 510,000 元＋滞纳金 |

## 九、可复用要点

1. **先锁命门再动笔**：面对"合伙企业股票减持/分红"风险，第一件事是查清款项是"收回本金"还是"分利"——用银行流水时间线+合伙协议出资比例来定，不要被客户"对方没办变更"带偏。
2. **法人合伙人分利必缴税**：合伙企业"先分后税"，法人合伙人就其分得所得并入应纳税所得额缴纳企业所得税，且**不适用**居民企业间股息红利免税（合伙企业非居民企业）。
3. **主动自查的价值**：选案阶段主动确认补缴并附完税凭证，是"无主观故意"的最强证据，可把补税案摁在立案前，或把"偷税"定性打掉。
4. **自查报告结论必须自洽**：要么确认、要么排除，绝不能一份报告里既"暂排除"又"确认补缴"——自相矛盾必然被打回。

## 十、踩过的坑

1. **原稿自相矛盾**：初稿在同一份报告中既写"我司暂排除该涉税风险"，又在结论处"确认补缴510,000元"。两处冲突，交付前必须统一。
2. **错误排除理由**：曾试图以"对方不配合股权变更登记、公示系统仍显示为投资人"主张排除——这不是税法依据，税务处理以所得实质归属（先分后税）为准，不取决于登记是否变更。
