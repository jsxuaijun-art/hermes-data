# 税收法律群（主路由 Skill）

## 任务目标

把"某个税种/税务场景"的提问路由到正确的税收子 skill，再由子 skill 给出结构化索引与精确条文。
所有条号最终以各子 skill `references/全文.md` 为准。

## 路由决策树（按触发词）

- "增值税 / 进项 / 销项 / 视同销售 / 小规模" → `tax-vat`
- "企业所得税 / 汇算 / 小微 / 高新 / 税前扣除 / 源泉扣缴" → `tax-enterprise-income`
- "个税 / 综合所得 / 专项附加扣除 / 经营所得 / 汇算清缴" → `tax-individual-income`
- "税务登记 / 申报 / 稽查 / 偷税 / 保全 / 复议诉讼 / 滞纳金" → `tax-admin`
- "合同贴花 / 产权转移书据 / 营业账簿 / 证券交易印花税" → `tax-stamp`
- "买房过户 / 土地房屋权属" → `tax-deed`
- "关税 / 进出口" → `tax-tariff`
- "土增 / 转让房地产" → `tax-land-appreciation`
- "消费税 / 烟酒化妆品小汽车" → `tax-consumption`
- 其余小税种按上表"税种"列直接命中对应子 skill。
- **跨法场景**：公司注销涉补税 → 同时引 `company-law`（清算/注销）+ `tax-admin`（补税/滞纳金）；
  股权转让 → 引 `tax-stamp`（产权转移书据）+ `tax-individual-income`/`tax-enterprise-income`（所得）。

## 注意事项

- 各子 skill 含 `references/全文.md`（维基文库转录的官方法条全文），引用条号以全文为准。
- 具体优惠比例、起征点、留抵退税条件等政策性口径，随国务院/税务总局文件动态调整，本群 skill 不替代现行有效规范性文件，须结合最新文件。
- 暂行条例（土地增值税、消费税）仍有效；增值税法 2026-01-01 起取代增值税暂行条例，引用时注意时间效力。
- 公司法相关问题不在本群，路由至 `company-law`。

## 全文与子 skill

每个子 skill 目录结构：`SKILL.md` + `references/全文.md`。调用时优先加载对应子 skill。
