# 涉法文案依据核查与引用库

## When to Use

- 短视频/公众号/客户答复里写了罪名、红线、税款数字、滞纳金、优惠额度等涉法涉税表述时，要**给依据、把关精度**
- 用户说"调用法律类skill" / "这条文案依据是什么" / "虚开最高判多少年" / "写红线文案"
- 不确定"最高无期""视同销售""债务重组利得"这类说法要不要限定条件

## 定位与分工

`content-evidence-discipline`（公司纪律，用户所有）管"先核实再引用、交付带依据清单"的总原则；本 skill 是在此之上的一站式**已核验引用库 + 精度自检**，避免每次都重搜。刑法条文原文去其它 skill——`criminal-law` / `corporate-crime` 各子 skill 的 `references/本章全文.md`（本地快，该文件不在本 skill 目录下）；税法文号去国家税务总局法规库 `fgk.chinatax.gov.cn` 核（权威）。

### 高频税法引用（均已对 fgk 原文核验）
- **企业所得税法实施条例第22条**：其他收入含"确实无法偿付的应付款项""债务重组收入"→长期挂账、实际不用还的应付款项并入收入总额交所得税。
- **税收征管法第32条**：滞纳金按日万分之五（年化≈18.25%，文案可写"一年18%以上"）。
- **国税函〔2009〕312号**：认缴注册资本未缴足，未缴足差额对应借款利息不得税前扣除。
- **财税〔2016〕36号**：建筑服务一般9%/简易3%；有形动产租赁13%；增值税纳税义务时间按书面合同约定收款日。
- **小微企业**：年应纳税所得额300万以内实际税负5%（减按25%×20%）；超300万按25%。**限时优惠，标"以现行政策为准"**。
- **小规模**：月10万/季30万以内免增值税。**限时政策，标"以现行政策为准"**。

## 精度自检（写之前过一遍）

1. "最高无期"必须限定增值税专用发票虚开；普通发票及其他罪名别套无期。
2. 每个罪名找得到对应犯罪构成（非法占有的目的 / 不特定对象 / 国家工作人员身份），找不到就删。
3. 限时优惠（小微、免征额）一律带"以现行政策为准"，不写成长期事实。
4. 拿不准的文号/数字先 `web_search`「文号 + 核心内容」→ fgk 正文页逐字核对 → 多源交叉后再写。

## 核验路径

1. 刑法：本地 `criminal-law` / `corporate-crime` 子 skill `references/本章全文.md` 逐字对条号+刑期；量刑以司法解释为准。
2. 税法：fgk.chinatax.gov.cn 正文页；官库 + 一两个权威第三方交叉。
3. 交付：关键结论附"出处+文号+核验日期"依据清单。

## Pitfalls

- `content-evidence-discipline`、`criminal-law`、`corporate-crime` 等法律类 skill 目前是**用户所有/未 adopt**，本 agent 不能直接改；发现它们缺内容时建议用户 `hermes curator adopt <名>`。
- 罪名刑期随司法解释变动，本清单是营销文案常用口径，不等于量刑工具。
