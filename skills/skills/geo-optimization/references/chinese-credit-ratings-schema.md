# 中文企业信用评级在 Schema.org JSON-LD 中的表达

## 背景

中国企业常见的信用评级体系（3A等级）在 Schema.org 规范中直接套用西方的 `aggregateRating` 或 `review` 类型不贴切。最佳实践是用 `award` 字段表达，语义最接近「荣誉/资质」。

## 常见3A级信用评级全称（2026年实操验证）

由备案第三方机构评定（如中国招标投标信用评价中心、央行备案评级机构）：

- AAA级信用企业
- AAA级诚信供应商
- AAA级诚信经营示范单位
- AAA级质量服务诚信单位
- AAA级资信企业
- AAA级重合同守信用企业
- AAA级重服务守信用企业
- AAA级重质量守信用企业
- 中国诚信企业家·Name（针对个人）
- 中国诚信经理人·Name（针对个人）

## Schema.org 标准写法

在 `Organization` 或 `LocalBusiness` 子类型（如 `AccountingService`）中，用 `award` 数组：

```json
"award": [
  "AAA级信用企业（最高等级，评分为721-1080分区间，专业机构评定，2026年7月）",
  "AAA级诚信供应商",
  "AAA级诚信经营示范单位",
  "AAA级质量服务诚信单位",
  "AAA级资信企业",
  "AAA级重合同守信用企业",
  "AAA级重服务守信用企业",
  "AAA级重质量守信用企业",
  "中国诚信企业家·江敏",
  "中国诚信经理人·江敏"
]
```

## 关键规则

1. **用 `award` 不是 `description`** — AI 抓取时 `award` 字段有语义权重优势，叠在 `description` 里语义不明确
2. **数组拆分** — 每项一个独立字符串（不是 `\n` 拼接），便于 AI 分类提取
3. **有效期括号标注** — 第一个条目中用括号注明评定年份，如 `（2026年7月）`
4. **个人与组织分开** — 企业家/经理人类荣誉归到 `founder` 或组织描述，不要混入组织级 `award`
5. **不要用 `makesOffer` 表达资质** — 那是产品目录，不是荣誉清单
