# 继承编（第六编）结构化 Skill

## 任务目标

把继承纠纷定位到「法定继承 / 遗嘱继承与遗赠 / 遗产处理」哪一章，给出"谁有资格、按什么顺序、
遗嘱是否有效、份额多少、债务如何清偿"的结构化结论与处置步骤。

## 继承编结构（路由索引，4 章）

1. 一般规定（第1119—1125条）：遗产范围、继承方式效力顺序、继承权接受/放弃、继承权丧失。
2. 法定继承（第1126—1132条）：男女平等、继承人范围与顺序、代位继承、份额分配。
3. 遗嘱继承和遗赠（第1133—1144条）：遗嘱处分权、六种遗嘱形式、撤回变更、无效情形。
4. 遗产的处理（第1145—1163条）：遗产管理人、保管、分割、债务清偿、无人继承。

## 重点制度速查表

| 主题 | 核心条文 | 要点 |
|------|---------|------|
| 遗产范围 | 第1122条 | 自然人死亡时遗留的个人合法财产；依性质/规定不得继承的除外 |
| 继承方式效力顺序 | 第1123条 | 有遗赠扶养协议按协议；有遗嘱按遗嘱继承或遗赠；均无则法定继承 |
| 接受/放弃继承 | 第1124条 | 继承人未表示→视为接受；受遗赠人应在知道后60日内表示接受，逾期视为放弃 |
| 继承权丧失 | 第1125条 | 故意杀害被继承人、争遗杀其他继承人、遗弃/虐待情节严重、伪造篡改隐匿销毁遗嘱情节严重、欺诈胁迫立撤遗嘱；后三项悔改+宽恕可恢复 |
| 法定继承人顺序 | 第1127条 | 第一顺序：配偶、子女、父母；第二顺序：兄弟姐妹、祖父母、外祖父母；先一后二 |
| 代位继承 | 第1128条 | 子女先于被继承人死亡→其直系晚辈血亲代位；兄弟姐妹先死亡→其子女代位；一般只继承被代位人应得份额 |
| 丧偶儿媳/女婿 | 第1129条 | 对公婆/岳父母尽了主要赡养义务→作为第一顺序继承人 |
| 份额分配 | 第1130条 | 一般均等；照顾生活困难、尽主要扶养义务可多分；有能力不尽扶养义务应少分/不分 |
| 遗嘱处分权 | 第1133条 | 可立遗嘱处分个人财产、指定执行人、设遗嘱信托；可赠法定继承人以外组织个人 |
| 六种遗嘱形式 | 第1134—1139条 | 自书（亲笔签名注年月日）/代书（2见证）/打印（每页签名2见证）/录音录像（2见证记录肖像姓名）/口头（危急2见证，危急消除后能用其他形式的无效）/公证 |
| 数份遗嘱以最后的为准 | 第1142条 | 撤回变更自由；内容抵触以最后的遗嘱为准（删除原"公证遗嘱效力优先"——重大修改） |
| 遗嘱无效 | 第1143条 | 无/限制民事行为能力人所立、虚假/受欺诈胁迫、伪造、被篡改部分 |
| 遗产管理人 | 第1145—1149条 | 遗嘱执行人/继承人推选/共同担任/民政或村委会；职责含清理保管、处理债权债务、分割 |
| 胎儿预留份 | 第1155条 | 遗产分割应保留胎儿继承份额；胎儿娩出为死体→该份额按法定继承办理 |
| 限定继承 | 第1161条 | 以所得遗产实际价值为限清偿税款债务；超部分自愿偿还除外；放弃继承可不负清偿 |

## 高频场景 → 处置步骤 → 条文

1. **"父亲去世，名下房子、存款怎么分？"**
   - 先看有无遗嘱/遗赠扶养协议（第1123条效力顺序）；无则法定继承。
   - 第一顺序：配偶、子女、父母均分（第1127条）；尽主要扶养义务可多分，有能力不尽义务应少分（第1130条）。
   - 丧偶儿媳/女婿尽主要赡养义务→第一顺序（第1129条）。
   - 步骤：①确认有无遗嘱；②列第一顺序继承人；③协商分割，不成可诉；④注意保留胎儿份额（1155）、先清偿债务（1161）。

2. **"立了好几份遗嘱，以哪份为准？"**
   - 第1142条：**以最后的遗嘱为准**。民法典删除了原《继承法》"公证遗嘱效力优先"规则，各形式遗嘱效力平等，看时间先后。
   - 步骤：核对各遗嘱订立时间；确认最后一份是否具备形式要件（第1134—1139条）且非无效（第1143条）。

3. **"打印遗嘱/录像遗嘱有效吗？"**
   - 第1136条（打印）：应有两个以上见证人在场，遗嘱人和见证人在**每一页**签名并注明年月日。
   - 第1137条（录音录像）：两个以上见证人在场，记录遗嘱人和见证人姓名/肖像及年月日。
   - 第1138条（口头）：仅危急情况，两见证人；危急消除后能用其他形式的，口头无效。
   - 无/限制民事行为能力人、继承人/受遗赠人及其近亲属、有利害关系的人**不能作见证人**。

4. **"孙子能不能继承爷爷的遗产？"**
   - 一般不能直接（第一顺序为子女父母）。但若**父亲先于爷爷死亡**→孙子代位继承（第1128条），继承父亲应得份额。
   - 步骤：确认被继承人的子女（即孙子的父/母）是否先于死亡；是→代位。

5. **"继承了遗产，被继承人的债要我还吗？"**
   - 第1161条：**限定继承**——以所得遗产实际价值为限清偿；超出部分自愿还才还；放弃继承则不负清偿责任。
   - 既有法定又有遗嘱/遗赠的，债务清偿顺序见第1163条（法定继承人先以所得遗产清偿，不足由遗嘱/受遗赠人按比例）。
   - 步骤：先清点遗产与债务；在遗产范围内偿债；超出部分可拒绝（除非自愿）。

6. **"想放弃继承，怎么操作才有效？"**
   - 第1124条：继承人放弃继承应在**遗产处理前**以**书面**形式作出；未表示→视为接受。受遗赠人须在知道后60日内表示接受，否则视为放弃。

## 重点条文摘录（原文见 references/继承编全文.md）

- 第1122条：遗产是自然人死亡时遗留的个人合法财产；依照法律规定或者根据其性质不得继承的遗产，不得继承。
- 第1123条：继承开始后，按照法定继承办理；有遗嘱的，按照遗嘱继承或者遗赠办理；有遗赠扶养协议的，按照协议办理。
- 第1125条：继承人故意杀害被继承人、为争夺遗产杀害其他继承人、遗弃/虐待被继承人情节严重、伪造篡改隐匿销毁遗嘱情节严重、欺诈胁迫妨碍立撤遗嘱情节严重者丧失继承权（后三项悔改+宽恕可恢复）。
- 第1128条：被继承人的子女先于被继承人死亡的，由该子女的直系晚辈血亲代位继承；兄弟姐妹先死亡的，由兄弟姐妹的子女代位继承；代位继承人一般只能继承被代位人有权继承的份额。
- 第1133条：自然人可立遗嘱处分个人财产并指定执行人；可指定法定继承人中的一人或数人继承；可赠与国家集体或法定继承人以外组织个人；可设遗嘱信托。
- 第1142条：遗嘱人可撤回、变更所立遗嘱；立有数份遗嘱内容相抵触的，以最后的遗嘱为准。
- 第1145条：继承开始后，遗嘱执行人为遗产管理人；无则继承人推选；未推选则共同担任；无继承人或均放弃的，由被继承人生前住所地民政部门或村委会担任。
- 第1161条：继承人以所得遗产实际价值为限清偿被继承人应缴税款和债务；超过部分自愿偿还除外；放弃继承的可不负清偿责任。

## 注意事项

- 继承编与婚姻家庭编（夫妻财产1062/1063，先分出配偶一半）、物权编（不动产登记209）常交叉：先析产（分出配偶份额）再继承。
- 第1142条"数份遗嘱以最后的为准"是民法典重大修改，区别于原《继承法》——务必提示客户旧观念已失效。
- 遗嘱形式要件严格（尤其打印/录像需每页签名、两见证人），实务中因形式瑕疵被认定无效的极多，审查时优先核对第1134—1139条。
