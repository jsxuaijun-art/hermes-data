# 上帝视角 · 商务/实业考察短视频（行业自然流 × 高瞻远瞩）

> 适用：用户实地/线上考察某家上市公司、工厂、制造企业、产业园（如"明天去欧普照明/追觅"），
> 想产出泛财经圈层+老板决策共鸣+财税垂类的短视频文案。
> 触发词封装：用户说"调用短视频skill"→ 先任何search搜实时信息 → 上帝视角切角度 → 出脚本。

## 数据-角度映射法（把硬数据变成"头头是道的不同观点"）

一个企业/事件能切出多个上帝视角，核心是把**财务/经营硬数据**翻译成**反直觉的商业判断**。

| 数据信号 | 反直觉观点（上帝视角） |
|---|---|
| 营收大（70亿）但净利薄（9亿） | "做到行业老大，利润率还不如一家奶茶店" → 制造业赢在现金流与确定性，不拼规模 |
| 营收降(-1.78%)净利反涨(+1.94%) | 闭眼挣钱时代过去，靠砍费控本硬抠利润 → 降本增效是所有老板的必修课 |
| 研发占比高(4-10%) | 把它翻译成"在赌未来赛道"（如灯→按算法收费的光）→ 真正的高手顺着研发箭头看三年后 |
| 把大比例利润分红掉(68%) | 成熟企业不扩张先落袋 → 账户上"被压着的钱"才是关键 |
| 多业扩张后宣布"战略回归主业" | 扩张刹车不是认怂，是"先把账算清楚再跨赛道"（壮士断腕信号） |
| 区域产业集群（吴中700家/千亿、吴江一个镇出隐形冠军） | 制造业利润薄是假象，供应链密度+研发投入才是真正的牌 → 落到老板该关心什么 |

## 三条黄金切割法（同类素材可复用的骨架）
1. **账本视角**：营收/净利/分红数字逐个拆 → "钱去哪了/被压着多少" → CTA问老板自己账面。
2. **信号视角**：研发投入+业务扩张/刹车 → "它在赌未来什么" → 老板决策（算清账再动）。
3. **产业视角**：两家看似无关的企业 → 同一底牌（产业集群/供应链）→ 老板被什么卡过脖子。

## 黄金三秒铁律（沿用）
- 热点/炸点数据必须放第一句，个人经历/实地见闻放第二段。（见 skill 主文"热点开头铁律"）

## 采集与交付
- 数据来源：优先 anysearch 实时搜（新浪财经/经济观察网/官网/维基/政府网），跨来源交叉验证；硬数字（营收/净利/日期）必须核实，不沿用旧记忆。
- **口径提醒**：市场吹风口径（如"营收400亿"）与官方年报数字要区分标注，避免翻车。
- 交付：脚本速览 + 每条(标题三件套/标签/完整文案/拍摄分镜表)，docx 拷桌面 + txt 备份。
- 结尾 CTA 引导收藏/评论/复访（平台最高权重），克制泛赞。
