# 50词 · 12词根组（2026-07-03 实验版验证通过）

> 词根分组来源：高考英语词汇表3817词.txt 实际扫描 + 人工验证。
> 每组词根 = 共享同一拉丁/希腊词根的词汇，前缀和后缀仅作辅助拆解。

---

## 1. tract（拉/抽）

| 单词 | 拆解 | 含义 |
|------|------|------|
| abstract | abs-(离开) + **tract(拉)** → 从具体中抽离 | 抽象的 |
| attract | at-(朝向) + **tract(拉)** → 把注意力拉过来 | 吸引 |
| attractive | at-(朝向) + **tract(拉)** + -ive(…的) | 迷人的 |
| subtraction | sub-(向下) + **tract(拉)** + -ion(名) → 往下抽 | 减法 |

## 2. press（压）

| 单词 | 拆解 | 含义 |
|------|------|------|
| express | ex-(向外) + **press(压)** → 把想法压出来 | 表达 |
| expression | ex-(向外) + **press(压)** + -ion(名) | 表达；表情 |
| impress | im-(向内) + **press(压)** → 压进脑子里 | 留下印象 |
| impression | im-(向内) + **press(压)** + -ion(名) | 印象 |

## 3. port（运/带）

| 单词 | 拆解 | 含义 |
|------|------|------|
| import | im-(向内) + **port(运)** → 从外面运进来 | 进口 |
| portable | **port(携带)** + -able(能…的) | 便携式的 |
| report | re-(回) + **port(带)** → 把信息带回来 | 报告 |
| support | sup-(向上) + **port(运)** → 从下面托着 | 支持 |
| transport | trans-(跨越) + **port(运)** → 从一处运到另一处 | 运输 |

## 4. fer（带/拿）

| 单词 | 拆解 | 含义 |
|------|------|------|
| differ | dif-(分开) + **fer(拿)** → 各自拿着不同的东西 | 不同 |
| different | dif-(分开) + **fer(拿)** + -ent(…的) | 不同的 |
| offer | of-(朝向) + **fer(拿)** → 拿到对方面前 | 提供 |
| prefer | pre-(前/先) + **fer(拿)** → 优先拿 | 更喜欢 |
| refer | re-(回) + **fer(拿)** → 拿回去参考 | 提到/参考 |

## 5. cess/cede（走/去）

| 单词 | 拆解 | 含义 |
|------|------|------|
| access | ac-(靠近) + **cess(走)** → 走过去靠近 | 通道/进入 |
| necessary | ne-(不) + **cess(走)** + -ary(…的) → 不能走开的 | 必需的 |
| process | pro-(向前) + **cess(走)** → 向前走 | 过程/处理 |
| success | suc-(紧接) + **cess(走)** → 紧跟着走下去 | 成功 |

| aspect | a-(朝向) + **spect(看)** → 看过去的方面 | 方面/外观 |
| inspect | in-(向内) + **spect(看)** → 往里面看 | 检查/审视 |
| respect | re-(反复) + **spect(看)** → 反复看→因重视而尊敬 | 尊敬 |
| suspect | sus-(在下) + **spect(看)** → 从下面偷偷看 | 怀疑/嫌疑人 |

## 8. rupt（断/破）

| 单词 | 拆解 | 含义 |
|------|------|------|
| abrupt | ab-(离开) + **rupt(断)** → 突然断开 | 突然的 |

| erupt | e-(向外) + **rupt(断)** → 从内部崩出来 | 喷发/爆发 |
| interrupt | inter-(中间) + **rupt(断)** → 从中间打断 | 打扰/中断 |

## 9. mit/miss（送/发）

| 单词 | 拆解 | 含义 |
|------|------|------|
| admit | ad-(朝向) + **mit(送)** → 送进来 | 准许进入/承认 |
| commit | com-(共同) + **mit(送)** → 把想法投入行动 | 犯(罪)/承诺 |
| permit | per-(通过) + **mit(送)** → 送过去让其通过 | 允许 |
| submit | sub-(在下) + **mit(送)** → 从下往上送 | 提交/呈递 |
| dismiss | dis-(离开) + **miss(送)** → 把人送走 | 解散/解雇 |

| 单词 | 拆解 | 含义 |
