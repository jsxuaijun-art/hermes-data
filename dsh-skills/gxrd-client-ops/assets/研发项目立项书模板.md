# 研发项目立项书模板

> 用途：客户立项时必填。**技术指标栏（§四）是证明「创新目标+结果不确定性」的关键**，务必量化并与同类产品对比（参照 cases.md A4 机电伺服正例）。
> 自主研发无须事前科技部门鉴定/备案，企业内部有权部门决议即可——但立项书是留存备查第一要件。

## 一、项目基本信息
- 项目名称：__________
- 项目编号（RD-__）：__________
- 起止时间：____年__月 至 ____年__月
- 项目负责人：__________
- 项目组人数：____（其中研发人员__人）
- 项目预算总额：__________ 元（其中研发投入预算____元）

## 二、立项背景与必要性
（围绕「客户未被满足的需求 / 现有技术瓶颈」，说明为什么必须做这次研发，不得写成日常经营）

## 三、拟研究开发内容与创新点
（说明技术路线、拟采用的新工艺/新材料/新方法；**创新点要与现有市面方案区分**）

## 四、关键技术指标（必填、必量化）
| 指标项 | 本项目目标值 | 国内外同类产品/技术对比值 | 测试/验证方法 |
|--------|-------------|--------------------------|--------------|
| 例：响应时间 | ≤10ms | 行业 20ms | 台架测试 |
| | | | |

> ⚠️ 指标必须可测、可验证。A2 反例表明「未设定定量技术指标」是专家判定非研发的重要依据。

## 五、研究开发活动阶段与进度
| 阶段 | 起止 | 主要任务 | 交付物/里程碑 |
|------|------|---------|--------------|
| 研究阶段 | | | 可行性/技术验证报告 |
| 开发阶段 | | | 样机/试制/试验 |
| 结题 | | | 结题报告、验收决议 |

## 六、财务预算与费用归集口径
（按六大类列：人员人工 / 直接投入 / 折旧 / 无形资产摊销 / 新产品设计费等 / 其他相关费用；委托、合作、集中单列）
| 费用类别 | 预算金额 | 说明 |
|---------|---------|------|
| 人员人工费用 | | 工时测算依据 |
| 直接投入费用 | | 材料/燃料/动力、模具、样品样机 |
| 折旧费用 | | 共用设备按工时/机时分摊 |
| 无形资产摊销 | | 软件/专利/非专利技术 |
| 新产品设计费等四项 | | 设计/工艺/临床/勘探试验 |
| 其他相关费用 | | 先查正列举，再算限额 |
| 委托/合作/集中研发 | | 合同登记证明 |

## 七、立项决议
**项目立项决议**：经公司有权部门（董事会/总经理办公会）__年__月__日审议通过，同意设立本研发项目并批准项目预算。
- 决议文件编号 / 日期：__________
- 负责人签字：__________　日期：__________

## 八、留存备查提示
- [ ] 本项目立项书、立项决议已归档
- [ ] 立项时已按项目设研发支出辅助账（不可事后补）
- [ ] 已确定费用分摊方法（工时/机时/面积，一经确定不得随意变更）
- [ ] 项目组及研发人员名单、工时表已建立

> 归档要求：立项书、决议、项目组与研发人员名单是留存备查第①项（见 assets/留存备查资料清单与签收单.md）。
