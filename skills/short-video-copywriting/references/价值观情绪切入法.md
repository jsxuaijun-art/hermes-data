# 价值观情绪切入法 — 短视频选题方法论

> 来源：2026.7.25 离岸信托征税公平角度生产案例
> 已验证：用户主动提出「不是仇富，而是期待公平」切入 → 命中社会主义核心价值观 → 产出2条脚本

## 核心洞察

大多数财税类短视频走**恐惧驱动**路线（「不这样做会被罚」「风险很大」），观众早已审美疲劳。
但有一种更高级的情绪驱动力——**公平感**（Fairness）。

## 触发条件

当符合以下任一场景时，加上价值观情绪切入角度的脚本：

| 场景 | 翻译成价值观切入 | 案例 |
|:-----|:----------------|:-----|
| 富人逃税/避税新闻 | 「不是仇富，是期待公平」 | 离岸信托征税20% |
| 大企业罚单 | 「大厂倒赔得起，小厂倒了全家哭」 | 携程51.79亿 |
| 政策倾斜/补贴 | 「凭什么他能拿我不能？」 | 高新技术企业补贴 |
| 法规对个人/小企业的冲击 | 「规则是给守规矩的人定的」 | 个人所得税新规 |

## 五步执行法

### Step 1 — 找到情绪内核

问三个问题：
1. **谁受委屈了？**（普通人/小企业主/纳税人）
2. **谁占了便宜？**（富人/大企业/会钻空子的人）
3. **读者听完想说什么？**（「对！说得对！」/「早该这么干了」）

### Step 2 — 嫁接价值观体系

不要只说「气愤」「不满」—— 要给这种情绪一个**合法、安全、有高度的包装**：

| 情绪原味 | 价值观包装 |
|:---------|:-----------|
| 仇富 | 期待公平（社会主义核心价值观·公正） |
| 愤怒 | 规则公平（法律面前人人平等） |
| 不爽 | 纳税公平（多赚钱多交税） |
| 焦虑 | 保护自己（合规是给自己的安全边际） |

### Step 3 — 标题公式

```
[普通人视角] + [为什么叫好/不服/支持] + [价值观关键词]
```

示例：
- 「离岸信托征税，老百姓为什么拍手叫好？」← 价值观情绪共鸣
- 「携程被罚51亿，小老板为什么说罚得好？」← 价值观共鸣+利益关联

### Step 4 — 内容三段式

```
开篇（3秒钩子）：反常情绪 — 普通人不该叫好的事，他们为什么叫好？
中段（20秒）：事实+价值观捆绑 — 不是仇富，是XXX（价值观收口）
尾部（10秒）：利益关联+CTA — 这件事说明什么？对你有什么启发？
```

### Step 5 — CTA设计

价值观情绪切入的CTA不宜太「交易感」：
- ❌ 「想合规的找我」
- ✅ 「评论区聊聊你觉得公平不公平」

## 验证清单

每条价值观情绪脚本发布前自检：

- [ ] 是否有一个清晰的「委屈方」和「占便宜方」？
- [ ] 情绪是否找到了**合法的价值观包装**？
- [ ] 标题是否让读者产生「对！说得对！」的第一反应？
- [ ] 中段是否有**具体事实/数据**支撑（不只是情绪煽动）？
- [ ] 结尾是否留给了观众「讨论空间」而不是「广告空间」？

## 风险提示

- **不要站错队**：爱国/仇富一线差。确保价值观始终站在「期待公平」而非「煽动对立」的立场
- **不要只打情绪不给信息**：情绪是钩子，信息是价值。纯情绪没有收藏率（抖音算法收藏权重最高）
- **不要广告化结尾**：价值观情绪脚本的观众防御心最强，不要在结尾突然卖产品。引导讨论 > 引导购买
