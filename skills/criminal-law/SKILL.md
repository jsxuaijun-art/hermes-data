# 中华人民共和国刑法（主路由）

> 现行合并本 = 1997-03-14 修订 + 《刑法修正案》(1999) 及修正案（二）~（十二）（至 2023-12-29 第十四届全国人大常委会第七次会议）。
> 维基文库转录全文已拆入 5 个子 skill，每个含 `references/本章全文.md`。引用以官方文本为准。

## 路由决策

- **犯罪构成 / 刑罚种类 / 量刑 / 单位犯罪 / 自首立功 / 追诉时效** → `criminal-law-general`
- **破坏社会主义市场经济秩序罪（涉税犯罪·虚开·骗取出口退税·金融诈骗·公司犯罪）** → `criminal-law-economic`  ⭐盈信最高危：第201条逃税、第205条虚开增值税专用发票
- **侵犯人身权利 + 侵犯财产（职务侵占·挪用资金·侵占·盗窃·诈骗）** → `criminal-law-property-person`
- **贪污贿赂 + 渎职（受贿·行贿·渎职·税务人员不征少征税款）** → `criminal-law-corruption`
- **其余分则（国安·公共安全·社会管理·国防·军人）+ 附则附件** → `criminal-law-social-order`

## 盈信重点关注（代账/财税服务刑事边界）

1. **虚开增值税专用发票、用于骗取出口退税、抵扣税款发票罪（第205条）**——代账行业最高危，无金额门槛。
2. **逃税罪（第201条）**——首次逃税经追缴+罚款已受行政处罚的不予追究（但五年内二次或曾受刑除外），须保全申报底稿。
3. **隐匿、故意销毁会计凭证、会计账簿、财务会计报告罪（第162条之一）**——不得应客户要求销毁凭证。
4. **职务侵占（第271条）/ 挪用资金（第272条）**——接触客户资金须设防火墙。
5. **徇私舞弊不征、少征税款罪（第404条）**——拒绝任何'通融少缴'暗示，保全与税务人员沟通记录。
