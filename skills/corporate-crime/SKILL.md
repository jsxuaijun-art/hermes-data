# corporate-crime —— 公司主体犯罪总路由

**事实源**：《中华人民共和国刑法》(2023年) 现行合并本（1997主法 + 12个修正案）。
**定位**：不重复收录整部刑法，只做按公司主体、经营、负责人维度的罪名切片与路由；条文原文一律取自原文，未作改写。

> **防幻觉铁律**：引用条文前，先在本 skill 群的 `references/*.md` 中核对原文。
> 本 skill 不替代司法解释；量刑细则以各罪司法解释与量刑指导意见为准。

## 二、总论：单位犯罪（必须先掌握）

**第三十条**：公司、企业、事业单位、机关、团体实施的危害社会的行为，法律规定为单位犯罪的，应当负刑事责任。

**第三十一条**：单位犯罪的，对单位判处罚金，并对其直接负责的主管人员和其他直接责任人员判处刑罚。

### 三个必须记住的结论

1. **法定才行** —— 第三十条写明「法律规定为单位犯罪的」。不是任何单位行为都构成单位犯罪，必须有法律明文规定。判断方法：看罪条末尾有没有「单位犯前款罪的，对单位判处罚金……」的表述；没有该表述的，只罚自然人。
2. **双罚制** —— 单位犯罪的既罚单位（罚金），又罚人（直接负责的主管人员 + 其他直接责任人员）。分则中大量条文以「单位犯前款罪的，对单位判处罚金，并对直接负责的主管人员和其他直接责任人员……」收尾。
3. **主体按实际认定，不按登记推定** —— 分则中大量罪名表述为「直接负责的主管人员和其他直接责任人员」，而非「法定代表人」。**法定代表人不等于天然责任人**，实务中按「谁决策、谁经办」认定。

## 四、法定代表人与负责人的常见认知误区

| 误区 | 正确口径 |
|---|---|
| 我是法定代表人，出了事就该我担 | 刑事责任的「直接负责的主管人员」按实际决策与经办认定，不按工商登记推定；挂名法定代表人可抗辩 |
| 公司出事只罚公司 | 第三十一条双罚制，罚金加直接责任人刑罚并行 |
| 公司注销了就查不到我了 | 第一百六十二条、第一百六十二条之二（清算期犯罪）及个人罪责不因注销消灭；第三百一十三条拒不执行判决亦不因注销豁免 |
| 我只是做账的，出事与我无关 | 第一百六十三条、第二百七十一条、第二百七十二条主体为「工作人员」，不限高管；代账机构参与虚开按共犯追究（真实案：(2021)沪0118刑初1027号、(2019)豫08刑终303号） |
| 章是公司注销前刻的真章，继续用不算伪造 | 关键区分：第二百八十条只罚「伪造」。真章使用不落本罪；但若用于签约骗钱，落第二百二十四条合同诈骗罪（真实案：(2024)沪0107刑初510号） |

## 五、代账及财税机构的两条刑事红线（速记）

| 红线 | 落点 |
|---|---|
| 应客户要求虚开发票、虚增成本、参与过账 | 第二百零五条（无金额门槛）+ 与客户共犯（真实案：(2021)沪0118刑初1027号，代账人员判三年缓三年；客户已判刑） |
| 客户注销时销毁或隐匿依法应保存的会计凭证 | 第一百六十二条之一（情节严重处五年以下）；江都张某隐匿凭证致清算无法进行案判二年 |
| 应客户要求补刻已注销公司印章 | 第二百八十条第二款共犯 |
| 出具与实际财务情况不符的审计或验资报告 | 第二百二十九条（法条明确列举「会计」职责） |

**对应的民事责任线**：代账工作失误（算错、漏报、错报）引发客户民事索赔，走委托合同纠纷，按比例担责（真实案：(2024)皖0521民初1833号，代账承担百分之七十）。**失误赔钱，参与犯罪坐牢——这是两条量级完全不同的线。**
