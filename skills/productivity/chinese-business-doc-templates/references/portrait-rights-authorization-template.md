# 抖音肖像权授权书 — 完整模版（2026-08 产出）

场景：短视频/直播/广告拍摄，出镜者（甲方）签给拍摄方/账号运营方（乙方）。
结构按用户指定：一.授权人信息表格；二.授权内容；三.授权期限；+ 其他约定 + 签署区。
交付：python-docx 生成 .docx 存桌面（`/mnt/d/OneDrive/Desktop/`，本机桌面在 D 盘）。

## 完整模版

标题：肖像权授权书（抖音短视频 / 直播使用）
引言：授权人（甲方）：____　被授权人（乙方）：____

一、授权人信息（表格，两列：字段 / 空值填写行）
- 姓名 / 身份证号码 / 联系电话 / 联系地址 / 抖音号·昵称

二、授权内容
甲方自愿将其本人肖像（包括但不限于姓名、形象、声音、影像、视频、照片及相关肖像素材）
授权给乙方，用于以下用途（在"□"内打"√"，可多选）：
- □ 抖音短视频的拍摄、制作及发布
- □ 直播活动（含带货直播）
- □ 商业广告及商业推广（含植入式广告）
- □ 图文、海报、宣传页等宣传物料
- □ 其他（请注明）：____
乙方使用时应保持形象正面、真实，不得歪曲、丑化或损害甲方形象及名誉；
不得用于违反法律法规、违背公序良俗的用途。

三、授权期限
1. 授权期限：自 ____年__月__日起至 ____年__月__日止。
2. 期限届满后乙方应立即停止使用，并对已发布内容中涉及甲方肖像的部分
   进行下架、删除或遮挡处理。
3. 本授权自甲方签署之日起生效。

四、其他约定
1. 本授权为：□ 无偿授权　□ 有偿授权（金额：人民币____元，支付方式及结算节点：____）
2. 未经甲方事先书面同意，乙方不得将本授权中的肖像权转授权、转许可给任何第三方。
3. 本授权书一式两份，甲乙双方各执一份，具有同等法律效力。
4. 争议协商解决；协商不成，任何一方可向乙方所在地有管辖权的人民法院提起诉讼。

签署区：
甲方（签字 / 捺印）：____　日期：____年__月__日
乙方（盖章 / 签字）：____　日期：____年__月__日

## 给用户的专业提醒（每次交付附上）

1. 「有偿/无偿」必须明确勾选——出镜主播通常有报酬，金额+支付方式+结算节点写清楚。
2. 「授权内容」用途范围越明确对甲方（被拍摄者）越安全；越宽对乙方（拍摄方）越有利——
   先问清用户是哪一方再倾向。
3. 授权期限务必填具体起止日，不写"长期/永久"——人身权授权，明确期限对双方都稳妥。
4. 抖音平台对肖像/实名认证内容有合规审核，商业合作拍摄建议双方签章后各留纸质/电子原件存档。

## python-docx 中文字体要点

- Normal 样式设 `style.font.name='Times New Roman'` + `style._element.rPr.rFonts.set(qn('w:eastAsia'),'宋体')`
- 每个 run 都要单独设 eastAsia 字体（`rFonts.set(qn('w:eastAsia'),'宋体')`），否则中文可能回退默认字体
- 表格用 `doc.add_table(rows, cols)` + `table.style='Table Grid'`，列宽用 `Cm()`
- 页边距 section.top_margin/bottom_margin/left/right = Cm(2.5~2.8)
