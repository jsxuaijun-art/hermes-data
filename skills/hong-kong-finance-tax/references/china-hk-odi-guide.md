# China–Hong Kong ODI Guide

For investments from Mainland China into Hong Kong, determine the PRC outbound investment compliance path before treating the Hong Kong structure as fully implemented.

Check:
- PRC investing entity
- new setup / acquisition / capital increase
- project jurisdiction
- sensitive country / region considerations
- sensitive industry considerations
- NDRC path
- MOFCOM path
- foreign-exchange / bank capital remittance path
- registered investment amount
- actual remittance amount
- subsequent capital increase
- shareholder loan
- dividend repatriation
- consistency between ODI documents and actual transaction

Use current official PRC rules and effective dates.
Do not hard-code approval thresholds or filing deadlines.
