## 零、⚠️ 时效分界：增值税的"新旧法"（2026年后必看）

**《中华人民共和国增值税暂行条例》已于 2026年1月1日废止。**

- 《中华人民共和国增值税法》（主席令第41号，2024-12-25通过）自 **2026年1月1日**起施行
- 《中华人民共和国增值税法实施条例》（国务院令第826号，2025-12-25公布）同步施行
- 《增值税暂行条例》及其实施细则**同时废止**

**但稽查查的往往是以前年度，所以必须按所属期分界：**

| 应税交易发生时间 | 适用法规 |
|---|---|
| **2026-01-01 起** | 《增值税法》第20条 + 《实施条例》第18条 |
| **2025-12-31 及以前** | 《增值税暂行条例》第7条 + 实施细则（**该条例对过往年度仍然有效**，不是"废止了就不能引"） |

> **常见错误**：一概改用《增值税法》去套 2023 年度的案子——**错**，那是溯及既往。反之，2026 年的交易还引"暂行条例第7条"——**也错**，已被废止。
> **动作规则：引用增值税条款前，先确认涉案所属期，再选法条。**

**销售额明显偏低/偏高的核定（现行）**

- 《增值税法》**第20条**：销售额明显偏低或者偏高且**无正当理由**的，税务机关可以依照《税收征收管理法》和有关行政法规的规定核定销售额。
- 《实施条例》**第18条**：核定顺序——① 纳税人最近时期同类平均价格；② 其他纳税人最近时期同类平均价格；③ 组成计税价格＝成本×(1+成本利润率)+消费税税额，成本利润率 10%（税务主管部门可调整）。
- ⚠️ 注意新法表述是"**偏低或者偏高**"双向，旧条例只有"偏低"。

→ 用途：核定销售额争议的第一顺位依据；"有正当理由"即抗辩落点（见 `04` 案由三）。

## 一、《税收征收管理法》

| 条 | 要点 | 用途 |
|---|---|---|
| 第32条 | 滞纳金按日万分之五。**滞纳金是法定的**，只在第32/52/63/64条列明的情形下收取；单纯被要求补税并不必然产生滞纳金 | 计算滞纳金 / 抗辩"补税≠必然滞纳金"（如价格核定调整可否收滞纳金有争议） |
| 第52条 | **追征期**：税务机关责任3年（不加滞纳金）；纳税人计算错误等失误，3年，累计税款10万元以上的5年；偷税、抗税、骗税无限期追征 | ★最便宜的抗辩，先查这个 |
| 第54条 | 税务机关检查权范围 | 判断检查是否越权 |
| 第56条 | 纳税人、扣缴义务人必须接受检查，如实反映情况，提供有关资料 | 配合义务的依据 |
| 第63条 | **偷税**：伪造、变造、隐匿、擅自销毁账簿凭证；在账簿上多列支出或不列、少列收入；经通知申报而拒不申报或进行虚假纳税申报，不缴或少缴税款。追缴税款+滞纳金，并处**50%以上5倍以下**罚款 | ★定性的生死线 |
| 第64条 | 不进行纳税申报，不缴或少缴应纳税款：追缴+滞纳金，处50%以上5倍以下罚款；编造虚假计税依据：责令限期改正，并处5万元以下罚款 | 定性降级的落点 |
| 第86条 | 违法行为在**5年内未被发现的**，不再给予行政处罚 | 处罚时效抗辩 |
| 第88条 | 纳税争议：先缴清或提供担保，然后复议；对复议不服再起诉。当事人对处罚决定、强制执行措施、税收保全措施不服的，**可依法申请行政复议，也可依法起诉** | 清税前置 + 罚款可单独救济 |

### 修订动态（重要，2026）

2026年8月31日国务院常务会议原则通过《税收征收管理法（修订草案）》，提请全国人大常委会审议。主要方向：

- **取消行政复议"清税前置"**，保留"诉讼前清税"
- "滞纳金"更名为"**税款迟纳金**"，新增**不予／免予加收**情形
- 新增无过错"**漏税**"情形（区别于偷税）
- 明确强制措施期限
- 扩大关联交易认定范围、加大发票违法责任

→ 新法施行后，本文件第52条、第88条相关表述需同步更新。目前对外文书**仍按现行法引用**。

## 三、《行政处罚法》

| 条 | 要点 |
|---|---|
| 第29条 | 同一个违法行为不得给予两次以上罚款 |
| 第33条 | ★**不予处罚三情形**：① 违法行为轻微并及时改正，没有造成危害后果；② 当事人有证据足以证明**没有主观过错**；③ 初次违法且危害后果轻微并及时改正（首违不罚） |
| 第32条 | 从轻／减轻：主动消除或减轻危害后果、受他人胁迫或诱骗、主动供述、配合查处有立功表现等 |
| 第63条 | 较大数额罚款等情形，应告知听证权 |
| 第64条 | 要求听证的，应在告知后**5日内**提出 |
| 第66条 | 当事人确有经济困难，经申请和批准，可以**暂缓或者分期缴纳**罚款 |

## 四、首违不罚清单

《国家税务总局关于发布〈税务行政处罚"首违不罚"事项清单〉的公告》（国家税务总局公告2021年第6号），共14项，典型包括：

- 未按规定将全部银行账号向税务机关报送
- 未按规定设置、保管账簿或保管记账凭证和有关资料
- 未按规定期限办理纳税申报和报送纳税资料
- 使用税控装置开具发票未按规定期限报送开具发票数据（无违法所得）
- 未按规定取得发票、以其他凭证代替发票使用（无违法所得）
- 未按规定缴销发票（无违法所得）
- 未加盖发票专用章（无违法所得，第二批）

**适用条件**：一个自然年度内首次发生 + 危害后果轻微 + 在税务机关发现前主动改正或在责令限期改正期限内改正。

> 注意：首违不罚清单**不适用于偷税、虚开发票等严重违法行为**。它主要解决申报、账簿、发票管理等程序性瑕疵。

## 六之二、滞纳金的法定性（抗辩用）

**补税 ≠ 必然产生滞纳金。** 按《税收征收管理法》，滞纳金只在第32条（未按期缴纳税款）、第52条（因失误少缴）、第63条（偷税）、第64条（不申报）等列明情形下收取。被要求补税但未落入上述任一情形的（如税务机关依法核定调整价格、政策适用争议），是否应收滞纳金存在争议，可作抗辩点。测算时仍按"滞纳金=补税额×0.05%×天数、标明起算日"给区间，但不要默认"补了税就一定有滞纳金"。

## 六、《刑法》第201条 · 逃税罪（移送预警线）

- 纳税人采取欺骗、隐瞒手段进行虚假纳税申报或者不申报，逃避缴纳税款**数额较大并且占应纳税额百分之十以上**的，处三年以下有期徒刑或者拘役，并处罚金；数额巨大并且占应纳税额百分之三十以上的，处三年以上七年以下有期徒刑，并处罚金。
- **数额标准（现行）**：逃避缴纳税款 **10 万元以上**＝"数额较大"；**50 万元以上**＝"数额巨大"。
  依据：最高人民法院、最高人民检察院《关于办理危害税收征管刑事案件适用法律若干问题的解释》（法释〔2024〕4号，2024年3月20日施行）第2条。
  ⚠️ 旧的"5万元/25万元"标准（2010年立案追诉标准（二））已废止，**严禁再引用旧数字**。
- **出罪条款**：经税务机关依法下达追缴通知后，补缴应纳税款，缴纳滞纳金，已受行政处罚的，不予追究刑事责任；但是，**五年内因逃避缴纳税款受过刑事处罚或者被税务机关给予二次以上行政处罚的除外**。

→ 实务含义：**行政阶段的补缴结果直接决定刑事风险有无**。这也是"争取在行政阶段结案"的最大价值——比省下的罚款重要得多。

## 六之二、《刑法》第205条 · 虚开增值税专用发票罪（红线）

依据：法释〔2024〕4号第11条（2024年3月20日施行）。

| 档次 | 标准 |
|---|---|
| 定罪处罚（3年以下/拘役） | 虚开**税款数额 10 万元以上** |
| 数额较大（3–10年） | **50 万元以上** |
| 数额巨大（10年以上/无期） | **500 万元以上** |
| 其他严重情节 | ①提起公诉前无法追回税款达 **30 万元**以上；②五年内因虚开受过刑事处罚或二次以上行政处罚、又虚开且数额达 30 万元以上 |
| 其他特别严重情节 | ①无法追回税款达 **300 万元**以上；②五年内因虚开受过刑事处罚或二次以上行政处罚、又虚开且数额达 300 万元以上 |

其他要点：
- 以同一购销业务名义既虚开进项又虚开销项的，**以其中较大的数额计算**。
- 以伪造的增值税专用发票虚开，达到上述标准的，以本罪论处。
- **行为犯**：不以是否抵扣、是否造成税款损失为要件。

⚠️ **严禁引用的旧数字**："虚开1万元以上即追诉""致使税款被骗5000元以上"——这是 2024 年前的标准，现已提高至 10 万元。引用旧数字会导致严重误判（既可能过度恐慌，也可能在文书中被对方指出不专业）。

→ 实务含义：虚开是**红线案件**，出现嫌疑立即提示律师/税务师，本 skill 只做行政程序文书与"善意取得"方向论证。
