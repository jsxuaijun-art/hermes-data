### 百度文库会员方案（备用，需用户操作）

如果用户有百度文库会员，这是最可行的路径：

1. 搜狗搜索返回的链接包含了 **百度文库文档**
2. 让用户手动打开百度文库 → 搜「雅思词汇表 完整版」→ 选一个文档 → 下载到桌面
3. 然后我们解析文件转成默写本格式

### 文档猫、原创力、淘豆网等中间站点

- 搜狗搜索返回的链接指向这些中间站，但链接是搜狗跳转格式（`/link?url=hedJjaC291...`），非原始URL
- 尝试用Playwright直接打开搜狗跳转链接 → 跳转到anti-spider页面
- 这些站点本身也要登录/付费才能下载完整文档

### 核心教训

**对于中国教育类内容的爬取，优先级应该是：**

1. ✅ **用户自己的账号登录**（百度文库VIP、豆丁VIP等）— 最快
2. ✅ **频率筛选法**（用现有词频库 + 已知词汇表取交集）— 对考试词汇最可靠
3. ⚠️ 搜狗搜索第一次请求（curl_cffi）— 能拿到链接但解析不了
4. ❌ Bing.cn / Bing.en — JS渲染不可用
5. ❌ 百度搜索 — 必定验证码
6. ❌ 搜狗连续请求 — 必定anti-spider

### 用户偏好（本session确认）

- 用户百度文库VIP，可以付费下载
- 但用户说百度文库的「雅思词汇表」不完整，要求找更好的来源
- 对于这种「不完整」问题，**直接建议用户用文库搜「新东方雅思词汇 词根 联想」**，新东方出版的盗版扫描件通常最全
- 如果用户还是不满意，说明没有公开免费的全本，承认搜索失败
