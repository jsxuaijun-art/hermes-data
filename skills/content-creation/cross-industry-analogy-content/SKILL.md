# 跨行业类比内容创作

> **一句话定位：** 用户丢来一篇**别的行业**的文章（医疗、教育、餐饮、制造、互联网…）加一句
> 「类比〈我们这行〉进行创作」时，本 skill 是方法论母板：抽出**机制链**，整条链换行业代入，
> 而不是把原文话题搬过来再接一句「我们这行也一样」。

**典型原话（2026.10.26 实战）：**
> 「调用公众号skill，读取这个链接…的文章，然后类比代理记帐行业进行创作，充分引用话术、销售skill中关于低价营销或压价的相关内容。」

## When to Use

- 用户发来**非本行业**文章链接，并明确说「类比〈本行业〉创作 / 参照改编 / 翻译成我们的语言」。
- 用户拿一个热点事件（他行的暴雷、官方点名、行业整治）说「这个能不能写一篇我们行业的」。
- 需要把外部行业报告、政策、新闻当**素材骨架**，产出公众号长文 / 短视频口播 / 朋友圈文案。

**不适用**：原文本身就是同行文章（走 `skills/wechat-publish` 的模式C 常规改写）；
纯政策解读（走政策解读模板）；用户只给主题不给素材（走模式A 标准写作）。

---

## 一、核心原则：抽「机制」不抽「话题」

跨行业类比最常见的失败形态，是**两张皮**：前半段讲别人的行业（药品、集采、医院），
后半段硬接本行业，中间没有任何逻辑桥。读者看完只觉得「你说了两件事」。

正确做法：**先把原文读成一条因果链，再把整条链接换行业代入。**

四步：

1. **抽机制链** — 读成因果链，不是事实清单。固定三问：
   - 谁在压价 / 谁在推动？
   - 省下来的钱从哪个环节抠出来？
   - 最终谁承担后果？
2. **找同构点** — 在本行业里找同一条链上**位置完全对应**的角色（压价方→压价方、抠成本环节→抠成本环节、终端受害者→终端受害者）。
3. **建映射表** — 逐项对齐，**每一行都要落到读者最怕的「出事、挨罚、赔钱」**，落在抽象词（偷工减料、质量下降）上等于没写。
4. **只留逆向证据** — 原文里凡是「行业已在纠偏 / 官方点名 / 规则在改」的信号，升级为文章立意的**权威背书**。

> ⭐ **第 4 步是跨行业改写最大的红利**：借一个更权威行业的官方表态，
> 替本行业把「低价不可持续」这句话说出来。自己喊一百遍，不如人民日报喊一遍。

## 二、已验证案例：医疗集采「极端低价」→ 代理记账「低价内卷」

**原文要点**（人民日报痛批集采极端低价）：内镜止血夹报价 7.4 元（正常 20 元、出货价 26–30 元，
显著低于成本）；低价中标后出现质量问题（0.22 元/支中标的注射液被查出不合格）、**断供**
（成本上涨/产能不足直接不供货）；国家医保局 7.23 发文强调「集采不能只看低价」，
第 12 批集采围绕「反内卷」优化竞价规则。

**机制链**：官方推动降价 → 有人报到低于成本 → 亏本就得从别处抠 → 质量降级 / 直接断供 →
终端使用者（患者、医院）承担后果 → 官方回头纠偏、给极端低价划边界。

**映射表（可复用范式，换行业时照此结构重建）：**

| 他行业（医疗集采） | 本行业（代理记账） | 落点 |
|:---|:---|:---|
| 7.4 元 vs 成本 26–30 元，明显低于成本 | 99/199 元/月 vs 一个主办会计的硬成本 | 数字反差，让读者自己算 |
| 报价时就明知赚不到钱，仍要投 | 低价机构明知不可能足量做工，仍要签 | 低价≠高效，是在透支 |
| 亏本 → 从原料/工艺里抠 | 低价 → 从五个环节省工（不索银行流水 / 不问真实业务 / 年终不移交账册 / 用实习生顶账 / 会计频繁更换） | 本行业「省工信号」清单 |
| 质量下降（注射液不合格） | 账做乱、票对不上、少报漏报 | 稽查、补税、罚款 |
| **断供**（中标后不供货） | **断供翻译**：会计突然换人、账套不交、机构跑路、第二年不续 | 危机感最强的一节，务必写足 |
| 患者吃不上药 | 老板拿不到真账、年报/汇算没人管 | 责任还是老板扛 |
| 医生反复解释、工作量增加 | 老板事后自己补账、跑税务局解释 | 「钱是省了，活儿回到你身上」 |
| 反安慰剂效应：负面印象不断被强化 | 读者对「便宜没好货」将信将疑，直到自己踩坑 | 心理层，可略写 |
| 官方：不能只看低价，给极端低价划边界 | 借为立意：低价内卷已被官方点名，本行业同理 | ⭐ 权威背书 |

**必配的本行业弹药**（本次为销售话术，其他行业替换成自家核心论点）：
「服务费 = 买断工作时间」——一天 24 小时对谁都公平 → 低价同行把时间花在开票跑腿（明面上让你开心的事）
→ 分给做账的时间就少 → 做账是看不见的无形服务，做多做少你根本不知道 → 大数据监管下风险全在
→ 所以先比资质专业，再比价格。

## 三、给「发散建议」的正确姿势：主线 + 可融合元素（两层，不是四选一）

常规选题建议是给 2–5 个**互斥**角度让用户挑一个。**跨行业类比类任务不是互斥选题**，
而是一条骨架 + 若干血肉，必须分层给：

```
💡 发散建议
主线（选一个做骨架）：
  A. 借对方的官方表态切入（站位最高、传播力最强）
  B. 数字冲击 / 算账叙事（最贴老板）
  C. 把对方的「断供/暴雷」翻译成本行业场景（危机感最强）
  D. 从低价/落后一方自身不可持续切入（让读者看清「便宜=迟早出事」）

可融合元素（可多选，融进主线）：
  - 数字反差对比表
  - 断供 / 跑路 / 换人场景
  - 对方活不下去的成本账
  - 自查验钞清单（五大信号类）
```

**判断依据（实证）**：徐总的回答是「我觉得 ABCD 的内容都有，但以 A 为主线」——
说明用户要的是**A 当骨架、BCD 当血肉**，不是四选一。
所以默认推荐给法就是 **A 主线 + B/C/D 全融合**，只推一个角度会丢掉他想要的素材。

## 四、执行顺序（固定流程）

1. **读原文** → 抽机制链（先别动笔）。
2. **加载本行业弹药 skill**，把「充分引用我这些话术/素材」这类要求落到实处。
   财税/销售场景 = `communication/sales-communication` + `compliant-accounting/price-negotiation`，
   但**不要只信固定文件清单**——话术库还在持续增补，清单会过期。

   **必做的全库检索（不许跳过）：** 对技能根目录跑一次关键词 grep，再按命中的文件挑着读：
   ```
   search_files(pattern="低价|压价|砍价|便宜|服务费|买断|时间",
                path="/mnt/d/obsidian-vault/50-Skills",
                file_glob="*.md", output_mode="files_only")
   ```
   首次跑会有 50+ 命中（列表上限），说明弹药散在多个 skill 里，逐一点开挑相关段落，
   而不是只读「三个文件」就动笔。**已知实际可用的低价/压价弹药路径索引见
   `references/低价压价弹药-实际路径索引.md`**（本次实测逐个 read_file 成功，可直接按图索骥）。
3. **出「主线 + 可融合元素」发散建议**，等用户圈定主线与风格。
4. **写稿**：长文/公众号成稿走 kimi-k3 子代理（`delegate_task`，禁 deepseek）；
   短文案走 doubao。**把机制链、映射表、弹药关键论点全部塞进子代理 context** ——
   子代理看不到本会话，不给它映射表，它写出来必然两张皮。
5. 出稿 → 用户预览确认 → 配图 → 发布。发布流程与尾部模板归各自的渠道 skill：
   - 公众号：`skills/wechat-publish`（模式A 第2、3步；配图铁律、尾部公司介绍/话题标签/CTA三动作）
   - 朋友圈：`wechat-moments-marketing`
   - 短视频：`short-video-*` 系列

## 五、红线

- **原文数字是原文的**：可引用，但要标来源方（人民日报 / 国家医保局 / 某官网），
  **不得改数、不得加码、不得把「某批中标价」说成「普遍价」**。
- **本行业没有官方来源的数字**（人力成本、行业均价、需接多少客户才能活）：
  要么用「据行业经验」表述，要么保留用户自述版 + 灰色小字免责，不写成硬性红线。
- **不贬同行**：写「低价压缩的是看不见的服务时间，风险最终回到企业自己」，
  不写「低价代账违法」「他们没质量」这类会招反噬的结论。
- 跨行业类比只迁移**机制**，不迁移**结论**。他行业受监管强度、成本结构与本行业不同，
  直接照搬「某价格违法」之类的判定会出事。
- 事实纪律制服：`content-evidence-discipline`（先核原文再引用、交付附依据清单）。

## 六、用户原话是弹药，必须逐字进稿（2026.10.26 徐总纠正）

徐总原话：
> 「hermes 里有不少关于低价、压价的论述，相关 skill 中也不停的丰富过，比如：『每名会计的工作时间
> 都是有限的，服务费相当于买断代记机构的工作时间……你支付二百元，答应即给你做帐又开发票……
> 只能把明面上让你看得的工作做了，你看不的帐处处理就要减少流程偷工减料，风险就引埋下』。
> 以及：『贪图便宜使用了 7.4 元的内镜止血夹，将危害健康甚至危及生命线；同样的，相信低价代理记帐
> 可能带来和财税风险和罚款，影响业务发展……』」

**教训三条：**

1. **他引用的原话 = 他认可的表述，必须逐字成段用**，不许改写、不许「润色成书面语」、
   不许压成一句带过。他口语里的粗糙（「看不的帐处」）恰恰是他的客户听得懂的话。
2. **他补素材 = 说明上一稿引得不充分**。他贴出第二段时不是「加个素材」，是提醒
   上一稿把最重要的价值对句（7.4 元止血夹 ↔ 低价代账 = 健康/生存风险）写漏了。
   接到这类补充不要只把那句话插进某段，要**回头通检全篇还有哪些自家弹药没用上**。
3. **原话最适合放在「收尾金句段」**：自查清单之后、一句话总结之前，
   单独开一节（如「公道自在人间，价格自有公理」），把他的原话直接抬成全文立意，
   比任何 AI 生成的总结句都有力。

**交付形态（必带）：** 「充分引用」类任务出稿后，回复里附一张 **引用对照表**
（用户原话/弹药点 → 融入文章哪一节），让他一眼看出覆盖了哪些、漏了哪些，
再请他圈定要补的。不给对照表，他无法判断是否「充分」，只会反复补素材。

## 七、对外稿价格口径与 AI 代账论点（2026.10.26 徐总定稿）

徐总原话（改稿指令）：
> 「把『200 元/年』替换为『超低价代理记帐』，所涉及的成本计算也相应改变一下。」
> 「『只有三条路：』中添加第 4 条：用 AI 做帐可能也在摸索中，完全相信也可能是个坑；
> AI 是个利器，可以在各行各业的提质增效，在医院里暂时还无法取代医生。」

### 1. 本行业价格：只写「超低价代理记账」，绝不写具体价档

| 位置 | 规则 |
|:---|:---|
| 他行业数字（7.4 元、26–30 元、0.22 元/支） | **可写**，标来源方（人民日报 / 医保局） |
| 本行业报价（200 元/年、16 元/月、99/199 元/月） | **一律不写**，统一用「**超低价代理记账**」 |
| 成本核算段 | 只给「一个会计最多服务 40–60 家 / 直接人工 150–300 元/户」这类**成本底**，让读者自己反推，不给对比阈值 |

**为什么**：写死某个价档＝指名比价，容易滑向贬低同行、被对号入座；泛指「超低价」覆盖全部低价档，
价格行情变了稿子也不用改。数字冲击力改由**他行业官方数据**承担（7.4 元这侧照样扎人）。

### 2.「超低价机构怎么活」= 四条路（第 3 条是他定稿的 AI 论点）

1. **压人工** —— 实习生、无证会计、一人接 100 家
2. **省流程** —— 不查发票真伪、不做银行对账、不报小税种
3. **用 AI 做账** —— 可能也在摸索中，完全相信也可能是个坑；AI 是利器，可以在各行各业提质增效，
   但**在医院里暂时还无法取代医生**，在代账行业也一样 —— AI 可辅助，但**替代不了专业会计的判断和责任**
4. **跑路** —— 收一年钱，做几个月就消失

第 3 条的写法要点：**不贬 AI、不神化 AI**。落点始终是「AI 替代不了判断和责任」，
借医疗行业做类比（医院不敢让 AI 顶医生），比直接说「AI 做账不准」高级得多，也不得罪技术方。

### 3. 改口径时的全篇同步清单（本次实测漏了一处）

替换任何数字/口径后，**逐处 grep 旧值**，以下位置一个都不能漏：

- 标题（frontmatter `title:` + 正文 H1）
- `abstract:`
- S1/S2/S3 钩子段
- 对比表的「报价」行
- 正文小节标题 ← **本次漏改：`## 一、7.4 元 vs 200 元：数字冲击下的同一套逻辑` 仍留着 200 元**
- 各节正文引述句
- 「一句话总结」与文末金句

> 教训：用户只说了「替换 200 元/年」，但口径是全局的。**改一处 → 立刻全篇普查同类表述**，
> 别只改用户点名的位置（与「编造一处被发现 → 全篇事实普查」同一条纪律）。
