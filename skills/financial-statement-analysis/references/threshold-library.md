## 3. 资金链 / 回款专项阈值

- 应收周转天数 vs 赊账账期：≤账期健康🟢；超账期 30-60 天关注🟡；超账期 60 天+承压🔴
- 应收增速>收入增速 1.5 倍 且 连续 2 年 → 激进赊销🔴
- 经营 CF 负 + 利润正 → 纸面富贵🔴（四象限）
- 现金比率<10% + 应收恶化 + 短借上升 → 资金链高风险🔴
- 不同行业账期差异大（零售现结 vs 工程按节点），必须按行业设账期基准

## 4. 指标计算标准公式

```
毛利率 = (营业收入 - 营业成本) / 营业收入
净利率 = 净利润 / 营业收入
研发费用占比 = 研发费用 / 营业收入
收入增长率 = (本年收入 - 上年收入) / 上年收入
流动比率 = 流动资产 / 流动负债
速动比率 = (流动资产 - 存货) / 流动负债
资产负债率 = 总负债 / 总资产
应收周转率(年化) = 营业收入 / 应收平均余额 × 12 / 本期月数
存货周转率(年化) = 营业成本 / 存货平均余额 × 12 / 本期月数
周转天数 = 365 / 周转率
利润含金量 = 经营活动现金流净额 / 营业利润      # >1 优质, <0.5 含金量低
核心营业利润占比 = (营业收入-营业成本-税金-销售-管理-研发-财务) / 利润总额   # >70% 健康
可持续增长率 SGR = ROE × (1 - 股利支付率)
杜邦分解: ROE = 净利率 × 总资产周转率 × 权益乘数
自由现金流 = 经营现金流净额 - 资本支出
```

## 5. 双层基准获取与标注

- **上市/规模企业参照（上限）**：目标行业上市公司年报指标，代表优秀水平，不作"达标线"。
- **非上市/中小微口径（贴近客户）**：行业统计年鉴、工信部/统计局中小企业数据、协会报告、同行代账样本。
- 报告每个对标指标**必须标注对标对象类型**（上市参照 / 非上市口径 / 通用默认值）。
- 联网校准为可选项：用户明确要求或库值明显过时才做；提案经确认后写回本文件对应行。
