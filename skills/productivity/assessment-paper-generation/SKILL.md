# 考核/面试试题生成

## 触发场景
- 用户要出一份百分制试卷考人（招聘面试、培训结业、能力测评）
- 已经有一份「考察问题清单」/「知识点文档」，想提炼成正式试题
- 用户问「出选择题还是填空题 / 怎么设分值 / 多少题量」这类出题策略问题

## 业务背景（重要，避免表述错误）
盈信企业管理（苏州）**自身不是高新技术企业**，而是**为高新技术企业提供咨询/服务的机构**：直接给客户做高企申请、账务处理服务，也为客户**代为招聘专职会计**——"高企代账会计招聘面试题"正是因「代招专职会计」而生。撰写题干/介绍业务场景时不要把盈信本身说成高企，主语是「盈信为高企客户代招的专职会计岗」。

## 核心策略：为什么用「混合题型」而不是单一题型
面试/考核对象的能力分两个层次，单一题型会漏掉一层：
- **硬性数据 / 概念**（背得出 = 有基础）：硬指标、期限、表号、占比。用客观题（单选/判断/多选）——错就是不懂，不浪费时间，也好判卷。
- **实操经验**（答得出细节 = 真做过）：流程怎么做、合规红线、异常处理。只能用**简答/案例分析**逼对方说具体做法——没做过的人编不出细节，客观题背得出但简答必露馅。

**一句话：客观题是淘汰门槛，简答题是录取筛子。**

## 推荐题型结构（已验证，高企代账题，27题/45分钟/100分）

| 题型 | 题量 | 每题 | 小计 | 测什么 |
|------|------|-----|------|--------|
| 单选题 | 10题 | 3分 | 30分 | 硬性政策数据 |
| 多选题 | 5题 | 4分 | 20分 | 政策叠加、合规要点（多选/少选/错选均不得分） |
| 判断题 | 8题 | 2.5分 | 20分 | 实务易错认知（√/×） |
| 简答题 | 4题 | 7.5分 | 30分 | 实操流程与合规判断 |

- 题量控制在 20-30 题、作答 40-50 分钟，够全面又不拖垮节奏。
- 分值侧重可调：更看重实操就把简答提到 40 分。
- 简答可升级为案例分析题（给虚构场景让候选人诊断）。

## 设计步骤
1. **盘点知识点**：从用户已有的问题清单/研究报告/知识点文档提取全部考点，按主题分组（如高企代账：研发费用专项、科技人员、高新收入、申报备案、优惠政策、知识产权）。
2. **分配题型**：硬指标 → 单/判；易错认知+政策叠加 → 多选；实操流程+合规判断 → 简答。
3. **定分值**：按题型重要度分配百分制（客观 70 : 简答 30 是常见起步），保证各题分值凑整。
4. **写题干+选项+答案+解析**：客观题带【答案】+简短解析，简答题列【参考答案要点】分点。
5. **定采用人参考线**：如「客观题≥57 且简答≥20 → 可实操复核；客观题<57 → 能力存疑」。

## 交付：双版本 docx（python-docx）
**核心便利点：一份数据，两种渲染。** 用同一份结构化试题数据（题干/选项/答案/要点），渲染成两份文档：
- **考生版**：题目+选项+作答区（简答留 3 行空行），**不含任何答案**，直接打印给被考人。
- **教师版**：含每题的【答案】【解析】+简答【参考答案要点】，红色标注答案便于批改，末尾附计分表和采纳参考线。

关键实现要点（详见 `scripts/gen_exam_dual.py` 模板）：
- 用 python-docx 从 hermes venv (`~/hermes-agent/venv`) 调，已装好：`/tmp venv 或 ~/hermes-agent/venv/bin/python -c "import docx"`
- 中文标题/正文字体：`run.font.name='Times New Roman'` + `run._element.rPr.rFonts.set(qn('w:eastAsia'),'宋体')`（否则中文可能走默认字体）
- 答案红色 `RGBColor(0xC0,0,0)`，解析用楷体
- 页边距 `Cm(2.2)` 左右，`Cm(2)` 上下
- 生成后必须用 python-docx 读回校验（统计含「答案」的段落数 == 题目数 + 简答要点，确认没丢内容）

## 铁律
- **数据慎用真实性**：涉及政策/法规/数据时，遵守用户「严禁AI幻觉」铁律——题目里的硬指标（税率、年限、占比）必须有官方依据，拿不准的先查证或删掉，不能编造。
- 判断题/选择题的选项要互斥清晰，避免两可。
- **出高企/税务题前，先加载 `ga-xin-tax-knowledge` skill**：那里沉淀了已核验的高企核心辨析（15%税率、科技人员≥10%、高新收入≥60%、5%/4%/3%研发占比档、亏损10年、"其他费用"双口径——高企认定20% vs 加计扣除10%、高企15%与小微二选一、A107041、I/II类知识产权等）。曾因未引用它把"其他费用"口径写混，务必先核对再落答案。
