# 研发费用加计扣除 vs 高企研发费用 三张差异表

为财税服务客户生成三张研发费用表格模板（.xlsx），用于研发费用加计扣除口径与高新技术企业（高企）认定口径的差异归集、填报备查。自动生成并保存到用户桌面。

## 何时使用

用户在提到 **高企** 或 **高新技术企业** 时（含“高企研发费用/高新认定”“高新技术企业研发费用”等说法），即使未提“加计扣除”，也要**自动加载本skill**并按需生成三张差异表。其余触发词：研发费用加计扣除、财税〔2015〕119号、下脚料/残次品/中间试制品特殊收入、研发领用材料形成产品销售、研发人员工时分配，并要求「生成表格模板/输出到桌面」。

## 核心政策规则（财税〔2015〕119号 及配套文件）

| 情形 | 加计扣除口径 | 高企认定口径 | 依据 |
|---|---|---|---|
| 专职研发人员工资薪金/五险一金/公积金 | 全额计入 | 全额计入（一致） | 119号 第一条第(一)项 |
| 兼岗(同时做非研发) | 按研发工时占比计入 | 按实际工时占比计入 | 119号 / 97号公告第二条 |
| 外聘研发人员劳务费(劳务派遣) | 可计入 | 可计入 | 97号公告 / 40号公告第十四条 |
| 纯管理/后勤人员费用 | 剔除(不得计入) | 按规定比例可计入 | 119号 第一条第(一)项第5目 / 国科发火〔2016〕195号 |
| 直接消耗材料/燃料/动力 | 可加计 | 可计入（一致） | 119号 第一条第(二)项 |
| 下脚料、残次品、中间试制品等特殊收入 | 冲减当年可加计研发费用 | 不冲减 | 119号第六条 / 40号公告第七条 |
| 研发形成产品/组成部分销售 | 对应材料费不得加计 | 计入直接投入 | 119号第六条 / 40号公告第八条 |
| 其他相关费用(差旅/会议/资料等) | 有10%上限 | 限额较宽 | 119号 第一条第(五)项 / 40号公告第六条 |

## 生成的三张表

1. **表一 两口径差异调整明细表** — 14 个费用项目 × (加计口径/高企口径/差异额/调整说明/政策依据)，差异类别(无差异/口径差异/加计特有)用红字标出。列：序号/费用项目/差异类别/加计扣除口径/高企认定口径/差异额/调整说明/政策依据。
2. **表二 产品销售冲减明细表** — 领用材料形成产品/下脚料销售冲减研发费用。列：序号/所属月份/研发项目/领用材料品名/领用数量/领用金额/形成产品/销售数量/对应材料成本/特殊收入/备注。底部两行 SUM 公式汇总「对应材料成本(不得加计)」和「特殊收入(冲减当年可加计)」。
3. **表三 人员工时及人工费用调整表** — 列：序号/姓名/岗位/是否专职/全年总工时/研发工时/非研发工时/研发工时占比/工资薪金/社保公积金/其他人工费/可加计扣除人工费/备注。内置公式：研发工时占比=F/E；可加计人工费=SUM(I:K)*H。非专职行标红。

## 执行流程

1. 确认 openpyxl：`python3 -c "import openpyxl; print(openpyxl.__version__)"`，缺失则 `pip install openpyxl`。
2. 定位桌面：`ls -d /mnt/c/Users/*/Desktop/`，取真实用户目录（如 jiangmin）。
3. 运行本skill的 `scripts/build_rd_tables.py`（自动把三张表写入 `<Desktop>/研发费用加计扣除三张调整表.xlsx`）。
4. 用 `xlsx_read.py --sheets` 验证 sheet 名、行列、合并、freeze_panes；确认表二/表三公式 SUM 区间正确。
5. `search_files`（files 模式）确认 .xlsx 已落地桌面。

## 关键技术陷阱（openpyxl）

- openpyxl 3.1.5（及更早）`merge_cells` 必须传 `start_row=.../start_column=.../end_row=.../end_column=...` 关键字或范围字符串，不能传4个位置坐标参数（会报 `TypeError: argument of type 'int' is not iterable`）。
- 数据元组用圆括号 `()` 闭合，别手滑写成方括号 `]`（语法错误）。
- openpyxl 不计算公式，公式结果只在 Excel/LibreOffice 打开时计算；交付前用 `xlsx_read.py --formulas` 确认公式字符串在位即可。
- 数字格式：金额 `#,##0.00`，工时 `#,##0`，工时占比 `0.0%`。
