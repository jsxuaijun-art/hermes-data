# 控股平台 / 企业管理公司 · 经营范围方案

> 适用：公司只负责控股、不从事具体经营，行业特征=「企业管理」。
> 案例（2026-11 连云港）：连云港斯若维企业管理有限公司。
> 定稿前到 jyfwyun 实时核对条目（本库条目随版本变动，以下 scopeCode/permit 以实测为准）。

## 推荐核心组合（皆为 一般事项 permit=0，零前置，可直接写进章程）

| 规范条目 | scopeCode/行业 | 定位说明 |
|---------|--------------|---------|
| 企业管理 | 7219 其他组织管理服务 | 不具体经营，只管重大决策/资产管理/协调下属 |
| 企业总部管理 | 7211 企业总部管理 | 同上，纯管理总部定位 |
| 控股公司服务 | 692 控股公司服务 | 「仅控制股权，不直接参与经营管理」——最贴控股 |
| 以自有资金从事投资活动 | 7212 投资与资产管理 | 自有资金做实业/项目/创业/股权投资，免金融牌照 |
| （可选）自有资金投资的资产管理服务 | 7211 | 自有资金运用，排除私募/公募 |
| （可选）信息咨询服务（不含许可类信息咨询服务） | 7249 | 需要做信息/撮合/咨询时再加 |

### 章程/执照常用写法
```
企业管理
企业总部管理
控股公司服务
以自有资金从事投资活动
```

## ⚠️ 禁忌（控股权限分明）
1. **不写「金融控股公司业务」**——前置许可 permit=1，需《金融控股公司准入管理决定》准入，非持牌平台写了被驳回/年检麻烦。
2. **不写「股权投资」「以私募基金从事…」「私募股权投资基金管理…」**——绑定私募基金/基金业协会备案，纯自有资金控股不需要。
3. **不写裸「资产管理」**——库里无无前缀"资产管理"，只有「自有资金投资的资产管理服务」这类限定表述才合规免牌照。
4. 明确「不直接参与被控股子公司的经营管理」=「控股公司服务/企业管理」条目定义，按此口径即合规。

## 一句话逻辑
公司名带「企业管理」+ 行业特征企业管理 → 用**企业管理+企业总部管理+控股公司服务**锁定"控股平台/管下属"身份，再用**以自有资金从事投资活动**覆盖"拿自己钱做股权/项目投资"——四者皆 permit=0，一次写对，开票/出资/增资不受限。**坚决避开任何带"金融/私募/资产管理"裸词的条目。**

## 附：非苏州地区 jyfwyun 查询路径（连云港等）

`business-registration-advisor/scripts/query_jyfwyun_scope.py --tree` 只打印江苏→苏州→辖区树（硬编码苏州）。
**其他地级市需手动用 API 下钻拿 ac 码**：
1. `POST /cross/regionList` body `{}` → 找江苏省 id
2. `POST /cross/regionList?pcode=<江苏id>` → 找目标市（如 连云港市 ac=320700），pcode 必须走 URL query
3. `POST /cross/search` body `{"keyword":..., "ac":"320700"}` → 拉规范条目（ac 进 JSON body）
连云港市 ac=320700（连云 320703 / 海州 320705 / 赣榆 320721 / 东海 320722 等）。
