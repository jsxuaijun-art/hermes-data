# Office Equipment Procurement Skill

为高用量场景做办公设备采购选型，以及复核别人已经写好的选型建议。
覆盖打印机 / 复印机 / 电脑 / 税控设备等实物或软件采购，产出
「该考虑什么 → 推荐 2-3 款 → 采购建议 → 待确认清单」。

**本技能覆盖两种采购模式，先判断用户在哪一种，再决定用哪套判据：**
- **买断 + 自购耗材** → 决策重心是「耗材结构」（见核心原则 1-5）
- **按张付费全包（印量包 / 租赁 / 外包）** → 耗材维度**整体作废**，重心转为
  「机器规格 + 合同条款 + 供应商可靠性」（见核心原则 6 与「按张付费全包模式」章）

不做：设备安装调试、二手设备估值、供应商授信评估。

## When to Use

- 用户说"帮我选两三款""买什么好""想换台 XX""这个值不值得买"
- 用户拿来一份别人（同事 / WorkBuddy / 其他 AI）写的选型建议，要你复核、补充或给第二意见
- 需要回答"到底哪种方案长期更便宜"
- 用户拿回一份"按张付费 / 印量包"报价，要你判断该不该换方案、怎么谈

## Prerequisites

- 知道用户的年用量 / 月用量 / 峰值用量。没有就先问 —— 这是选型第一输入，缺了后面全错
- **知道用户办公室在用的操作系统**（尤其是否还有 Win7 及以下）。老系统是硬门槛，
  2023 年后新机型普遍不再支持 Win7，问漏了整份推荐作废
- **知道打印机的使用方式**：一人一机（USB 直连）/ 多机共享（USB 接一台电脑再共享）/
  局域网直连（打印机自带网口）。**这一问会根本改变兼容性判据** —— 共享 / 局域网模式下
  「每台电脑都必须装厂商驱动」的逻辑不成立，真判据变成**「打印语言是不是 GDI」**
  （见 `references/network-shared-printing-compat.md`）。实测：用户主动纠正
  "不是一台电脑对应一台打印机，必须共享或局域网模式"，直接推翻了上一轮基于 USB 直连的
  Win7 结论。**没问使用方式就谈系统兼容 = 结论随时会被推翻。**
- 能访问厂商官网 + 电商 + 行业报价站（web_search / web_extract）

## 核心原则（按优先级，先记住这个）

1. **采购的本质是算术题**：年用量 × 单页(单次)成本 = 真正的钱。
   设备价往往只是耗材/运营年支出的零头（实例：购机 ¥1,650，年耗材 ¥1,920 —— 一年耗材就超过机器本身）。
   **先算账，再谈机型。不要一上来就说哪个牌子好。**
2. **第一顺位不是"便宜"，是"耗材结构便宜 + 不易坏 + 出问题有人管"。**
   用户这三个诉求是一体的，别拆开答，也别只答其中一条。
3. **区分厂商参数里的"极限值"和"舒适区"。** 最大月负荷 vs 建议月印量是两个不同的数，
   混用会严重高估机器能力、或用长期超负把机器做坏。
4. **高印量场景先看耗材容量 / 换粉频次，再看参数（用户修正，2026-10）。**
   "粉盒越大，综合成本越低"方向成立，但单页成本是五层叠加的：
   原装 vs 兼容 / 自加粉（差约 7 倍，影响最大）→ 鼓粉分离 vs 一体 →
   锁不锁芯片 → 粉盒容量 / 换粉频次 → 感光鼓寿命。大粉盒必须与"可自加粉 / 兼容粉便宜"配合才有意义，
   单看大小会踩空。实例：6,400 页/月下，2,600 页小粉盒约 9 个工作日换一次
   （申报期最怕半途没粉），11,000 页超大粉盒约 1.5-2 个月一次。
5. **⚠ 任何具体型号在落笔前必须过三道门（2026-10 翻车后新增，代价两版返工）：**
   **① 型号真实存在 → ② SKU 在售 → ③ 系统兼容（尤其 Win7）。顺序不能反，缺一门必返工。**
   型号名**只从厂商官网照抄，永不靠命名规律推演**；官网在架 ≠ 在售（停售机型的
   「立即购买」链接会变成"商品已下架"）；系统兼容以**驱动下载页**为准，不以规格表为准。
   完整清单见 `references/model-availability-verification.md`。
6. **⚠ 全包单价要和「买断的单页综合成本」比，不是和购机价比 —— 比赢了就要换主方案（2026-10 结构性更新）。**
   判定：`全包元/张` vs `买断路线的单页综合成本（购机摊销＋耗材＋维修＋纸张以外的一切）`。
   实测：本地服务商报 **0.03 元/张全包**，买断自加粉约 **0.031～0.034 元/页** →
   全包更省，且首期 0 投入、零维修风险、零加粉管理。做**印量敏感性**（5 万 / 7.68 万 /
   10 万张/年三种情形）后结论不变，**所以这个判断不依赖印量估得准不准** —— 这一点要明确说给用户听。
   ⚠ 这个模式会让整套「耗材结构」维度**一次性作废**（鼓粉分离 / 自加粉 / 粉盒容量 /
   换粉频次 / 单页耗材成本 / 兼容件价格 —— 全部与买方无关）。**必须显式告诉用户
   "前面几轮的哪些结论作废、哪些仍成立"**，不要让旧结论悄悄失效。
   详见「按张付费全包模式」章与 `references/print-meters-per-page-service.md`。
7. **幅面折算只对碳粉成立、对成像鼓不成立（2026-10 新增）。** 碳粉耗量 ∝ 覆盖面积——
   A5=半张 A4，一盒粉在 A5 上可打的张数翻倍；但成像鼓（鼓粉分离的"鼓"）按物理过机张数磨损，
   A5 也过一张算一张，且是经常性耗材（月印 6,400 张时，1 万页鼓约 1.5-2 个月一换、年约 6.4 个，
   原装鼓年费可达近 ¥2,800）。算单页成本必须拆两笔账：粉按面积、鼓按张数。
   实案与全套数字见 `references/page-size-and-drum-economics.md`。

## 复核他人建议文档的固定动作

用户常拿一份已有文档说"参考它的结论，但不要被它限制"。按这个三段套路处理，缺一段都不算完：

1. **采纳清单** —— 逐条写出它抓对的地方（锁定共识，也让用户知道你没无视它）
2. **修正清单** —— 逐条 `它的说法 → 我的修正 → 依据/来源`。**必须带依据**，不带依据的修正不算
3. **增量结论** —— 它没覆盖、但会改变决策的维度

不要照抄，也不要无视。三份清单都要写出来。

## 用户主动提出选型规则时（例："粉盒越大，综合成本越低"）

1. **先验证这条规则再表态** —— 用 web_search 核实（厂商耗材页把容量分档、行业公认大容量
   降单页成本），给出可验证的来源再给结论。
2. **诚实盘点上一版推荐有没有软肋** —— 规则若击中某台推荐机型（如它配的是小粉盒），
   明说"这台让位"，不要为原方案辩护。
3. **重排而不是解释** —— 把同时满足该规则 + 成本低的机型提到第一，其余保留作其他路线。
4. **补一句边界** —— 规则对的部分、不完整的部分都讲清，避免用户被单一规则带偏。
   用户认可后再改文档；旧版压缩包若被 Windows 进程占用删不掉（Permission denied），
   如实说明并让用户手动删，勿死磕。

## 用户提出"行业潜规则 / 内幕"类说法时

用户常带着道听途说的业内说法来求证（例："奔图就是以前的三星"、"粉盒打印量是糊涂账、
存在虚标"）。**先做事实核查，再表态；不要顺着说，也不要空口否定。** 固定三步：

1. **给事实** —— 查厂商官网 / 权威标准 / 财媒报道，把可验证的事实摆出来
   （例：三星打印机业务 2017 年被惠普收购，与奔图无关；奔图母公司是纳思达）。
2. **找用户直觉里的合理内核** —— 用户往往抓到了真问题的影子，只是归因错了。
   （例："粉盒虚标" → 真问题是 ISO/IEC 19752 只按 **5% 覆盖率**标称，
   而财税凭证/报表实际覆盖率 15%～30%，所以实际页数只有标称的 1/3～1/2。
   **不是某品牌骗人，是全行业统一口径。**）
3. **给可落地的替代结论** —— 核查完必须落到用户能用的动作上
   （例：备货按标称打对折甚至 1/3；第一次买机用客户自己的凭证+报表实测一盒能打多少页）。

**必要时主动更正自己的旧结论**（本次即更正了"奔图兼容耗材生态弱于兄弟"这句 ——
纳思达是全球通用耗材与打印芯片龙头，奔图的加粉/兼容生态其实是最强之一）。
认错时明说"我错了、错在哪、成因是什么"，不要模糊成"信息有更新"。

## 按张付费全包模式（印量包 / 租赁 / 外包）—— 当它成为主方案时怎么做

用户可能自带一份本地报价回来问"要不要换方案"。这个模式一旦比赢，**整个打法要换**。

### 决策维度收缩（必须先讲清这点）

买断模式下要操心的是「耗材结构」；按张付费模式下，下表左侧**全部失效**：

| 作废（与买方无关） | 仍成立（改为向供应商"要求"） |
|---|---|
| 鼓粉分离 / 可自加粉 / 加粉生态 | 月负荷 ≥ 峰值 2～3 倍 |
| 粉盒容量 / 换粉频次 | 速度（决定申报期会不会排队） |
| 单页耗材成本 | 纸盒容量、出纸容量 |
| 兼容耗材单价与保修风险 | 复印 / 扫描 / 输稿器需求 |
| —— | **打印语言（GDI vs PCL/PS）** |
| —— | 系统兼容（Win7 等），可转为**供应商责任** |
| —— | 纸张成本（一般不含纸，仍自付；双面可省约 30%） |

### 三条反直觉但关键的动作

1. **单价固定了，就要"压配置"，不是"压价"。** 同样 0.03 元/张，机器越快、纸盒越大、
   功能越全，买方越划算。**主动向供应商要更好的机器**，而不是继续砍单价。
2. **0.03 元/张已低于行情约 40% 时，不要继续压价** —— 压太狠，服务商会用低配机器
   或放慢响应把成本找回来。谈判火力转到合同条款（见下）。
3. **A3 要翻案。** 早期方案常以"A3 更贵、用不上"砍掉 A3；在按张付费下该理由不成立 ——
   A3 黑白复合机能打 A4，且通常速度更快（25～40ppm）、纸盒更大（1000 页起）、
   月负荷更高、标配双面+复印+扫描+输稿器。**同价或小幅加价就该争 A3。**

### 合同必查清单（本模式的核心价值就在这张纸上）

| 优先级 | 条款 | 要点 |
|---|---|---|
| **必须** | **月最低印量 / 最低消费** | **唯一能让低价变贵的条款。** 若月最低 8,000 张而实际只用 6,400 张，三年白付约 5.76 万张 × 单价。要求：无最低，或不高于实际月均的 80% |
| **必须** | 锁价 | 合同期内单价不变，白纸黑字 |
| **必须** | **备机条款** | 修不好须提供备用机 —— **这是印量包最大的价值点**，对"申报期不能停机"的业务尤其如此 |
| **必须** | 系统兼容责任转移 | 写明"供应商负责接入局域网并确保所内全部电脑（含 Win7）可正常打印及使用金蝶/用友凭证打印；不能满足须无偿调整或更换设备"。**一句条款就把兼容风险从买方转到设备所有方** |
| **必须** | 设备带网口 + 支持 PCL/PS | 拒绝仅 USB、仅 GDI 的机型 |
| 争取 | 速度 ≥30ppm、纸盒 ≥500 页、含复印/扫描/ADF | 单价固定，配置越高越划算 |
| 争取 | 超印单价 ≤ 合同单价；彩色另行锁价；含税开票 | |
| 争取 | 中途解约与残值买断条款 | 服务变差时留退路，用得好可留下 |
| 核实 | 抄表方式（自动联网上报 / 人工读数） | 只涉及页数计数，但要向客户说明数据边界 |

### 交付物：询价包（三步，用户要"能直接发出去"的东西）

不要只给一份分析报告。做成**可直接使用的询价包**，模板见
`templates/supplier-rfq-letter.md`：

1. **询价函** —— 写成「可直接复制发出」的成品正文：我方情况（印量/峰值/幅面/使用方式/
   系统环境）+ 需求（模式/设备要求）+ 逐条待答问题表 + 现场试打要求 + 落款。
   用户拿来填个名字就能发。
2. **候选服务商名单** —— **优先品牌官方授权体系**（授权经销商 / 授权维修站 / 区域总代理 /
   厂商自营租赁），附厂商官方「经销商 / 服务网络查询」入口页。建议给 3～7 家、要求同时询价
   3～4 家，避免单一供应商依赖（供应商跑路 = 机器被收走 = 客户没机器用）。
3. **价格锚点表** —— 用公开可查的价格给用户一把尺子，判断报价虚实
   （例：本地某商 0.03 元/张 · 华东常规行情约 0.05 元/张 · 月租模式 150～600 元/月 + 超印单价）。
   附**谈判底线表**（必须项 vs 争取项），让用户知道哪些不能让。

另配一张 **xlsx 比价表**：核对项 × N 家供应商横向并排，含"谁最优"列，可直接打印给商家填。

### 副产品：把验证过的模式反向打包成客户产品

当用户是**服务型乙方**（财税代理 / 咨询），这套采购经验本身可以变成一项卖给客户的产品
（"办公设备全包，客户只按张付费，什么都不用管"）。**给方案时务必附诚实的期望值管理**：
打印差价很薄（每张 2 分，月印 3,000 张的客户一年毛利才约 ¥720），
**定位应是"增援型产品"**（增加客户每月接触点、提升主服务签约率与客单价、制造转介绍钩子），
**不是独立利润线**。落地只需一步：**向服务商问一句"如果我把客户介绍给你们，
渠道价 / 分润怎么算？"**
渠道洞察：**区域总代理 / 授权维修站本身就有分销体系，且最缺稳定的小微客户流量** ——
双方天然互补，可直接谈渠道合作，不必从零搭供应链。

## Procedure

1. **先答"该考虑什么"**，分组给：业务量 / 成本结构 / 可靠性与售后 / 行业专属坑。
   标出其中「需你确认的前提」。用户明确要求这个顺序 —— 别跳过直接给机型。
2. **核实现役型号与参数**，渠道优先级：
   厂商官网（参数最权威，处理服务政策）→ 中关村在线 ZOL 详情页（参数 + 参考价）→
   京东（实际成交价）→ 行业评测 / 知乎（看真实口碑）。搜索里 SEO 垃圾多，直接抓官网和 ZOL 详情页。
   **同时跑三道门（见核心原则 5）**：型号名照抄官网 → 点开官网「立即购买」链接确认未下架 →
   去驱动下载页核对客户所有在用系统的驱动。三道门全过才进下一步。
3. **搜索用精确组合**：`品牌 + 型号 + 参数 + 耗材型号 + 价格`。
   例：`兄弟 HL-B2080DW 参数 硒鼓 DR-B021 价格`。泛词搜不到有效参数。
   若某型号在电商搜不到明确在售条目，直接标注"国内主销状态存疑，需确认"，不要默默保留。
4. **问清使用方式后再定兼容性结论**（一人一机 / 共享 / 局域网直连）。共享与局域网模式下
   **打印语言（GDI vs PCL/PS）是真判据，不是"支不支持 Win7"** ——
   详见 `references/network-shared-printing-compat.md`。
5. **算三种口径**：购机价 / 年度耗材 / 年度纸张及其他易耗，输出 3 年 TCO。
   **口径必须写明并统一** —— 不能一边用"1.5-3 分"一边用"2.5 分"。
   ⚠ 耗材年费要按**覆盖率折算后的实际页产量**算，不能直接照抄标称页产量，
   否则低估 2～3 倍（见 `references/high-volume-toner-economics.md`）。
6. **把"全包服务"从"对照项"升级为"候选主方案"，用真实报价判胜负。**
   拿用户手里（或本地服务商）的实际元/张报价，与买断路线的**单页综合成本**正面比，
   并做印量敏感性测算（低 / 中 / 高三档）。**若全包 ≤ 买断，就把它作为主方案输出**，
   不要因为用户默认"要买断"就把它降级成一句"多花的钱买到了什么"。
   比赢时按上面「按张付费全包模式」章重排决策维度并输出合同清单。
7. **给 2-3 款不同定位**（最优 / 最省 / 最耐用），每款列：参数、耗材结构、参考价、优势、**风险点**。
   只推一款、或漏写风险点，都算没做完。用一句话说清"为什么主推它"。
8. **采购建议落到合同条款**：保修年限、**上门 vs 送修**、备机条款、耗材单价锁定、
   响应时效、第三方耗材是否影响保修。选型的一半价值在这张清单上。
9. **列"必须先内部确认的 N 件事"** —— 会改变选型的变量，让用户先内部定再询价。
   （老系统机器数量、**打印机使用方式**、复印扫描需求、峰值印量等都属于这类，**不要替用户默认**。）
10. **给"采购前现场必做"的动作清单**，并说清试什么。打印机 = 带用户自己的纸样 +
    一份真实业务软件任务现场试，看三件事：小纸进纸稳不稳、双面卡不卡、驱动是否即插即用。
    **有老系统（Win7）机器时，必须要求商家用客户那台机器现场装机验证驱动，不接受口头承诺。**
    参数表替代不了试打。给链接时优先给**厂商官网的官方店名单页**而非具体 SKU 链接
    （SKU 会下架失效，名单页长期有效）。
11. **交付**：产物先入同名文件夹 → 压成一个 zip → 桌面只留压缩包；
    正文一律给 Windows 盘符路径（见 deliverable-handoff，注意用户名要现场发现，别硬编码）。
    **被多轮追问后的迭代版本要清理旧压缩包**，桌面只留最新一版。

## Quick Reference

| 维度 | 问什么 | 为什么 |
|---|---|---|
| 用量 | 年 / 月 / 峰值分别是多少 | 决定机器档次，只看月均必错 |
| 负荷 | 最大月负荷 vs 建议月印量 | 极限值 ≠ 舒适区 |
| **使用方式** | **一人一机 / 共享 / 局域网直连？** | **决定兼容性判据本身**，不问必被推翻 |
| 耗材 | 一体式 / 鼓粉分离 / 可自加粉 | 单页成本差 3-7 倍，第一顺位（**但全包模式下作废**） |
| 粉盒容量 | 标准 / 高容 / 超大容量 + 换粉频次 | 高印量场景第一优先（**全包模式下作废**） |
| 耗材形态 | 兼容件单价 ÷ 实际页产量（不是形态本身） | 一体式 + 便宜兼容件也能做到 1-2 分/页 |
| 锁耗材 | 是否屏蔽第三方或兼容耗材 | 想省钱会被固件锁死（见 Pitfalls） |
| 售后 | 上门还是送修？几小时响应？ | "不能停机"场景的生死线 |
| 易耗 | 纸张等其他年成本 | 与耗材同量级，最常被漏算 |
| 行业 | 非标规格纸 / 专用软件 / 专用单据 | 头号隐形坑，问漏了推荐必错 |
| **系统兼容** | **办公室是否还有 Win7 及以下？驱动页支持吗？** | **硬门槛**：2023 年后新机普遍不支持 Win7 |
| **打印语言** | **支持的打印语言是 GDI 还是含 PCL/PS？** | **共享/局域网下的真兼容判据**：GDI 机型 Win7 无解 |
| **在售状态** | **官网「立即购买」链接是否仍有效？** | 官网在架 ≠ 在售，下架即生命周期结束 |
| **型号真伪** | **这个型号字符串是从哪一页抄下来的？** | 靠命名规律推演出的型号不存在（见 Pitfalls） |
| **全包单价** | **元/张，含哪些、月最低印量多少？** | 与买断单页综合成本比；最低印量是唯一能让低价变贵的条款 |

## Pitfalls

- **把"最大月负荷"当"建议月印量"用** —— 厂商这两个参数常差几倍，用错就买错档位。
- **惠普"动态安全 (Dynamic Security)"是省钱路线的雷区** —— 固件升级后可屏蔽使用
  非 HP 芯片的硒鼓（HP 官方通告原文："打印机利用动态安全措施，屏蔽使用非 HP 芯片的硒鼓"）。
  凡用户想走兼容耗材 / 自加粉，必须**主动排除**带该策略的机型，并在建议里点名说明原因。
- **"上门 vs 送修"要核实到厂商官网的服务政策页** —— 实例：奔图 A4 激光机型为**送修**，
  仅 A3 机型才上门。对"停机就是损失"的业务，这条比机器参数重要。默认往合同里写"上门"。
- **漏算纸张 / 易耗** —— 只算机器和硒鼓会低估约三成总成本，而这笔钱和耗材同量级。
- **忽略换粉频次** —— 高印量（月均数千张）只问单页成本、不问粉盒容量，会选到小粉盒机型，
  结果每月都要盯粉、申报期最容易半途没粉。优先支持超大容量粉盒（如 11,000 页级）的机型。
- **漏算成像鼓 / 把幅面折算错套到鼓上（2026-10）** —— 鼓粉分离的"鼓"同样是经常性耗材、按物理张数算：
  月印 6,400 张时 1 万页鼓约 1.5-2 个月一换、年约 6.4 个，只谈粉盒会低估年耗材。且 A5 只省碳粉
  （面积减半）、不省鼓（过一张算一张）——幅面折算只对碳粉成立，对外谈外包价也同用此口径。
  详 `references/page-size-and-drum-economics.md`。
- **把"粉盒越大越省"当跨机 / 跨牌定律** —— 它在同一台机器的标准 / 高容 / 超高容之间基本成立；
  跨机器不能只比粉盒大小（京瓷原装粉盒再大也约 0.14 元/页，比小粉盒走兼容粉贵好几倍）。
  正确表述：大粉盒 × 可自加粉 / 兼容粉便宜 两个条件同时满足才划算。
- **直接把标称页产量当作耗材预算依据** —— 标称按 ISO/IEC 19752 的 **5% 覆盖率**计，
  财税凭证 / 报表实际覆盖率 15%～30%，实际页数只有标称的 **1/3～1/2**。
  备货按标称打对折甚至 1/3 算，并让客户用自己的凭证+报表实测一盒。
- **断言"一体式一定比鼓粉分离贵"** —— 判据是**兼容件单价 ÷ 实际页产量**，不是耗材形态。
  实测：佳能 CRG070H 一体式（10,200 页）+ 兼容件 ¥80～180/支 ≈ 1～2 分/页，与鼓粉分离相当。
- **行业专属规格不问清就推荐** —— 财税行业的凭证纸是非标小尺寸（A4 整张 / A5 半张 /
  240×140 专用纸），必须核对：驱动能否自定义尺寸、进纸机构对小纸是否稳定（易歪斜、易多张）。
  其他行业同理（标签纸、票据、多联复写单）。
- **按过期型号做对比** —— 用户或同事给的旧文档里可能是已停产/换代的型号。核实"现役在售"再对比。
- **⚠ 用命名规律推演型号名（2026-10 实测翻车）** —— 凭"D=双面 / W=无线"的规律推出了
  **不存在的"奔图 P3016DW"**，写进交客户的交付文档，连错两版、返工两次，
  还把该型号写进技能库、污染了多个后续会话。**型号名只能从厂商官网 / 电商页照抄，永不推演。**
  交付文档里出现的每个型号，都必须能在厂商官网找到同名产品页。
- **⚠ 把"厂商官网有产品页"当成"能买到"** —— 官网会常年保留停售机型，
  其「立即购买」按钮指向的链接已变成"商品已下架"。实测：奔图 P3016D、BM5100FDW
  的官方购买链接双双下架。**落笔前必须点开链接验证在售。**
- **⚠ 用产品页规格表判断系统兼容（尤其 Win7）** —— 规格表常保留老系统字样，
  驱动下载页未必真放出驱动。**必须以厂商「驱动下载」页逐型号确认。**
  Win7（2020-01 已停支持）是老办公环境的硬门槛，这条会直接决定机型范围。
- **⚠ 把未核实"在售 + 系统兼容"的型号写进交付文档** —— 这是本类任务最大的返工源。
  顺序必须是：核实型号真实存在 → 核实 SKU 在售 → 核实系统兼容 → 才算可推荐。
  详见 `references/model-availability-verification.md`。
- **⚠ 不问清"使用方式"就下系统兼容结论（2026-10 实测）** —— 只要还在按"每台电脑都要装驱动"
  的 USB 直连逻辑谈 Win7，结论就是脆的。**共享 / 局域网下真判据是打印语言 GDI vs PCL/PS。**
  同理，**GDI 机型（仅主机型）在共享/局域网下是死结** —— 它靠电脑端专用驱动渲染，
  客户端必须装厂商驱动，没有 Win7 驱动就绕不过去；PCL/PS 机型可用 Windows 通用驱动。
  实测：奔图 P3010DW / P3019DW 打印语言**仅 GDI**（据此出局，多一条排除理由）。
- **⚠ 忽略共享打印的 SMB1 坑** —— Win10 / Win11 默认**关闭 SMB1**，而 Win7 访问共享打印机
  依赖它（常见症状：连不上、资源管理器崩溃）。**"USB 接一台电脑再共享"这个做法本身还有
  单点故障**：那台电脑必须 24 小时开机，它一关机全公司停工。带网口走局域网直连才是正解。
- **⚠ 把"按张付费全包"永远只当对照项** —— 全包单价一旦 ≤ 买断的单页综合成本，
  它就是主方案。实测 0.03 元/张全包 < 买断自加粉 0.031～0.034 元/页，且首期零投入、
  零维修风险、零加粉管理，"申报期不能停机"的场景下风险转移比省的那点钱更值钱。
  错过它 = 给用户一个更贵更操心的方案。
- **⚠ 在全包模式里继续谈耗材结构 / 继续压单价** —— 耗材维度已作废，讲它是答非所问；
  单价低于行情约 40% 还继续压，服务商会用低配机器或放慢响应找回来。
  这个模式下该做的是**压配置 + 攻合同条款**。
- **⚠ 换方案时不显式声明旧结论失效** —— 用户被追问多轮后，脑子里留着上一版的结论。
  换模式时必须专门写一节「哪些作废 / 哪些仍成立」，逐条对照，否则用户会拿着过期结论去谈。
- **只推一款** —— 用户要的是"两三款"，且要能看出各自的代价。单款推荐等于没给选择。
- **默默接受别人拍的"不需要"边界** —— 复核他人文档时，别人砍掉的功能要质疑一次。
  实例：旧文档砍掉扫描/复印，但财税公司每天要复印执照、扫描进项发票归档。
  把质疑写清楚 + 让用户定夺，不要默认接受。

## Verification

- 每个参数和价格都能指出来源吗？价格是否标注"参考价，以询价为准"？
- **三道门过了吗？** ① 每个型号都能在厂商官网找到同名产品页 ②「立即购买」链接未下架
  ③ 驱动下载页覆盖客户所有在用系统。三道门全过才允许出现在交付文档里。
- **问过"打印机使用方式"了吗？**（一人一机 / 共享 / 局域网直连）没有的话，
  所有系统兼容结论都不算成立。
- **共享 / 局域网场景下，报出的机型支持 PCL/PS 吗？（避开仅 GDI）**
- **全包 / 按张付费报价与买断的单页综合成本正面对比了吗？做印量敏感性测算了吗？**
- **若换了主方案，是否单列了「旧结论作废 / 仍成立」对照表？**
- **合同清单给了吗？其中是否包含月最低印量、备机条款、系统兼容责任转移？**
- TCO 口径统一吗？是否包含易耗品（纸张）？耗材年费是否按**折算后的实际页产量**算？
- "该考虑什么"和"推荐哪几款"两个问题都答了吗？
- 复核场景：采纳 / 修正 / 增量三段都写了吗？每条修正都带依据吗？
- 是否给出了"必须先内部确认的 N 件事"？其中是否包含"办公室老系统机器数量"？
- 是否给了"采购前现场必做"的动作（试打 + 老系统现场装机验证）？
- 交付物是"分析报告"还是"能直接发出去的东西"（询价函 / 比价表 / 候选名单）？
- 产物是否已打包 + 给了 Windows 盘符路径？旧版压缩包是否已清理？
