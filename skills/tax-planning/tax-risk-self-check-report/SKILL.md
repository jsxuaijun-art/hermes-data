# 税收风险自查报告 撰写方法论

## 概览

客户收到税务机关《税务事项通知书（风险提示专用）》后，需在规定期限内提交
《税收风险自查报告》。这是财税代理机构的日常涉税文书，与 corporate-tax-planning
（筹划方案设计）是不同工作流：后者面向客户做方案，本文书面向税务机关做回应。

**核心原则：报告交给税务机关，两级结论必须一致、法条必须真实。**

## When to Use

- 客户收到税务风险提示/风险疑点，需要出具自查报告
- 完善/修订已有自查报告草稿（常见问题：内部结论矛盾、法条引用臆造）
- 用户只要求"列明法律法规条文文号"（此时给表格，不解释）

## 工作流程

```
① 读取原始报告全文（read_file 支持 .doc/.docx 自动转换）
② 通读找结构性矛盾：风险点自查结论与总补缴金额/其他章节是否打架
③ 涉税定性：先想清楚该笔业务的税法定性再动笔（如合伙企业"先分后税"）
④ 联网核对法条官方原文：fgk.chinatax.gov.cn（国家税务总局政策法规库）
   + xzfg.moj.gov.cn（国家行政法规库），确认文号、条款号、条文内容
⑤ 用 python-docx 生成 .docx（见 references/ 的 docx 配方）
⑥ 解包 XML 校验：zip 完整性 + 关键金额/文号字符串存在
⑦ 交付 Windows 桌面/D盘相应目录，报告改动要点
```

## 报告结构模板

```
标题：税收风险自查报告
抬头：<公司全称>（以下简称"××"）
引言：收到《税务事项通知书（风险提示专用）》（编号：__），依据征管法、
      企业所得税法等自查，共确认风险事项N项，应补缴XX年度企业所得税
      X,XXX,XXX.00 元（不含滞纳金）
一、企业基本情况（全称、统一社会信用代码、成立日期、经营范围）
二、风险自查情况
    （一）<风险点名称>
        1．风险描述（时间线+金额，写清每笔款项性质）
        2．涉税分析及法律依据（逐条列法条，先定性再引条文）
        3．自查结论（确认/排除，必须与其他章节一致）
        4．举证材料（附件1/2/3...）
三、其他涉税事项自查情况
    （一）增值税自查情况（法条+检查清单+结论）
    （二）企业所得税自查情况
    （三）其他税种自查情况（印花税/城建税及附加等）
四、涉税风险确认及整改承诺（金额、滞纳金、整改承诺）
联系人/联系电话 → 公司全称（加盖公章）→ 法人代表、财务负责人签章 → 日期
另页：相关举证材料目录（序号/材料名称/页码）
```

## 用户格式规则（盈信财税标准，硬性）

1. **数字统一 Times New Roman**；金额以元为单位、加千分位符：`510,000.00`、
   `2,040,000.00`。生成 docx 时给 run 设 `ascii=Times New Roman` +
   `eastAsia=宋体/黑体`，数字自动走 TNR、中文走中文字体。
2. **企业名称首次出现用全称**，后加（以下简称"××"），此后一律用简称。
3. **法条引用必须真实**：文号、条款号必须对照官方原文核实，绝不臆造、编造。
   这是用户红线（与公众号铁律一致）。
4. 用户说"只需列明条文/不需要解释"时 → 直接给表格：
   `| 序号 | 文号/法条 | 文件名 | 关键内容 |`，不写任何解释。

## Pitfalls（实战教训）

1. **两级结论矛盾是致命伤**（GFSBDT案例教训）：草稿第X行写"暂排除该涉税风险"、
   后面又写"确认补缴510,000元"，直接打架。提交前必须全文一致性检查，统一为
   一个结论。"对方不给撤资证明/未做股权变更登记"不是不缴税的依据——先分后税
   下收到分利就是应税所得，公示系统显示仍为投资人也不影响纳税义务。
2. **法条先核对再引用**：引用前用 web_search 查 fgk.chinatax.gov.cn 官方原文，
   确认文号、条款号、关键措辞（如实施条例第83条"直接投资于其他居民企业"）。
3. **"逾期三年未收款=可税前扣除"是认知误区**：坏账损失税前扣除须符合
   国家税务总局公告2011年第25号条件（实际资产损失+完整证据链），逾期三年只是
   条件之一；以前年度追补扣除限5年（详见 references/）。
4. **金额口径要首尾一致**：风险描述金额、自查结论金额、总补缴金额、整改承诺
   金额四处必须全部相等，且与税率测算吻合（如 2,040,000.00 × 25% = 510,000.00）。
5. **《税务事项通知书》编号、联系人、日期**是留空占位项，交付时提醒用户补填。

## 已核验法条速查（官方原文核对过）

### 合伙企业法人合伙人（"先分后税"）

- 《企业所得税法》第一条第二款：合伙企业不适用本法
- 《企业所得税法》第六条：收入总额含"股息、红利等权益性投资收益"
- 《企业所得税法》第二十六条：符合条件居民企业间股息红利免税
- 《企业所得税法实施条例》第八十三条：免税限"直接投资于其他居民企业"；
  合伙企业非居民企业 → 法人合伙人分得所得不适用免税
- 财税〔2008〕159号：先分后税；法人合伙人缴企业所得税；当年留存利润也要并入；
  亏损不得抵减法人合伙人其他盈利
- 《企业所得税法》第四条（25%）、第五条（应纳税所得额）、第五十四条（汇算清缴）
- 《税收征收管理法》第三十二条：滞纳金 0.05%/日

### 坏账损失税前扣除

- 国家税务总局公告2011年第25号《企业资产损失所得税税前扣除管理办法》
- 国家税务总局公告2018年第15号（申报管理/留存备查）
- 追补扣除以前年度损失限5年
