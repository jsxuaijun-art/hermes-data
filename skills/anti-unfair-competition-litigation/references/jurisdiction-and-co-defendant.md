# 管辖选择 与 共同被告（股权连带）论证

来源：2026-10 苏州盈信诉企优托/好账本 商业诋毁案实案核验（法条按现行有效文本）。

## 一、管辖

### 地域管辖
- 依据：《最高人民法院关于适用〈反不正当竞争法〉若干问题的解释》（法释〔2022〕9号，2022-03-20施行）第26条：
  “因不正当竞争行为提起的民事诉讼，由**侵权行为地或者被告住所地**人民法院管辖。”
- 侵权行为地＝实施地 + **结果发生地**（《民诉法解释》第24条）；信息网络侵权中，结果发生地可含**被侵权人住所地**
  （《民诉法解释》第25条 + 最高法《关于审理利用信息网络侵害人身权益民事纠纷案件适用法律若干问题的解释》第2条）。
- 实务结论（有生效判例背书：“商业诋毁案件：原告住所地法院具有管辖权”，可见于律所/最高院裁判案例摘要）：
  网络商业诋毁/虚假宣传，**可在原告住所地（＝侵权结果发生地/被侵权人住所地）基层法院立案**。
- 风险：被告常在住所地（另一区）提**管辖异议**。应对：备选以“被告住所地”法院立案为退路，不比拼到知产法庭。

### 级别管辖（江苏口径）
- 江苏高院《关于明确全省法院知识产权民事案件级别管辖标准的通知》：
  发生在苏州市辖区、**诉讼标的额 200 万元以上**的商标/著作权/不正当竞争/技术合同纠纷 → 中院（知产法庭）；
  **200 万以下 → 基层法院一审**。
- 本类“诋毁差评”案标的额通常 5万–数十万，归基层；诉请金额写法=“暂计 X 万（以法院认定为准）”，不虚高连累级别与受理费。

### 立案前动作
- **电话向拟起诉法院立案庭确认收案口径**（“商业诋毁＋虚假宣传”第一审是否收、以何连接点），再定稿“此致 某某人民法院”。
- 诉状“此致”写原告住所地法院可接受；被异议则按退守方案改被告住所地法院，重出诉状。

## 二、共同被告 / 连带责任论证（股权穿透）

### 场景
榜单第一名（好账本）≠ 发布者（企优托），但同属一个集团：需把两者拉为共同被告主张连带。

### 首选证据链条（国家企业信用信息公示系统，可打印/存证“股权穿透”）
```
被告一(集团) ──100%──▶ 中间层公司 ──100%──▶ 被告二(榜单第一品牌运营主体)
```
→ 被告二系被告一的**间接全资子公司（孙公司）**。

### 措辞硬规
- **写“被告二系被告一的间接全资子公司（孙公司）”**，证据里写清持股 100% 的完整链条（含中间层公司）。
- **勿仅写“母子公司”**——经中间层控股不是直接母子，写“母子公司”不精确，会被对方以“非直接控股、无关联”抗辩。
  反例教训即本次：起诉状初稿写“两被告系母子公司关系”，核后改为“间接全资孙公司＋同址”。

### 三证互证（人员/场所混同 → “一套班子多块牌子”）
1. 股权穿透（含中间层、100%）；
2. 两被告**同址**：同园区、同楼层（如“建业科技园D区二层”企优托 2012 室 vs 好账本 2045 室）；
3. 官网“多品牌矩阵包含于集团”自述页 + 关联域名。

### 责任基础与决策点
- 《民法典》第1168条（共同侵权）、第1169条（帮助侵权）→ 连带责任。
- 决策点（起诉前定）：能证股权/同址/矩阵关联 → 列告、主张连带；证不了 → **撤回对被告二**、聚焦主被告，
  不拖累立案与整体认定 —— 起诉状里不要留“如撤回则不需”这类跟结论矛盾的括注。

### 证据清单新增项
- 被告一→中间层→被告二 股权穿透打印/截图（含中间层公司、持股比例 100%）；
- 两被告登记住所地（国家企业信用信息公示系统）页面（证同址）；
- 被告官网“多品牌矩阵”自述页及关联域名公证/存证。
