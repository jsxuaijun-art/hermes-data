## 粤语化改造方法论

### 核心原则

> **「唔似翻译，似倾偈」** — 不是拿普通话文案逐字翻成粤语，而是直接用粤语思维写。

### ⚠️ 核心纪律：不要从普通话翻译（本skill第一重要规则）

**这是写粤语脚本最常见的坑，也是用户最敏感的雷区。**

过去的做法（已被用户纠正）：
```
写普通话版 → 词汇替换（的→嘅 是→係）→ 语序调整 → 润色
```
❌ 这本质上是**翻译思维**。逐字替换的结果是「普语粤讲」——广东人一听就觉得怪。

正确的做法（用户明确要求的）：
```
直接用粤语想 → 直接用粤语写 → 检查有没有无意中带了普语句式 → 调整
```
✅ 这是**母语思维**。广东人一听就觉得「自己友」。

**判断是否「翻译腔」的黄金标准：**
- 读出来顺不顺？如果觉得在「读翻译稿」，那就是翻译腔
- 将一句粤语「原封不动」用普通话读——如果听着也通顺，那就有问题
- 真正地道的粤语句子，直接用普通话读是**不通顺**的

**实战对比（来自用户真实反馈）：**

| 维度 | ❌ 翻译腔版本（被纠正） | ✅ 地道版本（用户认可） |
|:--|:--|:--|
| 开头 | 「你知唔知啊，一个广东人出到外省做嘢，最挂住嘅係咩？」 | 「你估下——一個廣東人出到外省，最掛住嘅係咩？」 |
| 问题 | 「你知道吗」粤语是「你知唔知」，但真正自然的问法是「你估下」 | 本土提问方式 |
| 回忆 | 「我自己啱啱毕业嗰阵」 | 「我啱啱畢業嗰陣」去掉多余的「自己」 |
| 惊讶 | 「咦？早晨饮茶食点心？呢班人唔使返工㗎？」 | 「嘩！朝頭早就飲茶食點心？呢班人唔使返工㗎？」 |
| 问题 | 「咦」偏书面，「早晨」不是地道说法 | 「嘩」+「朝頭早」才是廣東人自然反應 |
| 比喻 | 「你饮惯咗老火汤，再去饮清水，就係唔係嗰个味」 | 「你飲慣咗阿媽煲嘅老火湯，返轉頭去飲清水，點都唔係嗰回事㗎喇」 |
| 问题 | 缺少情感锚（阿妈），语序平铺 | 「阿媽煲嘅」+「返轉頭」+「㗎喇」三重地道 |
| 收尾 | 「以后用到就唔使周围搵」 | 「以後用嘅時候就唔使周圍問人」 |
| 问题 | 「周围搵」偏直译 | 「周圍問人」更符合广东人表达习惯 |

**实操口诀：**
- 写之前先想「如果我是广东人，我会怎么跟老乡说这句话？」
- 不逐字对照普通话版，写完一整段再回头看有没有「普语底」
- 卡住了就问自己：这句广东话我会不会在茶楼跟朋友讲？


### 粤语层级选择

**核心原则：以「粤語（香港）(zh-HK)」为标准。**
这是用户明确指定的方向，也是所有粤语脚本的基准。

| 层级 | 特征 | 适用情况 |
|:--|:--|:--|
| **香港粤语（标准）** | zh-HK，词汇偏古典+自然混英文 | ✅ **主要内容，95%的文案用这个** |
| 广府粤语 | 广州话发音+地道用词 | ⚠️ 偶尔点缀，内容兼顾广东观众 |
| 粤语俚语 | 「搞掂」「放飛機」、「bookmark先」 | ✅ 精选用，增加地道感 |
| 地方土话 | 黄/佛/莞等地特有 | ❌ 避免，非目标受众听不懂 |

**香港粤语 vs 广东白话的关键区别：**
1. **用词更古典**：「後生仔一名」而非「後生仔一個」，「朝早」而非「朝頭早」
2. **英文自然混入**：「bookmark先」「check下」「confirm俾你」等
3. **部分词汇不同**：「琴日」(HK) vs「尋日」(廣州)
4. **语气词略有差异**：HK 多用「嘅」在某些场景替代「㗎」
5. **目标群体**：在苏沪的香港人及广东人，以香港人为核心

> 详细对比见 `references/香港粤语vs广东白话差异指南.md`

### 粤语句式转换规则

#### 规则1：语序调整

| 普通话句式 | 粤语句式 | 例子 |
|:--|:--|:--|
| 我先走 | 我走先 | 「我讲完先」 |
| 多给一点 | 俾多啲 | 「俾多啲时间」 |
| 我比你大 | 我大过你 | 「我经验多过你」 |
| 你先去 | 你去先 | 「你去办先」 |
| 给我一个 | 俾我一个 | 「俾我一个电话」 |

#### 规则2：否定式

| 普通话 | 粤语 |
|:--|:--|
| 不知道 | 唔知 |
| 不是 | 唔係 |
| 不要 | 唔好/唔使 |
| 不能 | 唔可以/唔得 |
| 没有 | 冇 |

#### 规则3：量词差异

| 普通话 | 粤语 | 例子 |
|:--|:--|:--|
| 一个人 | 一个人 | 同义 |
| 一张桌子 | 一张枱 | 同义多用「张」 |
| 一台电脑 | 一部电脑 | 用「部」 |
| 一辆车 | 一架车 | 用「架」 |
| 一件事 | 一件事 | 同义 |
| 一家公司 | 一间公司 | 用「间」 |

#### 规则4：粤语特色句式

- **「有+动词」**：「你有冇注册公司？」（你有没有注册公司？）
- **「动词+得/唔+补语」**：「搞唔搞得掂？」（搞不搞得定？）
- **「好+形容词」**：「好简单、好快」（非常简单、非常快）
- **「同...讲」**：「我同你讲个真实案例」（我跟你说个真实案例）
- **「俾...」**：「俾你一个建议」（给你一个建议）

### 粤语文案打磨三步法（先写粤语，再用此验证）

**⚠️ 注意：这不是「翻译方法」，是「写完粤语版后检查地道的验证工具」**

正确的流程：
```
Step 0 — 直接用粤语写初稿（母语思维，不看普通话版本）
Step 1 — 词汇审查：检查是否有普语词混入（见下方对照表）
Step 2 — 语序审查：检查是否有普语句式残留（「我先走」→「我走先」）
Step 3 — 地道润色：加语气词，调整自然度
```

| 步骤 | 操作 | 示例 |
|:--|:--|:--|
| Step 0 — 粤语初稿 | 直接用粤语思维写作，不参考普通话 | 「你估下，一個廣東人出到外省最掛住嘅係咩？」 |
| Step 1 — 词汇审查 | 找出可疑的普语词，换地道粤语词 | 「早晨」→「朝頭早」，「什么」→「咩」 |
| Step 2 — 语序审查 | 把普语句式扭正 | 「总觉得少了点什么」→「個心硬係覺得爭啲嘢」 |
| Step 3 — 地道润色 | 加语气词，让句子有「人味」 | 句尾加「㗎」「喇」「啦」「啫」 |

**语气词插入规则**（让粤语更地道的关键）：

| 语气词 | 用法 | 示例 |
|:--|:--|:--|
| 啦 | 句末，轻松肯定 | 「好简单嘅啦」 |
| 啫 | 句末，轻描淡写 | 「几百蚊啫，湿湿碎」 |
| 咋 | 句末，仅此而已 | 「三日就搞掂咋」 |
| 㗎 | 句末，强调/反问 | 「你唔知㗎？」 |
| 啦喂 | 句末，提醒/催促 | 「快啲啦喂」 |
| 嘛 | 句末，理所当然 | 「就係咁简单嘛」 |

### ⚠️ 粤语表达禁忌

| 禁忌 | 原因 | 正确做法 |
|:--|:--|:--|
| **翻译思维写粤语** ⚡ | **这是用户最敏感的雷区**。逐字从普通话翻译，广东人一听就觉得「假」 | 直接用粤语思维写，不参考普通话版本 |
| 硬译普通话句式 | 「他是这样说的」→「佢係咁話嘅」✅ 而非「佢是這樣說的」❌ | 用粤语思维重写整个句子 |
| 过度使用俚语 | 「食死猫」「呃鬼食豆腐」等俚语年轻广东人也不一定懂 | 精用，一条视频最多1-2个 |
| 粤语拼音/音标 | 视频文案中不要出现jyutping/粤拼 | 纯汉字粤语表达 |
| 广东各地土话 | 「异咗」(客家)/「因住」(香港过时)等 | 坚持香港粤语(zh-HK)标准 |
| 笑粤语不标准的人 | 有人为了效果故意说"煲冬瓜"（不标准普通话） | 不靠嘲笑语言差异制造笑点 |

> 详细对比见 `references/粤语实战案例-翻译腔vs地道版.md`

## 平台运营策略

### 视频号（主阵地）

**为什么视频号最适合起步：**
- 视频号用户偏成熟，广东人在外省做生意的比例高
- 粤语内容在视频号属于「蓝海」，竞争远低于抖音
- 视频号可以快速利用微信社群传播（广东同乡群/商会群）
- 视频号算法对冷启动更友好

#### 「粤语打人设」冷启动三步法

**第一阶段：人设立住（第1-10条）**
- 全部用香港粤语出镜
- 内容：自我介绍+为什么一个香港人在苏州做商事登记
- 开头固定句式：「大家好，我係苏州做公司注册嘅徐经理，喺香港大嘅...」
- 每条结尾引导收藏：「觉得有用就bookmark先，以後一定用得着」
- 前10条完成人设锚定+粤语印象

**第二阶段：价值输出（第11-30条）**
- 香港粤语为主，偶尔穿插普通话+粤语双版本
- 开始出现商事登记干货，解决实际问题
- 每条必须具备「收藏价值」——收藏率是视频号第一权重
- 开头钩子+中间干货+结尾粤语亲切收尾

**第三阶段：转化收割（第30条后）**
- 粤语自然融入，不再刻意强调
- 70%商事登记+30%轻财税
- 开始出现客户案例（用粤语讲「我有个客...」）
- CTA从「bookmark先」变为「私信我」或「评论区见」

#### 视频号粤语内容黄金结构

```
[0-3s]  粤语钩子  — 「你估下...」/「好多人都唔知...」
[3-15s] 业务切入  — 用粤语讲一个常见误区/客户故事
[15-50s]专业价值  — 解法+干货+实操建议
[50-55s]粤语收尾  — 「搞唔掂就搵我啦，实帮你搞掂」
[55-60s]CTA      — 「bookmark先，以後用嘅時候就唔使周圍問人」
```

**关键节奏**：粤语开场抓住乡愁→普通话或双语讲干货→粤语结尾拉回亲切感

### 抖音（建议策略）

#### 抖音与视频号的区别

| 维度 | 视频号 | 抖音 |
|:--|:--|:--|
| 用户年龄段 | 30-55岁为主 | 18-45岁为主 |
| 粤语内容竞争 | 蓝海（很少） | 红海（很多粤语博主） |
| 冷启动难度 | 低（私域助推） | 高（纯公域赛马） |
| 广东人精准触达 | 一般 | 强（标签系统成熟） |

#### 建议打法

**如果不做粤语（推荐起步）**：
- 普通话版内容，切商事登记痛点
- 标题和封面用激烈数字/反差吸引点击
- 内容同步视频号文案即可，不需要单独制作

**如果做粤语**：
- 与视频号共用文案，但改标题/话题标签
- 利用抖音标签系统：#粤语 #公司注册 #苏州创业 #上海创业
- 不建议纯粤语，抖音用户对粤语接受度低于视频号
- 最佳配比：粤语开场（5秒）+普通话主体+粤语彩蛋结尾

#### 最佳抖音内容类型

| 类型 | 适合徐经理吗 | 理由 |
|:--:|:--|:--|
| 知识口播 | ✅ 首选 | 门槛低，商事登记天然适合，配合字幕即可 |
| 对话/情景剧 | ⚠️ 可选 | 需要两个人，人手不够不建议搭场景 |
| Vlog办公日常 | ✅ 可做 | 「广东人在苏州的一天」类内容天然有传播力 |
| 行业揭秘 | ✅ 高潜力 | 「代辦公司內部唔話你知嘅嘢」类是爆款密码 |

### 小红书（建议策略）

**定位不同**：小红书不是「短视频平台」而是「种草+搜索平台」

| 维度 | 小红书特性 | 适配策略 |
|:--|:--|:--|
| 用户画像 | 70%女性，25-35岁 | 重点方向：女性创业/开工作室的注册问题 |
| 内容形式 | 图文为主，视频为辅 | 发布"图文笔记"比纯视频更高效 |
| 搜索流量 | 占50%+流量 | 标题=核心关键词，如「苏州注册公司流程2026」 |
| 粤语 | 非常少见 | 建议普通话，笔记正文可在末尾加粤语彩蛋 |

#### 小红书落地三件事

1. **图文笔记**（每周2-3篇）
   - 标题：关键词前置，如「苏州注册公司｜个体户vs有限公司的区别」
   - 正文：分点+emoji，轻阅读
   - 封面：纯色底+大字号标题

2. **视频笔记**（每周1条，同步视频号内容）
   - 封面必须重新做（小红书封面尺寸3:4）
   - 标题改为小红书风格：emoji+关键词+悬念

3. **评论区运营**
   - 每条笔记发完后自己留一条引导评论
   - 回复及时，态度诚恳

## 工作流程

### 日常选题→发布流程

**⚠️ 关键纪律**：Step 3 是用粤语思维写初稿。不允许先写普通话版再翻译。详见「核心纪律：不要从普通话翻译」。

```
Step 1 — 选题
  ├─ 常规选题：按日历轮换（设立/变更/注销/案例）
  └─ 热点选题：监控新闻/热搜→找切入点→问江姐确认

Step 2 — 确认钩子
  ├─ 确定核心钩子和业务植入点
  └─ 想好粤语开场方式（用粤语思维想钩子）

Step 3 — 直接写粤语初稿
  ├─ 不用写普通话版，直接用香港粤语写
  ├─ 如果不是母语写作者：先用粤语想好每句的意思，直接落笔
  └─ 完稿后对照检查：有没有「普语底」混入（详见粤语文案打磨三步法）

Step 4 — 拍摄
  ├─ 直面镜头口播
  ├─ 粤语开场（0-3秒）→ 粤语/双语主体 → 粤语收尾
  └─ 字幕加粤语汉字（不做粤拼）

Step 5 — 发布
  ├─ 视频号：主阵地，粤语版首发
  ├─ 抖音：剪映改封面/标题，普通话版或双语版
  └─ 小红书：改封面尺寸+标题风格+图文笔记同步
```

### 热点响应流程

利用 `short-video-industry-flow` skill中的热点事件处理流程，增加粤语适配步骤。

**⚠️ 注意：以下是粤语写作流程，不是翻译流程。不写普通话底稿，直接用粤语写。**

```
Step 1 — 收到热点/江姐给视频
Step 2 — 分析热点内核 → 找商事登记映射点（用粤语想切入点）
Step 3 — 直接用香港粤语写文案（参考6大切入角度）
Step 4 — 粤语打磨（三步法：词汇→语序→语气词）
Step 5 — 快速拍摄+发布（热点有时效，当天出片）
```

### 文案→粤语转化工作流（从江姐Skill复用）

当徐经理想获得粤语版文案时，提供以下服务：

1. **输入**：一个选题方向/热点事件/普通话初稿
2. **我做的**：
   - 如果只有选题 → 先出普通话基础版文案
   - 如果有普通话初稿 → 直接做粤语化改造
   - 输出标准粤语文案（纯汉字，带语气词标注）
   - 标注粤语发音提示（仅对可能混淆的字词）
3. **输出格式**：

```
📍 标题（粤语）：《你知唔知注册公司有几多个坑》
📍 标题（普通话备选）：《注册公司这几个坑，九成老板不知道》
时长：60秒 | 风格：直面口播 | 语言：粤语
话题标签：#粤语 #公司注册 #苏州创业 #工商变更

粤语文案：
【0-3s】你估下，注册公司其实有几个坑，好多人踩过。
【3-15s】琴日有个客揾我，佢话注册咗公司半年，一毛钱生意都未做...
【15-50s】实际解决方法...（粤语主体）
【50-55s】搞唔掂就搵徐经理，实帮你搞掂。
【55-60s】觉得有用就bookmark先，以後用嘅时候就唔使周围问人。

粤语发音提示：
- 「琴日」= 昨天（kam4 jat6）
- 「揾我」= 找我（wan2 ngo5）
- 语气词「啦」发 laa1 音，不要发 laa3
```

## 拍摄指南

### 口播风格

| 要素 | 建议 |
|:--|:--|
| 语速 | 中等偏慢，粤语本身比普通话快，要刻意放慢 |
| 语气 | 温和亲切，像一个懂行的老乡在跟你聊天 |
| 表情 | 自然微笑，不要板着脸讲干货 |
| 手势 | 适当配合，不要太夸张 |
| 着装 | 商务休闲（Polo衫/衬衫，不要西装革履） |

### 视觉风格

**推荐风格**：纯色背景 + 半身口播 + 大字幕

| 元素 | 说明 |
|:--|:--|
| 背景 | 纯浅色（灰/白/浅蓝），或办公室实景 |
| 镜头 | 手机横屏/竖屏均可，眼睛看镜头不要看屏幕 |
| 灯光 | 面光充足，避免顶光造成的阴影 |
| 字幕 | 粤语用粤语汉字，关键数据加粗/变色 |
| 封面 | 标题大字+个人头像，风格统一 |

### 场景建议

- **主场**：办公室书桌前（背景有书/文件，显专业）
- **变化**：偶尔拍外景（在市场监管局门口/在办事大厅）
- **Vlog**：去办事的路上拍几句「今日去帮客搞变更...」

## 数据反馈与优化

### 核心指标（按权重排序）

```
收藏率 > 复访率 > 铁粉互动 > 5秒完播 > 整体完播 > 评论 > 点赞 > 转发
```

### 粤语内容的特殊指标

| 指标 | 健康值 | 含义 |
|:--|:--|:--|
| 粤语评论占比 | >30% | 说明真的触达了广东人 |
| 「广东人报到」类评论 | 每百条>5条 | 粤语人设打中了 |
| 私信：「我也是广东人」 | 每周>3条 | 社群效应启动 |
| 粤语视频完播率 | 高于普通话版10%+ | 粤语内容留人更强 |

### 优化决策树

```
完播率高 | 收藏率高  → 按此模式批量出5条（上限）
完播率高 | 收藏率低  → 优化内容干货密度，增加实操价值
完播率低 | 收藏率高  → 重做前5秒钩子
完播率低 | 收藏率低  → 换选题方向，这个角度不通
粤语评论少            → 检查粤语是否太「翻译腔」
```
