# 月度税政巡查简报 · 交付三件套模板

用途：每月例行巡查产出三份交付物，按本模板结构写，保持口径一致、方便 WorkBuddy 对照。
范本：2026-09 首轮已实测（详见 /mnt/d/obsidian-vault/50-Skills/tax-audit-response/法规巡查/）。

## 1) vault 详细简报（主档）
路径：/mnt/d/obsidian-vault/50-Skills/tax-audit-response/法规巡查/YYYY-MM-DD-税政变动简报.md
结构：
- 巡查概况（日期 / 方式 / 覆盖范围）
- 新发布 / 新施行（文号 + 施行日 + 要点）
- 废止 / 失效（文号 + 替代文件；重点盯总局《失效废止部分税务规范性文件目录》清理批次）
- 待核项结论（把 skill 中标「待核」的文号逐一给现行性结论：全文有效 / 条款修订 / 已废止+替代）
- 对 tax-audit-response 的影响（是否需改 02/04；若改，SKILL.md 版本记录加 `vX.Y 因法规巡查更新：...` 一行）
- 在途变动提示（如增值税法实施后的后续清理、征管法修订进展）

## 2) 桌面提醒简版
路径：C:/Users/Admin/Desktop/本月税政变动简报-YYYY-MM.md
开头第一行醒目标注：「请查看本月税政有无变化」。
结构：
- 巡查要点（一两句结论先行，如"核心文号全部现行有效"）
- 最重要发现（有则写；无则写"本月无重大变动"，不硬凑）
- 对咱们的影响（是否波及 tax-audit-response 案由）
- 需注意文号（⚠️ 列表，如"引用时按现行条款"）
- 指向 vault 详细版链接
- 落款：Hermes 税政法规巡查（tax-regulation-monitor skill）

## 3) WorkBuddy 同步简报（六段式）
路径：/mnt/d/obsidian-vault/50-Skills/WorkBuddy税政巡查同步-YYYY-MM.md
结构（2026-09 实测范本）：
一、本月巡查做了什么（动作说明，一两句）
二、重大变动（需知悉——新的重要法规 / 废止批次，如增值税法施行 + 18号公告清理）
三、已核验现行有效（✅ 官方 fgk 库逐项确认清单，可放心引用）
四、需复核项（⚠️ 交 WorkBuddy 复查的待核文号/数字）
五、与 tax-audit-response 的协作说明（改源码两边生效）
六、后续节奏（每月一次、三路交付）

## 写作纪律（所有三份通用）
- 只引官方权威源（fgk.chinatax.gov.cn、各省税务局官网、gov.cn），二手解读站只作线索。
- 政策数字一律标注文号 + 施行日；拿不准标「待核」，绝不写死。
- 发现影响 tax-audit-response 的变动，先在 vault 详档记录，再决定是否改案由文件。
