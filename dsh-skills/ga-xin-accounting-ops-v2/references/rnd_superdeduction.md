# 研发费用加计扣除申报全流程

> 定位：从「判定适用」到「申报享受 + 留存备查」的端到端操作。
> 源：吴健《实务与案例》p65–165、p218–261；政策底稿见 `policy_basis.md`；测算用 `scripts/rnd_calc.py`；案例见 `cases.md`。
> 适用双路径：`client_intake.md` 判定的【路径 A 高企】与【路径 B 非高企】均走本流程，区别只在是否另填 A107041。

## 一、前置过滤（先做，别急着算）

→ 完整清单见 `client_intake.md`。速记四道关：
1. **主体**：会计核算健全、查账征收、能准确归集研发费用的居民企业（事业单位亦可；核定征收、非居民不适用）。
2. **行业**：6 类负面清单；兼营按 `该业务收入 ÷ (收入总额 − 不征税收入 − 投资收益) > 50%` 判定（书 p83 例 2-5）。
3. **活动**：7 类不适用活动反列举；须满足「明确创新目标 / 系统组织形式 / 结果不确定」三要点（书 p45–46）。
4. **证据**：立项文件 + 辅助账；**无辅助账不得加计**。

## 二、可加计扣除研发费用的归集范围（6 类，正列举）

| # | 类别 | 关键细目与边界 |
|---|------|----------------|
| 1 | 人员人工费用 | 直接从事研发人员工资薪金、五险一金、**外聘研发人员劳务费用**；劳务派遣研发人员劳务费；对研发人员的**股权激励支出**；兼职人员报酬；**同时从事非研发活动的须按工时等合理方法分摊**（书 p89–98） |
| 2 | 直接投入费用 | 研发活动直接消耗的材料、燃料、动力；模具/工艺装备开发制造费、不构成固定资产的样品样机及一般测试手段购置费、**试制产品检验费**；仪器设备租赁费；**研发与生产共用的水费电费须合理分摊，划分不清不得加计**（书 p99–100、p108） |
| 3 | 折旧费用 | 用于研发活动的仪器、设备折旧；**共用设备按工时/机时分摊**；加速折旧按税收口径（书 p101–103） |
| 4 | 无形资产摊销 | 用于研发活动的软件、知识产权、非专利技术摊销；共用同样分摊（书 p105） |
| 5 | 新产品设计费等四项 | 新产品设计费、新工艺规程制定费、新药研制临床试验费、勘探开发技术现场试验费；由辅助生产部门提供的按分配标准分摊（书 p106–107 例 2-28） |
| 6 | 其他相关费用 | **正列举**：技术图书资料费、资料翻译费、专家咨询费、高新科技研发保险费、研发成果检索/分析/评议/论证/鉴定/评审/评估/验收费、知识产权申请费/注册费/代理费、差旅费、会议费、职工福利费、补充养老保险费（含企业年金）、补充医疗保险费。**未列明费用不得计入**（书 p107–108 例 2-30/31/32） |

**明确不得加计**：法律行政法规规定不得税前扣除的费用；**研发用房屋的折旧费和租赁费**；已计入无形资产但不属于加计范围的项目摊销时也不得加计（书 p112、p117）。

> 新旧政策差异（书 p117）：现行口径新增外聘研发人员劳务费、试制产品检验费、专家咨询费、高新科技研发保险费、差旅费、会议费、职工福利费、补充养老/医疗保险费；房屋折旧与租赁费仍未放开。

## 三、其他相关费用限额（最高频算错点）

### 3.1 现行公式（2021 年度起）
```
其他相关费用限额 = 全部研发项目的「人员人工等五项费用之和」 × 10% / (1 − 10%)
可加计的其他相关费用 = min(实际发生额, 限额)
```
推导：设限额 X、前五项之和 Y，则 X = (X + Y) × 10% ⟹ X = Y × 10%/(1−10%)（书 p109）。
- **2021年第28号**：由一个纳税年度内**按每一项目分别计算**改为**全部项目统一计算**，不同项目限额可相互调剂；**资本化项目费用在形成无形资产的年度统一纳入计算**。
- 旧口径（2015年第97号，2020.12.31 前）：逐项目计算，项目间限额不能调剂。

**书 p110 例 2-33**：C 项目前五项 88 万 + 其他 12 万，D 项目 84 万 + 8 万 → 限额 (88+84)×10%/(1−10%) = **19.11 万** < 实际 20 万 → 可加计研发费 = 88+84+19.11 = **191.11 万**，加计额 191.11 万。
**书 p110–111 例 2-34**：A 88+12、B 92+8 → 旧口径 9.78+8 = 17.78 万；新口径 (88+92)/9 = 20 万，实际 20 万全额 → **20 万**，且只需算一次。

### 3.2 资本化项目「其他相关费用」四步法（书 p111）
1. 按**当年全部费用化项目 + 当年已结束的资本化项目**统一计算当年全部项目限额；
2. 比较限额与实际发生数，确定可加计的「其他相关费用」金额；
3. `可加计金额 ÷ 全部项目实际发生的其他相关费用` = **可加计扣除比例**；
4. `比例 × 每个资本化项目实际发生的其他相关费用` = 该项目可加计金额，与该项目其他可加计研发费用一并在**以后年度摊销**。

> 复算：`python scripts/rnd_calc.py other_limit <前五项合计> <实际其他费用>`

## 四、应冲减 / 剔除的特殊情形

| 情形 | 处理 | 依据/源页 |
|---|---|---|
| 下脚料、残次品、中间试制品等**特殊收入** | 在**计算确认收入当年**从已归集研发费中扣减；**不足扣减按零计算** | 40号公告七(二)、书 p114 |
| 研发直接形成产品或作为组成部分形成的产品**对外销售** | 对应的**材料费用**不得加计；材料与销售跨年度的，在**销售当年**冲减，不足冲减**结转以后年度继续冲减** | 书 p115–116 |
| 政府补助作**不征税收入**处理 | 用于研发形成的费用或无形资产**不得加计/摊销** | 97号二(五)、书 p116–117 |
| 政府补助作**应税收入**处理 | 可按规定计算加计/摊销 | 书 p117 |
| 会计上按**净额法**直接冲减研发费用、税务未确认应税收入 | 按**冲减后的余额**计算加计 | 40号、书 p116 |
| 不允许税前扣除的费用 / 房屋折旧租赁 / 无形资产中不属加计范围部分 | 一律剔除 | 书 p111–112 |

> 算例（书 p117）：研发支出 200 万、政府补助 50 万 → 作不征税收入：150×100% = 150 万；作应税收入：200×100% = 200 万。**企业可自行择优**。
> ⚠️ 风险实例（书 p114 例 2-36）：某高企大批量试制品对外销售未冲减，多列加计基数 1500 万，按 15% 补税 **225 万**。

## 五、不同研发形式的税务处理

| 形式 | 加计规则 | 必备要件 |
|---|---|---|
| 自主研发 | 按归集范围全额计入 | 企业内部有权部门（董事会等）立项决议；**无须科技部门事前鉴定或备案**（书 p55） |
| 委托境内机构/个人 | 按费用实际发生额 **80%** 计入委托方，**受托方不得再加计**；按独立交易原则确定 | 合同经科技行政主管部门**登记**；委托个人须凭**发票**；**关联方**：受托方须提供研发项目费用支出明细（书 p127–129） |
| 委托境外机构 | 按 **80%** 计入，且**不超过境内符合条件研发费用的 2/3** | 签订技术开发合同、由**委托方**到科技部门登记；关联方须提供明细；**不含委托境外个人**（财税〔2018〕64号、书 p131） |
| 合作研发 | 由合作各方**按各自实际承担的费用**分别归集加计 | 合同经科技部门登记；各方独立核算（书 p135–136） |
| 集中研发 | 按**合理方法分摊**，各方就分摊部分加计 | 集团决算表、分摊明细、关联申报（书 p139–141） |

**关联方明细易错点**（书 p129 例 2-40）：委托方支付 100 万、受托方实际发生 90 万（其中可加计口径 85 万），受托方只提供 80 万明细 → **错误**，应提供**实际发生 90 万**的明细。委托**非关联方**则无需提供明细（商业秘密），但仍须符合独立交易原则。
**合同登记易错点**（书 p129 例 2-41）：委托合同未到科技部门登记 → **无法加计**（依据国科发政字〔2000〕63号第六条）。

> 复算：`python scripts/rnd_calc.py entrust <委托境内> <委托境外> <境内符合条件研发费总额>`

## 六、加计比例与特殊主体

| 对象 | 比例 | 摊销 | 备注 |
|---|---|---|---|
| 一般符合条件企业 | **100%**（2023.1.1 起制度性） | 无形资产 **200%** | 2023年第7号，书 p65 |
| 集成电路 / 工业母机 | **120%**（2023–2027） | **220%** | 2023年第44号；清单管理；资本化按**摊销时点**判断，书 p67、p76 |
| 企业出资基础研究 | 100% | — | 2022年第32号；须签协议明确资金用于基础研究；接收方该收入免税，书 p76 |
| 创意设计活动 | 100% | — | 书 p79 |
| 科技型中小企业 | 100%（现行） | — | 需入库登记编号；评价含基本条件、直通车、指标，书 p142–165 |

**疑难口径**（书 p85–88）：加计可形成或扩大亏损（一般结转 5 年、高企 10 年）；符合条件未享受可**追溯 3 年**（按所属年度政策执行）；**资本化时点税收与会计一致**；研发失败、跨年度项目当年费用化部分均可加计；加计可与其他所得税优惠叠加（15% 与小微仍须择一）。

## 七、申报流程（SOP）

1. **预缴三时点**（2023年第11号，书 p39）：7 月预缴可选当年**上半年**、10 月预缴可选**前三季度**、汇算清缴**统一享受**；前一时点未选择的，可在后续时点统一享受，不是作废。前提是「能准确归集核算研发费用」。
2. **汇算填报** `A107012` → `A107010` → `A105000` → `A100000`；高企另填 `A107041`。
3. **填表基础**：《研发支出辅助账汇总表》；辅助账 / 专项审计 / 申报表**三处口径一致**。
4. **留存备查**：2018年第23号「自行判别、申报享受、资料留存备查」，无需事前备案。
5. **后续管理**：税务机关核查、异议鉴定（国科发政〔2017〕211号，由税务机关转请科技部门出具鉴定意见）。

> **A107012 完整行次（40–52 行）与全链填表示范**见 `auxiliary_ledger.md` §7.3（书 p206–208 表 4-8，例 4-1）：40 行 = 2 + 36×80% + 38；41/42 费用化/资本化；43 本年形成无形资产摊销额；45 允许扣除研发费用合计；46–49 特殊收入与研发产品材料冲减；50 加计比例；51 本年加计扣除总额；52 结转以后年度扣减金额。另有含 L1/L1.1/L1.2 分季度拆分的**预缴版**表样（书 p131 案例），二者行次不同，**以电子税务局当年表样为准**。

### 7.1 A107012 行次结构（书 p233–234 表 5-6，逐行填报示范）

**适用**：当年度享受加计扣除（含结转）的纳税人**均应填报**。表**不再要求按研发项目逐一填报**，但第 1 行须填「本年可享受加计扣除项目数量」。
填报总原则：作为**不征税收入**处理的财政性资金用于研发的部分应**扣除后**填报；其他相关费用、委托研发费用应**限额调整后**填报；研发与生产共同支出须**先分摊**后填报。

| 行次 | 项目 | 勾稽与要点 |
|---|---|---|
| 1 | 本年可享受加计扣除项目数量 | 数量，非金额；与立项书、辅助账项目数一致 |
| 2 | 一、自主研发·合作研发·集中研发 | = 3 + 7 + 16 + 19 + 23 + 34 |
| 3 | （一）人员人工费用 | = 4+5+6：工资薪金 / 五险一金 / 外聘研发人员劳务费 |
| 7 | （二）直接投入费用 | = 8…15：材料、燃料、动力、模具工艺装备、样品样机及测试手段、试制产品检验费、仪器设备运维检验维修、经营租赁租入仪器设备租赁费 |
| 16 | （三）折旧费用 | = 17+18：仪器折旧 / 设备折旧 |
| 19 | （四）无形资产摊销 | = 20+21+22：软件 / 专利权 / 非专利技术（含许可证、专有技术、设计和计算方法等） |
| 23 | （五）新产品设计费等 | = 24…27：新产品设计费、新工艺规程制定费、新药研制临床试验费、勘探开发技术现场试验费 |
| 28 | （六）其他相关费用 | = 29…33：技术图书资料费/翻译费/专家咨询费/高新科技研发保险费；检索分析评议论证鉴定评审评估验收费；知识产权申请注册代理费；职工福利费/补充养老/补充医疗保险费；差旅费/会议费 |
| **34** | **（七）经限额调整后的其他相关费用** | ⚠️ 填**限额调整后**数，不是实际发生额；用 `rnd_calc.py other_limit` 复算；与 2 行合计钩稽 |
| 35 | 二、委托研发 | = 36+37+39 |
| 36 | （一）委托境内机构或个人 | 按实际发生额 **80%** 计入 |
| 37 | （二）委托境外机构 | 按 **80%** 且 ≤ 境内符合条件研发费 **2/3** |
| 38 | 其中：允许加计扣除的委托境外机构费用 | 即 37 行经 2/3 限额调整后的可加计数 |

**实操提醒**：34 行与 38 行是**两个独立限额**，不要合并计算；表下半部（40 行以后）为特殊收入冲减、当年/以前年度销售研发产品对应材料、本年允许加计扣除总额、分季度拆分、加计扣除总额、结转以后年度扣减金额，见上方案例表样说明。**表版本每年可能调整，以电子税务局当年表样为准**。

## 八、留存备查资料

→ 完整清单与签收单见 `assets/留存备查资料清单与签收单.md`。
速记三类必备：① 项目计划书 + 立项决议 + 项目组与研发人员名单；② **研发支出辅助账及汇总表**；③ 人员/材料/设备/无形资产的分配说明（含工时记录）。委托/合作加合同登记证明；集中研发加决算表与分摊明细；委托境外加合同、发票、2/3 限额测算；创意设计加活动说明。

## 九、常见错误速查

| 错误 | 后果 | 出处 |
|---|---|---|
| 限额按项目分别算（未用 28 号统一口径） | 少加计或算错 | p109–111 |
| 其他相关费用塞入未列举项目 | 被调增 | p108 例 2-30 |
| 特殊收入 / 试制品材料未冲减 | 补税 + 滞纳金 | p114 例 2-36 |
| 不征税收入用于研发仍加计 | 不得加计 | p116–117 |
| 委托合同未登记 / 委托个人无发票 | 不得加计 | p129 例 2-41 |
| 关联方只提供部分费用明细 | 资料不合规 | p129 例 2-40 |
| 房屋折旧、租赁费计入加计 | 不得加计 | p117 |
| 事后补建辅助账 | 不得加计 | 红线 |
