# Hand-drawn poster / 手抄报 (SVG -> PNG/PDF)

## Core requirement (non-negotiable)
Posters for school / children must look DRAWN BY HAND, not arranged by a computer. This user rejected neat boxed layouts outright ("太工整了…不是这样工工整整的"; "太丑了") and affirmed the hand-drawn direction ("对"). Apply ALL of these to sell the hand-made look:

- **Handwriting CJK fonts**, not system 黑体. From Google Fonts (OFL, free): Ma Shan Zheng (brush), ZCOOL KuaiLe (rounded handwritten), Zhi Mang Xing (scrawly). Install once; see references/watercolor-svg-rendering.md.
- **Wobbly hand borders**: generate every border/polygon as a closed path with randomly-jittered per-point coordinates (several points per side); re-stroke as a faint second line. NEVER clean rounded rects, straight borders, or perfect grid alignment.
- **Blocks tilted** +/-1-3 deg, top edges staggered (not one shared row), varied sizes, some overlapping. Break the grid deliberately. Everything inside an irregular whole-page wavy frame (2-3 layered strokes) with corner spirals.
- **Washi tape**: semi-transparent strips with torn/jagged ends across block top edges/corners.
- **Doodles everywhere**, including gaps and margins: hand sun + rays, outlined clouds, hand stars, hearts, flowers, fireworks (radiating lines + end dots), scribble/scrawl lines, arrows.
- **Highlighter band** (soft tilted ellipse, ~55% alpha) behind each title PLUS a wobbly squiggle underline.

## Procedure
1. Decide deliverable. On the user's Windows machine an `.html` opens in their browser (has CJK fonts) for zoom/print; otherwise deliver a **300dpi PNG + vector PDF**, plus the SVG source. Copy all to `/mnt/c/Users/<user>/Desktop`. A4 portrait.
2. Author the art as **SVG generated by a Python script** (procedural wobble + doodle helpers, `random.seed(...)` fixed so output is reproducible/editable) rather than hand-writing a flat SVG.
3. Render SVG -> PNG/PDF with cairosvg. CRITICAL: execute it through the SYSTEM python - the `execute_code` sandbox interpreter is a different Python and will NOT see packages pip-installed into system python. Use `subprocess.run(["/usr/bin/python3","-c","import cairosvg; cairosvg.svg2png(...); cairosvg.svg2pdf(...)"])`.
4. Confirm the handwriting font is actually used (cairosvg silently falls back to wqy/black otherwise): render the same CJK string at the same size in the handwriting font vs wqy and compare ink-pixel counts - different counts prove the font loaded.
5. Because you often CANNOT see the image (non-vision model / vision API rejects the image), verify programmatically then ask the user to visually approve:
   - render a small PNG, sample pixels (count distinct colors; confirm banner red present; confirm NOT all-black),
   - validate every block's bounding box stays inside the page frame,
   - tell the user the exact file paths and ask what to tweak (do not claim it "looks beautiful" without seeing it).

## Pitfalls
- A full-page paper-grain overlay using `feTurbulence` + `feColorMatrix` makes the ENTIRE SVG render **pure black** in cairosvg. For watercolor look use only `feGaussianBlur` and `feDisplacementMap` (both safe) plus low-alpha soft-color blobs; never a colorMatrix-over-noise overlay.
- Heavy `feTurbulence` at print resolution (3300px+) is extremely slow; a long foreground terminal render can get blocked ("silence is not consent") waiting on the user. Strip the grain filter and render normally (then it is ~seconds); if still heavy, render in the background and poll.
- ReportLab and PIL `ImageFont.truetype` cannot load OTF/CFF fonts ("postscript outlines are not supported"). Use TrueType only (wqy-microhei-regular.ttf, or the downloaded handwriting .ttf). Noto Serif CJK is CFF - cairosvg/Pango can use it, ReportLab/PIL cannot.
- Do NOT put emoji in SVG `<text>`: the CJK font usually lacks the glyph and renders tofu. Use safe CJK symbols (e.g. star/geo codepoints) and draw illustrations as vector paths, never emoji.
- LibreOffice `soffice --headless --convert-to pdf` HTML->PDF flattens CSS (grid/absolute positioning collapse, content spills to extra pages). Not usable for designed posters; ship the HTML for browser-print instead of converting it.

See references/watercolor-svg-rendering.md for fonts, filter-safe list, and render commands.
