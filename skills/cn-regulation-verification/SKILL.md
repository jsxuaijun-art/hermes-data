# 中国税收/法规文号现行性核验

## When to Use
在以下场景 MUST 加载本 skill：
- 用户问「某文号还有效吗」「查核现行性」「是否已废止/修改」——任何**单点文号核验**请求
- 写公众号/文书/咨询回复前，确认某个税收文件是否仍是现行依据（防引用废止法规）
- tax-audit-response 或 tax-regulation-monitor 中标「待核」的文号需回填
- 税务总局发布"失效废止文件目录"类清理公告后，核对已引用文号是否被波及

## 目标
在任何引用中国税收法规、税务规范性文件、司法解释之前，核验该文号的**现行状态**——防止引用已废止、已失效或已被部分修改的文件（用户公众号铁律：禁止引用错误法规）。本 skill 与 tax-regulation-monitor（定期巡查机制）、tax-audit-response（稽查应对）配合使用；凡标「待核」的文号都走本流程。

## 核心方法：fgk 官方政策法规库终裁

**终裁标准**：以国家税务总局政策法规库 `fgk.chinatax.gov.cn` 的**文件详情页状态标签**为准，不看二手站。

- 官方详情页 URL 形如：`https://fgk.chinatax.gov.cn/zcfgk/c100012/c<id>/content.html`（税务规范性文件；其他类别 c 前缀不同）
- 详情页会明确标注三种状态之一：
  - **「全文有效」** → 可放心引用（例：国税发〔2000〕187号、2018年28号、2014年67号）
  - **「已修改」** → ⚠️ 不等于废止！指部分条款被后续公告废止/修改（例：2015年97号研发加计，多条款被2017年40号/2019年41号/2021年28号废止，核心归集规则仍现行）。**引用须按现行条款**，勿整体引用旧号。
  - **「全文废止失效」** → 绝不可引用
- 详情页正文里常直接给出废止关系（如 2014年67号 明确"上承 2010年27号同时废止"），这是免费的上位/下位链证据。

## 检索路径

1. `anysearch batch_search` 搜「文号 + 废止」或「文号」找官方库详情页链接（优先 fgk.chinatax.gov.cn 域名，其次省级税务局官网）。
2. `web_extract` 抓 fgk 详情页，读状态标签 + 成文日期 + 正文注释/废止关系。
3. 落到核验矩阵（见下）得出结论。

## 已实测的坑（2026-09 验证）

- **fgk 附件 xls 下载触发反爬**：直接 curl 附件链接返回 HTML（登录/跳转页），非真实文件。绕过：抓 fgk 公告正文 + **省级税务局「解读」页**（URL 形如 `shanghai.chinatax.gov.cn/zcfw/zcjd/...`），解读页会给出清理规模与性质（例：2026年18号=增值税法衔接清理 144 件，主要废止"与增值税政策不一致或已被替代"的增值税类文件）。
- **二手站标注不可信**：
  - `shui5.cn` 有 WAF/混淆 JS，爬取返回加密内容 — 当线索可以，别当证据。
  - 部分建站库（如 tfcjtax）曾把仍**全文有效**的 2018年28号 误标「全文废止」— **一律以 fgk 状态标签为准，不信二手站**。
- **清理批次≠全面废止**：税务总局"公布失效废止部分税务规范性文件目录"类公告（如 2026年18号）通常只针对某税种衔接（增值税法），不波及其他税种文件。核验时要确认目标文号**是否在具体批次目录内**，不能因"有废止清理"就默认受影响。解读页的"主要废止对象"描述是关键线索。

## 输出：核验矩阵（固定格式）

```
| 文号 | 名称 | fgk状态 | 结论 |
| 国税发〔2000〕187号 | 善意取得虚开专票处理通知 | 全文有效 | ✅ 现行 |
| 2015年97号 | 研发费用加计扣除有关问题 | 已修改（部分条款废止） | ⚠️ 按现行条款引用 |
| ... | | 全文废止失效 | ❌ 禁用 |
```
每一行必须写清状态标签的**具体文字**和结论，不带"可能/大概"。

## 与相邻 skill 分工

- `tax-regulation-monitor`（用户自有）＝定期全网巡查机制（cron 双周触发）→ 产简报存档 `法规巡查/YYYY-MM-DD-税政变动简报.md`。本 skill 是其"单点核验"执行器。
- `tax-audit-response`（用户自有，vault 维护）＝稽查应对文书。其引用文号标「待核」时，用本流程核验后回填。
- `chinese-legal-research`＝法院判例/诉讼文书，涉及的是裁判文书网，非本 skill 范围。
