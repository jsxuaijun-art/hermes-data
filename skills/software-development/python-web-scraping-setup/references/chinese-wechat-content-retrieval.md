# 微信公众号 / 视频号 检索实操 (WSL+China 网络)

2026-08 实测。场景：行业"专项自查/专项整治通知"或监管新政在政府官网无公开网页时，
**公众号转载是主要情报源**（财税/政务机构号常全文转载红头文件并加解读）。视频号是微信封闭生态，基本查不到。

## 一、搜狗微信 —— 公众号文章检索（可用，能抓标题+摘要）

搜索入口 `https://weixin.sogou.com/weixin?type=2&query=<urlencode>`：
- **requests(requests+bs4) 能直抓结果列表和正文长摘要**（首次请求返回 200）。摘要常直接含公众号引用的通知原文片段，
  足以判断"是不是这份文件"+ 提取关键内容，不必点进正文。解析选择器：`.news-list li, h3 a`（标题）、`.account/.s2`（公众号名）、整条文字（摘要）。
- 结果链接是 `/link?url=...` 签名跳转，**requests 跟随也拿不到 mp.weixin.qq.com 真实地址**（需浏览器二次 JS 跳转 + 真实指纹）。
- ⚠️ **浏览器直接打开 weixin.sogou.com 搜索结果会触发 antispider**（`/antispider/?antip=wx_sh2` 人机验证页）。
  所以"用浏览器点开看正文"这条路基本断掉——**只靠 requests 的摘要字段收集正文片段**。
- 想拿某篇转载的全文：用"标题 + 关键词"去 360/搜狗网页版（非微信）搜非微信的 10w+ 转载站（腾讯网 new.qq.com、搜狐、百家号、
  地方政务/信用网站 credit.xxx.gov.cn、中国政府采购招标网 gov-cg.org.cn 等），很多公众号原文会被这些站收录，requests 可直接抓。

### 抓取代码骨架（已验证）
```python
import requests, urllib.parse
from bs4 import BeautifulSoup
UA={"User-Agent":"Mozilla/5.0 ... Chrome/120 Safari/537.36","Accept-Language":"zh-CN,zh;q=0.9"}
S=requests.Session(); S.headers.update(UA)
r=S.get(f"https://weixin.sogou.com/weixin?type=2&query={urllib.parse.quote(q)}",timeout=18)
r.encoding=r.apparent_encoding or "utf-8"
soup=BeautifulSoup(r.text,"html.parser")
for li in soup.select("li"):        # 宽松选择器，再按关键词过滤
    a=li.select_one("a")
    if a and any(k in a.get_text(strip=True) for k in ["自查","专项","承诺","整治"]):
        print(li.get_text(" ",strip=True)[:160])  # 含公众号名+正文摘要
```

### 拿 mp.weixin.qq.com 真实直链 —— 用搜狗【网页版】搜标题（重要，本会话新增）
微信版（weixin.sogou.com）给的是 /link?url= 加密跳转解不出真实地址。但**搜狗网页版 `www.sogou.com/web?query=<标题>`**
（type 默认，非 weixin 版）**能直接返回 mp.weixin.qq.com/s?src=11&timestamp&ver&signature=... 的秒传直链**，
requests 抓 `a[href*='mp.weixin.qq.com']` 即可拿到，可交给用户点击，也可继续解析。这与微信版行为不同，是两条独立通道：
- 微信版（weixin.sogou.com/weixin）→ 加密 /link?url=，拿不到 mp 直链，但摘要全。
- **网页版（www.sogou.com/web）→ 直接用标题搜，能拿到 mp 秒传直链**，适合给用户可点击链接。
注意：网页版在浏览器直接开也会触发 antispider（antip=web_hd），requests 抓 html 没问题。

**⚠️ 秒传链接正文读取的坑（勿误判）**：`mp.weixin.qq.com/s?src=11&signature=...` 用 requests 带 `Referer: https://weixin.sogou.com/`
请求，可能返回 **200 + 一堆 HTML 但实际是 JS 模板壳**——特征：无 `#js_content` / `rich_media_content`、`__biz` 是字面量 `${window.biz}`、
`<title>` 空白。这不是"文章还在但抓不到"的简单情况，而是微信把正文交给客户端侧 JS 验签填充，**自动化环境（headless/requests）拿不到正文**，
只有真实浏览器+微信 cookie/指纹能渲染。所以：标题/公众号/发布日期/摘要可信，**正文全文别承诺能读**；需要正文就告诉用户浏览器打开，或走"标题+关键词搜非微信转载站"路线。

## 二、视频号 —— 微信封闭生态，不进搜索引擎

- **视频号内容不进入任何通用搜索引擎索引**（搜狗/360/百度都搜不到号内具体视频），因为视频号没有公开可爬的网页版——只能靠微信 App 内刷。
- 想**确认"没有相关视频"**：用 360 视频 `https://video.so.com/v?q=<urlencode>`（会重定向到 tv.360kan.com），
  无结果时页面明确显示"没有与'XX'相关的视频哦"。这一步可以放心地**排除**视频号这个渠道，不用再找。
- 这类区级部门行政自查通知通常只在公众号/机构工作群流转，**机构不会发视频号**（视频号只做泛科普引流）。
- 若客户/用户坚持要视频号素材：告知需微信内手动搜索对应财税号，自动化不可行（同"方案B 人工采集"偏好）。

## 三、公众号内容可信度分级（涉及文号，务必区分）

公众号转载分两类，引用前必须区分，避免拿"解读号"当"官方源"：
- **全文转载类**：直接贴红头文件原文（通常注明"附原文"），可信度近官方，可据此提炼通知要点。
- **解读号**（标题党如"重磅！""别慌！真相一次说清"）：作者是财税公司/自媒体，会转述甚至**加工政策细节**
  （如把某参考口径50户/18万说成"全国统一红线"、标注一个查不到官方源的文件号如"财会〔2026〕8号"）。
- **文号铁律**：公众号里出现的文件号（财会〔XXXX〕N号、沪财发〔XXXX〕N号）**必须到官方源二次核对**——
  拿"文件标题全称"去 360 搜官方转载（credit.xxx.gov.cn 信用中国、各省市政府网），确认文号后才可写进客户通知/公众号推文。
  核对不到的，明确标注"公众号口径，未经官方源确认"，宁可少说不说错（用户公众号铁律）。
- **警惕印刷相近/同期的两个文件号**（本会话实例）：2026年上半年财政部办公厅发的是**《关于做好2026年代理记账行业管理工作的通知》（财办会〔2026〕7号，2026-03-02印发)**——
  年度备案+常态化治理（未备案/有照无证/虚假承诺/超出胜任能力执业）；而用户/部分公众号引用的**《财政部 税务总局 市场监管总局关于组织开展2026年代理记账行业治理工作的通知》（财会〔2026〕8号）**是另一份三部门专项治理文件。
  两者标题相似、时段相近、治理对象高度重叠，极易混。引用前务必用**文件标题全称**区分，别只报一个号就写稿。

## 四、一份"虚假承诺 + 超出胜任能力自查"通知的公众号旁证（2026-07/08 实测案例）

2026年上海市财政局下发代理记账专项自查通知（虚假承诺自查 = 2025-07-01至2026-06-30 告知承诺取得许可机构
+ 2026年度备案专职人员变动机构；超出胜任能力自查 = 超出能力承接业务、开票规模与经营能力严重不匹配）。官网无公开网页。
搜狗微信命中（requests 摘要即可确认存在+内容）：
- 公众号"CC的日常账本"《代账行业大事件，这个信号你看懂了吗？》2026-07-29 —— 引用上海市财政局 2026-07-20 通知，最完整
- 公众号"刘宗河说财税"《代理记账行业整治工作启动，人均代账超50户纳入监控（附原文）》—— 附原文+解读，标注"财会〔2026〕8号"（号待官方核）
- 上海国家会计学院转载《人均代理超50户、人均年收入超18万，启动自查！》—— 超出胜任能力参考口径（专职≥3名也属此语境）
- 财学智慧库《代理记账50户、18万红线？别慌！》—— 澄清 50户/18万 是部分地区参考口径非全国统一

> 结论：公众号能确认"通知存在+基本框架+发文机关+部分文号"，但**原文全文/精确文号仍需官方源或用户红头文件**。
