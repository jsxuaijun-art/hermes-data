# 粤语实战案例 — 剧情对话香港化（2026.8.14）

> 素材：一段"父亲节认亲"剧情对话（女自称是阿爸的女儿 → 识破 → 转到注册公司）。
> 用户实测反馈第一版（广东白话味）不是纯正香港粤语，本文件记录广府版→香港版的逐句改造，供后续剧情对白复用。

## 逐句对比

| 第一版（广东白话味） | 香港粤语版（用户认可） | 改造点 |
|:--|:--|:--|
| 你係邊度㗎？ | 你邊度人呀？ | 去「㗎」，改「呀」，更简洁 |
| 你揾我做乜嘢？ | 搵我有咩事？ | 「揾我做乜嘢」偏广府 → 「搵我有咩事」HK 说法 |
| 送咩禮物？ | 送咩禮物俾我呀？ | 补「俾我」，口语自然 |
| 你唔好同我亂開玩笑喎 | 你唔好玩我啦 | 句尾「喎」→「啦」 |
| 你點知㗎？ | 你又知嘅？ | 「㗎」→「嘅」，更 HK |
| 個女幾大喇？ | 個女幾大呀？ | 「喇」→「呀」 |
| 點可能呀？ | 點會呀？ | 更地道反问 |
| 你係咪真係我個女㗎？ | 你係咪真係我個女呀？ | 「㗎」→「呀」 |
| 你姓咩㗎？ | 你姓咩呀？ | 「㗎」→「呀」 |
| 你嗰個阿爸叫咩名呀？ | 你阿爸叫咩名呀？ | 去「嗰個」 |
| 咁而家點算呀？ | 咁依家點算呀？ | 「而家」→「依家」（HK 標誌） |
| 佢阿爸知唔知個女唔係佢親生㗎 | 佢阿爸知唔知個女唔係佢親生呀 | 「㗎」→「呀」 |

## 核心规律

1. **语气词是最大区别**：「㗎」「喎」「囉」→ 换成「嘅」「喇」「呀」，立刻港味
2. **「而家」→「依家」** 是香港标志
3. **HK 口语更简洁文雅**，句子更短，删冗余（如「嗰個」）
4. **剧情/日常对话不要硬塞英文**（两个香港人闲聊硬夹英文反而怪），港味靠语气词+用词体现；商务场景才中夹英
