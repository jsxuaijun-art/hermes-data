## 一、机制总览：三阶段全链条

```
事前引导（政策找人）→ 事中校验（智能审+风险提示函）→ 事后监管（大数据扫描+自我遵从）
```

## 三、事中校验：风险体检提示函 + 智能审

### ① 风险体检提示函
- 申报前大数据分析 → 按户归集推送 → 引导自主自查
- **扬州案例：** 鸿轩实业集团收到后自查发现汇率换算时点偏差 → 申报前修正

### ② 智能审（申报拦截校验）— 183个指标
| 维度 | 数据 |
|------|------|
| 指标总数 | 183个（少缴税费43+违规享受114+应享未享9+数据质量17） |
| 覆盖范围 | 8税种+3非税种，增值税101个（占比最高） |
| 汇算清缴专项 | 50余个指标 |
| 扫描频率 | 每日2次，问题最快当天推送 |
| 2025上半年推送 | 5.7万户次 |
| 更正准确率 | >90% |
| 税款成效 | 9.44亿元 |
| 汇缴更正减免税差错 | 3.2亿元（7658户） |
| 小微企业应享尽享 | 2422户 |
| 错误优惠整改免罚 | 5236户 |

**运作方式：** 点击"申报"→ 智能校验启动 → 拦截预警 + 更正指引

**核心原则：** 征收期内推送、及时更正的——**不加收滞纳金、不罚款、不影响纳税信用**；优惠政策应享未享的——提醒及时享受

**昆山案例：** 博厚建设工程错按3%税率多申报增值税 → 提醒后更正并收到退税1.2万元

**基层效益：** 南京市建邺区税务局实施提示提醒后，后续核查任务工作量下降近八成

**苏州案例：** 园区某教投公司"已抵扣贷款利息支出"填错栏次 → 提醒后修正本年度+其他年度一并更正

## 四、事后监管：大数据风险扫描 + 自我遵从

### 核心机制（2025年已推行）：提级推送

**运作模式：** 省局直接确定指标和风险纳税人名单 → 电子税务局直推纳税人（无需层层下发）

**关键数据：**
- **79个风险指标**，税费种全覆盖
- **17万户次**已推送，**自行整改率超六成**，入库税费**5.7亿元**
- 应对时长从1个月缩至**15天以内**，降幅一半以上
- 453户回访：提示方式"好"占比85%，内容"明确"占比88%

**风险模板"五个明确"：**
法律依据明确 · 风险区间明确 · 风险信息明确 · 整改方式明确 · 法律后果明确

**自动化流程：**
风险疑点自动加工 → 提醒信息自动转换 → 提醒文书自动推送 → 修正情况自动验证 → 疑点化解自动判断

**二次扫描机制：** 自我纠正期满后系统再次扫描。正确更正申报→风险彻底消除；未改正→递进管理

**苏州案例：** 园区某教投公司"已抵扣贷款利息支出"填错栏次 → 提醒后修正本年度+其他年度一并更正

### 重点监管事项（14个）
政策性搬迁、股权转让、高新优惠、法人合伙人应分得所得等

### 智能报表
12张智能报表 × 109个指标 → 大数据分析 → 推送管理建议

### 行业治理
医药领域先行 → 大额代开发票问题提级监管 → 推动企业将发票验真、业务关联校验嵌入财务系统

## 六、风险提示函的实操应对（含双推送模式详解）

### "双推送"模式
税收风险疑点信息同时推送给 **税务人员应对** + **纳税人电子税务局端口**

### 收到风险提示函的完整操作流程

| 步骤 | 操作 | 说明 |
|:----:|------|------|
| ① | 登录电子税务局 → 首页下方「服务提醒」 | 查看《纳税风险提醒函》 |
| ② | 进入「我要办税」→「线上执法」→「提示提醒回函」 | 注意：超期会提示"已过反馈期限，无法再进行反馈" |
| ③ | 填写风险自查反馈情况说明 | 据实填写，措辞合理 |
| ④ | 上传附件资料（非必报项） | 更正后的申报表、税票等文件 |
| ⑤ | 税务人员根据反馈确认风险是否排除 | 排除→办结；未排除→递进措施 |

### 逾期后果（递进式）
1. **第1次逾期** → 再次推送提醒
2. **第2次逾期仍不反馈/整改不到位** → **转为接触式风险应对**（约谈、实地检查等）

### 应对建议（来自实战指南）
1. 了解稽查目的 — 询问确认本次稽查目标
2. 准备好资料 — 财务报表、凭证、账簿、合同、发票、银行流水
3. 配合度高 — 及时向税务部门咨询
4. 保持沟通畅通

### 收入类稽查企业自查要点
- 收入真实性（瞒报/虚列成本）
- 收入完整性（所有应计入收入是否录入）
- 收入确认及时性（有无挂在往来账户）
- 收入来源合法性
- 税收优惠合理性（高新企业被稽查概率更大）
- 发票四流一致（合同/发票/付款/物流）

### 税前扣除类自查要点
- 未取得发票 — 汇算清缴时需补充有效凭证，否则纳税调增
- 分割单作为税前扣除凭证（共同接受劳务场景）
- 作废发票占比异常
- 佣金和手续费与发票金额不匹配
- 财务费用与发票金额不匹配（银行手续费需发票）
- A105000表"其他"纳税调增金额异常

### 应对原则
- 不要慌 → 这是服务措施，不是处罚
- 认真自查 → 有则改之，据实反馈
- 征收期内更正 → **不加收滞纳金、不罚款、不影响纳税信用**
- 不会的找盈信 → 盈信可协助客户完成自查报告和回函

## 八、盈信服务场景

1. **汇算清缴前** → 主动确认客户是否收到"风险体检提示函"，提前介入
2. **研发费用客户** → 重点核查归集口径，避免智能审拦截
3. **高新企业客户** → 确保研发费用占比达标（智能审直接拦截）
4. **销售费用较大客户** → 核查发票验真和业务关联凭证
5. **收到提示函客户** → 协助撰写自查报告和回函
