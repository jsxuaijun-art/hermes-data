# 漫画风科普短视频 · 完整方法论

本参考文档为「comic-explainer-video」skill 的核心方法论。它把"做什么样的视频 + 怎么写文案"彻底解耦，使任何主题都能套用同一套生产规范。

---

## 一、视频制作工艺（与主题无关，1:1 复用）

### 1.1 视觉风格规范（关键，决定画风可复现）
- **画风**：美式漫画 / 平面矢量插画（flat vector, American comic book style）。
- **配色**：统一的**紫色系 + 浅紫背景**（purple / lavender palette），关键警示元素用**红色点缀**。
- **描边**：所有主体元素加**粗白色描边**（bold white outlines），几乎不写实阴影（minimal shading）。
- **背景**：纯色或极简几何体，留白充足，保证文字可读。
- **构图**：横版 16:9，主体居中或偏一侧，预留顶部声明条 + 底部字幕区。
- **AI 生图关键词固定串**（每次生图必须包含，见 imagegen_prompts.md）：
  `American comic book style, flat vector illustration, purple and lavender color palette, bold white outlines, minimal shading, clean solid background, horizontal composition, 1920x1080`

### 1.2 字幕与文本规范
- **关键词高亮**：每句旁白中的核心词（数字、风险点、转折词）用**黄色**突出。ffmpeg subtitles 用 `PrimaryColour=&H00FFFF&`（ASS 的 BGR 顺序，即黄色）。
- **字号**：42 左右，加粗，底部居中（`Alignment=2, MarginV≈70`）。
- **顶部声明条**：合规类内容（财税、法律、医疗等）必须在画面顶部常驻一行小字声明（如"内容仅供参考，具体以官方政策为准"），用 `drawtext` 黑底白字 box 实现。

### 1.3 节奏与声音设计
- **整体节奏**：慢 → 快 → 慢。开场钩子慢（留白、字少），中段数据密集快剪，结尾互动慢（留白引导评论）。
- **声画同步**：旁白驱动画面，一镜一意。每句旁白配一个强隐喻画面（见视觉符号表）。
- **配音**：中文用 `edge-tts`，推荐 `zh-CN-YunyangNeural`（云扬，男声沉稳，适合警示/干货调性）；女声可选 `zh-CN-XiaoxiaoNeural`。
- **BGM**：轻量、不抢人声；警示类可用低频铺底，趋势类可用轻快节奏。

### 1.4 生产流水线（确定性，见 scripts/build_video.py）
选题 → 文案头脑风暴 → 分镜（每镜一图一旁白）→ AI 生图（紫色漫画风）→ edge-tts 配音+字幕 → ffmpeg 合成（缩放动画+字幕高亮+顶部声明）→ 拼接成片。

## 二、文案叙事结构库（与主题解耦，按意图选结构）

原"律师饭碗被砸"视频只是 **T1 颠覆认知型**。以下 6 种结构可按主题任意替换，制作工艺完全一致。

| 结构 | 适用意图 | 经典骨架 |
|---|---|---|
| **T1 颠覆认知型** | 推翻大众对某职业/事物的固有印象 | 钩子(人物困境)→颠覆数据→具象冲击→三点归因→两极分化+互动 |
| **T2 趋势解释型** | 解释为什么 XX 火了/凉了 | 现象→数据→驱动因素→未来走向→普通人应对 |
| **T3 反向机会型** | 在悲观叙事里找被低估的机会（调性积极） | 大众悲观→反例/数据→底层逻辑→可抓住的机会→行动建议 |
| **T4 实用指南型** | 教普通人避坑 / 做决定 | 痛点→错误做法→正确做法→步骤清单→提醒 |
| **T5 人物故事型** | 用一个人的命运讲大议题 | 人物登场→遭遇→转折→结局→升华 |
| **T6 清单盘点型** | 关于 XX 的 N 个信号 / 迹象 | 引子→信号1..N（每条一图一句）→总结 |

**结构选择决策表**（按用户主题意图）：
- 想讲"一个被忽略的风险/陷阱" → T1 或 T4
- 想讲"一个反共识的机会" → T3
- 想讲"某个行业正在发生什么" → T2
- 想讲"一个真实的人/客户故事" → T5
- 想讲"几个值得警惕的迹象" → T6

## 三、通用五幕文案骨架（T1/T4 最常用，可直接填空）

> 把 `[ ]` 替换为主题内容即可产出脚本。

1. **钩子（5-10s）**：用一个具体人物困境把观众拉进来，点出"明知故犯"的人性张力。
   - 例："你明明知道便宜没好货。可看到 99 元包年代账，你还是点了。"
2. **机制拆解（15-25s）**：把问题拆成 2-3 个可感知的环节，落点到具体动作。
   - 例："低价是怎么低下去的？无非三件事：少报、漏报、不核对。"
3. **具象后果（15-25s）**：把风险落到可量化的损失（钱、信用、经营停摆）。
   - 例："为了省一年几千块代账费，可能搭进去几万、几十万。"
4. **归因 / 升华（10-20s）**：为什么会发生（人性/机制/环境），给出判断。
5. **互动收尾（5-10s）**：抛一个让观众对号入座的问题，引导评论区。

## 四、视觉符号替换表（一句话配一个强隐喻画面）

| 抽象概念 | 具象画面（紫色漫画风） |
|---|---|
| 贪图便宜 / 侥幸 | 人物盯着手机上的超低价广告，表情纠结 |
| 风险链条 | 倾斜的天平 + 错位的账本 + 红色警示符 |
| 数据监控 / 暴露 | 公司被半透明数据网笼罩，桌面红头罚单 |
| 两极分化 | 沙漏（上多下少）或阶梯（两端人群） |
| 趋势下滑 | 向下折线图 / 落石 |
| 机会 / 反向 | 裂缝中的光、逆行的人、被忽视的角落 |

## 五、合规与数据核实清单（发布前必查）

- [ ] 涉及政策/法规的措辞使用**官方口径**（如金税四期、非正常户等引用税务总局表述）。
- [ ] 所有数据 `[ ]` 替换为**可查证的公开来源**（财政部、行业协会、权威媒体）。
- [ ] 财税/法律/医疗等内容顶部声明常驻，文末加"仅供参考"免责。
- [ ] 不承诺具体收益、不贬损具体机构（避免侵权/虚假宣传）。
