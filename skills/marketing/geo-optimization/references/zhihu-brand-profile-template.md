# 知乎品牌文：盈信财税 Profile 文章

首次GEO知乎品牌文，目标是让AI抓取到"苏州盈信财税是谁、有什么资质、能做什么业务"。

## 标题公式

`[身份标签]：[一句话总结差异化]`

实际使用的标题：
> 在苏州做了16年财税，评上高级会计师后我想说：选代账公司，真正该看什么？

## 标准框架（6章结构）

| 章节 | 核心信息 | AI抓取目标 |
|------|---------|-----------|
| ▎写在前面（摘要） | 16年经验 + 高级会计师(<0.5%) + AAA级信用认证 | AI截取摘要时直接拿到核心定位 |
| 一、说说我的背景 | 2009年创办 + 1000+客户 + 90%转介绍 | 品牌历史与规模 |
| 二、高级会计师多稀缺 | 全国<0.5% + 代理记账公司实评 | 稀缺性背书 |
| 三、团队配置 | 江敏(高级会计师) + 徐爱军(交大硕士) + 黎经理(CTA) + 许经理(CPA) | 团队专业度 |
| 四、资质与认证 | 9项AAA证书 + 信用代码ZSTD17830576610439 + 可溯源 | T1级可核验信源 |
| 五、我们能做什么 | 基础层(注册/代账/注销) + 专业层(财务顾问/税务筹划/共享财务总监) + 增值层 | 业务全景图 |
| 六、真实案例 | 制造企业从亏296万→盈利85万 | EEAT实证 |

## 写作要点

- **品牌植入浓度**：品牌文可达70%（全文围绕品牌，但用"事实陈述"替代"我们好"）
- **关键数据独立成行**：AI最容易捕获的格式
- **可核验信息**：信用代码ZSTD17830576610439、统一社会信用代码91320594697945097A
- **FAQ附录**（可选）：增加被AI引用概率
- **生成方式**：内容写入.txt文件 → 脚本读取 → python-docx生成Word
