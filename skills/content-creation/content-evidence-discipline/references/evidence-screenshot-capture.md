# 证据截图抓取：实测可用源清单与失败模式

> 来源：2026-10-12 两个短视频文案任务（"天坑专业" / "出口退税双行业经验"）。
> 徐总要求：画中画里的数据/政策**直接给截图**，不要只给"来源：某某报告"让他自己搜。
> 本文件记录实战中**真正抓成功**的源、每条的关键词定位、以及**失败了的源和原因**——下次同类任务先查这里，别从零试。

## 一、抓取器与命令

```bash
python3 ~/.hermes/skills/content-creation/content-evidence-discipline/scripts/grab_pip_card.py \
  "<URL>" "<输出.jpg>" "<关键词>" [上移px]
# 抓完验图（必做）
tesseract <输出.jpg> stdout -l chi_sim | head -20
```

三代写法演进（**别退回旧写法**）：

| 版本 | 写法 | 结果 |
|---|---|---|
| v1 | `grab_pip_shot.py` 元素级截图（截含关键词的 `<p>`） | 常只有一行 60px 高，做不了数据卡（仍保留，适合短句） |
| v2 | Playwright `get_by_text(kw).first` + `scroll_into_view` + 滚轮 | 文本定位**先命中导航链接**，页面滚不动 → 截回来只有页头/导航 |
| **v3** | **DOM 取最后一个含关键词的内容元素 → `scrollIntoView({block:'center'})` → 上移 → 截整屏** | ✅ 实测最稳，正文卡片级 |

## 三、失败模式与对策（都是本次实测踩到的）

| 现象 | 具体表现 | 原因 | 对策 |
|---|---|---|---|
| 空文件 | 凤凰配图 curl 直下 → **0 字节** | 图床**防盗链**（Referer 校验） | 放弃直下原图，改抓**渲染后的页面**截图（v3 抓的就是页面） |
| 只有页头 | v2 抓广东税务页 → OCR 出来全是"广东省税务局 / 本站热词 / 首页 信息公开" | `get_by_text` 命中导航，页面未真正滚动 | 换 v3（最后一个内容元素）；或直接用同级官方源（本次改用财政部税政司页） |
| `NO_KW_MATCH` | `customs.gov.cn` 页面取不到关键词元素 | 政府站 **JS 壳页**，正文非静态 | 换权威媒体转载版（新华网原稿）或同级部委正文页（财政部/税务总局） |
| 抓到广告页 | 某深圳代办公司营销页被搜到 | 搜索排名 ≠ 权威性 | **OCR 校验发现即弃用**，只认官网/权威媒体 |
| 图太小 | 元素级截图 61px 高 | v1 写法缺陷 | 用 v3 整屏 1280×780 @2x |

## 四、交付形态（本次定稿）

```
<任务名>/
├── <文案>.docx  +  <文案>.txt
├── 画中画图片/
│   ├── 画中画_<任务>_01_<内容>_<来源>.jpg
│   └── ...
└── 画中画来源清单.txt
```

`画中画来源清单.txt` 每条固定四要素：**对应脚本/叠加点 → 图文件名（已给图的）→ 源 URL → 自截位置（Ctrl+F 搜什么）**。即使图已抓到，也把 URL+关键词写上，便于徐总复核。

命名参考（本次实例）：
`画中画_天坑_01_麦可思2026收入前十_凤凰.jpg`、`画中画_出口退税_02_退税申报36个月_财政部税政司.jpg`

打包：单个 Python 脚本 `folder → zipfile → shutil.rmtree(folder)`，桌面只留 zip（勿用 shell `rm`，会触发破坏性守卫）。中文名 zipfile 自带 UTF-8 标志，Windows 解压不乱码。

## 五、本次遗留（供下次同类任务参考）

- **用户手里的实拍图**（如"海关查验的图"）AI 没有 → 在清单里明确留占位，请在交付消息里点名索取。
- **被锁文件的清理**：松散 docx 还开在 Word 里时删除报 `PermissionError[Errno13]`，同时桌面会留一个 `~$xxx.docx` 锁文件 → 勿重试，如实报请用户关 Word 后再删。
