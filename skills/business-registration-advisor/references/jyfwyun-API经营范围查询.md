# jyfwyun 经营范围规范表述——API 直连查询

> **使用前置（徐总 2026-10 要求）：每次做经营范围查询前，先问清楚客户/自己要查哪个市辖区**（吴中/姑苏/园区/相城/吴江…），再用 `--tree` 拿到该区 ac 码后查询；不要默认用上一个区的 ac。

> 比网页手动点选快得多，且可脚本化批量拉取。网页仍是最终展示/校对视图，但取数用 API。

## 接口

Base: `https://backapi.jyfwyun.com/cloud-service`（POST，JSON）

### 1) 区域树（下钻拿 ac 行政区划码）

- `POST /cross/regionList`：body `{}` → 省级列表；**子级用 URL query `?pcode=<父节点 id>`**，不能放 JSON body（body 会被忽略、仍返回省级）。
- **下钻参数是父节点的 `id`，不是 `ac`**。每级节点同时有 `id` 与 `ac`。
- 江苏→苏州下：高新区/吴中/相城/姑苏/常熟/张家港/昆山/吴江/太仓/工业园区。
  **自贸区是独立节点**，所以「自贸区外」就是逐级选这些常规辖区，别选自贸区那个子树。

### 2) 关键词搜索规范条目

- `POST /cross/search`，body：`{"keyword": <词>, "pageNum": 1, "pageSize": 20, "ac": <区划码>}`
- 结果在 `result.data.records`，每条含 `standardItem`(规范表述)、`scopeCode`、`gbName`(国民经济行业)、`permitType`、`description`、`negativeListRule`(负面清单规则)。

## permitType 含义

| 值 | 含义 | 例 |
|----|------|----|
| 0 | 一般事项（无需许可） | 组织文化艺术交流活动 |
| 1 | 前置许可（先证后照） | 从事艺术培训的营利性民办培训机构 |
| 2 | 后置许可（先照后证） | 歌舞娱乐活动、营业性演出、电影放映 |
| 4 | 备案 / 行业监管类 | 物业管理、资产评估、诊所 |

## 已证实的操作要点（踩坑）

1. **ac 必须放 JSON body**，放 URL query 会返回 `code 500 无效的区域码`。这是最易错的一处。
2. 高频连续请求会被限流返 `HTTP 503`，脚本内做指数退避重试（约 6 次）即可通过。
3. 先抓关键词全集去重（按 `scopeCode`），再按客户业态筛选，别只盯着单个关键词的首页结果。

## 行业特例：文化娱乐公司

- 歌舞/游艺 → 必须用 `歌舞娱乐活动`(R5001) / `游艺娱乐活动`(R5002)，后置《娱乐经营许可证》；
  带点歌/驻唱的酒吧也落到歌舞娱乐活动，只有纯清吧才用 `酒吧服务（不含演艺娱乐活动）`(H2005)。
- **「剧本娱乐活动」在苏州（自贸区外）库里搜不到**——文旅部五部委 2022-70 号要求剧本杀/密室登记为
  “剧本娱乐活动”，但该库无此枚举条目，注册时要**自定义/手动录入**该表述，并到县级文旅部门做告知性备案（30 日内）。
  给客户出经营范围时把这条单独点出，是差异化加分项。
- 体育健身类几乎全是“一般事项”（健身休闲活动、台球、棋牌、体育赛事策划…），仅高危险性体育运动
  （游泳/潜水/攀岩/滑雪）为后置。

## 脚本

`scripts/query_jyfwyun_scope.py`：`--tree` 打印江苏→苏州→辖区 ac；`--keyword <词> --ac <区码>` 拉规范条目。
