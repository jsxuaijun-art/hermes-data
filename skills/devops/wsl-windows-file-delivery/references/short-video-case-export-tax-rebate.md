## 一、输入素材（徐总原话要点）
- 「现在还有多少靠一个行业能干到老能吃一辈子的工作啊？鸡蛋不要放到一个篮子里」
- 客户喊他「徐会计」，老本行是公司注册、财务会计；**其实做出口也好些年了**，出口公司是**税务 A 级纳税人**
- 熟悉出口全流程直到出口退税；「看下面的图，我正常关心海关查验的事情」（**图未提供**）
- 「锻造」过三四个持证报关员，**当年资格考试通过率只有 7% 上下**
- 结论句：「两个行业经验都有的人，对出口退税的理解会更深刻一点——经验的积累，我是相信岁月的沉淀的」

## 三、3 条成稿（角度 + 主标题）
1. **反常识·上帝视角**｜《死磕一个行业？早就不吃香了》——「真正值钱的不是把一个行当熬到老，而是能同时拎得清两套行业规则」；单做账的摸不透海关、单做出口的算不准税 → 落到出口退税。
2. **资历·信任**｜《为什么我办出口退税更靠谱？》——双背景自证（A 级纳税人走退税绿色通道、带出三四个持证报关员、盯海关查验）。
3. **共鸣·价值观**｜《现在哪有能干一辈子的工作？》——接「靠一个行业干到老」的焦虑 → 鸡蛋不放一个篮子 → 岁月沉淀。

**朋友圈同步版**（短视频发出后顺带发）：从「朋友只觉得我扎在财会这行」切入 → 出口 A 级享退税绿色通道 + 报关员考试 14 年已取消、此前通过率不足一成 → 「两边经验攒一块，对出口退税的理解自然更透」+ 留口子（相关问题随时找我聊）。

## 四、本案例新增的两条技法
1. **豆包地域标签会跑偏**：默认输出给成 `#北京创业 #山东外贸 #广东外贸 #深圳创业`，交付前必须统一改成 苏州 / 上海 / 江苏。
