# 中国教育类网站爬虫实测记录

## 目标
从百度文库、Bing等中国教育网站下载/提取考试词汇文件（TXT格式）。

## 环境
- WSL (Ubuntu) + Hermes venv
- Playwright (headless Chromium) — 可用
- curl_cffi — 可用
- DrissionPage — 已安装（但缺Chrome二进制）
- scrapling — 已安装（但缺patchright依赖）

## 尝试记录

### 百度文库 (wenku.baidu.com)
| 尝试 | 结果 |
|:--|:--|
| 直接搜索「苏州中考词汇表」 | ✅ 页面加载成功，显示搜索结果 |
| 获取文档全文 | ❌ 预览仅显示前几个条目 |
| 页面滚动触发懒加载 | ✅ 可滚动，但预览长度有限 |
| 搜索结果中的词汇预览 | 可提取少量词汇（约9个），不完整 |

**限制**：百度文库要求登录才能查看/下载完整文档。搜索预览片段长度有限。

### Bing 搜索 (cn.bing.com)
| 尝试 | 结果 |
|:--|:--|
| 普通搜索 | ✅ 返回结果页 |
| 精确搜索「中考英语词汇表 filetype:txt」 | ⚠️ 结果不稳定，有时显示有时空白 |
| 搜索结果中链接跳转 | ✅ 可点击，但大多导向资讯页面而非下载页 |

**限制**：Bing 搜索结果偏向资讯类站点，文件下载链接稀少。动态加载导致 Playwright 有时抓不到结果元素。

### 百度搜索引擎 (baidu.com)
| 尝试 | 结果 |
|:--|:--|
| 直接搜索 | ❌ 触发滑块验证码（CAPTCHA） |
| 多次重试 | ❌ 始终触发验证码 |

**限制**：百度对无头浏览器+机房IP实施强验证，无法绕过。

## 实测结论
| 来源 | 词库获取 | 推荐方案 |
|:--|:--|:--|
| 百度文库 | 有词库但需登录 | 人工付费下载或手动复制 |
| Bing | 无直接下载 | 搜索引导用户找资源 |
| 百度搜索 | 被验证码拦截 | 不可用 |
| 其他教育站点 | 零散无统一格式 | 不推荐 |

## 替代方案（已验证可行）
1. **频率筛选法**：用 `en_50k.txt` 词频数据 + 词汇表交集，选前 N 个高频词作为某级别考纲词汇
2. **PDF提取法**：若已有类似上海中考默写本PDF，用 PyMuPDF(fitz) 提取文字，但表格格式提取效果有限

## 推荐工作流
当用户要求「去网上找某个考试词汇表」时，优先走方案A（频率筛选法），因为：
- 不需要绕过反爬
- 数据质量可控（基于真实语料库频次）
- 生成速度快（几分钟完成）

方案B（网上搜索）仅在用户坚持时尝试，最多用 Playwright+反检测脚本尝试3个搜索词，不行就建议用户提供文件。
