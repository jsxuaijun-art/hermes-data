# 实体活动/事件「是否真存在」核实（Entity-Event Mention Verification）

配套 `scraping-request-handling` 的「实体/品牌全网提及审计」需求类型之**变体 B**。
变体 A（负面舆情排查）见 `brand-mention-audit.md`；本文管**变体 B：证实/证伪一场活动或事件**。

2026-10-14 首例定型。徐总原话：

> 「调用爬虫skill，搜索全网，包括但不限于公众号、视频号、抖音，查找如下要素：'苏州隆奔财税服务集团有限公司'、'刘洪英'，沙龙、财税政策宣讲，我的记忆中是在苏州市相城区进行的的一个活动，可能是相城区高新区的公众号或官网中出现，也可能仍是苏州隆奔财税服务集团有限公司的公众号或官网中出现的。」

**判类要点**：这是**核实记忆**，不是查舆情。目标产出＝"有没有这场活动 + 全部要素 + 一手来源"，交付物不是分类清单而是**时间/地点/人物/主办方坐实的证据链**。别套用变体 A 的三色 xlsx。

---

## 1. 与变体 A 的区别（先判类，再动手）

| 维度 | 变体 A 负面舆情审计 | 变体 B 活动/事件核实 |
|---|---|---|
| 用户诉求 | 品牌被谁提及、有无负面 | 我记得的那件事是否真存在 |
| 主要动作 | 枚举 → 逐条点名校验 → 分类 | 关键词组合面 → 拿一手来源坐实要素 |
| 高价值产出 | 黑稿硬伤、政府公示 | **官方来源 + 现场图 + 讲课原话要点** |
| 交付形态 | 三色 xlsx + md | 证据链 md（结论/来源清单/同期活动对照/覆盖边界） |
| 失败形态 | 漏条目 | **把"我没查到"说成"不存在"，或反过来把记忆错误当事实** |

---

## 2. 查询组合面（关键词要**笛卡尔式铺**，不是单点搜索）

事件类检索的命中率取决于**组合面**：主体 × 人物 × 形式 × 地域 × 时间。只搜"苏州隆奔 沙龙"会漏掉实际举办的那场（题目里根本没有"沙龙"二字）。

| 轴 | 本次用的词 | 说明 |
|---|---|---|
| 主体全称 | `"苏州隆奔财税服务集团有限公司"` | 精确词 |
| 主体简称 | `"隆奔财税"`、`"苏州隆奔"` | 简称命中率常高于全称 |
| 人物 | `"刘洪英"` + 行业词/主体词 | **人物词必须与主体词分别组合**，别只搜人名 |
| 形式词 | 沙龙 / 宣讲 / 讲座 / 培训 / 专题辅导 / 分享会 / 圆桌会 / 公开课 | **同一件事在不同稿子里叫法完全不同**——漏形式词＝漏活动 |
| 地域 | 相城区 / 相城 / 高新区 / 元和街道 / 太平街道 | **区级 vs 街道级要都铺**，见 §4 |
| 时间 | 年份 + 月份 | 缩小时间窗 |
| 定向 | `site:mp.weixin.qq.com …`、`site:douyin.com …`、`site:<政府域名> …` | 逐站枚举 |

**执行方式承变体 A**：全部查询丢进一个 `execute_code`，循环 `web_search(q, limit=8)` 打印 `title/url/description[:180]`，命中候选再 `web_extract` 拉正文。本次 12 条查询 ≈20 秒出结果。

## 3. 一手来源优先级（拿正文，别停在搜索摘要）

1. **主办/承办单位官网**（最硬）—— 本次相城区企业综合服务中心／太平街道口径
2. **企业侧官网页**（含现场图 + 全文）—— 本次 `lbcw.cn/lbdt/...`
3. **本地权威媒体**（名城苏州 2500sz.com 系、苏州新闻、人民网江苏）—— 本次 `zxqyh.2500sz.com/doc/...`，**正文带两张现场图，可直接引用**
4. **同场其他主讲人/协办方的侧记**（交叉印证，见 §5）

**必做**：拉到正文后**点名核验**文章里真的有这两个要素（`re.findall("刘洪英", content)`、企业全称），**搜索摘要命中 ≠ 正文命中**（承变体 A 纪律）。

---

## 4. 最常见的用户记忆偏差：「区」与「街道」「园区」层级错位

**本次实例**：用户记忆"在相城区**高新区**"，实际活动落在 **相城区太平街道（阳澄湖节能环保产业园）**；且 **相城区政府官网 szxc.gov.cn 未发布该稿**，传播走的是"区企业综合服务中心（主办）＋街道（承办）"这条线。

**所以**：
- 用户说的"某区某街道/园区"是**提示不是约束**——地域轴要把区、街道、园区、开发区**全部铺一遍**，命中后再回填精确地点；
- 用户说的"可能在某公众号或官网出现"也只是猜测，**用实际来源结构回答，而不是顺着猜**；
- **一定要在结论里显式纠正偏差**（"你记的是 A，实际是 B，同一场活动"），这是本次交付最高价值的一句话——用户拿到的不是"找到了"，而是"找到了而且你的记忆需要修正"。

---

## 5. 交叉印证：同场其他主讲人 / 协办方是最好的独立来源

本次关键突破：抓到 **同场另一位主讲人（王敏霞律师，相城区律协专委）的侧记**，独立证实 7月23日同一场活动，且证实"财税＋合同"双主题是**一人一半**——她讲合同风控、目标人物讲财税风控。这条比企业自家稿更硬（第三方口径）。

**打法**：命中主办方/活动名后，**反查同场其他人的署名文章**（承办单位、协办单位、兄弟机构），往往能：
- 补出企业自家稿没写的细节（本次：确切地点"阳澄湖节能环保产业园"、参会 **30家**）；
- 提供**独立第三方**口径，避免单一来源（承 `content-evidence-discipline` 的多源交叉纪律）。

---

## 6. 同期活动必须单列成对照表（防混淆 + 防误引）

目标人物/机构往往**同期办了好几场同类活动**。本次刘洪英同期有：7月23日相城专题辅导、9月17日昆山"亲企+1℃"圆桌会、8月起发起的"50场民企财税合规公益讲座"（首场在昆山）、2025-12 昆山高企协会专题沙龙（隆奔承办）、年终关账沙龙、高端智造产业沙龙、VIP女企业家端午沙龙……

**交付里必须有一张"同期/相邻活动对照表"**（时间｜地点｜活动｜链接），否则用户会把自己记得的那场和别的场搞混，后续引用极易张冠李戴。顺带还能给出**可复用打法洞察**（本次：主办申报链条"市企服中心指导→区企服中心主办→街道承办→工商联+律所+科技公司协办"是可复制的进街道/园区宣讲口子）。

## 7. 覆盖边界（承变体 A，写清"查不到"与"不开放"）

- **微信公众号图文**：不进通用搜索索引（抖音/微信生态常态）→ 写"未直接拿到公众号原文"，并给出替代路径：直接找企业索要、或联系主办单位（区企业服务综合服务中心）取通稿；企业官网底部常挂公众号二维码，可作入口。
- **视频号**：完全封闭，无外部索引 → 如实写"无法公开检索"，指出企业官网"视频展示"栏目可作人工入口。
- **抖音**：站内搜索对无头访问有 IP 信誉限制 → 用 `site:douyin.com <主体>` 枚举能拿到**账号矩阵**（本次拿到：官方号/老会计/周周/小刘总/英姐五个矩阵号），但**翻不到具体某场活动的现场视频**，如实写明"账号矩阵已获、该场视频未命中"。

**结论**：查不到 ≠ 不存在；只有拿到一手来源才敢说"存在"，只有铺完组合面才敢说"未命中"。

## 8. 交付结构（本次定型，可复用）

```
<主体>-<地域><事件类型>检索/
└── <主体>-<地域><事件>检索报告.md
    一、结论（已锁定，且不是孤证）＋要素对照表 ＋显式纠正记忆偏差
    二、权威来源清单（逐条：标题／完整 URL／发布日／含图直链）
    三、活动内容要点（讲课原话/主线/五个维度，逐条可引用）
    四、同期/相邻活动对照表（防混淆）
    五、社交/视频平台检索结果（逐平台一行：拿到什么／未命中什么）
    六、覆盖边界（诚实声明，逐项给原因）
    七、可动作的建议（要素材找谁、要核口径看哪、打法可否复制）
```

打包承铁律：folder → zipfile → rmtree，桌面只留 `<任务名>.zip`，不散落。

## 9. 工作实例（2026-10-14 苏州隆奔财税 / 刘洪英 · 相城区活动）

- **需求**：核实"隆奔财税 + 刘洪英 + 沙龙/财税政策宣讲 + 相城区"这场活动是否存在。
- **结论**：存在。**2026-07-23**，苏州市相城区**太平街道**（阳澄湖节能环保产业园），主题「**财税合同双风控、企业合规稳经营**」专题辅导；刘洪英任**主讲嘉宾**；苏州市企业综合服务中心指导 → **相城区企业综合服务中心主办** → 太平街道企业综合服务中心承办；协办：相城区工商业联合会、江苏晟贤律师事务所、企麟科技（苏州）；参会辖区 **30家** 中小微/高新/专精特新企业负责人及财务、法务专员。
- **三个独立来源**：隆奔官网 `lbcw.cn/lbdt/2026-07-29/1100.html`（含现场图）／苏州中小企业汇 `zxqyh.2500sz.com/doc/2026/07/30/1221948.shtml`（含 2 张现场图，可直接引用）／同场主讲人王敏霞律师侧记 `wangminxia.com/news/hydt/1130.html`（第三方独立印证）。
- **记忆偏差纠正**：用户记"相城高新区"，实为**太平街道**；且相城区政府官网未发布，传播在"区企服中心＋街道"线。
- **可复用要点**：①判类为变体 B，不套三色 xlsx；②组合面铺词（尤其**形式词要全铺**）；③拿到主办方后**反查同场其他人**做交叉印证；④同期活动单列对照表；⑤覆盖边界（公众号/视频号/抖音站内）如实写。
