# 抖音收藏转 AI 知识库（能检索才是真拥有）

## 核心原则
**知识库的价值不在"存"，而在"需要时能检索调用"。**
收藏/记录一堆 ≠ 拥有知识；只有做到"可检索、用的时候一眼调出来"，收藏才算真正是你的。

## 落地方法（已跑通）
刷到有价值内容 → 照常收藏 → 丢链接给 Hermes → 自动：下载 → 转写 → 生成知识卡片（一句话概括 + 核心要点 + 长视频分章 + 原链接）→ 存 Obsidian → 需要时一句话检索。

- 存：粘贴抖音链接即触发（skill `douyin-kb`）
- 查：「在收藏库找：主题词」
- 看原视频：卡片里的链接一键跳转

## 两个值得内化的交互
1. **写作前让 AI 先检索历史库**：动笔前先翻存量（Obsidian + session_search + 技能统一库），复用素材而非每次从零起稿。
2. **入库先问归属、你只管确认**：不花整块时间分类打标，AI 看到新东西先问"放哪"，确认即入库，省下整理时间。

## 三条纪律（踩过的坑）
1. **专业内容人工把关**：AI 归类/摘要会出错（如语音把"打标签"转成"打标圈"）。涉税/政策内容涉及文号、口径，必须人工核，绝不因"显得省事"而全自动。宁少勿错。
2. **数据边界**：涉客户/涉税敏感内容不入开放库（Obsidian 主库随同步上云）；敏感内容放私有区。视频不落库，只存文字+原链接（省存储、不拖垮 git 同步）。
3. **分清内核与话术**：这类视频多是 App 广告（"1500万字""用户只管点头"是推销演示）。内核可借鉴，工具载体不必为它付费——本地 Hermes+Obsidian 已具备同等甚至更强（可编程、私有）能力。
