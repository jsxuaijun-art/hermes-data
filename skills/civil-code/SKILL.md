# Civil Code（民法典）总路由 Skill

## 任务目标

当用户提出与《民法典》相关的法律咨询、条款查询、场景判断时：
1. 先判定问题归属哪一编（路由判断）；
2. 命中已建子 skill 的，调用对应子 skill 获取结构化、可精确引用的答案；
3. 未建子 skill 的编，按「七编索引」给出条文范围与主题指引，并提示可补建对应子 skill。

## 民法典概况

- 通过：2020-05-28 第十三届全国人大第三次会议；施行：2021-01-01。
- 结构：**7 编 1260 条** + 附则。施行同时废止《婚姻法》《继承法》《民法通则》《收养法》
  《担保法》《合同法》《物权法》《侵权责任法》《民法总则》九部法律。
- 效力层级：民法典为全国人大基本法律；特别法（如《商标法》《消费者权益保护法》）有规定的，
  依《立法法》优先适用特别法，无规定或需补充时回到民法典。

## 民法基本原则（总则第3—9条，跨编通用）

1. **合法权益受保护**（第3条）：民事主体的人身、财产权利及其他合法权益受法律保护。
2. **平等**（第4条）：民事主体法律地位一律平等。
3. **自愿**（第5条）：按自己意思设立、变更、终止民事法律关系。
4. **公平**（第6条）：合理确定各方权利义务。
5. **诚信**（第7条）：秉持诚实、恪守承诺（"帝王条款"）。
6. **守法与公序良俗**（第8条）：不得违反法律，不得违背公序良俗。
7. **绿色**（第9条）：有利于节约资源、保护生态环境。

1. 用户问"签了合同 / 违约 / 买卖 / 借款 / 租赁 / 定金 / 格式条款 / 物业" → **civil-code-contracts**
2. 用户问"被撞 / 被打 / 高空抛物 / 产品缺陷 / 医疗损害 / 网络侵权 / 饲养动物咬人 / 谁赔" → **civil-code-tort**

5. 用户问"名誉 / 肖像 / 隐私 / 个人信息" → 人格权编（待补建）
6. 用户问"行为能力 / 代理 / 诉讼时效 / 民事法律行为效力" → 总则编（待补建）

## 使用注意

- **引用须精确到条文号**（如"民法典第577条"），禁止凭印象给条文号。
- 回答前优先调用对应子 skill；子 skill 内 `references/` 含该编完整简体条文，可精确摘录。
- 涉及司法解释（如《合同编通则解释》《担保制度解释》《婚姻家庭编解释》）时，注明"需结合
  司法解释"，不要将司法解释条文混入民法典正文。
- 旧法（合同法/物权法等）已废止，引用一律指向民法典对应条文。
- 本 skill 不提供诉讼代理意见，属普法/条款检索辅助；复杂个案建议提示咨询执业律师。
