# 合同逐条审查清单（合同审查模块）

> 触发：客户上传/粘贴合同（合作、供货、服务、租赁、劳动合同除外另条处理）。
> 流程：解析 → 逐条审查 → 红黄绿风险分级 → 给修改建议 → 出结论。

## 一、审查通用清单（缺一条都要勾）

### 主体与背景
- [ ] 双方主体（自然人身份证 / 公司统一社会信用代码）完整
- [ ] 签约代表有授权 / 公司用章、法定代表人签字
- [ ] 合同目的、交易背景（避免"阴阳合同"风险）

### 交易内容（逐条对齐）
- [ ] 标的、数量、质量标准、验收标准与异议期
- [ ] 价款/单价/含税与否、**付款节点与比例**、逾期付款违约责任
- [ ] 交付/履行时间、地点、方式、风险转移时点
- [ ] **违约金**：比例是否过高/过低、计算方式是否明确（过高可在诉讼中请求调减——民法典定金/违约金规则，条文号联网核实）
- [ ] 知识产权归属（定制成果、使用哪些素材）
- [ ] 保密条款（范围、期限、违约责任）
- [ ] 不可抗力、情势变更条款
- [ ] 合同解除权与解除后清算（退款/退货/补偿）
- [ ] **争议解决条款**：约定仲裁 or 诉讼（**二选一**，避免两者都写导致无效）；管辖地点；优先写"被告住所地或对己有利地"
- [ ] **送达条款**：明确送达地址+电子送达（邮箱/微信），对日后通知/诉讼送达至关重要
- [ ] 合同份数、生效条件、签署页、骑缝章

### 高频缺失条款（一定要提醒补）
- 送达条款（最容易被忽略，涉诉时最难）
- 违约金计算方式（写"每天万分之几"不如写"逾期未付按日____‰"）
- 验收期限与书面异议期（否则被"默认验收"拖死）
- 对账单确认机制（货款类合同强烈建议加：按月对账、盖章确认）
- 退出/终止条款（长期合作尤其要）

## 二、红黄绿风险分级
| 级别 | 含义 | 处理 |
|:--:|--|--|
| 🔴 高 | 重大权利义务失衡、违法无效、巨额敞口 | 建议改，不改则不签；必要时转律师定稿 |
| 🟡 中 | 条款不明确、有歧义、对我方不利 | 提修改建议，建议措辞 |
| 🟢 低 | 常规条款、文字优化 | 可签，提出优化建议 |

## 三、输出结构（固定模板）
```
① 合同概况
   类型 / 主体 / 标的 / 金额(含税?) / 期限 / 生效条件
② 逐条风险表（条款→级别→问题→修改建议）
③ 缺失条款提醒（列清单）
④ 总体结论：
   - 可直接签署（🟢）
   - 修改后签署（🟡 列出必改项）
   - 建议执业律师定稿（🔴）
```

## 四、给客户的修改建议措辞示例
- 争议解决：建议写"双方协商不成的，向**XX地**人民法院起诉"（选对自己有利/方便的地区）；若已有仲裁别漏"一裁终局"提示。
- 违约金：建议写"逾期付款的，按未付金额的日万分之____向守约方支付违约金，且出借方有权暂停履行"。违约比例过高会被法院调减，别指望靠它"一劳永逸"。
- 付款节点：把"验收合格后付款"拆成"收到货 3 日内初检 → 7 日内验收并出具验收单 → 验收后 15 日内付款"。

> ⚠️ 涉具体法条/比例/期限一律联网核实后再给；凡涉及大额、股权、担保、劳动竞业等复杂条款，提示"建议执业律师定稿"。绝不代为出具正式法律意见。
