# 共享 / 局域网打印兼容专章

建立于 2026-10。触发场景：用户说"我们不是一人一机，必须共享或局域网"、
"办公室还有 Win7 电脑"、"这台机型支不支持 Win7"。

## 0. 先说结论（一句话）

**共享 / 局域网模式下，真正的兼容判据不是"这台打印机支不支持 Win7"，
而是"这台打印机的打印语言是不是 GDI"。**

- **PCL / PostScript 机型** → 客户端可用 Windows 自带通用驱动发任务 → **Win7 照样能打**
- **GDI（主机型 / Host-based）机型** → 必须装厂商专用驱动 → 没有 Win7 驱动就是**死结，绕不过去**

## 1. 为什么"USB 直连"的兼容逻辑在共享下不成立

| 模式 | 谁在驱动打印机 | Win7 靠什么活 |
|---|---|---|
| **USB 直连**（一人一机） | 每台电脑各自 | 必须有**这台电脑的**厂商驱动；厂商不给 Win7 驱动 = 打不了 |
| **局域网直连**（打印机自带网口，各机按 IP 添加） | 打印机本体（PCL/PS）或客户端（通用驱动） | PCL/PS 机型可用 Windows 通用驱动 → 能打 |
| **USB 接一台电脑再共享**（该机当"打印服务器"） | 承载共享的那台电脑 | 渲染实际发生在客户端；客户端仍需驱动，但 PCL/PS 可用通用驱动绕过 |

**关键推论：把"支不支持 Win7"当判据，会在共享场景下把可用机型砍掉一大片；
换成"打印语言是不是 GDI"，判据才准。**

## 2. 打印语言：GDI vs PCL / PostScript 的原理

**PCL / PostScript（页面描述语言 PDL）** —— 打印机自带控制器（CPU + 内存）解析指令。
电脑发出的是 PCL/PS 描述，**不依赖特定厂商驱动** → 可用通用驱动（如
"Microsoft PS Class Driver" 或 HP LaserJet PCL6 通用驱动）。
共享 / 局域网环境下最省事。

**GDI / 主机型（Host-based）** —— 打印机没有完整页面描述能力，
**由电脑上的专用驱动把页面渲染成位图**再发给打印机。因此：

- **必须装厂商专用驱动**，通用驱动完全不工作
- 客户端要渲染 → **每台客户端都得有对应驱动**；厂商不给 Win7 → 死结
- 通常便宜、内存小，属**低端机**（也常见于"建议月印量"偏小的机型）
- 对 Mac / Linux 支持通常很差或没有

**判断方式：** 查厂商官网规格页的「打印语言 / 打印语言支持」字段。
**只写 GDI 或 Host-based 的 = 效应等同于"需要厂商驱动"**。

## 4. 两种"共享"做法，差别很大（必须先跟用户分清）

### A 方案：打印机 USB 插在一台电脑上，把这台电脑当"打印服务器"共享出去

❌ **单点故障** —— 那台电脑必须 24 小时开机；它一关机 / 休眠 / 重启，全公司都打不了。
对"申报期绝对不能停"的业务，一次死机就是全公司停工。

❌ **SMB1 坑（经典）** —— Win10 / Win11 默认**关闭 SMB1 协议**，
而 **Win7 访问共享打印机依赖 SMB1**。症状：Win7 连不上共享打印机、报"无法连接"、
资源管理器崩溃。需在 Win10 上重新启用 SMB1（本身是安全隐患）才能通。

❌ 跨网段、防火墙、Guest 权限都容易出问题。

### B 方案：打印机自带网口，直接接路由器/交换机，每台电脑按 IP 直连  ← 推荐

✅ **不依赖任何一台电脑常开**（这是最大优势）
✅ 每台电脑独立添加，一台出问题不影响别人
✅ Win7 用"标准 TCP/IP 端口 + 通用 PCL 驱动"成功率很高，**绕开 SMB1 的坑**
✅ 对"不能停机"的业务，这是唯一正确的做法

**建议话术：** 如果用户还在用 A 方案，借这次换设备直接升级成 B 方案 —— 这一改，
Win7 那台的影响基本归零（它只是众多客户端之一，独立添加、用通用驱动，与别人互不干扰）。

## 5. Win7 客户端添加网络打印机实操（让 IT 照做）

1. 控制面板 → 设备和打印机 → **添加打印机**
2. 选 **"添加本地打印机"**（⚠ 注意不是"添加网络打印机"）
3. **创建新端口** → 选 **Standard TCP/IP Port** → 输入打印机 IP 地址
4. 厂商 / 型号列表里若没有这台机器 → 点"从磁盘安装"装厂商 Win7 驱动；
   **若厂商没有 Win7 驱动，就选通用驱动**（如 "Microsoft PS Class Driver" 或 HP LaserJet PCL6）
5. 打印测试页验证

**备用路径（A 方案下 Win7 连 Win10 共享打印机）：**
添加本地打印机 → 创建新端口 → **Local Port** → 端口名填 `\\主机IP\共享名` → 从磁盘安装驱动。

**Win7 SP1 需已安装 SHA-2 支持更新**，否则可能装不上较新的驱动包。

## 6. 收尾验证（不能省的那一步）

> **务必用用户自己的财务软件打一份真实凭证 + 一份电子税务局申报表，确认无误才算通过。**

参数表 / 官网兼容列表永远不等于"用户那台 Win7 + 那套财务软件能打"。
存在老系统时，要求商家**用用户那台机器现场装机验证驱动**，不接受口头承诺。
