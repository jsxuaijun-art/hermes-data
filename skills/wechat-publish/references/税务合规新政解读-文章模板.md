# 税务合规新政解读类文章模板

> 适用场景：税务新规/新机制发布后的解读文章
> 首篇实践：2026-06-29「江苏税务智能体检时代来了」
> 用户评价：效果待公众号预览确认

## 结构模板（五段式）

```
标题：XX"智能体检"时代来了：你的企业准备好了吗？
作者：盈信税务
封面：报表/商务风格
摘要：120字以内，点明新政核心+数据冲击+读者利益

⏱ 全文约 1,500 字 | 阅读需 5-6 分钟

──

① 开篇钩子：从两个真实案例切入
- 选一个"风险提示函"案例 + 一个"智能审拦截"案例
- 案例要有血有肉（企业名+人名+具体数据偏差）
- 结尾点题：这不是偶然，是系统性机制

📷 配图方向：政府办公/税务建筑/政策文件 → 营造权威感

② 数据硬核：用数字让读者感受到冲击
- 指标数量、推送户次、税款成效、扫描频率
- 用粗体/强调突出关键数字
- 补充延伸机制（如二次扫描、提级推送）增加深度

📷 配图方向：数据大屏/图表/电脑屏幕 → 强化可信度

③ 操作指南：告诉读者怎么办
- 先给"定心丸"——征收期内更正不罚
- 再给"警告"——逾期不反馈后果递进
- 最后给具体操作流程（5步清单）
- 强调每一步的难点和注意事项

📷 配图方向：清单/笔记本/办公桌面 → 视觉化指引

④ 本地影响：把宏大叙事拉回读者身边
- 选本地真实案例（苏州工业园区最佳）
- 提炼2~4个具体影响点
- 让读者觉得"这事跟我有关"

📷 配图方向：城市天际线/园区/写字楼 → 读者代入感

⑤ 公司价值：收网，回到服务
- 正名话术：严谨不是打扰
- 列出具体服务项（5条左右，用✅）
- 数字背书（客户数、转介绍率、资质）
- 品牌落款

📷 配图方向：办公场景/团队协作/专业环境 → 信任背书

──

品牌落款：
盈信企业管理（苏州）有限公司
高级会计师领衔 | 24年财税经验
苏州 · 上海双城布局
```

## 调性要点

1. **开头必须有真实案例** — 让读者觉得"这事是真的"，不是政策复读
2. **多用具体数字** — 183个指标、5.7万户次、9.44亿元，数字自己会说话
3. **先安抚后警告** — 先说"不罚"，再说"逾期后果"，节奏感
4. **本地案例要有** — 苏州企业案例让本地读者产生"我身边的事"的代入感
5. **服务段要正名** — 催数据是"严谨的工作方式"，不是"打扰"

**配图规则：**
- 每张图必须跟段落主题直接挂钩，不能随便塞
- 图片均匀分布在文章各段断点处，不扎堆
- 下载后用 `file` 命令验证是否为真实图片（排除404页面）
- 正文用 `![描述](sec0X_主题.jpg)` 引用，不用 `/tmp/` 前缀

## 字数控制

- 纯汉字约 1,500 字（含标点约 1,800 字）
- 正常阅读速度 300字/分 → 约5~6分钟
- 标注格式：`⏱ 全文约 1,500 字 | 阅读需 5-6 分钟`
