# 已核实文号：被稽查公司的「注销 / 责任穿透 / 恶意注销」主题

> 2026-11-09 核实（写作时对关键条款逐一溯源，经 fgk/权威源对过原文）。
> 写公众号/文案/咨询回复涉及「正在被稽查的公司能不能靠注销跑路」时直接用本清单，勿沿用旧稿里的错误文号。

## 常见错误文号（勿引用）

| 错误写法 | 真相 | 处理 |
|---|---|---|
| "2025年24号公告规定特别纳税调查期间不予注销" | 2025年第24号 = 《国家税务总局 最高人民法院关于企业破产程序中若干税费征管事项的公告》，讲破产企业税费核销，与稽查无关 | 弃用此号；用下方 2017年6号第四十六条 |

## 正确依据（可直接引用）

1. **特别纳税调查期间原则上不予注销**
   - 出处：《特别纳税调查调整及相互协商程序管理办法》第四十六条，国家税务总局公告**2017年第6号**
   - 原文：被调查企业在税务机关实施特别纳税调查调整期间申请变更经营地址或者注销税务登记的，税务机关在调查结案前原则上不予办理税务变更、注销手续。
   - 适用：被**特别纳税调查**的公司（关联交易调整类稽查）。

2. **一般性"处于税务检查/稽查状态不予（容缺/简易）注销"**
   - 出处：《企业注销指引（2025年修订）》，市场监管总局等六部门，2025-12-12 发布
   - 要点：容缺即时办理条件含"未处于税务检查状态、无欠税（滞纳金）及罚款"；存在未办结涉税事项且不符合承诺制容缺即时办理条件的，税务机关不予注销。简易注销程序不适用"正在被立案调查或采取行政强制"等情形。
   - 适用：普通税务稽查/检查状态下的注销卡壳，最常引用的依据。

3. **偷税、抗税、骗税追征不受期限限制（责任穿透的时间要件）**
   - 出处：《中华人民共和国税收征收管理法》第五十二条第三款
   - 原文：对偷税、抗税、骗税的，税务机关追征其未缴或者少缴的税款、滞纳金或者所骗取的税款，不受前款规定期限的限制。（一般少缴税款三年/特殊情况五年追征期，偷抗骗不设限。）

4. **逃税罪刑事责任**
   - 出处：《中华人民共和国刑法》第二百零一条
   - 要点：纳税人采取欺骗、隐瞒手段进行虚假纳税申报或者不申报，逃避缴纳税款数额较大并且占应纳税额百分之十以上的，处三年以下有期徒刑或拘役，并处罚金；数额巨大并且占应纳税额百分之三十以上的，处三年以上七年以下有期徒刑，并处罚金。经税务机关依法下达追缴通知后，补缴应纳税款、缴纳滞纳金，已受行政处罚的，不予追究刑事责任（五年内因逃避缴纳税款受过刑事处罚或者被税务机关给予二次以上行政处罚的除外）。

5. **偷税罚款幅度（0.5~5倍的出处）**
   - 出处：《税收征收管理法》第六十三条第一款（经《企业注销指引（2025年修订）》转引确认）
   - 原文：对纳税人偷税的，由税务机关追缴其不缴或者少缴的税款、滞纳金，并处不缴或者少缴的税款百分之五十以上五倍以下的罚款。
   - 即"0.5~5倍罚款" = 百分之五十以上五倍以下。

6. **恶意注销/弄虚作假的行政后果**
   - 出处：《企业注销指引（2025年修订）》"注销法律责任及有关规定提示"部分 + 简易注销承诺机制
   - 要点：全体投资人书面承诺真实性；弄虚作假 → 撤销注销登记、列入严重违法失信名单。公司被强制注销的，原公司股东、清算义务人的责任不受影响。

## 写作提示

- 数字（如"补税+滞纳金约28万"）来自具体个案素材，写进文章标「个案参考，因案而异」，不写成普遍数字。
- 罚款"0.5~5倍"可补一句换算举例（欠税20万 → 罚款区间10万~100万）增强冲击，注明幅度依法定。
- 文末依据注明统一格式：依据国家税务总局公告2017年第6号《特别纳税调查调整及相互协商程序管理办法》第四十六条、《企业注销指引（2025年修订）》、《税收征收管理法》第五十二条、《刑法》第二百零一条等现行规定撰写，具体案情请咨询专业机构。
