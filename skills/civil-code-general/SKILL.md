# 总则编（第一编）结构化 Skill

## 任务目标

总则是整部民法典的"总纲"。把用户问题定位到「自然人/法人/民事权利/法律行为/代理/民事责任/诉讼时效」哪一章，
给出"主体资格、行为效力、代理存亡、责任与免责、时效"的结构化结论与处置步骤；并负责把分编问题路由到对应子 skill。

## 总则编结构（路由索引，10 章）

1. 基本规定（第1—12条）：立法目的、民法调整对象、六大基本原则（平等/自愿/公平/诚信/守法公序/绿色）、习惯补充、特别法优先、属地。
2. 自然人（第13—56条）：权利能力、行为能力（17—22）、监护（26—39）、宣告失踪/死亡（40—53）、个体工商户与农村承包经营户（54—56）。
3. 法人（第57—101条）：一般规定（57—75）、营利法人（76—86）、非营利法人（87—95）、特别法人（96—101）。
4. 非法人组织（第102—108条）。
5. 民事权利（第109—132条）：人格权、财产权、债权、知识产权、继承权、数据/网络虚拟财产（127）。
6. 民事法律行为（第133—160条）：一般规定（133—136）、意思表示（137—142）、效力（143—157）、附条件/期限（158—160）。
7. 代理（第161—175条）：一般规定（161—165）、委托代理（166—171）、代理终止（172—175）。
8. 民事责任（第176—187条）：责任方式（179）、免责/减责（180—185）、责任竞合（186）、民刑责任优先（187）。
9. 诉讼时效（第188—199条）：普通时效3年（188）、中断/中止（195）、不适用时效（196）、不得预先放弃（197）。
10. 期间计算（第200—204条）。

## 高频场景 → 处置步骤 → 条文

1. **"8岁/10岁孩子给主播打赏、游戏充值，能退吗？"**
   - 第20条：不满8周岁为无行为能力人，所实施法律行为无效→全额退。
   - 第19条：8周岁以上未成年人为限制行为能力人，超出年龄智力相适应的（大额打赏/充值）须法定代理人同意/追认，否则无效或可撤销→可主张退回。
   - 步骤：证明充值/打赏行为由未成年人实施（设备、账号、时间、内容）；主张超出其行为能力；与平台协商退款，不成可诉（结合第145条限制行为能力人实施行为效力）。

2. **"被忽悠/胁迫签了合同/协议，怎么办？"**
   - 欺诈第148条：受欺诈方有权请求法院或仲裁机构撤销。胁迫第150条同理。显失公平第151条。重大误解第147条。
   - 撤销后依第157条：返还财产、折价补偿、过错方赔偿。
   - 步骤：收集欺诈/胁迫/误解证据；在**除斥期间**内（知道起1年，重大误解90日，受胁迫自终止起1年，最长行为成立5年）起诉/仲裁撤销。

3. **"员工/朋友没授权却代我签了合同，有效吗？"**
   - 无权代理第171条：未经追认对被代理人不生效→由行为人担责；相对人可催告，被代理人未作表示视为拒绝。
   - 表见代理第172条：相对人有理由相信有代理权（如曾有授权表象、盖章空白合同）→代理有效，被代理人担责后可向行为人追偿。
   - 步骤：看是否有授权表象；无→拒绝追认并通知相对人；有表象→可能构成表见代理需先担责再追偿。

4. **"朋友见义勇为受伤、或紧急救人弄伤对方，赔吗？"**
   - 第183条：因保护他人民事权益受损→由侵权人担责，受益人适当补偿；无侵权人/逃逸/无力担责→受益人应补偿。
   - 第184条：**自愿实施紧急救助造成受助人损害的，救助人不承担民事责任**（"好人条款"）。
   - 步骤：见义勇为受损→找侵权人，侵权人不明则请求受益人补偿；救助中误伤受助人→直接适用184条免责。

5. **"借条/欠款过了3年还能起诉吗？时效过了吗？"**
   - 第188条：普通诉讼时效3年（自知道权利受损及义务人起）；最长20年。
   - 第195条：起诉/请求履行/同意履行等→时效中断，重新计算。
   - 第196条：停止侵害、返还不动产/登记动产物权、抚养费/赡养费请求权等不适用时效。
   - 步骤：算起算点；看有无中断事由（催款记录、对方承诺还款）；时效届满仍可起诉（债务人提出时效抗辩才失胜诉权）。

6. **"公司欠债，能直接找老板个人还吗？（法人人格否认）"**
   - 第83条：营利法人的出资人滥用法人独立地位和股东有限责任逃避债务、严重损害债权人利益→对法人债务承担连带责任。
   - 步骤：证明财产混同/过度支配/资本显著不足等滥用情形；可诉请揭开公司面纱，追究股东连带责任。

## 重点条文摘录（原文见 references/总则编全文.md）

- 第17条：十八周岁以上的自然人为成年人；不满十八周岁的为未成年人。
- 第19条：八周岁以上的未成年人为限制民事行为能力人，实施民事法律行为由法定代理人代理或经同意、追认；但可独立实施纯获利益或与其年龄、智力相适应的行为。
- 第20条：不满八周岁的未成年人为无民事行为能力人，由法定代理人代理实施民事法律行为。
- 第143条：具备下列条件的民事法律行为有效（行为人有相应民事行为能力、意思表示真实、不违反法律行政法规强制性规定不违背公序良俗）。
- 第146条：行为人与相对人以虚假的意思表示实施的民事法律行为无效。
- 第148条：一方以欺诈手段使对方在违背真实意思情况下实施的民事法律行为，受欺诈方有权请求法院或仲裁机构撤销。
- 第150条：一方或者第三人以胁迫手段使对方在违背真实意思情况下实施的民事法律行为，受胁迫方有权请求撤销。
- 第153条：违反法律、行政法规的强制性规定的民事法律行为无效（但该强制规定不导致无效的除外）。
- 第157条：法律行为无效、被撤销或确定不发生效力后，取得的财产应予返还；不能返还或没必要返还的折价补偿；有过错方赔偿对方损失；各方都有过错各自担责。
- 第171条：行为人没有代理权、超越代理权或代理权终止后实施代理行为，未经被代理人追认的，对被代理人不发生效力。
- 第172条：无权代理但相对人有理由相信行为人有代理权的，代理行为有效（表见代理）。
- 第179条：承担民事责任的方式主要有停止侵害、排除妨碍、返还财产、恢复原状、修理重作更换、继续履行、赔偿损失、支付违约金、消除影响恢复名誉赔礼道歉等。
- 第183条：因保护他人民事权益使自己受损害的，由侵权人担责，受益人可适当补偿；无侵权人/逃逸/无力担责，受害人请求补偿的，受益人应补偿。
- 第184条：因自愿实施紧急救助行为造成受助人损害的，救助人不承担民事责任。
- 第186条：因一方违约损害对方人身/财产权益的，受损害方有权选择请求承担违约责任或侵权责任（责任竞合）。
- 第188条：向法院请求保护民事权利的诉讼时效期间为三年（法律另有规定依其规定）。
- 第196条：下列请求权不适用诉讼时效（停止侵害、排除妨碍、消除危险；不动产物权/登记动产物权返还；抚养费/赡养费/扶养费；依法不适用时效的其他请求权）。

## 注意事项

- 总则编是总纲，分编（合同/物权/人格权/婚姻家庭/继承/侵权）的特别规定优先于总则一般规定（第11条特别法逻辑；分编有规定的从分编）。
- 路由建议：问"合同/买卖/借款/租赁"→civil-code-contracts；问"房/车/抵押/居住权"→civil-code-property；问"名誉/肖像/隐私/个人信息"→civil-code-personality；问"结婚/离婚/继承"→civil-code-marriage / civil-code-inheritance；问"被撞/被打/高空抛物"→civil-code-tort；其余主体资格/代理/时效/法律行为效力→本编。
- 法律行为可撤销的**除斥期间**与诉讼时效不同：撤销权超期消灭（第152条），务必提示客户及时行使。
- 第188条3年时效为"胜诉权"抗辩，非起诉权消灭；时效届满债务人抗辩则失胜诉权。
- 所有条文以 `references/总则编全文.md` 为准；引用务必核对该文件原文（本编来源为政府官网转载，个别标点与官方公报略有差异，以最高人民法院公报为准）。
