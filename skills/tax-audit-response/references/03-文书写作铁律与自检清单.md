# 文书写作铁律与自检清单

税务文书和一般商务文书最大的区别：**你说的每一句话，都可能被对方引用回来对你不利。**

---

## 一、十条铁律

**1. 只写事实，不写推测。**
禁用"可能""大概""应该是""不排除"。写了推测，等于主动提供一条对己不利的线索。

**2. 定性词是生死线。**
绝不在自己的文书里出现"偷税""故意""明知""为了少缴税款而……""客观上造成了少缴"。
替代表达：

| 不要写 | 改写成 |
|---|---|
| 我们偷税了 | 因对政策理解偏差，导致申报口径与税务机关认定不一致 |
| 故意不申报 | 因办税人员交接疏漏，未能按期办理申报 |
| 为了少缴税款 | 基于对××政策的理解，按××口径进行了申报 |
| 我们知道这样不对 | 现已认识到申报口径存在偏差 |
| 帐外经营 | 部分业务未及时入账 |

**3. 每一句主张后面挂证据。**
格式："……（详见证据 3：2024年6月15日银行回单）"。没有证据支撑的陈述，不如不写。
**行政执法中没有真相，只有证据。** 检查人员依法制作的询问笔录，证明力高于企业提供的合同等一般书证，所以"我们手里有什么证据、证据证明力如何"要先想清楚。

**证据证明力层级（判断证据强弱、决定举证策略）：**
- 国家机关依职权制作的公文文书 > 其他书证
- 鉴定结论、现场笔录、档案材料、经过公证或登记的书证 > 其他书证/视听资料/证人证言
- 原件、原物 > 复制件、复制品
- 法定鉴定部门的鉴定结论 > 其他鉴定部门的鉴定结论
- 原始证据 > 传来证据
- 数个种类不同、内容一致的证据 > 一个孤立的证据
> 实操含义：① 证据越接近"国家机关/原始/公证"越硬，优先收集这类；② 现场笔录（询问笔录）证明力高于自备书证——**所以回答询问要谨慎、事先准备，一句话可能成为对方最硬的证据**；③ 对方笔录若来自有动机的员工（劳资纠纷/利害关系）、或存在诱导胁迫，可攻击其证明力让其降效。

**4. 先讲业务，再讲税。**
检查人员判断定性，核心看业务真实性。文书结构永远是：**业务背景 → 合同 → 资金流 → 货物流/服务交付 → 发票 → 账务处理**。三流一致讲清楚了，定性就下来了。

**5. 数字必须前后一致，口径标注清楚。**
含税／不含税必须写明。同一个数字在文书里出现三次，三次必须一样。金额一律用表格列示，不要散落在段落里。

**6. 时间线精确到日。**
"2024年上半年"不行，写"2024年3月至2024年6月"或具体到日。模糊的时间表述会被按最不利方式推定。

**7. 态度要配合，立场要清楚。**
开头表明配合态度（"我局/公司高度重视，积极配合检查"），但配合不等于认下定性。
标准句式："**对检查机关指出的问题，我公司在事实层面如实说明如下；对其中××项的法律定性，存在不同理解，恳请复核。**"

**8. 留协商余地。**
不要在文书里写死"请求免予处罚"这种一步到位的要求。要写"请求依法从轻、减轻或不予处罚"，给对方台阶，也给自己后续谈判空间。金额争议用表格另行列示，不在正文写死。

**9. 法条引用全称 + 条号。**
"《中华人民共和国税收征收管理法》第五十二条"，不要写"《征管法》52条"。

**10. 结尾三要素缺一不可**：请求事项（具体可执行）＋ 事实理由 ＋ 此致机关全称。

**11. 动笔前先算清程序性救济窗口。**
很多案子的正解不是"怎么写得动听"，而是"有没有一条程序性途径能让这个争议根本不成立"。
典型如无票支出：《企业所得税税前扣除凭证管理办法》（国家税务总局公告2018年第28号）第15条给了**被告知之日起 60 日**的补救窗口，第14条给了**凭资料证实真实性即可税前扣除**的通道。
**先查 `references/04-常见案由论证要点.md`，再动笔。** 顺序永远是：程序性补救 → 定性抗辩 → 金额测算。跳步就会丢掉最省力的那条路。

## 二、生成后自检清单

逐条打勾，任何一条不过关就重改：

- [ ] 阶段判断正确？文书类型与当前阶段匹配？
- [ ] 每一个事实主张后面都有证据编号？
- [ ] 全文无"偷税""故意""明知""为少缴税款"等自我不利定性？
- [ ] 数字前后一致？含税／不含税口径统一并已标明？
- [ ] 时间线精确到日？
- [ ] 法条引用为全称 + 条号，且现行有效？
- [ ] **是否已用尽程序性补救途径**？（如无票支出：28号公告第15条的 60 日窗口、第14条六项资料）
- [ ] 案情分析是否给出了**路径分叉**（至少两条），而不是替客户假设单一路线？
- [ ] **税率口径是否核实**？是否先确认了小微企业身份，而不是默认按 25% 算？
- [ ] 滞纳金、罚款测算是否给出**区间**而非单一数字？是否标明了起算日？
- [ ] 请求事项具体、可执行，且留有余地？
- [ ] 配合态度到位，但未认下定性？
- [ ] 落款、日期、联系人、联系电话齐全？
- [ ] 附件清单与实际能提供的证据一一对应？
- [ ] 所有【待确认】项已标出，无编造内容？
- [ ] 涉及虚开、逃税罪风险点的，已提示客户寻求律师/税务师介入？

## 三、常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 文书里大段辩解"我们不是故意的" | 主动把"故意"这个定性要件摆上台面 | 直接不提主观状态，只陈述客观事实 |
| 一口气否认所有问题 | 丧失可信度，后续真有争议的点也没人信 | 承认事实无争议的部分，集中兵力打有争议的部分 |
| 把内部沟通、会计的个人判断写进去 | 制造新的不利证据 | 只写有书面证据支撑的交易事实 |
| 提交未经整理的原始凭证一大摞 | 检查人员自行解读 | 附证据清单，逐份编号并注明证明目的 |
| 口头答应检查人员的要求后无书面留痕 | 事后无法核实 | 重要沟通后补一份《情况说明》或会议纪要 |
| 逾期提交 | 视为放弃陈述申辩 | 期限内先提交框架，注明"详细证据材料后续补充" |

## 四、语气尺度

- 不卑不亢，不用"恳请领导开恩"这类表述，用"恳请依法复核"
- 不用情绪化词汇（"冤枉""无法接受""严重不公"）
- 不用威胁性表述（"否则我们将申请行政复议"）——救济意图放在心里，不写在文书里
- 篇幅控制在 3 页以内。超过 3 页没人认真看，把核心论证放前面，细节放附件
