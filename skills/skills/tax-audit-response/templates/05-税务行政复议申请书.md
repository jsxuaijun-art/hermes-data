# 模板：税务行政复议申请书

> **适用阶段**：执行阶段后。收到《税务处理决定书》或《税务行政处罚决定书》之日起 **60日内** 提出。
> **核心判断**：先分清申请对象是**处理决定**还是**处罚决定**——两者的前置条件和被申请人都不同。

---

## 申请前必读：三个先决判断

### 判断一：复的是处理决定还是处罚决定

| | 《税务处理决定书》 | 《税务行政处罚决定书》 |
|---|---|---|
| 内容 | 补税 + 滞纳金 | 罚款 |
| 性质 | 纳税争议 | 非纳税争议 |
| **清税前置** | **有**。须先缴清税款及滞纳金或提供纳税担保，才能申请复议（《税收征收管理法》第88条） | **无**。可直接申请复议，也可直接起诉 |
| 实务策略 | 成本高，慎重 | **门槛低，是主战场** |

> **修订动态**：修订草案拟取消复议清税前置、保留诉讼前清税。新法施行前，仍按现行法执行。**【待跟进】**

### 判断二：被申请人是谁

- 一般案件：作出决定的**稽查局**
- **经重大税务案件审理委员会审理的案件**：复议被申请人为**审理委员会所在的税务局**（不是稽查局），受理机关为该税务局的**上一级税务机关**
- 经上级税务机关批准作出的：批准机关为被申请人

→ 写错被申请人会被不予受理，务必先确认。

### 判断三：期限

- 行政复议：知道具体行政行为之日起 **60日**
- 行政诉讼：知道作出行政行为之日起 **6个月**
- **先缴税后复议的，注意在缴纳或提供担保之日起60日内提出**（期限起算点有特别规定，【待核实】具体条款）

## 使用要点

- **优先打罚款**：如果税款部分难撼动，单独就《税务行政处罚决定书》申请复议，无清税前置，成本最低
- **不要错过60日**：这是硬期限，逾期直接丧失救济权
- **停止执行申请**：复议期间具体行政行为不停止执行，但可申请停止执行，需说明理由
- **一案一申请**：处理决定和处罚决定分别申请复议，不要混在一份里
- **保留诉讼权**：对复议决定不服的，可在收到复议决定书之日起15日内向法院起诉
