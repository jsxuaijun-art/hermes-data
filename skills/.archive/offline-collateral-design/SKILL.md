# 线下营销物料设计

为苏州盈信（财税服务行业）设计或升级线下营销物料的完整工作流。核心信条：**线下物料不是"介绍自己"，而是用对方的眼睛看到为什么选你。**

## 核心原则

0. **‼️ 措辞封顶原则（优先级最高）** — 用户明确表达"太高调了/太张扬了/低调一点"时，立刻停止原有措辞路线。不要争辩"这样才有冲击力"，不要循序渐进，直接出一个收敛到极简的版本。用户说"对味"才算停。线下实物（文件袋/名片/宣传册）天然要收敛，线上传播可以放开。两套版本并存，按场景切换。

1. **信任 > 信息** —— 物料的第一使命不是告诉别人你能做什么（服务列表），而是告诉他们"为什么你值得信任"
2. **一个袋子的三重使命**：
   - ① 客户自己用的时候觉得有面子（信任感）
   - ② 客户带出去被别人看到时，别人能记住你（传播力）
   - ③ 别人想找你的时候，能马上找到你（行动力）
3. **稀缺身份 > 通用口号** —— 对江姐（盈信）来说，"高级会计师（八九百人里唯一代账公司出身）"远比"专业铸就品质"有杀伤力
4. **数据比形容词有力** —— "16年"好过"十余年"，"八九百人里唯一"好过"行业领先"
5. **大字电话是第一行动按钮** —— 在线下物料上，电话字号要大到能从3米外看清（如180-1262-7126 加分隔符易记）

## 工作流

### Step 1: 获取当前物料内容

如果用户有图片，先尝试 vision_analyze。若模型不支持图片（如 deepseek-v4-flash），降级方案：

```bash
# 1. 下载到 /tmp
# 2. 安装 tesseract-ocr + tesseract-ocr-chi-sim（如未安装）
sudo apt-get install -y -qq tesseract-ocr tesseract-ocr-chi-sim
# 3. OCR（需要先确认图片尺寸，必要时PIL增强对比度）
tesseract /tmp/file.jpg stdout -l chi_sim+eng 2>/dev/null
```

如果用户没有图片，问清楚：
- 物料类型（文件袋/名片/宣传单/展架/招牌等）
- 当前上面有什么内容
- 哪个部分不满意
- 现有库存还有多少（决定是立刻改版还是等用完再换）

### Step 2: 诊断 — 找到"一眼能看出问题"的点

诊断框架：

| 纬度 | 要问的问题 |
|------|-----------|
| 信任锚点 | 第一眼能看到"为什么选你"吗？还是跟1000家同行一样？ |
| 差异化 | 别人看到会记住吗？还是看完就忘？ |
| 视觉层级 | 信息有主次吗？还是平铺一堆文字？ |
| 行动号召 | 有明确告诉对方"下一步做什么"吗？ |
| 转介绍机制 | 客户带出去，别人扫一眼有用吗？ |

### Step 3: 设计策略

把用户最稀缺的身份/卖点提炼为**核心信任信号**，围绕它重新排布所有信息。

对盈信来说，核心信任信号层次：

```
信任层1: 🏅 高级会计师 创办          ← 第一眼看到的
信任层2: 专注财税16年 · 苏州上海     ← 数字+区域，可信感
信任层3: 八九百人里唯一一家代账公司   ← 好奇心钩子，让人想了解
          出身的高级会计师
```

### Step 4: 输出 Word 格式设计简报

用 python-docx 生成设计简报，包含以下章节：

1. **现状诊断** —— 当前物料问题清单（表格：维度 | 问题 | 改进方向）
2. **设计策略** —— 物料的三重使命 + 核心信任信号选择
3. **正面设计** —— ASCII 布局示意 + 元素详解表格
4. **反面设计**（如双面）—— 同上，含二维码扫码理由设计
5. **配色与材质** —— 主色/辅色/文字色/纸张/印刷工艺
6. **文案修改对照** —— 逐句对照表（现版 | 新版 | 为什么改）
7. **设计亮点总结** —— 3-4条核心逻辑，每条配简短说明
8. **印刷执行提示** —— 尺寸/工艺/纸张/批量建议/成本估算

### Step 5: 用户参与排版决策

**重要偏好**：用户对具体排版有清晰主张（如服务列表顺序、电话格式、单面/双面）。交付策略：

1. 先出**诊断+策略+布局框架**（你的专业判断）
2. 把**具体文案/排版选择权**留给用户——列你的推荐，但明确标注"这里您定"
3. 用户给精确内容后，直接生成终稿，不要二次建议
4. **⭕ 特别：措辞封顶原则**——用户会说"太高调了/太张扬了"，此时不用争辩，直接给出低调版本。线下实物（客户拿在手里的东西）要收敛，线上传播可以放开。两套版本并存，按场景切换

### Step 6: 盈信服务列表定稿 — 两个版本，按场景使用

**⚠️ 重要：线下物料（文件袋/名片）与公众号文章落款的展示顺序不同，不要混用。**

**版本A — 线下物料（文件袋/名片/宣传册）：**

```
税务合规 · 公司注册 · 代理记账
    会计外包 · 高企申报 · 财务咨询
```

设计要点：
- "税务合规"放首位——合规是老板的痛点，比"公司注册"更有杀伤力
- "会计外包"独立一行居中——悄咪咪展示高端业务能力
- 两端（公司注册·代理记账）和（高企申报·财务咨询）做支撑

**版本B — 线上传播（公众号文章落款/视频号简介，2026.7.25 江姐确认顺序）：**

税务合规 · 会计外包 · 高企申报 · 公司注册 · 代理记账 · 财务咨询

设计要点：
- 高端业务放前面：税务合规 → 会计外包 → 高企申报 = 塑造高端品牌印象
- 常规业务压后：公司注册 → 代理记账 → 财务咨询 = 拉回服务广度

**分界线：** 线下实物用版本A，线上落款用版本B。两者都是定稿，直接使用，不需要再次询问。

实际流程示例：
- 你：出v1方案（推荐排版）→ 问"服务列表这样排ok吗？"
- 用户：自己给出精确内容（如"税务合规·公司注册·代理记账 会计外包·高企申报·财务咨询"）
- 你：直接修改，不再输出"我觉得可以改成XXX"的二次建议

### Step 6: 交付方式

- 生成 .docx 放到用户桌面：`/mnt/c/Users/Admin/Desktop/`
- **文件名策略**：用有意义的版本号，如`文件袋设计_v2_单面.docx`。**绝对不要覆盖旧文件**——Word锁定后无法重写（PermissionError），即使`rm -f`也会被拒绝。每次交付都创建新文件名，不要清理旧版本，让用户在Windows下自己删
- 同时用文字回复核心改动要点（方便用户快速浏览）

## 文案技巧

### 电话格式化

```
❌ Bis (wis) : 18012627126      ← 用户现版，英文无关信息干扰
❌ 18012627126                    ← 一串数字，不易记
✅ 180-1262-7126                  ← 加分隔符，朗朗上口
✅ 132-2229-7318                  ← 第二个号码（微信同号），同样加分隔符
```

当面袋上展示双号码时：

```
📞 电话（微信）
132-2229-7318
180-1262-7126
```

两号上下排列，"电话（微信）"标注说明两号皆可加微信。

### 二维码扫码理由

不要写"了解更多""请加微信"这种软绵绵的话。要给明确的利益承诺：

```
❌ 关注公众号 了解更多
✅ 扫码关注公众号 · 每周推送财税干货
✅ 扫码添加创始人微信 · 免费诊断企业财税风险
```

### 二维码生成工作流

用户需要把微信二维码/公众号二维码放到印刷品上时，按此流程：

**步骤：**
1. 获取公众号/视频号链接 → 在微信里打开公众号主页 → 右上角「…」→ **如果找不到"复制链接"选项**，改用以下备选方案：
   - **视频号助手**（推荐）：电脑打开 channels.weixin.qq.com → 微信扫码登录 → 浏览器地址栏直接复制链接
   - **微信搜一搜**：搜自己的公众号 → 进主页 → 截图后上传到草料二维码（草料支持截图识别）
   - **电脑公众号后台**：登录 mp.weixin.qq.com → 设置与开发 → 浏览器地址栏复制链接
2. 打开 **cli.im**（草料二维码），免费，无需注册
3. 选择「文本/链接」类型 → 粘贴链接 → 生成二维码
4. 也可直接上传微信二维码的截图图片 → 草料自动识别生成印刷版高清二维码
5. 下载二维码图片（PNG格式，选高分辨率）
6. 把图片发给印刷厂，标注位置和尺寸

**注意：** 草料支持**活码**（可随时更换扫码后的跳转内容，二维码不变）和**扫码统计**（能看到扫码次数、时间等数据）。印袋子上建议用活码。

## 差异化金句（盈信专用）

**高强度版（适合短视频/文章等线上传播）：**

八九百人里唯一一家代账公司出身的高级会计师

这句话是真实数据（2018年江苏819人通过高级会计师评审，盈信是唯一代理记账公司），冲击力极强，适合线上场景。

**低调有内劲版（适合文件袋/名片等线下物料）：**

江苏省高级会计师 · 代理记账行业入选企业

**为什么改：** 线下物料是客户日常携带的实物，太张扬的措辞可能让客户觉得掉价（"你拿着这袋子是不是在帮我打广告"）。改成"入选企业"——不说"唯一"、不说"最好"，只说一个客观事实。懂的人知道江苏省高级会计师评审里代理记账公司凤毛麟角，看到"入选"自然会品出分量；不懂的人看到"高级会计师"也够用了。

**基本原则：** 线上传播（短视频/公众号）用冲击力强的版本，线下实物（文件袋/名片/宣传册）用低调有内劲的版本。同一句话，两副面孔。

## 常用python-docx代码片段

参见 `word-documents` skill 的 Helper Functions 章节。本 skill 重点使用：

- `add_table(headers, rows, col_widths)` —— 对比表格/元素详解表格

- 配色用 `shade_cell(cell, color)` + 深蓝 `1A3C6E` / 金色 `C8A84E` / 浅灰 `F0F4FA`
