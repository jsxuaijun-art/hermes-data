# 少代会提案登记表 撰写指南

## 提案构成（七部分，总约300字）

| 部分 | 说明 | 写作要点 |
|------|------|----------|
| 提案题目 | "关于……的提案" | 一事一议、切入点小、普适+创新 |
| 提案主题/类别 | 三选一（见下） | 勾选主类①②③④ |
| 提案关键词 | 2-3个，分号分隔 | 体现核心内容/建议方向 |
| 提出缘由 | 为什么提出 | 结合观察调查，体现必要性 |
| 主要内容 | 提案是什么 | 语言严谨精确，不用"据说/据反映" |
| 意见建议 | 应该怎么办 | 具体明确、条理清晰、可落地 |
| 附议人员 | ≥4人 | 写姓名+身份（队员/家长） |

## 主题类别（勾选其一）

1. 队员自身成长发展：①学习生活 ②身心健康 ③权益维护
2. 少先队组织建设：①制度创新 ②组织创新 ③活动创新 ④评价激励
3. 校园环境设施治理和学校发展：①校园文化 ②校园公共安全 ③科技创新 ④校园环境保护
4. 其他

## 常用话题 → 归类对照

- 心理健康 / 中考减压 / 情绪疏导 → 1.② 身心健康
- 手机 / 电子产品 / 作业管理 → 1.① 学习生活
- 校园垃圾分类 / 节电节水 → 3.④ 校园环境保护
- 科创社团 / 编程兴趣课 → 3.③ 科技创新
- 课间活动安全 / 校门口安全 → 3.② 校园公共安全

## 本用户（徐总孩子，交大二附中，初二升初三）实际范例

三个已生成主题（可复用作内容素材）：

1. **心理健康-心灵驿站**（归1.②）：在校内设"心灵驿站"（图书角/解压角/座位），心理教师+高年级"心灵小助手"轮流值守接受预约倾诉，设"心灵树洞"信箱留言板，每月一次心理主题班队活动。建议：德育处牵头定场地设备、信箱每周五开箱统一答复保护隐私、培训小助手、班队会宣传求助渠道。

2. **手机/电子产品管理**（归1.①）：上课及午休手机统一交由班主任保管放学领取，开展"合理使用电子产品"主题教育，控制单次时长防止沉迷。建议：统一保管机制、每日不超过1小时建议、科学用眼定期视力检查、家校联动。

3. **心理健康-中考备考压力**（归1.②，贴合初二升初三）：开设心理教育课帮队员认识压力情绪，设"心灵驿站"，每周一次心理减压活动或主题班会，培养高年级心灵小助手、家校联动营造轻松备考家庭氛围。

## 填空字段

生成后以下字段留给用户手填，交付时清单明确列出：
- 中队、代表姓名、性别、年龄、民族
- 附议人员4人（姓名+身份），通常3名同中队队员+1名家长
- 尾部"共计＿人"
