# 商事登记 · 公司注册与变更（含经营范围库）

> 商事登记（注册/变更/注销）是盈信核心业务线之一，与税务合规、代理记账、高级会计师背书并列。
> 本 skill 覆盖 **注册 + 变更 + 经营范围**；**注销**走 `company-deregistration` skill（先税后工再银、清税12雷区）。
> 用户说"商事登记skill"即指本 skill。

## 经营范围核心方法论（价值核心）

客户高频问题："经营范围怎么写？" —— 老板不懂、会计照抄同行、抄错就开不了票。这是代办注册的差异化价值点：一次写对。

### 五条铁律

1. **一般项目 vs 许可项目**：能写"一般项目"的尽量写全；涉及资质/许可证的（施工、餐饮、医疗、金融等）归"许可项目"，未取得许可前不得经营。
2. **"施工/工程"二字是分水岭**：只做设计、安装调试、集成、维护 → 写"工程、系统集成、技术服务"即可，无需资质；写"承接施工/总承包" → 需对应专业承包资质（如电子与智能化工程专业承包）。纯弱电布线多数地区不走资质，但以当地窗口核准为准。
3. **强电/弱电边界决定资质**：不碰220V及以上线路（配电箱、母线、强电电缆桥架）→ 无需电力工程资质/承装修试许可；一旦接强电柜的活儿 → 必须资质+电力设施许可，或分包给有资质单位。给客户的表述边界：**合同里写死"不含220V及以上线路"**。
4. **经营范围宁宽勿窄**：变更经营范围要公示+核准，来回一周起。一次性把"工程+施工+集成+维护+销售"写全。**开票依赖经营范围**：只写"咨询"不写"销售"，卖设备开不了"XX设备销售"的票 —— 高频踩坑点，做经营范围方案时必查客户开票需求。
5. **经营范围=未来开票上限**：客户问"能不能开XX发票"先看经营范围；超范围开票有风险，先变更经营范围再开票。

## 注册流程骨架（设立登记）

股东决议 → 核名（多备3-5个）→ 章程 → 网上申报（一网通办/企业开办一窗）→ 领取执照 → 刻章 → 银行开户 → 税务报到/核定 → 社保开户。
代办价值点：材料一次过、经营范围一次写对、**税务报到衔接**（避免新办企业忘报税变非正常户）。

## 股东国籍变更 → 企业性质（内资/外资）判定

客户场景：当初用中国国籍注册内资公司，后来取得境外永居或变更国籍，公司会不会自动变成外资？很多老板想当然以为要重做外资登记——**这个理解不完整**。

**核心结论：看「股权取得时间」，不看股东「现在的国籍」。先持股、后变国籍 → 公司性质不自动变。**
定海神针：《关于外国投资者并购境内企业的规定》（商务部令2009年第6号）第55条——境内公司自然人股东变更国籍的，不改变该公司企业性质。《外商投资法》第2条界定外商投资＝外国投资者**新设企业**或**通过受让股权、认购增资取得股权**；而这里股权在国内身份时已取得，不属外国投资者投资行为，不触发外资认定。

**四类场景判定表**（客户拿来直接对号入座）：

| 场景 | 判定 |
|---|---|
| ① 中国籍股东设立、持股之后，才取得外国国籍 | **仍是内资**。无需外资登记、无需商务外资准入审批、无需外商投资信息报告；章程记载股东证件的，提交国籍变更证明＋公证认证后的境外护照＋股东会决议＋章程修正案，更新股东证件信息 |
| ② 外国人受让内资公司股权（从中国股东手里收购） | **必须转外资**。属股权并购 → 外商投资信息报告＋市场监管变更企业类型 |
| ③ 外国人认购内资公司新增注册资本 | **必须转外资**。属外国投资者新增投资 |
| ④ 股东只拿绿卡（永久居留权）、未变更国籍 | **完全不影响，仍是内资**，无需变更、无需备案国籍。依据：《外商投资法实施条例》第3条（华侨）；商务部商办资函〔2005〕67号、外汇局汇综复〔2005〕64号——永居之前已持有股权的不改性质，永居之后再新设/受让/增资的参照外资管理 |

**五项温馨提醒（交付时必带，避免客户踩后续雷）：**
1. 公司虽内资、股东外籍 → 后续**分红跨境汇出、对外转让股权、税务和外汇**按外籍自然人规则审查，不能再沿用中国居民流程。
2. 中国不承认双重国籍：自愿取得外国国籍即自动丧失中国国籍，应**注销国内户籍与身份证**；后续市场主体登记/银行/税务用护照等作身份凭证。
3. 核查经营范围是否落入《外商投资准入特别管理措施（负面清单）》限制/禁止外方控股的领域。
4. 内资转外资不只做主体登记，还涉**商务、外汇、银行**等部门，需提前了解流程。
5. **资质与许可复核**：部分行业许可证、招投标资质对内资/外资有差异化要求。

## 经营范围变更

公示（简易/一般）+ 核准，周期一周起，跨月影响开票 → 首次注册就把经营范围写全，这是"宁宽勿窄"的根本原因。变更时同样适用五条铁律，尤其核对"施工"字眼与资质匹配。

## Pitfalls

1. **经营范围变更的隐性成本**：公示+核准周期，跨月影响开票 → 首次注册写全。
2. **"施工"字眼乱用**：小公司写"建筑工程施工"又无资质，接活被认定超范围经营或无资质施工。给客户降级表述（"工程"→"技术服务"）或明确分包路径。
3. **强电弱电混写**：经营范围既写弱电又写电力工程，监管按高要求管理，资质缺口暴露。
4. **行业类别选错**：注册时行业类别（电子与智能化 vs 建筑智能化 vs 网络科技）影响后续资质申报与税收优惠（高新/软件企业）口径。
5. **新办企业税务报到漏办**：注册完不管税务 → 非正常户，后续注销/变更全卡。代办注册必衔接税务报到。
6. **内资/外资判定看「取得股权时点」而非当前国籍**：客户误以为"股东变外籍＝公司自动转外资、要重做外资登记"——多数场景（先持股后变国籍/仅拿绿卡）无需；但把股权**转让/增资**给了外国人就**必须转外资**。别陪着客户冤枉做外资流程，也别漏做该做的外资认定。

## Verification

- 出经营范围方案前必问客户：①业务边界（是否施工？是否碰强电？）②开票需求（要开什么票）③是否已有资质/许可证。
- 对照"五条铁律"逐条过一遍再交付。
- 苏州/上海市监口径差异以当地窗口核准为准，重大方案标注"以窗口核准为准"。
