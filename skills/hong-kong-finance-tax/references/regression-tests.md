# 香港 V1.1 回归测试案例

## Case 1 — 国际贸易
香港公司向中国供应商采购，货物直接发往欧洲客户。

必须输出：
- 五大 / 三粗 / 六流
- key profit-producing operations
- source-of-profits facts
- accounting
- document checklist
- counterpart-country issues
- Needs Verification items

## Case 2 — 跨境管理费
香港公司向境外关联公司支付管理费。

必须输出：
- 服务实质
- deliverables
- related-party / TP
- Hong Kong side
- counterparty-country WHT / VAT/GST / PE checks
- DTA layer

## Case 3 — Holding / Dividend
香港 HoldCo 收取境外子公司股息并考虑再投资。

必须输出：
- source / FSIE screen
- group structure
- DTA / beneficial ownership
- accounting
- board / banking evidence

## Case 4 — Annual compliance
用户只说“帮我检查香港公司年度合规”。

必须输出：
- company
- accounting/audit
- tax
- employer/MPF
- annual filings
- evidence gaps
- action list
