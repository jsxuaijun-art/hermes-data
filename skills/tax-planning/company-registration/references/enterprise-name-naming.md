# 企业名称 · 起名方法论（音译造字号）

> 功能：客户只给「主要行业 + 主要经营范围」，据此造出字号。
> 核心=“音译造字”：关键词 → 译英（寓意好、发音简单、爆破音为主）→ 音译成近音汉字 → 校验寓意/语感/核名。
> 与 `enterprise-name-registration.md`（法规/禁限/比对）配套：先按此法**造名**，再用核名要点**过滤**。

---

## 一、工作流（四步）

1. **提取关键词**：从客户给的「主要行业 + 主要经营范围」中提取 2-3 个核心词。
   - 例：行业=贸易；经营范围=电子产品零售、市场营销策划 → 关键词=贸易、电子产品、市场营销。
2. **翻译成英文**：每个关键词译成英文，首选——寓意良好 + 发音简单（约 2 个音节）+ 以爆破音（b/p/d/t/g/k）开头或含爆破音。
   - trade（贸易）、electronic（电子产品）、marketing（市场营销）。
3. **音译成汉字**：按英文发音找**近音汉字**（不严格对应拼音，允许变通）。
   - trade → 川德；electronic → 依莱克；marketing → 马克听。
4. **校验 + 备选**：选寓意佳、发音干脆、好记的字号，造 3-5 个备选，再过核名禁限/相同相近比对。

---

## 二、爆破音选字逻辑（为什么选爆破音）

爆破音（塞音 plosive：b、p、d、t、g、k）发音短促有力、干脆利落，作字号好听、有记忆点、显大气——这是“发音简单”的落点。优先让英文词**以爆破音开头**或核心词根含爆破音。

### 爆破音 → 常用近音汉字（音译选字池）
| 爆破音 | 常见近音汉字 |
|-------|------------|
| b | 贝 / 博 / 邦 / 宝 / 伯 / 波 |
| p | 派 / 珀 / 普 / 珀 / 鹏 |
| d | 德 / 达 / 迪 / 顿 / 丹 |
| t | 特 / 图 / 坦 / 川 / 听 |
| g | 格 / 高 / 盖 / 广 / 国 |
| k | 克 / 卡 / 柯 / 阔 / 凯 / 可 |

> 说明：表中汉字仅为常见对应，音译可跨表取近音字（如 trade 的 t→“川”），**以整体发音近似 + 寓意好为准**，不要求逐字母对应拼音。

---

## 三、示例拆解（用户的例子）

| 关键词 | 英文 | 爆破音 | 音译 | 拆解 |
|-------|------|-------|------|------|
| 贸易 | trade | t / d | 川德 | tr→川，(d)→德 |
| 电子产品 | electronic | l(重音) / k | 依莱克 | e→依、lec→莱、tron/k→克 |
| 市场营销 | marketing | m / k / t | 马克听 | mar→马、ket→克、ing→听 |

三个候选音译都含爆破音（川[d]、德[d]、克[k]、听[t]），读起来干脆。可再从“寓意好 + 不撞同行业”选其一或组合。

## 五、校验清单（交付前必过）

1. **音译近音**：汉字读音与英文词发音整体近似，可接受变通。
2. **寓意好**：所用汉字（尤其首字）含义积极，不晦气、不歧义。
3. **爆破音**：优先含 b/p/d/t/g/k，发音干脆有力。
4. **好记**：2-3 字为主，读一遍能留下印象。
5. **核名过滤**：对照 `enterprise-name-registration.md`——结构（区划+字号+行业+组织形式）、禁限（政治敏感/领导名人/宗教/党政军/外文字母数字/国家级最佳等）、相同相近比对（同行业同音/包含/拆字都别撞）。多备 3-5 个字号防撞。
6. **与行业匹配**：字号不与行业用语/行政区划撞，不超出企业设立目的。

---

## 六、话术（给客户讲清“为什么这样取”）

> “你的字号不硬编，而是‘音译造字’：把你的主营业务翻成英文（trade/electronic/marketing 这类寓意好、发音干脆的爆破音词），再音译成汉字——川德、依莱克、马克听。既贴合你做什么，又好记、有国际感、念着响亮。”

## 附：与《企业名称登记管理规定实施办法》衔接
- 字号：2 个以上汉字（总局令82号§10；133号§12）。
- 行政区划、行业、组织形式**不得用作字号**——音译造字天然规避了“拿行业词当字号”的坑（如把“贸易”直接当字号不行，但音译成“川德”表意又避险）。
- 造完字号仍须过自主申报 + 保留期（2个月/有审批1年）+ 相同相近比对。
