# 高企账务质量诊断——客户材料准备清单

> 用途：诊断一家高新技术企业（或拟认定企业）账务处理质量与合规程度前，**发给客户照着准备的材料清单**。
> 对应 `schema/audit_case.schema.json` 与 `engine/rnd_engine.py audit`。
> 口径：以**被诊断年度**为主；高企资格维持项加看**近三年**。

## A. 财务报表与账套（必备基础）
| # | 材料 | 说明 | 是否是重点 |
|---|------|------|-----------|
| A1 | 资产负债表 / 利润表 / 现金流量表 | 近三年分年 | 必备 |
| A2 | **科目余额表**（总账/明细账） | 近三年；看科目设置与余额异常 | 必备 |
| A3 | 总账、明细账 | 抽查凭证依据 | 必备 |
| A4 | 企业所得税年度申报表（A100000 等全套） | 近三年已申报 | 必备 |

## B. 研发费用专用账套（重点中的重点）
| # | 材料 | 说明 |
|---|------|------|
| B1 | **研发支出辅助账（2021简化版）** | 加计扣除口径；无此账不得加计 |
| B2 | **高企认定专用辅助账**（表7-8：近三年分年、按RD项目） | 高企认定/复审专用，**两套账都要** |
| B3 | 研发费用专项审计报告 / 鉴证报告 | 有资质中介出具 |
| B4 | 「研发支出」科目设置及核算截图 | 费用化/资本化分设情况 |

## C. 研发项目档案
| # | 材料 | 说明 |
|---|------|------|
| C1 | 立项书、立项决议、可行性报告 | 判断立项真实性 |
| C2 | 项目计划书、进度、结题报告 | 研发过程证据 |
| C3 | 研发项目与生产项目的区分依据 | 防混入非研发 |

## D. 研发人员
| # | 材料 | 说明 |
|---|------|------|
| D1 | 研发人员名单（岗位、学历、在职/兼职/临时）| |
| D2 | 全年职工总数月平均数 / 科技人员月平均数 | ≥10% 判定 |
| D3 | 研发工时记录表 | 兼岗分摊依据；兼/临人员须≥183天 |
| D4 | 工资表、社保公积金、个税 | 人工费用归集佐证 |

## E. 研发投入佐证
| # | 材料 | 说明 |
|---|------|------|
| E1 | 领料单、出库单、材料明细 | 直接投入 |
| E2 | 设备使用记录、折旧/摊销分摊表 | 共用设备须分摊 |
| E3 | 外委研发合同 + 科技部门登记凭证 | 委托/合作 |
| E4 | 无形资产摊销、设计费、差旅会议等 | 其他相关费用 |

## F. 收入与产品
| # | 材料 | 说明 |
|---|------|------|
| F1 | 高新技术产品(服务)收入明细 / 总收入 | ≥60% 判定 |
| F2 | 主要产品（服务）技术说明、领域归属 | 八大领域 |

## G. 知识产权
| # | 材料 | 说明 |
|---|------|------|
| G1 | 知识产权清单（I类/II类、取得方式、状态）| II类仅用一次 |
| G2 | 证书、缴费凭证、登记证明 | 有效性 |

## H. 已申报与备查
| # | 材料 | 说明 |
|---|------|------|
| H1 | 汇算 A107012（研发费加计）| 加计口径 |
| H2 | 汇算 A107041（高新技术企业优惠）| 高企必填 |
| H3 | 高企年度发展情况报表报送记录 | 两年未报取消资格 |
| H4 | 预缴申报表（7月/10月） | 三时点是否享受 |
| H5 | 留存备查资料包 | 立项/工时/领料/分摊等 |

## 材料齐备性如何评估
对照以上逐项打勾，进 `audit_case` 的 `evidence` 字段（financial_statements / subject_balance / auxiliary_ledger / project_archive / staff_roster / input_evidence / income_evidence / ip_cert / filed_returns）。缺项会进诊断报告的「材料缺口」并影响「证据链完整」维度得分。

> 提示：本清单用于**诊断/承接评估**，不替代税务专项审计；被诊断年度与主管部门口径以电子税务局当年为准。
