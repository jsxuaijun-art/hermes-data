# 注册资本主题文章 — 已验证结构模板（2026-06-30）

> 适用场景：面向创业新手的财税科普 + 面向已有公司的老板的进阶内容
> 受众分割：一篇两分，上下篇

## 结构模板

```
上半篇：创业新手篇
├── 一、为什么要聊xxxx？        → 场景切入 + "常见误解"破题
├── 二、xxxx到底是什么？        → 大白话定义 + 核心概念对比（表格）
├── 三、三大视角深度解析
│   ├ ①公司法视角              → 红线/时限/罚款/加速到期
│   ├ ②税法视角                → 显性成本+隐性税务坑+优惠政策
│   └ ③运营视角               → 信用/招投标/股权转让影响
├── 四、创业者最容易踩的坑      → 4个坑（Xx体，方便扫读）
├── 五、实操建议               → 公式+节奏+缴不上怎么办+金句
└── 六、结尾/下期预告          → 引导互动

下半篇：已有公司的老板篇
├── 六/七、xx雷/陷阱           → 风险警示（行政+税务+刑事三层）
├── 七/八、xx操作与税务陷阱    → 流程+容易被忽略的税务成本
├── 八/九、特殊情景速查        → 门槛表/常见问题速查
└── 写在最后                   → 分受众总结
```

## 已验证的关键写法

1. **分割受众**：当话题对不同读者都有价值时，用 `# 上半篇：xxx篇` + `# 下半篇：xxx篇` 分开
2. **表格对比**：关键概念对比用 `| 概念 | 一句话解释 |` 格式，右栏用大白话
3. **实战公式**：给出可直接套用的公式（如：注册资本 = 行业门槛 × 1.5）
4. **加粗导语**：每个坑/要点用加粗开头（"坑一：xxx"），方便扫读
5. **一句话总结**：结尾前有一个加引用的金句
6. **配图原则**：每张配图必须匹配它所在章节的中心思想
