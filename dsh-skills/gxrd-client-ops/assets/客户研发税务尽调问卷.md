# 客户研发税务尽调问卷（承接前必填）

> 用途：判断「能做 / 整改后做 / 不做」，对应 references/client_intake.md。客户填写 + 盈信复核。
> ⚠️ 数据脱敏纪律：本问卷内客户公司名、信用代码、法人姓名一律按 security/desensitization 规则处理后使用，勿在交付物外留存真实身份。
> 填写口径：以**上一个完整纳税年度**为主，拟认定高企的加填近三年。
> 建议：把结果填成 JSON 存为 `clients/<客户代码>/<年度>.json`，直接喂 `gxrd_engine.py decide --profile`。
