# 生产案例：个体户补税半个亿 · 太仓金伯爵金店（2026.8.10）

来源：苏州税务局稽查局 2026年第60号公告《税务处理决定书/处罚决定书送达公告》（jiangsu.chinatax.gov.cn，art_9363_1768037）。
案例号：「太仓市沙溪镇金伯爵首饰店」偷税案。已产出公众号文章（草稿箱）+ 1条短视频脚本（40秒）。

## 核心数据（全部经公告核实，可放心用）

| 数据点 | 数值 | 冲击力 |
|:--|:--|:--|
| 注册资本 | **仅10万**（2017年成立，经营者王李新，天眼查可佐证） | 小店 vs 天价罚单 |
| 补税 | 3590万 | — |
| 罚款 | 1795万（50%处罚） | 法定**最低**档 |
| 合计 | **5386万（半个亿）** | 主钩子 |
| 消费税 | 3157万，占补税总额 **88%** | 冷知识：金银首饰零售环节有5%消费税 |
| 倒推少报收入 | **6.3亿**（3157万÷5%） | 倒推公式本身是内容亮点 |
| 罚款档位 | 50%是法定最低，最高5倍=1.79亿 | 二次反差 |

## 反差结构（本案例的爆点公式）

注册资本10万小个体户 → 补税罚款5386万 = "个体户不是法外之地"。
核心信息差：**很多人不知道金银首饰在零售环节有5%消费税**——老板以为卖金子只交增值税，这是最容易引发"原来如此"评论的点。
