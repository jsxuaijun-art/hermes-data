# 税务自查情况说明 · 汇算清缴后取得发票被稽查场景

客户情形：企业所得税汇算清缴前未取得成本发票、也未做纳税调增，清缴后才取得发票，被税务稽查。客户要求起草一份送审的《税务自查情况说明》，争取从宽。

## 关键法规依据（已核实）

| 文件 | 条款 | 内容 |
|------|------|------|
| 《企业所得税税前扣除凭证管理办法》（国家税务总局公告2018年第28号） | 第6条 | 企业应在当年度汇算清缴期结束前取得税前扣除凭证 |
| 同上 | 第9、15、17条 | 支出真实发生、因对方原因未取得发票 → 汇算清缴期结束前要求补开/换开；确实无法取得的，提供资料佐证真实发生 |
| 《国家税务总局关于企业所得税若干问题的公告》（2011年34号） | 第5条 | 预缴季度所得税可暂按账面金额核算；汇算清缴时应补充提供有效凭证 |
| 同上 | 第6条 | 汇算清缴结束后取得发票 → 按"以前年度发生应扣未扣支出"追溯追补扣除（追补年限不超过5年） |

## 核心起草策略（成败关键在"定性锚定"）

整份文书的目标：把事件定性为 **"业务真实 + 申报差错"**，避开《税收征收管理法》§63 偷税的从重定性（补税+滞纳金+0.5~5倍罚款，严重可涉刑）。

1. **先立"业务真实"的地基** — 详写成本真实发生、款项已实际支付、业务已完成，有合同/付款/交付资料佐证（对应附件清单）。这是追溯扣除的前提。
2. **"申报差错"定性锚定** — 把"未在汇算清缴前取得发票、未调增"表述为受托会计对政策把握疏漏、管理差错，而非主观偷逃。
3. **援引2011年34号公告第六条** 申请追溯追补扣除 → 争取把补税额压到最小（成本真实时本金可能被冲减，只补滞纳金）。
4. **结尾表态配合补税、承诺整改** — 争取从轻或免罚。**不要写死"申请免罚"的具体承诺**，稽查定调前不宜自认，保持主动权。

## 红线提醒

- 文书成败全在"业务真实性证据链"够不够硬。若实为找票/虚列成本，此模板**不适用**（那是另一套涉刑风险路径）。
- 收到稽查通知后**绝不要再补开/换开发票** — 28号公告允许补开的时点是汇算清缴期结束前，稽查立案后被认定为掩盖行为会从重（双倍罚款+刑事）。

## 文档结构（Word，公文格式）

标题 → 致【税局】→ 一、基本情况 → 二、涉税事项实际情况及形成原因（（一）真实性（二）未及时取得原因（三）汇算清缴后已取得）→ 三、法规依据 → 四、税务处理意见及申请 → 五、附件清单 → 结尾保证 → 此致 + 落款

全文用【占位符】标注待填字段：企业名称、统一社会信用代码、地址、法定代表人、年度、金额、发票号码、日期、税局名称。
