# 家访前微信沟通策略

> 适用于初中新班主任第一次家访前1-2天的微信沟通场景。

## 核心原则

1. **点到为止** — 目的是确认时间+建立第一印象，不是提前交答卷
2. **成绩数据、排名、暑假规划都留到家访当面聊** — 提前发了反而让面对面没话讲
3. **三四行恰到好处** — 老师带全班几十个学生，每个家访前都收到长消息也是负担
4. **侧面引导** — 说孩子"文静话不多"其实是在委婉告诉老师：她可能紧张，请多鼓励。老师读得懂这层意思
5. **不要问成绩** — 不要在家访前问"我家孩子成绩怎么样"或打听班级情况，这些当面聊，显得尊重家访流程

## 标准模板

```
X老师您好，孩子跟我说了您要来家访很开心。确认一下本周X（X月X日）晚上X点，我们在家等您。

孩子性格比较文静踏实，平时话不多但心里有数，各科里语文历史比较好学。见面她可能会有点紧张，到时候请您多鼓励她。

天气热，您路上注意防暑，我们在家准备好茶水等您来。😊
```

### 模板拆解

| 段落 | 功能 | 关键词 |
|------|------|--------|
| 第一段 | 确认时间 + 表达期待 | "开心""确认时间" |
| 第二段 | 描述孩子性格 + 含蓄传递需求 | "文静踏实""多鼓励" |
| 第三段 | 表达欢迎 + 人文关怀 | "防暑""茶水" |

## 变体

### 孩子外向型
```
X老师您好，确认一下家访时间——本周X（X月X日）晚上X点，我们在家等您。

孩子性格比较活泼，话多，有时候管不住自己。见面她肯定叽叽喳喳跟您聊一堆，您多担待，也帮她收一收。

我们在家等您来！
```

### 家长很忙、只求确认
```
X老师您好，确认家访时间：本周X（X月X日）晚上X点到家里聊，方便吗？

我们在家等您，辛苦了。
```

## 注意事项

- 老师的微信通常回复从简，不回复长篇大论很正常，别多想
- 如果老师没回，家访当天早上再发一条"今天等您来"即可
- 不要跟老师讨价还价时间（除非实在冲突）
- 不要在家访前微信发孩子的奖状、成绩单、作品照片
- 不要在家访前@其他家长或拉群
