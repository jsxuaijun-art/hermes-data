# 高新技术企业税务合规要点速查（2026年7月版）

基于2026年7月20日研究整理。核心依据：国科发火〔2016〕32号、财税〔2015〕119号、国税〔2017〕24号。

## 八大认定条件速览

| 条件 | 要求 | 关键点 |
|------|------|--------|
| 注册时间 | 成立一年以上 | — |
| 知识产权 | 核心产品核心技术知识产权所有权 | I类可重复用，II类只能用一次 |
| 技术领域 | 属《国家重点支持的高新技术领域》 | 八大领域之一 |
| 科技人员 | >= 10% | 累计工作183天以上 |
| 研发费用 | 按收入分档：5%/4%/3% | 境内占比>=60% |
| 高新收入 | >= 60% | 占同期总收入 |
| 创新能力 | >= 70分(满分100) | 知识产权30+成果转化30+组织管理20+成长性20 |
| 合规 | 无重大安全/质量/环保事故 | — |

## 稽查高危预警8项

1. 研发费用占比突降至标准以下
2. 科技人员占比连续下降
3. 高新收入占比低于60%
4. 加计扣除金额与高企研发费用差异过大
5. 知识产权全部为申报前突击受让
6. 研发人员社保未缴或按最低档缴
7. 高新收入与开票品名不一致
8. 研发设备闲置或不存在

## 常见5大误区

- 高企优惠 = 加计扣除 (实际是两套独立政策，可叠加)
- 拿到证书一劳永逸 (资格3年有效，每年备案)
- 小微+高新叠加更省钱 (不可叠加，选最优)
- 研发费用不用管口径 (高企口径 vs 加计扣除口径不同)
- II类知识产权可反复用 (只用一次，复审需新的)

## 企业操作5建议

1. 研发全流程留痕（立项→过程→成果）
2. 每半年自查一次（人员/研发费/高新收入/知识产权）
3. 到期前1年启动复审准备
4. 注意优惠叠加规则（高新+加计扣除=可叠加）
5. 每年一次专业合规体检
