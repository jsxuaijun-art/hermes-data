# GEO 项目综合巡检模板

> 用于定期检查 GEO 各工作线的状态，产出结构化的巡检报告。
> 每次巡检后更新 `references/cold-start-tracker.md`。

## 巡检清单

### 1. 百度百科词条状态

```
操作：浏览器打开百度百科词条 → 检查：
- [ ] 编辑次数是否增加（上次 N 次 → 本次）
- [ ] 最近更新日期
- [ ] 各章节文案是否正确显示（公司简介/所获荣誉/企业信息）
- [ ] 如有待审核编辑，检查审核结果
```

**⚠️ AI幻觉防范**：必须实际访问页面验证，不要凭记忆或推测断言审核状态。

### 2. 官网状态

```
- [ ] HTTPS 是否正常（curl -sI https://yingxinkuaiji.com）
- [ ] HTTP 是否正常
- [ ] SSL 证书有效性
- [ ] JSON-LD 结构化数据是否在线（grep ld+json）
```

### 3. 平台信源

```
- [ ] 知乎账号状态（是否绑定手机号、最新文章）
- [ ] 公众号草稿箱（待发布文章）
- [ ] 百家号/搜狐号等注册进度
```

### 4. 技术基建

```
- [ ] 阿里云 wenyan-server 运行状态
- [ ] GSC 索引报告
- [ ] sitemap 提交状态
```

## 用法

加载 geo-optimization skill 后，调用此模板进行巡检：

```
1. 逐项检查巡检清单中的状态
2. 更新 references/cold-start-tracker.md
3. 输出巡检报告给江姐确认
```
