# 案例：苏州交警×注册公司自然流

## 原始想法

> "苏州是一个温情的城市，苏州交警主动和外卖平台沟通，把外卖员等红灯时间从总时间里扣除，这样效能事故会减少。这种以人为本的思想也会体现在营商环境方面。"

目标：把这个思想与「注册公司」业务关联，产出行业自然流文案。

## 过程迭代记录

### 连接点的演变

| 版本 | 连接点 | 问题 |
|:----:|--------|------|
| V1 | 「窗口不会甩一叠表让你填…基本一趟能办完」 | ❌ 与实际脱节（已不是填表时代） |
| V2 | 「全程线上走完了，不需要找人代办，你在家就能办完」 | ✅ 正确，但要加业务身份 |
| V3 | 「我在苏州做公司注册二十年，我很清楚——现在的注册流程，全部线上走完了。」 | ✅ 正确+可信+引流 |

### 关键技法提炼

**技法1：行业身份融入论证**
- 把「我在这个行业做了多久」写进论证过程，而不是留在最后硬塞广告
- 「我在苏州做公司注册二十年，我很清楚」= 可信度 + 业务引流 + 真相背书
- 去掉这句话论证链就断了 → 融入成功；去掉后论证链没影响 → 硬塞的

**技法2：改规则，不折腾人（逻辑对位）**
- 外卖：交警改考核规则（扣掉红灯时间）→ 骑手不用拼命了
- 注册公司：政府把流程搬上网简化 → 老板不用折腾了
- 共同点：系统层面解决问题，不是让人去适应系统

**技法3：互动引导（提升评论率）**
- 末尾加：「你所在的城市，是哪种？」
- 设计：真实体会 + 对比 + 开放问句
- 效果：其他城市的老板忍不住对比自己的城市，评论区活跃

### 最终输出结构

1. **Hook（全国罚外卖 vs 苏州改规则）**
2. **故事细节（交警找平台谈判的过程）**
3. **提炼方法论（改规则，不折腾人）**
4. **引入业务（我在苏州做注册二十年，我很清楚…）**
5. **升华（不是服务水平，是制度设计）**
6. **互动引导（你觉得你所在的城市，是哪种？）**
