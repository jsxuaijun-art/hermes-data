# 香港利润来源地（Source of Profits）分析框架

## 1. 核心原则
来源地分析以产生利润的真实业务活动为中心，不能仅凭公司注册地、银行所在地、发票抬头、客户所在地或货物是否经过香港直接下结论。

## 2. Trading / Service 常见事实
- 谁寻找供应商 / 客户
- 谁谈判
- 谁批准价格和信用条件
- 合同在哪里谈判 / 订立
- 采购和销售操作在哪里完成
- 服务由谁、在哪里执行
- 哪些人员承担关键功能
- 风险在哪里管理和控制
- Goods route / delivery terms
- Bank / payment path
- Related-party involvement

## 3. 输出
- Key profit-producing operations
- Hong Kong activities
- Offshore activities
- Evidence
- Preliminary source conclusion
- Assumptions
- Missing facts
- Needs Verification
- Effective Date / Source / Review Tier
