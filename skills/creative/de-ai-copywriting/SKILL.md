# 去AI味 Copywriting Skill

写好的中文文案（公众号文章、短视频脚本、客户话术）交付前过一遍"去AI味"，再用朱雀AI检测验收，让内容读起来像真人写的、检测不出AI痕迹。徐总/江姐的财税内容默认都要过这一关（2026-08 确立，用户要求"安排起来"）。

## When to Use

- 用户提到「朱雀AI」「去AI味」「AI味太重」「检测AI率」「像AI写的」
- 任何公众号文章 / 短视频脚本 / 话术交付前，**默认**先过一遍去AI味（用户已要求固化为默认流程）
- 用户要求"检测一下这篇是不是AI写的"

## Prerequisites

- **去AI味核心方法**：加载 `humanizer` skill（creative/humanizer），按其29条AI模式逐条扫描改写
- **朱雀AI检测（验收工具）**：https://matrix.tencent.com/ai-detect （腾讯官方，免费在线，额度按次计，约5次）

## Key Facts About 朱雀AI ⚠️

- 朱雀AI是腾讯的 AI 内容**检测**工具（matrix.tencent.com/ai-detect），**不是"去除"工具**——别答应"用朱雀去AI味"，要跟用户讲清：朱雀负责验收，去AI味靠改写。
- 它检测一段文字是不是AI写的、AI率多高；中文检测准确率96%+（官方口径，仅供参考辅助判断）。
- 免费在线可用；自动化操作时会触发交互式验证码（滑块/点选类），无 vision 能力的主模型无法自动完成。
- **落地方式**：我方备好一段纯文本检测稿 → 用户复制粘贴到朱雀网页 → 用户手动过验证码 → 看AI率 → 偏高则再改一轮。

## Workflow（写 → 去AI味 → 朱雀验收）

1. **写作**：公众号走 `wechat-publish`，短视频走 `short-video-copywriting`（用户自有技能，只调用不修改）。
2. **去AI味改写**：加载 `humanizer` skill，按其Pattern逐条扫正文（见 humanizer SKILL.md 的29条）。
3. **中文财税内容额外注意**（见下节）。
4. **备好检测稿**：把改后正文整理成一段连续纯文本，放桌面或直接贴在回复里，告诉用户"复制到朱雀 matrix.tencent.com/ai-detect 检测"。
5. **迭代**：AI率偏高 → 重点替换高频AI连接词、打破整齐排比、增加口语节奏 → 重新交付。

## 中文财税文案去AI味要点（2026-08 税收洼地文章两轮实测）

### ⚠️ 实测结论：表层改写过不了朱雀（2026-08-21）
- V1 只做"换词+拆句+口语化"，朱雀报告：片段1 AIGC **0.9116**（占59%）、片段2 **0.9969**（占41%）→ 整篇判 AI。**表层措辞改写无效**，朱雀看的是句法节奏、篇章结构、词汇分布。
- 去AI高频连接词（首先/其次/综上所述/另一方面/翻译成人话就是）、疑问句口语化（"这说明啥？"）、拆长句——这些只是**起点**，远不够。
- **每一轮改写必须上朱雀实测**，AI率说话；不要凭手感自评"这次应该过了"。

### 结构层手法（V2 起用；每轮仍要实测）
- 开头用**真实场景+老板原话对话**（"江姐，XX园区说我去注册，税能返我四成，靠谱不？"），不用宣言式直开。
- **打破 `①②③④` 整齐排比** → 口语"一是…二是…"。
- **打破"一方面…另一方面…"对称** → "第一…第二…"+ 插入感叹（"你品品，833件啊"）。
- 口语感叹词/口头禅：你品品、你猜怎么着、我给你翻译、说白了、那才叫…
- **数字口语化+自我纠正**：129万户 → "一百二十九万户" 再补"对，129万户，不是129家"。
- 短句独立成段、长短句交错；避免全文句长均匀、反问句过密、情绪递进太整齐。

### 只改表达不改事实（红线不变）
- 政策数字、文号、官方法规必须原样保留（公众号"严禁AI幻觉"红线），去AI味只动语言不动事实。

### 朱雀报告单怎么读（用户给路径 → 直接 read_file）
- 用户说"检测结果/修改后文本见路径 X" → X 就是朱雀报告（PDF 自动转文本），直接读。
- 报告含：检测时间、《朱雀AI生成检测报告单》、片段表（占全文比例/占字符数/AIGC值）、每片段命中文字。
- 阈值：AIGC 0-0.5 人工特征；0.5-0.99 疑似AI；0.99-1 AI特征。

### 交付
- 生成 `_去AI味版.md` 与原稿并列保存（`/home/administrator/公众号素材/`），两版命名 ①原稿 / ②去AI味版。
- **徐总在 Windows，md 不可读** → 拷贝桌面时转 **.docx**（python-docx+微软雅黑）和/或 .txt。
- **文件名路径默认（徐总2026-08-21确立）**：用户只给文件名 → 完整路径 = `D:\OneDrive\Desktop\<文件名>`（WSL: `/mnt/d/OneDrive/Desktop/`）。
- 完整实测与手法清单见 `references/zhuque-ai-detection.md`

## Pitfalls

- 朱雀是**检测**不是**去除**——先讲清分工，别让用户以为工具能一键去AI味。
- 验证码需人工：自动化场景先说明"检测这步需要您手动粘贴"，不要硬耗轮次尝试自动过验证码。
- 模板尾部（公司介绍/CTA/二维码/免费资料话术）**不参与去AI味**，保持定稿版本原样。
- 去AI味必须包含**结构层改写**（打破排比/对称/工整分段）——V1 只做语言层换词实测 AIGC 0.91/0.99 整篇判 AI（见上"实测结论"）。但**内容层**重组（观点原创、顺序打乱）仍由 wechat-publish 模式C/D 负责，本技能不虚构事实。
- 若 user-owned 技能（wechat-publish / short-video-copywriting）需要承载这条流程但无法编辑，建议用户 `hermes curator adopt` 后再并入。

## Verification

- 通读一遍改后稿：任何"像AI写的"句子都改掉（humanizer 第6步反AI pass：自问"哪里一看就是AI写的"，改完再问一次）。
- 交付时附检测稿，等用户朱雀结果反馈后按需迭代。
