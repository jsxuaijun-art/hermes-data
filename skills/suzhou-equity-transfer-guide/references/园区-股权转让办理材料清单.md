# 苏州工业园区（星塘大厦3楼税务窗口）· 自然人股权转让办理材料清单

> 来源：客户实际提供的园区窗口材料清单（2026.11 客户提供，徐总接入本skill）
> 园区窗口口径最规范、最严，按此清单准备材料。
> 特点：申报表由盈信现场填报，其余材料由客户自备。区分"必报"与"选报"。

---

## 一、必报

### （一）由盈信前往办税服务厅现场填报的申报表
1. 《财产和行为税纳税申报表》
2. 《个人股东股权转让情况报告》

### （二）以下由客户提供 —— 自备文件
1. **股权转让合同/协议（原件）**
   - 内容须确定：原股东A持有的XX%的股权（人民币）xxx万元，以XXX元的价格转让给新股东B
   - ⚠️ 时间口径：**协议签订日 → 去现场递交日须在15个工作日内**
   - 也可提供转让信息后由盈信代为制作

2. **股权转让协议签订日上月月末财务报表**（必报一份即可；园区口径"上月月末"）

3. **股权原值资料**（按取得方式分类选报）：
   - (1) 若被转让股权为**以前年度购入**的：股权购入合同、支付凭证、上手纳税申报记录（完税证明、联系单等）
   - (2) 若被转让企业（本公司）为**转让方出资设立**的：出资协议、银行流水、验资报告、合理税费佐证材料等
   - (3) 若被转让股权以**非货币性资产出资方式**取得：出资协议、产权证明、合理税费佐证材料等
   - (4) 若被转让股权通过**无偿让渡**方式取得：亲属关系佐证资料、原持有人出资证明等
   - (5) 若被投资企业以**资本公积、盈余公积、未分配利润转增股本**：股东会决议、缴税证明、合理税费佐证材料等
   - (6) 如不符合上述选报项目：**补充情况说明并加盖公章**

4. **股权转让双方身份证件原件**（若为企业提供营业执照原件或复印件盖公章）
   - 身份证件原件有困难的：提供电子税务局app完成实名认证后的截图 + 身份证件复印件 + 手机号码
   - 实名查看路径：电子税务局app — 我的 — 账户中心 — 个人实名管理

## 二、选报（条件触发）

1. 若**委托办理**：被委托方身份证原件 + 授权委托书
2. 若被投资企业有**土地使用权、房屋、房地产企业未销售房产、知识产权、探矿权、采矿权、股权等资产**：
   提供**具有法定资质的中介机构**出具的净资产或土地房产等资产价值**评估报告**
3. **计税依据明显偏低但有正当理由**的证明资料
4. **以前历次股权转让**时完整的转让材料
5. 其他：涉及**长期股权投资**的，被投资企业股权转让协议签订日上月月末财务报表

## 三、提醒
1. **个人所得税**需通过**自然人电子税务局网页端自行申报**

## 易漏点 / 注意（实操提醒）
- 园区窗口：申报表（报表类）盈信代填，客户只需备齐自备文件。
- 协议时间口径是"15个**工作日**"（区别于高新区/一般"15日"），签订后尽快递交，避免超时。
- 股权原值资料是按"取得方式"分类选报的，**必须先确认转让方当初怎么取得这股权**，再套对应那一条，别漏。
- 涉及"股权/长期股权投资/房产/知识产权"类资产 → 选报评估报告大概率触发（类型C），提前评估再定价。
- 个税走自然人电子税务局**网页端**自行申报，不是现场表报。
