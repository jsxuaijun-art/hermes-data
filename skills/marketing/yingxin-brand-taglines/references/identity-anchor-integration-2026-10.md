## 二、融入纪律（5 条，硬）

1. **只进「理念层」，每项只定一版。** `canonical-identity-anchor.md` 自带「一次性定稿、引用不得改写」纪律 —— 融进去的必须唯一版。备选/多首只留在本 skill 的 references，**不上墙、不进引用源**（多版本进引用源 = 对外口径混乱）。
2. **先提案后动手。** 理念/文化属「品牌宣传类」内容，写进核心人设文件前必须列方案请用户拍板；未征得同意不落笔。
3. **按文件定去留**（见上表）：锚点文件加新章节；产品手册加一行；SOUL.md 不动。
4. **五副本全同步 + md5 核对**；★ 那份的差异保留。
5. **插入位置**：锚点文件现有章节为 一锚点逻辑链 / 二完整身份锚点 / 三标准表述 / 四关键数字清单 / 五使用纪律 / 六引用依赖图谱 → 新章节建议放「三、标准表述」之后，编号顺延（放「六、引用依赖图谱」之后会让依赖图谱不落在末尾，不推荐）。

## 三、融入提案稿（★ 待徐总拍板，未经同意不写入）

```markdown
## 企业文化 · 品牌资产（对外统一表述）

**企业精神**：信立盈门，专筑财税
**使命**：陪中小微企业稳健成长
**操守**：不越红线，不谋虚利

**四言藏头**：盈耕苏沪，信立诚彰。守规尽责，正伴业昌。（藏头：盈信守正）
**五言藏头**：盈程伴企兴，信立专业精。守规存诚敬，正途稳步行。（藏头：盈信守正）

> 使用纪律：以上一次性定稿，引用不得自行改写；藏头诗对外只此两版，其余仅作备选，不上墙、不进引用源。
```

**为什么只挑这五项**：四言/五言最凝练、背得下来，最宜当「理念锚点」；七言绝句/八句偏长，留给海报与文化墙，不进人设 md。
**口径提示**：四言与五言藏头都落在「盈信守正」，正好承接企业精神里的「守正」，对外口径统一。

**增值角度（可主动提，用户认可过这种"顺带发现"）**：
产品手册第六章「合规承诺 / 保密承诺 / 时效承诺 / 响应承诺」本质上就是操守「不越红线，不谋虚利」的**落地版** —— 让两处互引（对客讲"我们信什么"=理念，讲"我们承诺什么"=条款），虚一实正好闭环，比单摆标语有说服力。

1. **盈信筑梦，企服护航**（ang 韵）
   盈立姑苏，信昭誉扬，筑专砺能，梦伴微昌，
   企账清详，服暖客商，护防风险，航稳路长。
2. **盈信守正，行稳致远**（an 韵）
   盈通苏沪，信立诚端，守规不越，正业不偏，
   行贵务实，稳托企安，致精专技，远共途宽。
3. **盈信相伴，微企共兴**（ing 韵）
   盈耕财税，信铸金名，相呼即应，伴企同行，

> 复用提示：起句「盈耕苏沪」「盈通苏沪」「盈程伴企兴」都是"苏沪双城 + 深耕"意象，可持续复用；

## 五、交付流程（本次实测走通）

1. 写 brief（含事实白名单 + 硬格式约束 + 五维内涵）→ `/tmp/*_brief.txt`
2. 豆包出稿：`llm-longform-generation/scripts/stream_chat.py`，`--model Doubao-Seed-2.1-Pro --key-env TELECOM_DOUBAO_KEY`，stream 必须开（非流式 ~90s 超时会断）
3. **主会话机械核验**：藏头首字拼接 + 每句字数（`scripts/verify_acrostic.py`，四言用默认即可，已支持 4/5/6/7）；韵脚脚本只打印末字给人读
4. 组织交付：选中定稿 → 后续再谈是否 Word / 是否融入人设文件
