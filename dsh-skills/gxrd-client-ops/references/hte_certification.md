# 高新技术企业认定、优惠享受与维持

> 定位：路径 A（高企客户）的「拿得到 + 享得对 + 守得住」全流程。
> ⚠️ **高企口径 ≠ 加计扣除口径 ≠ 会计口径**：本模块用高企口径（其他费用≤20%、委托外部按80%、含建筑物折旧），勿与 rnd_superdeduction.md 混用。

## 一、优惠基本盘

| 事项 | 规则 | 依据 |
|------|------|------|
| 优惠内容 | 减按 **15%** 征收企业所得税（法定25%） | 《企业所得税法》第28条 |
| 资格有效期 | 自**颁发证书之日起 3 年** | 32号第九条 |
| 享受起点 | 自证书颁发之日所在年度起 | 32号第十条 |
| 期满当年 | 到期当年季度预缴仍按15%；年底前重新取得证书则全年继续享受，未取得则按25%补缴 | — |
| 主体限制 | 仅查账征收居民企业 | — |
| 与加计 | 15% 与研发费加计扣除可叠加；与小微择一 | — |
| 亏损结转 | 高企 **10 年**（一般5年） | 财税〔2018〕76号 |

**税率择一专项**：过渡期「两免三减半」与高企叠加，可选过渡期减半或15%，**不得按15%再减半**；软件/集成电路定期减半类似；西部大开发按适用税率计算减半。

## 二、认定八项条件与账务/证据准备

| # | 条件 | 乙方须准备的账务与证据 |
|---|------|------------------------|
| 1 | 申请认定时注册成立满1年 | 营业执照、成立之日起账套 |
| 2 | 取得对主要产品(服务)发挥核心支持作用的知识产权所有权 | 权属证书 + 与高新产品对应关系表；I类可复用、II类仅用一次 |
| 3 | 技术属《国家重点支持的高新技术领域》 | 核心技术说明 + 对应收入资料 |
| 4 | **科技人员占职工总数 ≥10%** | 「当年」=申报前一个会计年度。科技人员指直接从事研发和技创活动、以及专门从事上述活动的管理和直接技术服务人员，累计实际工作≥183天；含在职/兼职/临时聘用；均按全年月平均数计算。证据：名单、183天佐证、工时表 |
| 5 | **近三年研发费用占销售收入比例分档达标** | 高企口径辅助账+专项审计；`hte_ratio` 测算 |
| 6 | **高新收入占同期总收入 ≥60%** | 收入拆「高新产品(服务)」；**总收入=收入总额−不征税收入** |
| 7 | **创新能力评价 >70 分** | 知识产权、成果转化、研发组织管理、成长性四模块 |
| 8 | 申请前1年无重大安全/质量/环境违法 | 合规声明与查询记录 |

## 三、三项硬指标测算（每年滚动预警，别等复审）

```
研发费用占比 = 归集的近三年高新研发费用合计 ÷ 近三年同期销售收入合计
【分档依据 = 最近一年销售收入】（不是近三年合计！）
  ≤5000万 → ≥5% ；5000万~2亿 → ≥4% ；>2亿 → ≥3%
  另：境内研发费占全部 ≥60%；实际经营期不满三年按实际经营时间计算
高新收入占比 = 近一年高新收入 ÷ 同期总收入 ≥60%
科技人员占比 = 申报前一年科技人员数 ÷ 当年职工总数 ≥10%
```
> ⚠️ 分档**必须按最近一年销售收入**，勿用三年合计÷3 估算。复核特则：对占比有异议以问题所属年度及前两年度之比复核。
> 预警口径（书 p355）：研发费占比预警值 5%/4%/3%；A107041 第25行÷(26行+28行)>80% 触发核查。

## 四、高企研发费用归集口径（表7-16）

| 费用项目 | 加计扣除口径 | **高企认定口径** | 会计口径 |
|---------|------------|----------------|---------|
| 人员人工 | 直接从事研发人员工资/五险一金/外聘劳务 | **企业科技人员**工资/五险一金/外聘科技人员劳务 | 在职研发人员工资津贴补贴社保公积金+外聘（范围最大） |
| 直接投入 | 材料/燃料/动力；模具工艺、样品样机、试制检验费；仪器设备租赁 | 基本同左，另含**经营租赁租入固定资产租赁费** | 含房屋等固定资产相关租赁与运维 |
| 折旧与长期待摊 | 仅仪器、设备折旧 | 仪器、设备**及在用建筑物**折旧；研发设施改建装修的长期待摊 | 仪器、设备、房屋等固定资产折旧 |
| 无形资产摊销 | 软件、专利权、非专利技术 | 软件、知识产权、非专利技术 | 软件、专利权、非专利技术等 |
| 设计试验等 | 新产品设计费、新工艺规程、临床试验、勘探试验 | 设计费+**装备调试费**+试验费（含临床、**田间试验**） | 未列举，相关费用均可计 |
| 其他相关费用 | **正列举**，≤可加计研发费总额 **10%** | 可含办公费、外事费、培训费、通讯费等，一般 ≤ 研究开发总费用 **20%** | 无比例限制 |
| 委托外部研发 | 境内/境外按80%，境外另限2/3 | **委托外部按80%计入**（境内外均按此，无2/3） | 据实 |

> ⚠️ **四条最易混**：①房屋折旧/租赁费高企可计、加计不可计 ②知识产权摊销高企可计、加计只认专利权 ③装备调试费与田间试验费仅高企口径 ④其他费用 20% vs 10% 两套上限各卡各的。
> **高企其他费用限额按全部研发项目汇总计算**；多项目可按直接投入占比等合理方法分摊。装备调试费不含为大规模批量生产进行的常规工装准备。
> **两套账**：高企认定须按《企业年度研究开发费用结构明细表》另设高企认定专用辅助账（近三年分年、按RD项目分列），由有资质中介专项审计；不能拿加计辅助账顶替。

## 五、认定程序与时间轴

1. **自我评价**：对照 32号/195号，准备申请材料 + 参与审计/鉴证的中介机构资质证明。
2. **注册登记**：登录「高新技术企业认定管理工作网」(www.innocom.gov.cn) 或「科学技术部政务服务平台」(fuwu.most.gov.cn)。
3. **提交材料**：申请书、知识产权、科研项目立项、成果转化、研发组织管理、成长性指标、近三年研发费专项审计、高新收入专项审计、职工与科技人员说明等。
4. **专家评审 → 审查认定 → 公示 10 个工作日** → 备案、公告、颁发证书；有异议由认定机构核实处理。
5. 监督检查由**工信部、财政部、税务总局**组织（2023.9.24 起科技部相关职责划入工信部）。

## 六、申报填表（SOP）

| 环节 | 表单与行次 |
|------|-----------|
| 预缴 | A200000 第13行「减：减免所得税额」 |
| 汇缴·基础信息 | A000000「211 高新技术企业申报所属期年度有效的高新技术企业证书」栏 |
| 汇缴·主表 | A100000 第26行「减免所得税」 |
| 汇缴·明细 | A107040 第2/3/29/33行；A107041 全套 |
| 加计扣除 | 另填 A107012 → A107010，可与 15% 叠加 |

**A107041 行次速查**：
- 收入指标：1 本年高新产品(服务)收入 = 5 产品收入 + 6 技术性收入；7 本年企业总收入 = 8 收入总额 − 9 不征税收入；10 = 4/7 高新收入占比。
- 人员指标：11 本年科技人员数；12 本年职工总数；13 = 11/12。
- 研发费用指标：14 归集年度；15 归集的高新研发费用 = 16 内部研发投入 + 25 委托外部；16 = 17+18+19+20+21+22+24(23其他)；**25 = (26 境内 + 28 境外)×80%**。
> ⚠️ 第25行按 (26+28)×80% 自动勾稽；第24行可计入的其他费用受 20% 上限约束。表版本每年可能调整，以电子税务局当年表样为准。

## 七、维持与监督管理（守资格，最容易翻车）

| 事项 | 规则 | 后果 |
|------|------|------|
| 年度发展情况报表 | 每年 **5月底前** 在认定网填报上一年度知识产权、科技人员、研发费用、经营收入 | 累计两年未报 → **取消资格** |
| 更名与重大变化 | 三个月内向认定机构报告，网上提交《高新技术企业名称变更申请表》 | 仅更名且符合条件：公示10工作日重新核发证书（编号有效期不变）；涉重大变化不符合条件的，自该年度起取消资格 |
| 整体迁移 | 跨认定机构区域整体迁移，向迁入地提交证书+迁入证明 | 资格与证书继续有效，编号有效期不变 |
| 复核程序 | 有关部门发现不符合，书面提请认定机构复核 | 确认不符合→取消资格→追缴不符合年度起已享优惠；研发占比异议按问题年度及前两年度之比复核 |
| 税务机关日常管理 | 认定中或享受优惠期间不符合，提请复核 | 追缴证书有效期内自不符合年度起已享优惠 |
| 主动不享受 | 不符合条件当年主动不享受并补缴 | 无须再提请复核，保留资格 |
| 取消资格三类 | ①认定过程严重弄虚作假 ②重大安全/质量事故或严重环境违法 ③未按期报告重大变化或累计两年未报年报 | 自行为发生年度起取消并公告；按《税收征管法》追缴 |

> 税务机关应自高企被取消资格之日起 **30 个工作日内**追缴税款。

## 八、乙方服务检查点（盈信交付清单）

- [ ] 每年 3 月出三项硬指标滚动测算表，缺口提前预警并给整改方案。
- [ ] 高企口径辅助账与加计扣除口径辅助账分设或分栏，20%/10% 两套上限分别校验。
- [ ] 收入科目设「高新产品(服务)」明细，年度核验 ≥60%；总收入按税法口径重算。
- [ ] 科技人员名单 + ≥183 天佐证 + 工时表归档；人事台账与 A107041 第11/12行一致。
- [ ] 5月底前完成年度发展情况报表（设双人提醒）。
- [ ] 证书到期当年：季度预缴按15%，年底前盯紧重新认定结果，未获证立即按25%补缴测算。
- [ ] 证书、认定材料、知识产权、专项审计报告、辅助账、结构明细表按签收单归档。
- [ ] 出具《指标达标与风险提示函》，明确客户对资料真实性负责。
