## 一、三地窗口口径速查（既有沉淀）

> 以下为skill主体已有的三地差异，此处浓缩为"实然口径"清单，方便快速比对。

### 1.1 吴中区木渎分局（灵天路89号木渎分局纳服窗口）

- 短信通知中明确"**转让时点一般为签约时间**"这一实操口径（其他分局不一定明说）
- 材料要求相对齐整，人员少、排队短
- `[敏感]` 吴中木渎对"账面净资产 vs 评估价"的裁量空间，见江姐实操记忆，对外不主动说

### 1.2 工业园区（星塘大厦3楼税务窗口）

- 行政中心综合窗口，材料要求最规范、最严
- 主要按"三类型分类体系"审核（类型A即时/类型B即时/类型C非即时）
- `[敏感]` 园区对增值性资产"超过20%触发评估"的执行尺度

### 1.3 高新区（苏州高新技术产业开发区税务局）

- 三类型分类体系最完整（近亲属/无增值资产≤200万/非即时）
- **2019年以前成立的企业**必须提供"最近一次股转旧协议+旧章程+承诺书+完税证明"
- 要求"盖章修正案"与"股东会决议"二选一即可
- 要求最近一次股转的**承诺书+代扣代缴承诺书+授权委托书**（模板在skill references）
- 工作时注意：股权原值证明需分类（验资/实收资本入账/资金未到位声明/前次受让凭证）

## 二、净资产为负·零元转让（2026.6.4 实战案例）✅已验证

**结论：公司净资产为负时，零元转让不构成"计税依据明显偏低"，个税=0。**
```
净资产份额 = 资产 - 负债 = -75,466.28
转让价 0 > 净资产份额 -75,466.28 → 不启动核定 → 个税 0 ✅
```
**⚠️ 但有房产/土地/知识产权时必须先出资产评估报告**，评估升值可能把净资产"翻正"→ 触发核定 → 要交个税（案例：评估后+22.45万 → 个税约4.49万）。

**实操口诀：净资产为负≠个税归零，房产评估是变数。先看评估结果再定价，别急着签协议。**

## 三、两套财务报表教训（2026.6.4）

**血的教训：** 只问上年末财报会被客户反问"为什么不要最近一期？"——很尴尬。
**正确做法：** 出采集表即含"上年度末净资产 + 最近一个月末净资产"两个字段。
原因：①窗口要两套；②判断资产结构变化是否超20%；③判断期间新增盈亏。
