# 客户沟通话术（Client Communication）

## 适用场景
- 好消息通知（评上A级纳税人、退税到账、政策利好等）
- 日常关系维护（拉近距离、展示专业度）
- 服务到期/变更提醒
- 节日/生日/特殊日子问候
- 新政策解读推送
- **抖音评价回复**（好评/中评/差评/带细节好评/潜在客户疑问，见「抖音评价回复」章节）

## 核心原则

### 黄金结构（三段式）
1. **好消息前置** — 先说客户关心的结果，营造积极情绪
2. **价值解释** — 用客户听得懂的话说明"这对他意味着什么"
3. **自然收尾** — 归功于合作 + 为后续互动留口子

### ⚠️ 话术红线（已整合用户偏好）
- 先表扬客户公司底子好 → 再说咱们配合得好 → 最后落到持续合作
- 不能显得"邀功"，要让客户感觉这是"双赢"
- 不贬低同行，不踩低价（用"我们坚持专业路线"替代"他们低价没质量"）
- **默认风格：中和版** — 介于简短版和加强版之间，既不过于精简也不过于冗长。除非用户指定，否则优先输出"先给结论→再解释价值→最后收尾"的三段中和版

### 发送时机
- 好事趁热，当天发
- 配图（截图/证书）增加冲击力
- 客户回复后顺带一句"最近有没有新需求/政策要关注"，延续话题

## 抖音评价回复（子分支）

用于抖音评论区对客户评价/留言的回复。核心前提：一条回复同时说给
"平台（经营分/流量）+ 已成交客户（维系）+ 潜在客户（信任）"三种人听。

### 触发词
好评 / 好评回复 / 回好评 / 回评价 / 回复评价 / 评价回复 / 回个评价 /
评论回复 / 回评论 / 评论区回复 / 抖音评论 / 抖音评论回复 / 客户评价回复 /
差评回复 / 中评回复。
（裸「回复」需与上述词或"评论/好评/评价/抖音/客户"语境同现才触发，避免撞车。）

### 回复骨架（五段式）
①称呼+点名感谢 ②呼应评价原话的具体点（防复制感关键） ③轮换插入一个
专业点/文化点 ④延伸价值/互动反问 ⑤轻收尾+祝福不硬广。

### 可变模块池（轮换保证不重样）
- 文化锚点池 / 互动收尾池 / 称呼池：见 `references/douyin-review-axes.md`
- 按服务专业点池：见 `references/douyin-review-service.md`
- 示例库：见 `references/douyin-review-examples.md`

### 按评价类型选打法
- 纯好评 → 文化点 + 转介绍口子
- 带细节好评 → 抓细节 + 服务专业点
- 提疑问/求助（潜在客户）→ 先答疑立专业 + 引流私域
- 提建议 → 先谢不辩 + 线下处置
- 差评 → 公开道歉 + 私信解决 + 解决后回评更正（评论区内不争辩）

### 平台与经营分技巧
评价后当日回、150字+有信息量、带互动反问形成闭环、抓原话细节显真人感。
