# 一般纳税人vs小规模纳税人主题文章 — 已验证结构模板（2026-07-14）

> 适用场景：财税科普类，面向创业新手选择税务身份
> 受众分割：一篇两分，上半篇面向创业新手（主），下半篇面向已有公司老板（辅）

## 核心要素

- **目标读者**：刚注册公司或准备注册的初创创业者
- **获客目的**：让读者觉得"说得就是我"→建立专业信任→引导免费咨询
- **风格**：大白话 + 表格对比例 + 算账秀数字 + 行业速查

## 文章结构

```
上半篇：创业新手篇（主，占全文70%）
├── 一、先搞懂两个"身份"到底是什么    → 大白话定义 + 概念对比表
├── 二、核心差异一表看懂              → 11维对比表格（含费率/申报/费用/转换）
├── 三、四大判断维度——3分钟自测       → 客户→进项→利润率→销售额预期，逐级判断
├── 四、5个常见行业推荐速查表          → 科技/电商/餐饮/制造/咨询
└── 五、算一笔账——真实税负差          → 数字案例，说服力max

下半篇：已有公司的老板篇（辅，占30%）
├── 六、2026年新政策红利               → 增值税法4大变化
├── 七、三个容易踩的坑                 → 坑一坑二坑三
├── 八、一句话总结                     → 金句
└── 写在最后                          → 团队介绍+免费咨询引导
```

## 已验证的写法要点

1. **受众优先级**：创业新手为主角，代入感要强。即使话题对两类读者都有价值，新手篇占70%篇幅
2. **开头钩子**：用创业者注册公司时的真实困惑场景切入，让读者觉得"说的就是我"
3. **表格含费用**：代理记账费用200-400 vs 500-800元/月，很实在的对比
4. **4步自测法**：客户→进项→利润率→销售额，按顺序自测自动出结论
5. **行业速查**：5个常见行业一表看懂，读者对号入座
6. **算账**：直接上数字，月销售额50万，对比两种身份税负差（5倍对比）
7. **2026年新政**：增值税法实施后的小规模减按1%、季度30万免税、辅导期取消
8. **三个坑**：坑一（装面子）、坑二（丢客户）、坑三（超500万不转）
9. **结尾获客**：团队资质展示 + 首次咨询免费
