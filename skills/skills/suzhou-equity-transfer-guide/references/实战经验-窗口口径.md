- 材料要求相对齐整，人员少、排队短
- `[敏感]` 吴中木渎对"账面净资产 vs 评估价"的裁量空间，见江姐实操记忆，对外不主动说

### 1.2 工业园区（星塘大厦3楼税务窗口）

- 行政中心综合窗口，材料要求最规范、最严

- `[敏感]` 园区对增值性资产"超过20%触发评估"的执行尺度

### 1.3 高新区（苏州高新技术产业开发区税务局）

- 三类型分类体系最完整（近亲属/无增值资产≤200万/非即时）

- 要求"盖章修正案"与"股东会决议"二选一即可
- 要求最近一次股转的**承诺书+代扣代缴承诺书+授权委托书**（模板在skill references）
- 工作时注意：股权原值证明需分类（验资/实收资本入账/资金未到位声明/前次受让凭证）

## 二、净资产为负·零元转让（2026.6.4 实战案例）✅已验证

**结论：公司净资产为负时，零元转让不构成"计税依据明显偏低"，个税=0。**
```
净资产份额 = 资产 - 负债 = -75,466.28
转让价 0 > 净资产份额 -75,466.28 → 不启动核定 → 个税 0 ✅
```
**⚠️ 但有房产/土地/知识产权时必须先出资产评估报告**，评估升值可能把净资产"翻正"→ 触发核定 → 要交个税（案例：评估后+22.45万 → 个税约4.49万）。

**实操口诀：净资产为负≠个税归零，房产评估是变数。先看评估结果再定价，别急着签协议。**

## 三、两套财务报表教训（2026.6.4）

**血的教训：** 只问上年末财报会被客户反问"为什么不要最近一期？"——很尴尬。
**正确做法：** 出采集表即含"上年度末净资产 + 最近一个月末净资产"两个字段。
原因：①窗口要两套；②判断资产结构变化是否超20%；③判断期间新增盈亏。

## 四、"净资产为正但原值更高" → 个税也=0（2026.10.27 实战案例）✅已验证

**场景：** 苏州园区企业，外国个人 97.5% + 中国个人 2.5%，净资产 +110.39万（为正），实收资本 200万。

**关键结论：净资产为正 ≠ 要交个税。** 只要"股权原值（实缴资本）> 对应净资产份额"，即使被核定到净资产份额，仍是亏损转让 → 个税=0。
```
外国股东: 份额1,076,301  原值1,950,000 → 亏-873,699 → 个税0
中国股东: 份额27,597     原值50,000   → 亏-22,403  → 个税0
```
**与"净资产为负零元转让"不是一回事：** 那例是"资产<负债"；本例是"净资产为正但实缴资本更高"（累计亏损 89.6万，但实收资本大）。

**⚠️ 三个复杂度点（本案全踩中）：**
1. **长期股权投资 500,000 属"股权"型增值性资产，占资产约44% > 20%** → 不满足类型B即时办结，必须走类型C非即时办结，移送税源管理机构审核，耗时长。
2. **评估"翻正"变数：** 若该 50万长期股权投资/固定资产评估增值累计超约 87 万，会把外国股东从"亏损"掰成"盈利" → 个税从0变非0（20%）。**关键阈值 ≈ 能使 97.5% 份额扭亏的浮盈额。**
3. **外国个人股东 = 跨境因素：** 居民/非居民身份认定、身份证明、转让款是否资金出境，材料比纯内资多一档。

**实操口诀：净资产为正≠要交税；关键是"原值 vs 份额"以及"是否触发评估"。先摸清长期股权投资/房产的增值情况，再定价，别只看账面净资产。**

## 五、历次股转文件 & 长期股权投资核查（2026.10.27 案例补充）✅需落地

**场景：** 正是上面第四节那个园区外资案例（长投 50 万占资产 44%）延伸出来的两条实操要求。

### 5.1 历次股权转让的文件，要追"历次"不是"最近一次"

- 公司历史上每次股转的**旧协议 + 旧章程（修正案）+ 完税证明/申报记录**都要找齐
- 高新区硬性要（2019前成立企业只要最近一次），但**即使不要求也主动追历次沿革**——漏一次历史股转，窗口可能退回，也可能被认定计税依据问题
- 主动按时间倒序列：对手方、价格、计税依据、完税情况

### 5.2 账上有"长期股权投资"，问清投资标的是什么

- 问：投的是哪家公司、**持股比例**、**控股还是参股**、是否纳入合并
- **若控股子公司 → 必须索取：** 子公司名称+持股比例、子公司**财务报表（资产负债表+利润表）**看盈亏
- **为什么：** 子公司盈亏直接影响母公司长投价值 → 影响被转让企业净资产核定与转让定价合理性（子公司亏→长投减值→净资产被压；子公司赚→长投增值→评估"翻正"风险）

**口诀：账上有长投→问清投的谁、持股多少、盈亏如何；控股子公司→看它的财报，别只看母公司账面。**

## 六、两期数据原则 & 科目余额表体检（2026.10.30 瑞翼/园区案例）✅

**背景：** 客户只给了《2026年09月科目余额表》，缺2025年度正式报表。曾试图用"期末−本年累计"倒推年初数，结果资产/权益严重矛盾（倒推资产 222 万、权益仅 82.7 万），证明**倒推不可靠**。

### 6.1 原则：缺数据优先 A（补资料），B 只能过渡
- 股转测算要有"上年度末 + 最近一月末"两期报表；缺一期就**请客户补齐再算**。
- 只能先出过渡版时：只填可核实那期，缺项红标【待补：需XXXX年度报表】，明确写"两期对比无法判定"。
- 铁律：宁交"缺项标红+待补清单明确"的报告，不交"数字齐全但来源不可靠"的报告。

### 6.2 科目余额表 4 项体检（拿到先查）
1. 借贷平衡：资产−负债 应 = 所有者权益；不等先查（本案差 12,923.26）。
2. 应收账款贷方余额：属异常，疑预收未重分类或错账（本案贷方 230,387）。
3. 本年利润是否结转未分配利润：未结转→资产负债表未分配利润为空、亏损挂损益科目（本案 89.6 万挂账）。
4. 长期股权投资科目名是否写明标的：只写"XX"必须追问投资对象/持股/是否控股。

### 6.3 口径提醒
- 月度科目余额表"期初"= 月初，不是年初。年初只能用"期末 − 本年借累计 + 本年贷累计"逐科目还原，且须与正式报表交叉验证，**不可直接当上年度末填表**。

**案例数据（瑞翼·2026-09-30）：** 资产 1,121,031.32／负债 4,209.15／权益 1,103,898.91（差12,923.26待核）；实收资本 200万；累计亏损 -896,101.09；长投 50万占资产44.6%→类型C；本次转2.5%作价5万>净资产份额2.76万→个税0。
