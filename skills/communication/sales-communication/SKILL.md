# 销售沟通话术 · 统一母skill

> **一句话定位：** 盈信16年实战的销售与客户沟通全链路话术体系，按「客户全生命周期」组织成
> **新客线（从0到1）+ 存量线（从1到∞）** 两大板块、九个阶段。
> 用户提到 **话术 / 沟通 / 沟通建议**（或任一销售/谈判/客情/续费/转介绍词）即加载本skill。

---

## 使用方式（核心场景：客户来话 → 出话术）

**最常用用法：** 与客户洽谈中，客户发来一段话，你把**原话复制粘贴给我**，我按下面流程直接生成一条可发送的话术。

**你只需提供：** 客户的原始消息（复制粘贴即可）。最好顺带一句背景（新客/老客、什么行业、当前是报价/砍价/逼单/维护哪个环节）；不提供背景我也能根据原话自行判断。

**我收到后自动执行的流程：**
1. 判断客户原话属于哪个场景（砍价/比价/太贵了/考虑一下/同行更低/要资料/要优惠/续费/投诉/节日问候等）
2. 从「通用话术模块」调对应现成话术 + 定位所在阶段（新客线/存量线）的战略打法
3. 结合盈信身份锚点（高会/TSC五级/16年/双城），用客户原话和已知信息填空
4. 输出一条**可直接复制发送**的话术，中和版风格，无AI痕迹

**示例：** 客户发「你们怎么比别人家贵这么多？」 → 我按阶段三+通用-疑虑处理/报价逼单出话术（时间买断逻辑 + 资质锚定 + 先比专业再比价格）。

**铁律：** 不编造政策/数据。涉及具体政策文号、退税额、案例数字——你没给或没核实的一律不写死，留空格/占位符让你填真实数，宁可少说不说错。

## 新客线

### 阶段一 · 获客引流（前端触达）

目的：让潜在客户知道盈信、建立第一印象。**引流内容属内容创作，走独立skill**；这里只保留
「从触达到开口」的衔接话术。

- 电话/微信首次触达 3 分钟开场：先亮身份锚点 → 给一个价值钩子（「不耽误您时间，问5个问题就能初步判断」）→ 约面谈。
- 完整电话→面谈→跟进 SOP 见 `references/02-首次接触/初次洽谈SOP_完整版.md`。

### 阶段二 · 首次接触（企业诊断 + 建群开场）

**两条入口，都可能发生在签约前后：**

1. **初次洽谈·企业诊断**（签约前，15-20分钟）——目的不是成交，是「给3个钩子+留1个悬念」。
   - Teaser模式：亮身份 → 口头问5-8个关键问题 → 输出「税务风险(最痛)+股权/架构(啊感)+利润增长点(咦感)」3个发现 + 预约深度诊断的悬念。
   - Deep Dive模式：12模块完整诊断 + 成交引导。
   - 完整流程 + 话术 + 行业定制追问：`references/02-首次接触/企业初步诊断_完整流程.md`
   - 从注册入口自然延伸：`references/02-首次接触/company-registration-upsell.md`
   - 12模块原始模板：`references/02-首次接触/original-12-module-template.md`

2. **建群开场白**（签约后）——3段话定基调，只问公司名/老板称呼/主营业务3项。
   - 5大模块固定顺序：身份锚点 → 团队简介（闫经理带队+具体会计）→ 🔥行业痛点 → 配合事项(留痕+每月5号前交票) → 收尾「合作愉快」。
   - 完整模板 + 行业痛点匹配：`references/02-首次接触/建群开场白_完整流程.md` + `references/02-首次接触/industry-tax-pain-points.md`
   - **签约时服务边界书面化**（从源头防「把代账误当全职会计」的预期落差）：致客户《服务边界告知书》成稿 + 委托合同边界条款 + 法规出处速查 = `references/02-首次接触/建群开场白_完整流程.md` **附录**

### 阶段三 · 价值塑造·报价谈判（S1心理 + S2价值 + S3价格博弈）

客户不是在砍价，是在找安全感。**你的任务不是降价，是给安全感。**

- **S1 客户心理**：7大影响力原理（互惠/承诺一致/社会认同/喜好/权威/稀缺/联盟）+ 四型人格（老虎/孔雀/鸽子/猫头鹰）。砍价三个真实原因：心理不安全感60% + 占便宜欲望30% + 真预算不足10%。核心法则：镜子效应、锚定、互惠、损失厌恶。
- **S2 价值重塑**：SPIN提问法（背景→难点→暗示放大后果→需求效益）+ FABG法则（特性→优势→利益→Grabber）。把「代账」从成本项变投资项。
- **S3 价格博弈·核心逻辑**：**服务费 = 买断工作时间**（上帝对谁都公平，一天24小时，做了这个就不能做那个；低价同行把时间花在开票跑腿，分给做账的就没多少；做账是看不见的无形服务，风险跟着来；所以先比专业资质再比价格）。完整论述 + 杀伤链见 `references/00-核心弹药库/core-logic.md`。**数据版（规模经济表：单客户月均4–6h vs 全职176h）+ 法规溯源（代账≠全职会计，含会计法34/25/35/40条、代理记账办法）** 同见 `core-logic.md`——阶段三/五/七/八通用。新客若「想低价又要一对一」，报价阶段就用 `references/07-老客户压价/低价高服务应对.md` 的三层边界套话术（阶段七主力，阶段三提前可用）。
- 7大砍价应对话术 + 涨价沟通 + 10种促单技巧弹药库：`references/00-核心弹药库/S1-S5_核心弹药库_三书融合版.md`、`references/00-核心弹药库/话术精炼库_完整版.md`（30场景）、`references/00-核心弹药库/低价营销反击战术卡.md`

## 存量线

### 阶段五 · 日常客户服务·关系维护

**黄金结构（三段式）：** 好消息前置 → 价值解释（客户听得懂的话说明「对他意味着什么」）→ 自然收尾（归功合作+留口子）。

**话术红线：** 先表扬客户底子好 → 再说咱们配合好 → 最后落到持续合作；不邀功、双赢感；不贬同行（用「我们坚持专业路线」替代「他们低价没质量」）；**默认输出中和版**（先结论→再解释价值→收尾）。

场景：评上A级纳税人、退税到账、政策利好、服务到期/变更、节日/生日问候、新政策解读。发送时机：好事趁热当天发、配图增强冲击力、回复后顺带延续话题。

- 完整流程：`references/05-关系维护/客户沟通_完整流程.md`
- 示例：`references/05-关系维护/A级纳税人通知话术.md`
- 涨价沟通：`references/05-关系维护/price-increase-on-invoicing.md`
- **服务追责/提醒义务边界**（存量客户事后追责「没提前提醒我」——如久悬户/挂账，划「合同义务 vs 合理提醒 vs 应知应会」三层线 + 化解+转档位）：`references/05-关系维护/服务追责与提醒义务边界.md`

### 阶段六 · 中期粘性维护 ★（增加强链接、防流失）

**定位：** 粘性是续费的地基——客户粘性高，续费自然顺；粘性不够，到续费才临时抱佛脚就晚了。
**目标：** 让客户持续感知「团队在服务、价值在累积、换人成本高」，主动切断「没出事=不需要」的心智。

**核心动作（按节奏循环）：**

| 频率 | 动作 | 目的 |
|------|------|------|
| 每月 | 主动联系1次：政策提醒 / 节税机会 / 经营关怀（不只等客户找） | 持续刷存在感、显专业 |
| 每季 | 季度经营小简报（营收/税负/风险点一句话） | 让「看不见的服务」被看见 |
| 关键时刻 | 评上A级、退税到账、拦下风险 → 当天主动传递 | 制造「团队在为你出力」的感知 |
| 半年 | 一次深度回访（电话/见面） | 深挖新需求、预防性防流失 |

**粘性话术示例：**
> X总，这个月税务上有个【新政策/小提醒】，跟您行业相关，我帮您留意好了，先跟您说一声，具体要不要用您定。——不用长篇大论，重在「我在主动想着您的事」。

> 这个季度我帮您把账理了一遍，整体很稳，就是【X】这个点值得盯一下，我已经处理好了，您放心。——把看不见的活显性化。

**换人成本意识（续费前置）：**
> 咱们合作这一年，您的账务连续性、我对您公司的熟悉度、默契都在这里。真换个团队，光重新上手熟悉您业务就得小半年，这中间的风险谁也兜不住。——粘性话术里埋「换人代价」，为阶段八续费铺路。

### 阶段七 · 老客户压价应对 ★（声称同行更低）

**核心认知：** 老客户降价 ≠ 新客户比价。老客户有信任和合作历史，筹码是**过去实际交付的价值**，
打法重心是 **先探因 → 锚定已交付价值 → 用非价格让步换价格**；最大风险不是丢单，是**降价开先例**（一个降了，其他都来降）。

**五种真实动机先判单**：真资金紧张（共情+分期/延付，不直接降）、比价压价（锚定价值+时间买断逻辑）、
试探忠诚（给面子+送非价格价值）、想多要服务（把降价转成加服务）、真想换（专业资质+历史成果最后锚定，不硬留）。
判单关键一句：「您是觉得价格问题，还是服务有不到位的地方？」

**六招心法（成功率最高）：** ①时间量化分级（300买2小时 vs 200买半小时）②资质硬锚+反问（我们高会+TSC五级，你问问那家是不是）③可验证证据外放（把科目余额表拿给低价同行看能否做到）④行业镜像类比（用客户的行业讲你的道理）⑤信息不对称对等（你不懂代账偷工减料，就像我不懂你行业）⑥让步化妆术（让利不砍单价：付一年送一月，定性为「老朋友的面子」）。

**一句话心法：** 别人问价格你答价值，别人比单价你比深度，别人砍价你送情分。

完整共性打法 + 分行业针对性话术 + 黄金实战案例：`references/07-老客户压价/老客户降价应对.md`
**「客户想以低价获得高服务」（想要便宜又想要一对一）分支**（法规+成本立边界 → 把降价转成升级档位/送时长/送服务）见 `references/07-老客户压价/低价高服务应对.md`。
**老客也常直接问「能不能再低一点」** → 用 `references/03-价值塑造与报价/压价应答_养老院逻辑与精炼不偷工.md`（阶段三通用，阶段七同用）。

### 阶段八 · 续费谈判与欠费催收

**核心逻辑：** 不是「再交一年钱」，而是「继续买这份安心」。对手不是其他代账公司，是客户心里那句「没出事=不需要」。
**目标：** 把过去一年的隐形价值显性化。

**三步走（到期前45天→面谈→文字跟进）：**
1. 铺垫信（到期前45天）：预告「年度服务价值报告」，勾起好奇心。
2. 年度服务价值报告：记账12个月零差错 + 发现X个风险点(核心:避了多少雷) + 政策提醒X次 + 问题响应X小时 + 合规节省约X元。**收尾金句：** 5项服务分开采购至少11万/年，您花1/10的价格买了高级会计师团队全套服务。
3. 面谈3版本：理性型（性价比）/ 关系型（省心信任）/ 价格敏感型（时间买断逻辑）。
   异议处理：我再想想 / XX家更便宜 / 今年生意不好能不能便宜 → 老客户早鸟价。

完整话术：`references/08-续费/10-续费话术.md`

**欠费催收（客户拖欠服务费）**：先亮合同权利（拖欠可停服）+ 停服后果链（开不出发票/工商税务处罚/异常名录），
再讲「我们**选择不停**、给了宽限」的善意 + 同行欠费即停的对照 + 电信/电力预付费类比；四级递进、不撕破脸、
停服必先书面告知。见 `references/08-续费/催收服务费应对.md`。

### 阶段九 · 转介绍（老带新）

**核心认知：** 盈信90%客户来自转介绍——存量客户是最大的获客渠道。转介绍不是「求人帮忙」，
而是**给老客户一个「做顺水人情、显自己人脉」的机会**。

**触发时机：** 客户满意度高点（退税到账、拦下风险、评上A级、续费成功）之后顺势提。

**四步转介绍SOP：**
1. **先给价值，再开口** —— 先让客户感受到「你帮了他」，再谈介绍；不要一开口就要人。
2. **降低开口门槛** —— 不要求「介绍」，改成「推荐」：「X总，您身边要有朋友也遇到账务/税务上的麻烦，把我推荐给他，也算帮他个忙。」
3. **给身份与面子** —— 「您认识的人多，您的圈子认可您，您推荐的人我肯定优先认真服务，不丢您的脸。」
4. **闭环反馈** —— 介绍来的客户签约后，回头谢老客户，让他有「我的推荐很靠谱」的成就感，形成持续转介绍。

**转介绍话术示例：**
> X总，这一年合作下来您也看到了，我们是真把您的账当自己的事在做。您身边做生意的朋友，要是也有税务、账务、注册上的顾虑，您把我的微信推给他就行——我肯定给他认真看，不给您丢脸。

**反哺：** 转介绍来的新客户，直接进阶段二（企业诊断+建群开场）走新客线。
