# 弱电行业经营范围库（分类+资质对照）

客户画像：网络/电话线/服务器布线为主，明确**不含220V及以上线路**的弱电工程施工/集成/销售公司。
登记口径归「电子与智能化工程 + 信息系统集成 + 安防监控」几类，不碰电力工程资质（因不含强电）。

## 分类明细 + 资质对照

| 类别 | 规范表述 | 是否需资质 |
|---|---|---|
| 工程/施工类 | 弱电工程、电子与智能化工程、建筑智能化工程、综合布线工程施工 | 电子与智能化工程专业承包资质(许可) |
| 网络/通信类 | 网络工程、通信线路工程（电话线/网线/光缆）、计算机网络系统设计与安装 | 涉及施工需资质 |
| 智能化系统类 | 楼宇智能化系统工程、安防监控（视频监控/门禁/周界报警）、门禁考勤系统、会议系统、背景音乐系统、停车场管理系统的设计安装维护 | 安防工程施工需资质 |
| 机房/数据中心 | 机房工程、机柜与配线架安装、服务器及存储设备布线、UPS弱电配套、机房运维服务 | 无 |
| 集成/服务类 | 信息系统集成服务、弱电系统集成、计算机网络系统集成、弱电技术咨询/技术服务/运行维护 | 无 |
| 销售类(一般项目) | 网络设备、通信设备、电子设备、服务器及存储设备、机柜线材（网线/光缆/配线架）、监控门禁设备、UPS电源、计算机软硬件及辅助设备批发零售 | 无 |

## 资质判断要点（复用 SKILL.md 五条铁律 #2 #3）

- 只做布线/安装调试/集成/维护（写"工程、系统集成、技术服务"）→ 无需资质。
- 写"承接施工/总承包"或接强电柜 → 需对应资质+电力设施许可，或分包给有资质单位。
- 给客户边界建议：合同写死"不含220V及以上线路"，规避电力工程资质要求。

## 用途

做弱电客户注册/经营范围变更方案时直接取用并调整行业类别表述；开票科目对照"销售类"保证未来能开"XX设备销售"票。
