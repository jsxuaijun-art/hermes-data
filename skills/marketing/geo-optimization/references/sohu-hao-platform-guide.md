# 搜狐号（搜狐公众平台）平台指南

## 平台定位

搜狐号是搜狐旗下的自媒体内容平台（mp.sohu.com），在百度搜索中权重较高，尤其适合区域性服务行业（财税、法律、装修、教育等）做本地SEO引流。相比于知乎/百家号/公众号，搜狐号的**审核门槛较低、企业号好过审、搜索权重不低**。

## 账号策略：大号+小号双账号

### 大号（企业号）
- **名称示例：** 苏州盈信财税 / 苏州盈信企业管理
- **注册主体：** 企业营业执照（权重更高，文章更易被收录和推荐）
- **风格：** 专业权威，带团队背书（高级会计师、CPA、CTA）
- **频率：** 每周2-3篇
- **引导方式：** "如果您在苏州需要注册公司、代理记账，欢迎私信咨询"

### 小号（个人号）
- **名称示例：** 苏州老板财税圈 / 苏州创业指南
- **注册主体：** 个人实名（用不同手机号注册）
- **风格：** 口语化、第一人称（"我做了7年财税……"），像同行聊天
- **频率：** 每周1-2篇
- **引导方式：** "在苏州做生意的朋友，有问题可以私信聊聊"（软引导，不硬推）
- **额外战术：** 小号在大号文章评论区提问引流

## 注册流程（2026年）

### 企业号
1. 打开 mp.sohu.com → 注册 → 选择"企业/机构"
2. 营业执照照片 + 运营者身份证 + 企业授权书
3. 审核周期：1-3个工作日
4. 所需材料：营业执照正本、法人身份证、授权书（平台可下载模板）

### 个人号
1. 用不同手机号注册 → 选择"个人"
2. 个人实名认证即可
3. 审核周期：通常1个工作日内

## 文章发布要点

| 项目 | 说明 |
|------|------|
| 标题 | 30字以内，含核心地域词+业务词 |
| 封面图 | 900×500px，避免纯文字图 |
| 正文 | 800-1500字为宜，段落不要太长 |
| 关键词密度 | 地域词（如"苏州"）+ 业务词（"注册公司""代理记账"）自然出现3-5次 |
| 图片 | 每篇2-3张，配简单文字说明 |

## 小号评论引流战术

1. 大号发布文章后，用小号在评论区提问，例如：
   - "请问苏州园区这边的公司也能办吗？"
   - "我现在就是自己零申报的状态，看了文章发现风险很大，可以加个微信聊聊吗？"
2. 大号回复，自然引导私信
3. 两个号互动会产生"热度"，增加文章推荐权重

## 注意点

- 企业号和个人号不能用同一手机号注册
- 搜狐号没有定时发布功能，需手动发布
- 企业号发布后可在"互动管理"中回复评论
- 文章末尾自动加"关注"按钮，账号运营初期注意回复每一条评论
