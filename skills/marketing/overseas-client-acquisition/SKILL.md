# 财税海外拓客方案 (Overseas Client Acquisition)

## When to Use
用户提到「海外/外国投资者来华/外资设立/FDI/英文拓客/英语获客/外贸服务」时触发。
把外国投资者来华一条龙服务做成英语内容+海外渠道获客。

## 定位
盈信面向「外国投资者来华」的 inbound 一条龙服务商（FDI 入站）。
护城河：苏州/长三角在地 + 一条龙 + 价格实在，差异化于泛中国定位的国外大所
（Dezan Shira / Hawksford / Asomerit / fdichina / pathtochina）。

**核心判断（用户已认可方向）**：这类 B2B 是低频、高客单、决策链长，主渠道是
**Google 搜索(SEO) + LinkedIn**，**不是**像抖音那样的娱乐短视频流量。
YouTube 用「专业讲解长视频 + Shorts」，作用是喂 SEO，不是站内成交。

## 服务一条龙（用户列出 + 已补充）
已列：办公场所租赁 / 前台项目咨询筹划 / 公司设立登记 / 人员招聘 / 代理记账 / 税务申报 / 税务合规。
补充（外企真痛点+利润点）：
- 工作许可 + Z签证办理（外国老板来华常驻，高价值）
- 注册资本实缴 + 外汇(SFE)备案咨询（2024公司法5年实缴硬门槛）
- 银行开户对接（外资账户开立最卡壳）
- 常年财税合规顾问 + 年度审计对接
- 后续中文运营对接（翻译、社保、开票、跨境利润汇出 SAFE 申报）

## 渠道矩阵（按优先级）
- A 主力：独立站 + Google SEO（冷启动必须）。核心英文词：
  "How to set up a WFOE in China 2026" / "Suzhou company registration for foreign investors"
  / "China accounting & tax filing for foreign-owned companies" / "Foreign investor visa China"。
  配套免费工具留资：WFOE 成本估算表（照 Asomerit 思路）。
- B 主力：LinkedIn（B2B 天花板最高）。公司主页 + 个人号；每天1英文贴；
  精准加人搜 "Manufacturing CFO" "APAC expansion" "expat in China"；私信给价值再报价。
- C 辅助：YouTube（专业讲解 + Shorts 喂 SEO）。
- D 辅助：Quora + Reddit（答题获客，免费精准，文末挂官网）。
- E 可选：Fiverr / Upwork 挂单验需求。

## 执行顺序（30天）
第1周 英文官网落地页 + 注册LinkedIn(公司+个人)
第2-3周 前3篇SEO文章 + 1-2个讲解视频 + Quora答10题
第4周 LinkedIn 每日1贴 + 精准加人私信
此后 每周复盘：Google能否搜到关键词 / LinkedIn加了几个客户 / 有无询盘

## 现实提醒（三件事想清楚）
1. 内容必须地道英文——AI写初稿 + 专业人润色，绝不能机器直翻。
2. 信任问题——官网放苏州真实地址、公司资质、案例、收费透明。
3. 资质合规——签证/代账是许可业务，做前确认资质边界。
