# 上海初中家校沟通指南

## 触发条件

当用户提到以下任意关键词时加载本技能：
- 家访 / 老师来家里 / 班主任家访
- 家长会 / 开家长会
- 升学目标 / 市重点 / 区重点 / 闵行中学
- 班主任换了 / 新班主任 / 换老师了
- 成绩怎么跟老师说 / 怎么跟班主任聊
- 配合学校 / 家校配合
- 家访前 / 给老师发消息 / 家访短信

## 核心原则

1. **真诚第一** — 老师手上有全班成绩数据，实话实说比粉饰更能赢得信任
2. **让孩子参与** — 家访不是"家长跟老师聊孩子"，而是"家长+孩子一起跟老师聊"
3. **双向沟通** — 家长也要准备问题，提问质量体现重视程度
4. **合作开端** — 把每一次家访/家长会当作合作关系的起点，不是考核
5. **提前铺垫** — 家访前1-2天发一条确认微信，让老师对孩子有正面第一印象，降低初次见面的生疏感

## 家访全流程（四阶段）

### 第一阶段：家访前1-2天 → 发微信确认

目的：确认时间 + 建立第一印象。不是汇报成绩。

要点：
- 确认时间地点
- 一句话孩子的正面性格描述（"文静踏实""话不多但心里有数"）
- 含蓄传递需求（"孩子可能紧张，请多鼓励"）
- 表达欢迎（天气热注意防暑）
- **不要问成绩**——这些留给当面聊
- **不要长篇大论**——三四行恰到好处

见 `references/pre-visit-wechat.md`。

### 第二阶段：准备阶段

#### 了解老师

| 老师类型 | 特点 | 沟通侧重 |
|----------|------|----------|
| 语文老师当班主任 | 感性、重视阅读和习惯 | 聊学习态度、阅读面、综合素质 |
| 数学老师当班主任 | 理性、重视逻辑和成绩 | 聊薄弱环节的提分路径 |
| 英语老师当班主任 | 精细、重视积累 | 聊词汇量、听说读写均衡 |
| 化学/物理老师当班主任 | 偏理科思维、重视实验能力 | 聊理科兴趣、实验动手、思维训练（物理好的孩子在化学老师面前是加分话题） |
| 历史/政史地老师当班主任 | 视野开阔 | 聊孩子知识面、人文素养 |

#### 准备孩子成绩画像

**成绩四分法**——将科目分为四档，便于跟老师沟通：

```
✨ 强项（前15%） → 展示学习能力没问题
✅ 良好（15%-40%） → 提及但不展开
⚠️ 薄弱（40%-60%） → 坦诚弱项 + 说明暑假在补
🔴 弱项（后40%） → 重点求助，请老师给方法
```

#### 准备家长的问题（4-5个，记在本子上）

1. **关于班级** — 班级定位、培养方向、管理重点变化
2. **关于孩子学业** — 目标评估、学校支持、学科具体建议
3. **关于家校配合** — 配合方式、沟通渠道、频次

#### 家庭环境和物料准备

- 成绩单、期末试卷（特别是薄弱科目）放在桌上
- 暑假作业/补习资料展示学习状态
- 一本课外书体现阅读面
- 书桌整洁、电子产品管理口径统一
- 夫妻事前统一口径

### 第三阶段：现场交流

**开场**（消除初次见面的生疏感）：
> 先感谢老师来家访，如果老师是新科目老师，可以提"XX正好开XX课，这也是缘分"

**介绍孩子** — 推荐顺序：
> 强项带出学习能力 → 弱项坦诚带出努力 → 目标请老师评估

**自然带出家长背景**：
> 学历/职业一句话带过即可，核心是"我们关注教育，但具体方法老师专业"

**加分话题**（如果老师教孩子强项的相邻学科）：
> 物理好 + 化学老师 → "孩子物理这次前12%，她对理科有兴趣。您教化学，暑假要不要提前看看化学书？"

**结束**：
> 感谢 + 一个收获的关键点 + 表态配合

### 第四阶段：家访后24小时

1. 发微信感谢老师（简短：辛苦了 + 一个收获 + 会配合）
2. 跟孩子复盘：老师印象如何？孩子感觉如何？
3. 把老师建议整理成行动清单
4. 和孩子一起制定学期目标
5. 如有老师指出的问题，及时改进并让老师看到变化

## 避坑清单

- ❌ 不要过度包装成绩
- ❌ 不要把见面变成诉苦大会
- ❌ 不要当场提过分要求（换座位、特殊照顾）
- ❌ 不要家长全程说，孩子坐旁边玩手机
- ❌ 不要在老师面前夫妻意见不一致
- ❌ 不要问"考多少分能排第几"
- ❌ 不要全程录音（除非事先征得同意）
- ❌ 家访前不要发长篇成绩汇报
