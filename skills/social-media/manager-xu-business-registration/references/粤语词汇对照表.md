# 粤语词汇对照表（商事登记场景专用）

> 快速查阅用 — 做粤语化改造时对照替换
> 目标：让在苏沪的广东人感觉「呢個係地道廣東人」

## 三、地道粤语表达速查

### 日常表达

| 粤语 | 含义 | 使用场景 |
|:--|:--|:--|
| 搞掂 | 搞定/办妥 | 「注册公司三日就搞掂」 |
| 倾生意 | 谈生意 | 「我去同客倾生意」 |
| 帮衬 | 光顾/惠顾 | 「多谢大家帮衬」 |
| 话俾你知 | 告诉你 | 「我话俾你知点样搞」 |
| 你知唔知 | 你知道吗 | 钩子句式，引发好奇 |
| 唔使惊 | 不用怕 | 安抚情绪 |
| 好紧要 | 非常重要 | 「呢点好紧要」 |
| 冇问题 | 没问题 | 「放心，冇问题」 |
| 实得 | 一定行 | 广东人信心表达 |

### 程度表达

| 粤语 | 含义 | 例句 |
|:--|:--|:--|
| 好 | 很/非常 | 好简单、好快 |
| 劲 | 非常（程度更重） | 劲多人问呢个问题 |
| 鬼死咁 | 非常地（口语） | 鬼死咁简单 |
| 超 | 超级 | 超多人中过招 |
| 十分 | 十分 | 书面程度高 |

### 警示表达

| 粤语 | 含义 | 例句 |
|:--|:--|:--|
| 大镬 | 出大事了/麻烦了 | 「搞唔好就大镬」 |
| 中招 | 上当/被坑 | 「好多公司都中过招」 |
| 出事 | 出问题 | 「唔及时处理就会出事」 |
| 踩坑 | 掉坑 | 「呢个坑好多人踩过」 |
| 赖嘢 | 出问题/倒霉 | 「搞唔掂就会赖嘢」 |

### 轻松表达

| 粤语 | 含义 | 例句 |
|:--|:--|:--|
| 湿湿碎 | 小意思/小菜一碟 | 「呢个湿湿碎啦」 |
| 话咁易 | 容易得很 | 「话咁易就搞掂」 |
| 是但啦 | 随便啦/就这样吧 | 放松语气 |
| 冇所谓 | 无所谓 | 表示没问题 |
| 是是但但 | 马马虎虎/随便 | 谦虚语气 |

## 四、粤语语气词对照

| 语气词 | 用法 | 例句 |
|:--|:--|:--|
| 啦 | 句末，轻松肯定 | 「好简单嘅啦」 |
| 啫 | 句末，轻描淡写 | 「几百蚊啫，湿湿碎」 |
| 咋 | 句末，仅此而已 | 「三日就搞掂咋」 |
| 㗎 | 句末，强调/反问 | 「你唔知㗎？」 |
| 啦喂 | 句末，提醒/催促 | 「快啲啦喂」 |
| 嘛 | 句末，理所当然 | 「就係咁简单嘛」 |
| 啊 | 句中/句末，自然停顿 | 「係咁啊，你明唔明？」 |
| 咯 | 句末，肯定/无奈 | 「咁就得咯」 |
| 啫嘛 | 句末，轻描带过 | 「好细件事啫嘛」 |
| 咋嘛 | 句末，仅此而已（语气更轻） | 「三日咋嘛」 |
