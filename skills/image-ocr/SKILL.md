# image-ocr — 图片文字提取（OCR）

从图片里把文字「抠」出来。中文优先，支持中文简体 / 英文 / 中英混合。两种用法按需取用。

## 适用场景
- 扫描件、发票、合同、证件、表格截图转文字
- 批量把一摞图片里的文字导出成 txt
- 财税日常：客户发来的截图、拍照件快速转可编辑文本

## 形态一：网页应用（随手用）
文件：`image-ocr.html`（与本 SKILL.md 同级目录下，或工作区根目录）。
- 浏览器直接打开（双击即可，无需安装）
- 拖拽图片进去，或点「选择图片」多选
- 设置项：
  - **语言**：中文简体 / 中文繁体 / 英文 / 中英混合
  - **版面（PSM）**：默认「整块文字(6)」对营业执照、许可证、合同等满版文字最有效；自动(3)/单列(4)/稀疏(11) 按需切换
  - **放大**：默认 2 倍（小字补像素，识别率更高）；可 3 倍或不放大
  - **增强对比度**（默认开）：灰度 + 对比度拉伸，弱化背景干扰
  - **二值化**（默认关）：OTSU 自动阈值转纯黑白，适合红章/底纹/网格线干扰图
  - **反色**（默认关）：深底浅字扫描件用
  - **合并中文空格**（默认开）：去掉 Tesseract 中文逐字空格
  - **旋转校正**：左/右 90°、±1° 微调、归零，纠轻微倾斜
  - **显示预处理图**：把送进引擎前的图显示出来，方便判断预处理效果
- 点「开始识别」，逐张出文字，可复制单张或「下载全部为 txt」
- 首次打开会联网下载 OCR 模型（约十几 MB），之后浏览器缓存可离线

> 注意：网页应用依赖 CDN 加载 Tesseract.js，首次使用需联网。若环境完全离线，请用形态二并确保已预下载模型。

## 形态二：命令行批量（自动化 / 批处理）
脚本：`ocr.js`（依赖 `tesseract.js`，已装在 skill 目录的 node_modules 内；可选依赖 `jimp` 做图像预处理，已装）。

用法：
```bash
# 单张图片识别（默认中文简体，PSM6，原图直识别）
node ocr.js 发票.png

# 证照/单据：增强对比度 + 放大 2 倍（jimp 预处理）
node ocr.js 许可证.jpg --psm 6 --enhance --scale 2

# 红章/底纹干扰图：二值化
node ocr.js 合同.jpg --binarize --psm 6

# 整个目录批量，中英混合，递归，结果写入文件
node ocr.js ./scan_dir --lang chi_sim+eng --recursive --out result.txt

# 列出帮助
node ocr.js --help
```

参数：
- 位置参数：图片文件或目录（可多个）
- `--lang <代码>`：OCR 语言，默认 `chi_sim`（中文简体）。可用 `eng` / `chi_sim+eng` 等
- `--psm <0-13>`：页面分割模式，默认 `6`（整块文字，适合证照/单据）。`3`=自动 `4`=单列 `11`=稀疏
- `--enhance`：增强对比度（需 jimp）
- `--binarize`：二值化 OTSU 自动阈值（需 jimp）
- `--invert`：反色，深底浅字扫描件（需 jimp）
- `--scale <倍率>`：放大补像素，默认 1（如 2/3）（需 jimp）
- `--rotate <角度>`：旋转校正（度），默认 0（需 jimp）
- `--out <文件.txt>`：结果写入文件；不指定则打印到控制台
- `--recursive` / `-r`：递归处理子目录
- `--ext png,jpg,...`：限定处理的扩展名（默认常见图片格式）

> 未安装 jimp 时，带预处理选项会打印警告并退回原图直识别，不影响基础功能。

输出格式：每个文件一段 `===== 路径 =====` 标题 + 识别文本，多文件首尾相接。

## 语言代码速查
- `chi_sim` 中文（简体）
- `chi_tra` 中文（繁体）
- `eng` 英文
- 混合：`chi_sim+eng`

## 注意事项 / 坑
- 识别准确率受图片清晰度影响：清晰、正向、高对比度效果最好；歪斜、模糊、水印多会掉字。
- 表格类图片只抽文字不还原表格结构；如需表格结构化，另行用表格识别方案。
- 首次运行需联网下载语言模型（中文 chi_sim 约 19MB），请保证网络；后续会缓存。
- 涉密图片（身份证、执照等）优先在本地处理，勿上传第三方在线 OCR 服务。
