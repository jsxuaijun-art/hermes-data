# 在中国网络环境中获取英语词汇列表 — 实操指南

## 背景
从中国网络环境访问英语词汇数据源时，常见渠道存在各种限制。本文档记录已验证的工作流和失效路径，避免重复试错。

## 目标词汇类型
- **高考/中考大纲词汇**（~4000词）：已有 `vocab-memory-book` skill 内建
- **IELTS 雅思词汇**（~8000词）：需外部获取
- **TOEFL 托福词汇**（~8000词）：需外部获取
- **四六级/考研词汇**：需外部获取
- **学术词汇表（AWL）**：570词族，开源可获取

## 已验证渠道状态（2026.7.6）

| 渠道 | 状态 | 说明 |
|:--|:--:|:--|
| **搜狗搜索 + curl_cffi** | ✅ 搜索 | 能拿到标题和摘要，可判断资源质量。但链接是搜狗JS跳转，curl无法直接访问原始页面。连续请求触发antispider。 |
| **Bing国内版(cn.bing.com)** | ❌ 搜索结果 | JavaScript动态渲染，curl拿不到结果容器。返回的HTML数十KB但无有效内容。 |
| **Bing国际版(bing.com，无cn.)** | ⚠️ 有时可用 | 有时能返回静态搜索结果，但不如Sogou稳定。 |
| **百度搜索** | ❌ 验证码 | 一定触发验证码，不可用 |
| **GitHub Raw** | ❌ 429限流 | 请求几次后即被限流429，即使国际联网也如此。需要等较长时间恢复。 |
| **GitHub API** | ❌ 429/404 | 同样限流问题。 |
| **GitHub 浏览器访问** | ⚠️ 超时 | 国际联网后偶尔能访问，但非常不稳定（超时为主）。 |
| **知乎 zhuanlan.zhihu.com** | ❌ 403 curl | curl_cffi访问返回403。 |
| **知乎 浏览器** | ❌ 检测头部 | HeadlessChrome被检测，页面不渲染内容。 |
| **百度文库** | ✅ 可访问（需会员） | 页面能访问，但完整文档需要会员。如果用户有会员，可以直接下载。 |
| **原创力文档(book118)** | ❌ 反爬 | 有反爬机制。 |
| **WeChat公众号文章** | ❌ 链接过期 | 已有的文章链接大部分已失效。 |
| **英文网站(IELTSLiz/Magoosh等)** | ❌ 超时 | 即使国际联网也频繁超时。Magoosh无完整词表。 |

## 推荐工作流（从零获取词汇列表）

### 快速路径（推荐 — 5分钟）
1. **搜狗搜索** → curl_cffi 搜关键词（如 `IELTS 词汇 完整版 site:sogou.com`）
2. **筛选标题** → 找出有「完整版」「高频」「8000词」等标记的文章
3. **给出直达链接** → 告诉用户：知乎搜「XXX」→ 文章里有网盘链接
4. **用户手动下载** → 用户从百度网盘/阿里云盘下载TXT/DOCX → 发我 → 5分钟转默写本

示例话术：
```
我在搜狗找到了这个：
  149页!雅思8000高频词汇表(顺序版) - 知乎
你打开知乎搜这个标题 → 文章里应该有个网盘链接
下载TXT或DOCX → 放桌面 → 告诉我文件名
我这边5分钟就能转成默写本Word文档
```

### 备用路径（用户不便操作时）
1. **先搜 Bing 国内版**（curl_cffi，首次可能成功）
2. **再切 Bing 国际版**（去掉 cn.）
3. **然后搜狗**（但每次用新 session，连续请求会封）
4. **最后给推荐** — 基于平台规律（标签/BGM 等直接给推荐，不硬耗搜索）

### 已有本地数据（零成本可用）
- **en_50k.txt**：14441个常用英语词，含频率计数。本地 grep 可查任意词频。
  - 位置：`~/memories/en_50k.txt`（已缓存）
  - 下载：`curl -sL "https://raw.githubusercontent.com/hermitdave/FrequencyWords/master/content/2016/en/en_50k.txt"`
  - 若 GitHub 429 → 已有本地副本，直接用
- **高考3875词汇**：内建在 `vocab-memory-book` skill 的 `scripts/build_root.py`
- **COCA词频**：en_50k.txt 基于 COCA 语料库

### 从已有频率表构建IELTS/TOEFL词表
当无法从外部获取IELTS词汇表时，可用频率表构建近似词表：
```bash
# 从 en_50k.txt 提取排名 2000-8000 的词（约6000个高频学术词）
# 这覆盖了雅思学术词汇的主要范围
grep -n "^" ~/memories/en_50k.txt | awk -F: 'NR>=2000 && NR<=8000 {print $2}' > /tmp/ielts_approx.txt
# 再与已知高考词表去重，保留高考未覆盖的
```
但这只是纯英文词表，**没有中文释义**。需要补充释义时有两种方案：
1. 调用在线词典API（如有网络条件）
2. 用户下载已有的中英对照词表

## 平台特定注意点

### 搜狗搜索避坑
- 第一次请求通常成功，第二次极大概率触发验证码
- 每次用新的 `impersonate` 参数（如 `chrome124` → `chrome123` 轮换）
- 搜到的链接格式都是 `/link?url=xxx..` 的搜狗跳转，无法直达原始页面
- 有效信息在标题和摘要中，通过这些判断资源质量

### 知乎内容获取
- 知乎专栏文章（zhuanlan.zhihu.com/p/数字）通常包含网盘链接
- 这些文章在知乎内搜不到？→ 用搜狗搜 `雅思8000词汇大全 site:zhuanlan.zhihu.com`
- 文章摘要/标题足够判断内容质量
- 让用户手动打开链接获取网盘链接

### Bing.cn 避坑
- 搜索结果由JavaScript生成，`b_algo` 等结果容器在静态HTML中不存在
- 切换 `cn.bing.com` 到 `bing.com`（头去掉cn.）有时能返回静态结果
- Bing国际版对中文搜索的匹配不如中文版精准

## 底线性建议
- **搜索试3次**（Bing→Bing en→Sogou），不行就坦白说「公开数据扒不到」
- 基于已验证的资源清单给用户推荐，让用户手动获取
- 用户获取后发给我，5分钟就能转成默写本
- **不要硬耗5次以上搜索请求**——每次搜索失败都有token成本，而成功率并不会增加
