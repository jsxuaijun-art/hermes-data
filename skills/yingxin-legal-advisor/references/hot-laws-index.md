# 分领域法律索引（hot-laws-index）

> 用途：法律助手的"检索线索库"。**只列现行生效的主要法律名称**（不保证各条款号），
> 具体条文的现行性 / 条款号 / 最新修正，一律用 `cn-regulation-verification` 联网核验后引用。
> 权威核验源：国家法律法规数据库 flk.npc.gov.cn；涉税口径同步 `tax-regulation-monitor`。

## 一、劳动用工
- 劳动法（1995 施行）
- 劳动合同法（2012 修正）
- 劳动合同法实施条例（2008）
- 劳动争议调解仲裁法（2008）
- 社会保险法（2018 修正）
- 工伤保险条例
- 最高法劳动争议司法解释（现行版本请核验）

高频点：未签合同二倍工资 / 试用期上限 / 经济补偿 N 与赔偿金 2N / 竞业限制 / 仲裁前置与 1 年时效。

## 二、合同（商事交易）
- 民法典·总则编
- 民法典·合同编（通则 + 典型合同：买卖、承揽、租赁、借款、担保等）
- 民法典合同编通则司法解释（最高人民法院，2023 施行）
- 担保制度司法解释
- 仲裁法（涉外与排他条款）
- 民事诉讼法（2017/2021 修正）

高频点：诉讼时效 3 年 / 违约金调减 / 定金规则 / 争议解决条款 / 送达条款 / 支付令（督促程序）。

## 三、公司设立与治理
- 公司法（2023 年修订，2024-07-01 施行）——**全套规则以此为准**
- 公司法司法解释（1—5 号，现行版本核验）
- 市场主体登记管理条例（2022）

高频点：注册资本 5 年实缴 / 出资加速到期 / 董监高责任 / 决议瑕疵 / 一人公司财产混同连带责任。

## 四、股权与并购
- 公司法（2023 修订）
- 证券法（如涉上市公司）
- 股权转让、优先购买权、盈余分配、知情权、司法解散——均见公司法现行文本

## 五、知识产权
- 商标法（2019 修正）
- 专利法（2020 修正）
- 著作权法（2020 修正）
- 反不正当竞争法（2019 修正）

高频点：商标恶意抢注 / 专利三性 / 著作权登记与合理使用 / 商业秘密三性要件。

## 六、数据与个人信息
- 个人信息保护法（2021-11-01）
- 数据安全法（2021-09-01）
- 网络安全法（2017，最高法相关解释核验）

高频点：最小必要 / 告知同意 / 员工个人信息 / 数据出境（如涉）。

## 七、通用程序
- 民事诉讼法
- 仲裁法
- 诉讼费用交纳办法
- 最高法关于送达、管辖的司法解释（现行版本核验）

## 八、核验纪律
1. 每次引用前：`cn-regulation-verification` 查该法是否现行 / 已修改 / 已废止。
2. 拿不准的条文号 → 联网查国家法律法规数据库后引用；查不到 → 写"建议人工核实"，**绝不编**。
3. 涉财税条文（税务合规咨询）→ 同时走 `tax-regulation-monitor` 口径。
4. 更新时间快、争议大、涉诉 → 一律提示"建议执业律师复核"。
