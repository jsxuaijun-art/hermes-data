# 合规账定价案例：商贸公司（存货密集型）

> 来源：2026年7月 · 内衣贸易公司合规账方案
> 客户特征：存货1,200万元 · 年销售2,500万元 · 每月现场服务2次
> 关键风险：存货周转慢（约2.08次/年）、进销匹配、私卡收款

---

## 一、服务板块拆解（定价模型）

| 服务板块 | 内容说明 | 年费 | 占总价比例 |
|----------|----------|------|-----------|
| 基础财税托管 | 记账+全税种申报+发票辅导+社保+年度汇缴 | 12,000 | ~34% |
| 存货专项管理 | 进销存台账+账实差异分析+库存周转+盘点辅导 | 8,000 | ~23% |
| 合规风险排查 | 资金流/发票流/合同流排查，6份专业报告 | 6,000 | ~17% |
| 现场服务（每月2次） | 上门收单+对账+报表解读，含差旅 | 4,000 | ~11% |
| 季度经营分析报告 | 4份深度财务分析+风险预警 | 5,000 | ~14% |
| **合计** | | **35,000** | **100%** |

## 三、定价逻辑

### 核心原则：服务费 ≈ 买断工作时间

```
存货密集型企业的额外工作量：
  ① 进销存台账维护 → 每月多花1~2天（品类多、款式多、批次多）
  ② 账实差异分析 → 贸易企业存货是核心资产，差异必须月月对
  ③ 盘点辅导 → 每季度至少1次实地或远程盘点
  ④ 进销匹配审核 → 贸易企业进项和销项的品类/数量必须一致

→ 存货专项管理定价8,000元，对应约20个额外工作日
```

### 分项定价参考维度

| 维度 | 低 | 中 | 高 |
|------|-----|-----|-----|
| 存货金额 | <300万 | 300~1,000万 | >1,000万 |
| 年销售额 | <500万 | 500~2,000万 | >2,000万 |
| 现场服务频次 | 0次/月 | 1次/月 | 2次/月 |
| 票据量 | <30张/月 | 30~100张/月 | >100张/月 |

## 四、行业特定风险提示（报价时同步使用）

1. **存货风险** — 存货余额占年销售额近50%，税务系统自动比对进销项，库存账实不符触发预警
2. **进销匹配** — 内衣品类多、批次多、货号管理容易混乱
3. **私卡收款** — 贸易行业普遍存在客户要求走个人卡，金税四期税银联网监控
4. **费用列支** — 无票支出直接导致企业所得税虚高
5. **往来挂账** — 应收账款/应付账款长期挂账，易被认定为账外经营

## 五、话术要点（针对存货密集型客户）

> 「王总，你的仓库压了1,200万的货，一年周转2次。税务局看你的进销项数据就能算出来——进了多少货、卖了多少、还剩多少。如果账面库存和实际对不上，系统自动标红。每月对一次库存，就是这个价格买的核心价值。」

> 「你现在的代账会计有没有每个月给你出进销存台账？没有的话，说明他不知道你库存里藏了多少风险。」
