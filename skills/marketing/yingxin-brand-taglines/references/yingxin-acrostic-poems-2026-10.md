## 一、五言绝句（每句 5 字，四句）— 名片、桌牌

**【推荐】盈信守正**（ing 韵：兴·精·行，首句入韵）
```
盈程伴企兴，
信立专业精。
守规存诚敬，
正途稳步行。
```

**盈信行稳**（an 韵：宽·安）
```
盈邻惠苏沪，
信诚业路宽。
行端无妄念，
稳账保居安。
```

**盈信致远**（ang 韵：航·强·长）
```
盈舱助起航，
信笃技弥强。
致公持底线，
远虑护行长。
```

## 二、七言绝句（每句 7 字，四句）— 宣传册、文化墙边角

**【推荐】盈信行稳**（ing 韵：精·宁）
```
盈抱初心辅小微，
信立基牢技业精。
行循矩度崇真朴，
稳账前瞻远路宁。
```

**盈信守正**（ang 韵：航·彰·长，首句入韵）
```
盈畔双城护企航，
信立深耕技业彰。
守矩存诚不尚浮，
正账前瞻路自长。
```

**盈信敦慎**（an 韵：间·宽·安）
```
盈畴风暖苏沪间，
信立深耕道自宽。
敦行守矩无浮饰，
慎账前瞻久自安。
```
> 注：豆包原标此首藏头为「盈信敦行」，实为「盈信敦慎」（第 4 句首字是「慎」）。此处为已修正版。

## 三、七言八句（每句 7 字，八句）— 主文化墙、简介开篇

**【首推】盈信守正，行稳致远**（ang 韵一韵到底：昌·彰·张·防·长）
```
盈泽双城助企昌，
信立根基业脉彰。
守拙深耕轻近利，
正心崇实戒虚张。
行端界重存诚敬，
稳账勤应早虑防。
致知伴客同成长，
远路偕行岁月长。
```
> 八句依次对应五维全链，用词最自然，藏头「盈信守正，行稳致远」与「企业精神——精业守信，行稳致远」成一套，可配对用于文化墙左右两侧。

**盈信立诚，伴企同行**（ing/eng 近韵：英·明·声·宁·荣）
```
盈连吴沪聚群英，
信字为先心志明。
立本深耘财税域，
诚怀务实弃虚声。
伴为后盾消繁虑，
企交坦荡守密宁。
同跟政策早防险，
行稳途长共向荣。
```

**盈信修业，慎始敬终**（ong 韵一韵到底：融·衷·宗·慵·空）

## 复用提示

- 藏头除「盈」「信」外可换 2~4 字短词，八句版最宜两段各四字（盈信XXXX，XXXX）
- 首字生造是固有难点（盈程/盈邻/盈舱/盈畔/盈畴），交付时主动说明并留「可重拟」口子，别装自然
- 改句后**必须重跑** `scripts/verify_acrostic.py --split-blank` 再交付
- 事实纪律：全诗不含数字、奖项、典故、法条，意象只落在盈信实际业务（注册/代账/合规/高端会计）与苏沪双城
