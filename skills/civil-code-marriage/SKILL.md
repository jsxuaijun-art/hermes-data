# 婚姻家庭编（第五编）结构化 Skill

## 任务目标

把婚姻家庭纠纷定位到「结婚 / 家庭关系（夫妻财产·子女） / 离婚 / 收养」哪一章，给出
"效力、财产归属、债务承担、能否离、子女抚养、赔偿"的结构化结论与处置步骤。

## 婚姻家庭编结构（路由索引，5 章）

1. 一般规定（第1040—1045条）：基本原则、禁止行为、家风、收养原则。
2. 结婚（第1046—1054条）：自愿、法定婚龄、禁止血亲/疾病婚、登记、无效与可撤销。
3. 家庭关系（第1055—1075条）：夫妻关系（1060—1066，含共同财产/债务/家事代理）、父母子女与其他近亲属关系（1067—1075）。
4. 离婚（第1076—1092条）：协议离婚与冷静期、诉讼离婚、子女抚养、财产分割、补偿与赔偿。
5. 收养（第1093—1118条）：被收养人/收养人条件、成立、效力、解除。

## 高频场景 → 处置步骤 → 条文

1. **"老公背着我在外面借了钱，债主找我还，我要还吗？"**
   - 第1064条（核心）：只有"共同签名/事后追认"或"为家庭日常生活需要所负"才是共同债务；以个人名义**超出家庭日常生活需要**所负→不属共同债务，除非债权人能证明用于夫妻共同生活、共同生产经营或基于共同意思表示。
   - 步骤：①确认你是否签字/事后追认；②判断借款是否用于家庭日常（金额、用途）；③债权人主张超日常债务的，由债权人举证；④你无共同意思且未用于共同生活的，可抗辩不担责。

2. **"想离婚，流程怎么走？冷静期多久？"**
   - 协议离婚：双方自愿+书面离婚协议→登记机关申请（第1076条）；**30日冷静期**（第1077条）：期内任何一方可撤回；期满后30日内双方应亲自申领离婚证，未申领视为撤回。
   - 诉讼离婚：一方向法院起诉（第1079条）；感情确已破裂调解无效应准予；存在家暴/重婚/恶习/分居满2年等情形之一调解无效即准予；判决不准离后又分居满1年再诉应准予。
   - 步骤：能达成一致→协议离婚走冷静期；有争议/对方不同意→直接诉讼。

3. **"对方出轨/家暴，离婚能要赔偿吗？"**
   - 第1091条：重婚、与他人同居、实施家庭暴力、虐待遗弃家庭成员、其他重大过错→无过错方有权请求损害赔偿。
   - 第1087条：财产分割照顾无过错方。
   - 步骤：收集证据（报警记录、就医记录、聊天/照片）；离婚时一并主张赔偿与多分财产。

4. **"婚内买的房写他一人名，算谁的？"**
   - 第1062条：婚姻关系存续期间所得（含房产）一般为共同财产，平等处理权；登记在一方名下不改变共同性质（除非婚前全款/明确赠与一方，见1063）。
   - 步骤：看购房资金来源、登记时间；主张共同需举证婚内出资。

5. **"孩子归谁？抚养费怎么算？"**
   - 第1084条：不满2周岁随母；2周岁以上按最有利于未成年子女；8周岁以上尊重意愿。
   - 第1085条：不直接抚养方负担抚养费，数额协议不成由法院判（结合收入、当地水平、子女需要）。

6. **"冷静期内对方反悔不来了，怎么办？"**
   - 第1077条：冷静期内任一方可撤回；期满后30日未共同申领离婚证→视为撤回。只能转诉讼离婚（第1079条）。

## 重点条文摘录（原文见 references/婚姻家庭编全文.md）

- 第1042条：禁止包办、买卖婚姻和其他干涉婚姻自由的行为；禁止借婚姻索取财物；禁止重婚；禁止有配偶者与他人同居；禁止家庭暴力。
- 第1047条：结婚年龄，男不得早于二十二周岁，女不得早于二十周岁。
- 第1051条：有下列情形之一的，婚姻无效：（一）重婚；（二）有禁止结婚的亲属关系；（三）未到法定婚龄。
- 第1062条：夫妻在婚姻关系存续期间所得的工资奖金劳务报酬、生产经营投资收益、知识产权收益、继承受赠（除外）等财产，为夫妻的共同财产，归夫妻共同所有；夫妻对共同财产有平等的处理权。
- 第1064条：夫妻双方共同签名或者一方事后追认等共同意思表示所负的债务，以及一方在婚姻关系存续期间以个人名义为家庭日常生活需要所负的债务，属于夫妻共同债务；超出家庭日常生活需要所负的不属于共同债务，但债权人能证明用于共同生活/经营或基于共同意思表示的除外。
- 第1077条：自婚姻登记机关收到离婚登记申请之日起三十日内，任何一方不愿意离婚的，可以撤回离婚登记申请；期限届满后三十日内双方应亲自申请发给离婚证，未申请的视为撤回。
- 第1079条：夫妻一方要求离婚的，可调解或直接起诉；感情确已破裂调解无效应准予离婚（列举重婚/同居、家暴/虐待遗弃、恶习屡教不改、因感情不和分居满二年等）；判决不准离后又分居满一年再诉应准予。
- 第1087条：离婚时共同财产由双方协议；协议不成由法院按照照顾子女、女方和无过错方权益的原则判决。
- 第1091条：重婚、与他人同居、实施家庭暴力、虐待遗弃家庭成员、有其他重大过错导致离婚的，无过错方有权请求损害赔偿。

## 注意事项

- 夫妻债务认定（第1064条）是民法典重大修改，区别于原《婚姻法》解释"共债推定"；实务须严格按"家庭日常生活需要+举证责任"判断。
- 离婚冷静期仅适用于**协议离婚**，诉讼离婚无冷静期（但有审理周期）。
- 婚姻家庭纠纷常与物权（房产归属）、合同（赠与/借贷）、继承（一方死亡）交叉，路由见 civil-code 主 skill。
