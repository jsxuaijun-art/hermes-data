# 实战经验库 · 录入与维护工作流（跨skill统一规程）

> 当用户/徐总/江姐说「记一条经验」「把这个窗口口径存下来」「XX窗口实际是这个规矩」
> 或跑完真实案例发现与网上说法有出入时，执行本规程。这是盈信全skill体系共享的知识资产运维方法。

## 一、先选对库（不重复建文件）

| 经验领域 | 写入文件 | 归属skill |
|---------|---------|-----------|
| 商事登记（设立/变更/注销/住所/许可以及登记） | `references/实战经验-窗口口径.md` | business-registration-advisor |
| 股权转让（苏州各分局税务窗口） | `references/实战经验-窗口口径.md` | suzhou-equity-transfer-guide |
| 销售/谈判/客户案例 | `references/实战经验-销售客户.md` | yingxin-business-suite |
| 财税咨询/做账/稽查应对 | `references/实战经验-财税咨询.md` | yingxin-business-suite |

**铁律：** 先检查目标库是否存在该领域子主题。存在→在对应小节下追记；不存在→在同级目录新增小节（保持 `## 一、二、三…` 编号连续）。**绝不新建第N个散落在各处的经验文件。**

## 二、条目标准格式（每条必须包含）

```
### X.X 经验名 [YYYY-MM，地点/窗口]
- 窗口/电话：哪个区哪个窗口，电话（如 吴中区胥口镇 66567816）
- 口径：能办什么/不能办什么，分条列（记"实然"，不记"应然"）
- 材料：实际要交什么，什么算数什么不算
- 例外/备注：什么情况不适用；这只是本处口径，别处可能不同，用前电话确认
- [敏感]：涉税测数字/窗口潜规则/非标口径才标，对外转述先请示徐总/江姐
```

## 三、录入步骤

```
1. read_file 目标库文件 → 定位所属领域小节
2. patch 追记到该小节末尾；无对应小节则新增 `## N、` 小节
3. 若已有一条冲突/过时，用 patch 更新旧条目，不堆叠复述
4. 在归属skill的 SKILL.md「实战经验」章节表格里补一行 `| # | 主题 | 关键结论 | 来源 |`
   （若该SKILL.md有这张清单表的话——商事登记/股转skill有，business-suite是领域分库）
5. 全库统一用同一录入规则，保证未来可检索
```

## 四、检索优先级（回答任何客户咨询前）

```
先查对应库 → 命中 → 以实战经验为准（法规作补充）
未命中 → 常规方案 + 客户可见输出标注"窗口口径待核实"
```

## 五、配套：Obsidian 备份

- 这些库属于"可复用方法论/脱敏案例"层级，符合知识库存储原则，可同步进 Obsidian（/mnt/d/obsidian-vault）
- 更新后若需备份，跑 obsidian-sync 相关流程（见 obsidian skill）

## 六、坑

- 不要为一次性对话建独立skill/文件——经验必须落到既有四个库之一的对应小节
- 不要存"应然"（法规能查到的）——库只存"实然"（跑出来的口径）
- 别人名下的库（股转=江姐、商事登记=徐总）也可写，但 `[敏感]` 项转述先请示对应负责人
- 窗口口径有地域性：记清楚是哪个区哪个所，不要写成"全苏州/全省通行"，防止过度泛化
