# 财税内容创作 Skill（案例库 + 编辑手法）

> 面向财税行业（盈信/苏州）写公众号、短视频等观点/风险/预警类内容时的**可复用素材库与方法库**。
> 注意：公众号完整工作流（配图/排版/发布/尾部模板）在 `wechat-publish` skill（用户自有）；本技能只沉淀**跨场景可复用的案例与手法**，两者配合使用。

## When to Use

- 写财税风险/合规观点类文章或短视频，需要**官方通报案例**（网红、上市公司偷逃税/财务造假）镇场
- 用户要求文章"打乱顺序不抄袭无AI味"，需要**观点类编辑手法**（蝴蝶效应、金税四期支柱、情绪价值等）
- 用户要求"再加一个大型企业/网红案例"时，从本库挑并**重新核实数字**

## 已核实官方案例库（2026-08-14 核实）

> 每个数字都经搜狗/360搜索 + 官方媒体（新华社/央广网/中新网/证监会通报）核实。**引用前仍须重新核实一遍**（守"严禁AI幻觉"铁律），自媒体二手解读不引用。

### 案例1：薇娅（网红大咖档）
- 事实：头部主播黄薇（薇娅）偷逃税，被追缴税款、加收滞纳金并处罚款共计 **13.41亿元**（2021年12月，国家税务总局浙江省税务局/杭州市税务局稽查局通报；新华社/央广网/中新网报道）
- 用途：网红/个人偷逃税案例，证明"体量再大、手段再多，大数据下个人逃税也无处遁形"
- 金句：一天赚的钱普通人想都不敢想 / 说凉就凉

### 案例2：康美药业（上市公司档）
- 事实：A股上市公司康美药业 2016-2018 财务造假，**虚增约300亿元**，被证监会顶格处罚，股价蒸发近九成、差点退市（2020年行政处罚，2021年投资者赔偿判决）
- 用途：上市公司/大型企业案例，证明"公司再大、报表再光鲜，说塌就塌"
- 金句：那么大的公司、那么光鲜的报表，说塌就塌 / 连它都躲不过去，凭什么轮到你就能侥幸

### 双案例组合用法
观点/风险类文章配 **1 网红大咖 + 1 上市公司** 双案例镇场，顺序：金税四期/以数治税/大数据（观点支柱）→ 薇娅 → 康美 → 落到"咱们小门小户分分钟的事"。组合金句：薇娅也好、康美也好，那么大的体量、那么多手段都躲不掉，咱们这种小门小户，真要对上号，不也是分分钟的事？

## 观点/风险类文章编辑手法（2026-08-14 用户逐轮确立）

这些是用户多次追加、已定稿的手法，写财税观点/风险类内容时按需选用：

1. **蝴蝶效应/传导比喻**：讲"监管严、别觉得事不关己"——"今天你吃的瓜，迟早传导到你自己身上；社会发展到今天，谁又能真的独善其身"。落地例：隔壁低价抢单的同行靠买票/做假压成本→客户被抢→逼你也想跟着学→这就是传导，最后落到每个老实交税的人头上（先吃瓜，最后自己哭都来不及）。
2. **金税四期/以数治税/大数据 = 观点支柱**：翻译成大白话——"以前靠人举报、靠碰运气抽查，现在靠系统自己比对；进项、销项、成本、利润在系统里连成一条线，哪一环对不上，系统自己就标红"。
3. **低价代账批判金句**（用户定稿）：监管都严到这份上了，你还信"99元代账""360包一年"的低价营销，就等于把自己的财务安全放在火上烤——账总有"糊"的一天。真到糊了那天，你回头想想当初省下的那点钱，值吗？——呼应盈信"合规账"价值主张。
4. **同行"奇技淫巧"三问**（用户原话骨架，融入时拆成加粗小段）：① 你听到的/猜到的，很可能正是同行想让你去实践的（他拉你一起"脏"，好显得他没那么脏）；② 就算他说的是真的，你信他那套能撑多久？（大数据盯着，纸包不住火，早晚的事）；③ 这样的风险，你扛得起吗？（他倒他的，你要是跟着学，倒的时候连着你一起）。
5. **情绪价值收尾（自己人口吻）**：结尾从"说教"切到"站观众一边"——"我也从小生意做过起，知道你看到'合规'两个字就烦""合规不是我给你上的课，是咱们一起要过的坎""拿不准随时来找我，我帮你把把关——咱们是自己人，我不跟你整虚的"。共情 + 主动递出帮助，让读者觉得是自己人。
6. **token 成本沟通**：用户问"先审阅 vs 直接发布哪个费token"时，明确告知——审阅几乎零token（用户读文章不生成），配图+排版+发布是几十次工具调用、很贵，**返工（重发+删草稿箱旧稿）比先确认贵好几倍**。故固定"先审阅敲定→再一次性配图发布"，不跳过预览。

## 案例核实方法（web_search 未配置时）

- **选渠道先看总览**：本 skill `references/china-search-channel-capability-map.md` 是 China 网络下全渠道检索能力表（通用引擎 + 新媒体平台各自可行路线），接检索任务先按表选对渠道
- 用 `execute_code` + requests + bs4 抓 搜狗 `https://www.sogou.com/web?query=` 或 360 `https://www.so.com/s?q=`（带浏览器 UA + Accept-Language: zh-CN）
- 搜狗被限流（返回空）时**换 360 搜索**，不要在同一引擎反复重试
- **查抖音/短视频素材**：用 Hermes 内置浏览器路线（短链解析 video id → browser_navigate → 页面内 browser_console fetch aweme API），实测可行，详见 `wechat-publish`「抖音获取步骤」；别在 curl_cffi/Playwright 工具阶梯上耗时间
- 数字只认官方媒体（新华社/央广网/中新网）或官方通报（税务局/证监会），自媒体标题数字仅作线索，须交叉确认
- 用 `browser_navigate`/`web_extract` 打开权威页面复核具体数字（如金额、日期、机关名称）

## Pitfalls

- 案例数字每次引用前必须重新核实——监管口径、金额可能更新，绝不能凭记忆写
- 区分"财务造假"（康美=证监会罚，虚增收入/货币资金）与"偷逃税"（薇娅=税务局罚）两种违法性质，表述别混用
- 网红的"13.41亿"是主播偷逃税，不是财务造假；上市公司案例若选财务造假类，表述用"财务造假被证监会处罚"，不要写成"偷税"
- 只把案例当"监管多严"的论据，不替案例当事人下"罪有应得"式道德审判，保持顾问中肯口吻
- 自媒体号素材（如标"AI生成"的抖音号）不是官方信源，只当观点引子，不当事实依据
