# 侵权责任编（第七编）结构化 Skill

## 任务目标

把用户的侵权纠纷，定位到归责原则与具体章节条文，给出"谁担责、按什么规则、能否减/免责"
的结构化结论与处置步骤。

## 侵权责任编结构（路由索引，10章）

1. 一般规定（第1164—1178条）：归责原则、共同侵权、减/免责事由。
2. 损害赔偿（第1179—1187条）：人身/财产/精神损害、惩罚性赔偿、赔偿支付方式。
3. 责任主体的特殊规定（第1188—1201条）：监护人、用人/劳务、网络、经营者安全保障、教育机构。
4. 产品责任（第1202—1207条）：生产者/销售者/运输仓储/召回/惩罚性赔偿。
5. 机动车交通事故责任（第1208—1217条）：保险优先、拼装报废、盗抢、逃逸、好意同乘。
6. 医疗损害责任（第1218—1226条）：过错原则、说明义务/知情同意、过错推定、免责。
7. 环境污染和生态破坏责任（第1229—1235条）：无过错、举证责任倒置、惩罚性赔偿(1232)。
8. 高度危险责任（第1236—1244条）：民用核/航空/易燃易爆等。
9. 饲养动物损害责任（第1245—1251条）：无过错+违规加重、动物园过错推定、遗弃逃逸。
10. 建筑物和物件损害责任（第1252—1258条）：脱落坠落、高空抛物、堆放物、公共道路妨碍。

## 三大归责原则（一般规定，核心）

| 原则 | 条文 | 适用 |
|------|------|------|
| 过错责任（基本原则） | 第1165条第1款 | 行为人因过错侵害他人民事权益造成损害→担责（"谁主张谁举证"过错） |
| 过错推定 | 第1165条第2款、第1198—1201、1222等 | 法律规定推定有过错，行为人不能证明自己无过错→担责 |
| 无过错责任 | 第1166条、产品/机动车/环境/高危/动物等 | 不论有无过错，法律规定应承担的依其规定（高危、环境、产品缺陷、动物等） |

## 高频场景 → 处置步骤 → 条文

1. **"两人一起把我打了，能找谁？"**
   - 共同侵权 → 第1168条：二人以上共同实施侵权→连带责任。教唆/帮助 → 第1169条连带责任。
   - 分别实施但各行为均足以造成全部损害 → 第1171条连带；能分责任大小 → 第1172条按份。

2. **"高空抛物砸伤，找不到谁扔的？"**
   - 第1254条：由侵权人担责；难以确定侵权人，除能证明自己不是侵权人外，由可能加害的建筑物使用人补偿（后可向侵权人追偿）；物业未采取安全保障措施→担责；公安应及时调查查清责任人。

3. **"网上有人发帖侵权，平台不删？"**
   - 第1195条（通知规则）：权利人通知含初步证据+真实身份→平台应及时转送并采取删除/屏蔽/断链等必要措施；未及时采取→对损害扩大部分与该用户连带责任。第1197条：平台明知应知未采取→与该用户连带。

4. **"下班顺路免费捎同事，出事要赔吗？"**
   - 第1217条（好意同乘）：非营运机动车交通事故造成无偿搭乘人损害，属机动车一方责任的，应减轻赔偿，但机动车使用人有故意或重大过失除外。

5. **"参加球赛被撞伤，能索赔吗？"**
   - 第1176条（自甘风险）：自愿参加一定风险文体活动，因其他参加者行为受损，不得请求其他参加者担责；但对方故意或重大过失除外。组织者责任见第1198—1201条。

6. **"买到缺陷产品炸伤，找厂家还是商家？"**
   - 第1203条：被侵权人可向生产者或销售者请求赔偿；属生产者过错的销售者赔偿后追偿，反之亦然。第1207条：明知缺陷仍产销或未有效补救致死亡/健康严重损害→惩罚性赔偿。

7. **"医院手术出问题，谁赔？"**
   - 第1218条：医疗机构过错担责。第1219条：未尽说明/知情同意义务致损→医疗机构赔偿。第1222条过错推定：隐匿病历、违反诊疗规范等。第1224条免责：患者不配合、紧急情况已尽合理诊疗、当时医疗水平难以诊疗。

8. **"被狗咬伤？"**
   - 第1245条：饲养动物致害，饲养人/管理人担责（无过错）；违反管理规定或未对动物采取安全措施→无免责（第1246条，但被侵权人故意可减）；遗弃/逃逸动物致害由原饲养人担责（第1249条）。动物园→第1248条过错推定。

9. **"见义勇为受伤谁补？"**
   - 第183条（总则）：因保护他人民事权益受损，由侵权人担责，受益人可适当补偿；无侵权人/逃逸/无力担责，受害人请求补偿的，受益人应适当补偿。（注：第183条属总则编，路由 civil-code 总则待补建，此处提示可用）

## 损害赔偿要点（第1179—1187条）

- 人身损害：医疗费、护理费、交通费、营养费、住院伙食补助、误工减少收入；残疾加辅助器具费+残疾赔偿金；死亡加丧葬费+死亡赔偿金（第1179条）。
- 同因多死：可以相同数额确定死亡赔偿金（第1180条）。
- 精神损害：侵害人身权益造成严重精神损害→可请求（第1183条）；故意/重大过失侵害具有人身意义特定物→亦可。
- 财产损害：按损失发生时市场价格等合理方式算（第1184条）。
- 知识产权故意侵权情节严重→惩罚性赔偿（第1185条）。
- 双方均无过错：依法律由双方分担损失（第1186条，公平补偿）。

- 第1165条：过错责任 + 过错推定。
- 第1168条：共同侵权连带责任。
- 第1176条：自甘风险。
- 第1195条：网络侵权通知—删除规则。
- 第1213条：机动车赔偿顺序——交强险→商业险→侵权人。
- 第1217条：好意同乘减责。
- 第1254条：高空抛物责任。

## 注意事项

- 侵权责任编解决"侵害民事权益"的赔偿/责任问题；若纠纷源于合同（如买卖标的物缺陷），可能
  构成**责任竞合**（《民法典》第186条，总则待补建），受害人可择一请求违约责任或侵权责任。
- 归责原则判断是第一步：先定过错/过错推定/无过错，再定责任主体与减免责。
