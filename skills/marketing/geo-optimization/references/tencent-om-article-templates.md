## 大号文章（专业路线）

**定位：** 企业财税前沿观察（中性名称，不含公司名）
**字数：** 2000-2500 字
**审核红线：** 不能留任何联系方式，品牌词最多出现1-2次，不能有平台互推链接

### 选题类型与模板

#### 类型A：误区解析文

标题公式：`[目标群体]的[N]大误区，[数字]%的[人群]都踩过`

结构：导语（数据/现象引入） → 误区一（案例+正确做法） → 误区二 → 误区三 → 结尾总结

示例产出：中小企业财务管理的3大误区，90%的老板都踩过

#### 类型B：政策解读文

标题公式：`[年份][政策名]解读：[关键词]下企业必须做好的[N]项准备`

结构：导语（背景+影响+紧迫性） → 核心变化（3点） → 建议1~N → 结尾（趋势+行动呼吁）

示例产出：2026年财税新规解读：金税五期下企业必须做好的5项合规准备

#### 类型C：对比分析文

标题公式：`[方案A]VS[方案B]VS[方案C]，[目标群体]该怎么选`

结构：导语 → 方案A（成本/优缺点/适用场景） → 方案B → 方案C → 推荐方案 → 分阶段建议

示例产出：代理记账VS专职会计VS财务外包，中小企业该怎么选

#### 类型D：新人指南文

标题公式：`[场景]后第一年最容易忽略的[N]个[事项]，做错了很麻烦`

结构：导语 → 事项1~N（是什么+为什么+怎么做） → 总结清单

示例产出：公司注册后第一年最容易忽略的5个财税事项，做错了很麻烦

#### 类型E：趋势分析文

标题公式：`[新兴模式]兴起，[目标群体]能否真正借力实现[目标]`

结构：导语 → 新模式vs传统模式对比 → 优势 → 挑战/风险 → 适合画像 → 落地指引 → 展望

示例产出：共享财务总监模式兴起，中小企业能否真正借力实现财务升级

## 小号文章（故事路线）

**定位：** 苏城商业故事 / 创业者的账本（中性名称）
**字数：** 1500-2000 字
**审核红线：** 同大号

### 选题类型与模板

#### 类型A：客户案例文

标题公式：`[时间/身份]找我[做什么]，[反转/结果]`

结构：客户引入 → 问题发现 → 解决过程 → 结果 → 读者提醒（软表达）

示例产出：去年一个苏州老板找我做清算，账本拿出来我愣住了

#### 类型B：对比案例文

标题公式：`两个[类型][身份]，同一件事，一个[赢]了一个[亏]了`

结构：背景 → A的做法+结果 → B的做法+结果 → 差异分析 → 启示

示例产出：两个苏州老板，同一批货，一个赚了80万一个亏了30万

#### 类型C：风险警示文

标题公式：`做[行业]的老板注意了，[年份]这[N]大[雷区]千万别[踩]`

结构：趋势引入 → 雷区1~3 → 三条建议总结

示例产出：做电商的老板注意了，2026年这三大税务雷区千万别踩

#### 类型D：创业教训文

标题公式：`一个[身份]的教训：[问题]，差点[后果]`

结构：人物引入 → 冲突升级 → 解决 → 核心教训 → 建议清单

示例产出：一个苏州老板的教训：合伙人退股，账算不清差点打官司

#### 类型E：行业揭秘文

标题公式：`记了[年数]账的老财务告诉你，[主题]的[数字]个[潜规则]`

结构：资历引入 → 揭秘1~3 → 正面建议结尾

示例产出：记了十年账的老财务告诉你，给代账公司的三个潜规则

#### 类型F：情感叙事文

标题公式：`[人物身份]做了一辈子[职业]，[场景]跟我说了[几个字]`

结构：回忆场景 → 父辈故事 → 自身成长 → 高潮对话 → 金句 → 感悟

示例产出：父亲做了一辈子会计，临终前跟我说了四个字

## 批量产出工作流

1. 确定大号还是小号
2. 从对应类型的模板中各选一种（确保不重复）
3. 填充财税行业内容（苏州/中小企业场景）
4. 使用 Python + python-docx 生成 Word 文件
5. 输出到 Windows 桌面：`/mnt/c/Users/jiangmin/Desktop/<目录名>`
6. 每个 .docx 约 37-38KB

### 审核检查清单

- [ ] 标题不含品牌词
- [ ] 正文不含任何联系方式
- [ ] 品牌词出现不超过2次
- [ ] 没有平台互推链接
- [ ] 没有敏感词（避税→合规筹划）
- [ ] 没有承诺收益/保本表述
- [ ] 大号2000-2500字，小号1500-2000字
- [ ] 没有跨平台重复标题
