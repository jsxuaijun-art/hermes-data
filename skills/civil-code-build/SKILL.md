## 构建步骤（以"物权编"为例）

1. **取简体全文**：已有 `物权编_simp.txt`；或用 `clean.py` 模式生成 `references/物权编全文.md`
   （清页脚、截断到最后一条「第X条」、加来源头）。
2. **抽取结构骨架**：按 `^第[一二三四…]+编/分编/章/节` 提取层级（参考已生成的合同/侵权编 SKILL.md 结构写法）。
3. **写子 skill SKILL.md**，必须含：
   - frontmatter（`name`/`description` 写清触发场景与 3-5 个典型问法；`agent_created: true`）
   - 任务目标
   - 本编结构路由索引（章→主题）
   - 重点制度速查表（主题→核心条文→要点）
   - 高频场景→处置步骤→条文（3-6 个，带"警惕信号"）
   - 重点条文摘录（原文，核 references 全文）
   - 注意事项（参照适用、司法解释口径、废止旧法提示）
   - 末尾注明全文见 `references/<编>全文.md`
4. **回写主路由 `civil-code/SKILL.md`**：在「七编索引」表把该编状态由"待补建"改为"✅ civil-code-<编>"，
   并在路由决策树加一条。
5. **自测**：用 3 个真实问题验证路由与条文引用准确，不通过回到第 3 步。

## 关键约定（防幻觉）

- 条文号必须精确（如"民法典第577条"），引用前核对 `references/<编>全文.md` 原文，不凭记忆改字。
- 司法解释（合同编通则解释、担保制度解释、婚姻家庭/继承/侵权责任编解释等）属外部口径，
  注明"需结合司法解释"，不得混入民法典正文。
- 旧法（合同法/物权法/侵权责任法等）已废止，一律指向民法典对应条文。
- 全文源为繁→简机器转换，个别异体字已规范化；交付前抽样核对关键条文与官方简体一致。
