# 人格权编（第四编）结构化 Skill

## 任务目标

把人格权侵权纠纷定位到具体权利类型（生命/身体/健康、姓名/名称、肖像、名誉/荣誉、隐私、个人信息），
给出"是否构成侵权、谁举证、可主张什么救济、有无免责"的结构化结论与处置步骤。

## 人格权编结构（路由索引，6 章）

1. 一般规定（第989—1001条）：权利范围、保护、请求权不适用诉讼时效、违约责任与精神损害、人格权行为禁令。
2. 生命权、身体权和健康权（第1002—1011条）：法定救助义务、人体捐献、禁止性骚扰（1010）。
3. 姓名权和名称权（第1012—1017条）：姓名决定/使用/变更、笔名艺名参照保护。
4. 肖像权（第1018—1023条）：肖像制作/使用/公开、禁止丑化伪造（含AI换脸）、合理使用、许可合同。
5. 名誉权和荣誉权（第1024—1031条）：名誉/荣誉保护、舆论监督免责与合理核实、作品歪曲、信用评价。
6. 隐私权和个人信息保护（第1032—1039条）：隐私、个人信息处理原则、信息主体权利、处理者义务。

## 重点制度速查表

| 主题 | 核心条文 | 要点 |
|------|---------|------|
| 人格权范围 | 第990条 | 生命/身体/健康/姓名/名称/肖像/名誉/荣誉/隐私权等；其他基于人身自由尊严的人格权益 |
| 人格权请求权不适用诉讼时效 | 第995条 | 停止侵害、排除妨碍、消除影响、恢复名誉、赔礼道歉不受诉讼时效限制 |
| 人格权行为禁令 | 第997条 | 有证据证明正在/即将实施侵害且不及时制止将致难弥补损害→可申请法院责令停止 |
| 违约责任中的精神损害 | 第996条 | 因当事人一方违约损害对方人格权造成严重精神损害，受损害方可请求精神损害赔偿 |
| 生命/身体/健康权 | 第1002—1004条 | 任何组织个人不得侵害；法定救助义务（1005）；禁止性骚扰（1010） |
| 姓名/名称权 | 第1012—1014条 | 决定/使用/变更/许可；未成年人姓名变更依最有利于被监护人原则（1015—1016） |
| 笔名艺名保护 | 第1017条 | 笔名、艺名、网名、译名、字号等受姓名权规则保护 |
| 肖像权侵权 | 第1019条 | 不得以丑化/污损/信息技术伪造（AI换脸）等方式侵害；未经同意不得制作使用公开肖像 |
| 肖像合理使用 | 第1020条 | 为个人学习、新闻报道、公共利益等实施的不构成侵权 |
| 名誉权侵权 | 第1024条 | 不得以侮辱、诽谤等方式侵害；名誉=社会评价 |
| 舆论监督免责 | 第1025条 | 为公共利益实施舆论监督影响他人名誉，内容基本属实/合理来源/已尽核实等免责 |
| 合理核实义务 | 第1026条 | 认定是否尽合理核实，考量内容来源、对合法权益影响、公序良俗等六因素 |
| 信用评价更正 | 第1029条 | 民事主体可查询本人信用评价，发现错误有权提出异议并要求更正 |
| 隐私权 | 第1032条 | 私人生活安宁+不愿为他人知晓的私密空间/活动/信息；禁止刺探侵扰泄露公开 |
| 个人信息保护 | 第1034—1039条 | 可识别自然人信息受保护；处理须合法正当必要（1035）；主体有查阅复制更正删除权（1037） |

## 高频场景 → 处置步骤 → 条文

1. **"被人网上造谣/诽谤，转发很多"**
   - 名誉权第1024条：侮辱、诽谤侵害名誉→担责。
   - 若属舆论监督且内容基本属实、已尽核实→第1025条可能免责；失实可请求媒体更正/删除（第1028条）。
   - 救济：停止侵害、恢复名誉、消除影响、赔礼道歉、赔偿（含精神损害）；不受诉讼时效限制（第995条）。
   - 步骤：①固定证据（公证/录屏/截图，含发布者ID与内容）；②发函要求平台/发布者删除；③平台不删可主张连带责任（涉网络侵权参照 civil-code-tort 侵权责任编第1195条通知—删除规则）；④起诉主张赔礼道歉+赔偿。

2. **"AI换脸/丑化我的肖像发网上"**
   - 第1019条：不得以丑化、污损或**利用信息技术手段伪造**（即AI换脸、deepfake）等方式侵害肖像权；未经同意不得制作、使用、公开肖像。
   - 步骤：取证→通知平台下架（侵权内容）→主张删除+赔礼道歉+赔偿；营利性使用可主张财产损失（参照许可使用费，1018、1022）。

3. **"骚扰电话、偷拍、人肉搜索、泄露我的隐私"**
   - 隐私权第1032、1033条：禁止刺探、侵扰、泄露、公开；以短信/电话/即时通讯侵扰、拍摄窥视私密空间、处理私密信息均属侵权。
   - 个人信息第1034—1037条：违法处理可请求更正、删除；处理者未尽安保义务担责（1038）。
   - 步骤：取证（通话记录/截图）→向平台/运营商投诉→向网信、公安举报（违法处理个人信息）→民事索赔。

4. **"我的个人信息被APP滥用/买卖"**
   - 第1035条：处理个人信息应合法、正当、必要，不得过度收集；公开处理规则、明示目的方式范围、征得同意。
   - 第1037条：有权查阅、复制；发现错误可请求更正；违法/违约处理可请求删除。
   - 步骤：在APP内行使查阅/复制/删除权；平台拒绝→向网信部门举报（违反《个人信息保护法》另循行政/刑事途径）。

5. **"侵害正在发生/马上要发生，来不及起诉"**
   - 第997条：有证据证明行为人正在或即将实施侵害，不及时制止将致难弥补损害→可向法院申请责令停止有关行为（人格权行为禁令，类似行为保全）。

6. **"别人用我的笔名/艺名接商单牟利"**
   - 第1017条：笔名、艺名、网名、译名、字号等受姓名权规则保护；擅自商用可参照姓名权/名称权主张。

## 重点条文摘录（原文见 references/人格权编全文.md）

- 第990条：人格权是民事主体享有的生命权、身体权、健康权、姓名权、名称权、肖像权、名誉权、荣誉权、隐私权等权利；自然人还享有基于人身自由、人格尊严产生的其他人格权益。
- 第995条：人格权受侵害的，受害人有权请求承担民事责任；停止侵害、排除妨碍、消除危险、消除影响、恢复名誉、赔礼道歉请求权，不适用诉讼时效。
- 第997条：民事主体有证据证明行为人正在实施或者即将实施侵害其人格权的违法行为，不及时制止将使其合法权益受到难以弥补的损害的，有权依法向人民法院申请采取责令行为人停止有关行为的措施。
- 第1019条：任何组织或者个人不得以丑化、污损，或者利用信息技术手段伪造等方式侵害他人的肖像权；未经肖像权人同意，不得制作、使用、公开肖像权人的肖像。
- 第1024条：民事主体享有名誉权；任何组织或者个人不得以侮辱、诽谤等方式侵害他人的名誉权；名誉是对民事主体的品德、声望、才能、信用等的社会评价。
- 第1032条：自然人享有隐私权；任何组织或者个人不得以刺探、侵扰、泄露、公开等方式侵害他人的隐私权。
- 第1034条：自然人的个人信息受法律保护；个人信息是可单独或结合识别特定自然人的各种信息（姓名、证件号、生物识别、住址、电话、健康、行踪等）；私密信息优先适用隐私权规定。
- 第1037条：自然人可依法向信息处理者查阅或者复制其个人信息；发现错误有权请求更正；发现违法/违约处理有权请求删除。

## 注意事项

- 人格权编是"宣示+保护"编，具体赔偿标准（精神损害、财产损失）常与侵权责任编（第1164—1187条，civil-code-tort）并用。
- 网络侵权同时涉及本编（名誉/隐私/肖像）与侵权责任编第1194—1197条（网络侵权通知—删除规则），两条线并行。
- 个人信息保护另有《个人信息保护法》，本编为原则性规定；遇违法处理应同时提示行政/刑事救济渠道。
