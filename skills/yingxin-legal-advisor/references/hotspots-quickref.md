# 首场景速查：高频三类（货款拖欠 / 劳动纠纷 / 股东纠纷）

> 用途：盈信客户日常问得最多三类，直接按下面结构化路径作答。
> ⚠️ 所有法条引用前必须**联网核实现行性与条文号**（`cn-regulation-verification` 核现行性），本表只给处理框架，不替代核对。

## 一、货款拖欠 / 催收

### 核心链条
```
固定证据 → 判断时效 → 非诉催收 → （支付令/起诉）
```

### 分步要点
1. **定性**：买卖合同 / 服务合同 / 承揽合同价款请求权（民法典·合同编）。
2. **诉讼时效 3 年**（民法典第 188 条，具体条文号联网核实）：从"知道或应当知道权利受损及义务人"起算；期间每次有效催款/对方确认**中断并重新起算**。
3. **证据链（按重要性）**：
   - 合同/订单（约定付款时间、账期）
   - 对账单（双方盖章/签字=强证据）
   - 送货单/签收单（**必须有对方签收，否则最难追**）
   - 发票开具与签收记录
   - 微信/邮件中的催款与对方"承认欠款/承诺付款"记录（可作诉讼时效中断与自认证据）
4. **非诉催收三步**：电话/微信 → 书面对账函或催款函（**留痕、中断时效、固定对方自认**）→ 律师函。
5. **支付令（督促程序，快）**：债权债务关系明确、无其他债务纠纷、能送达 → 向基层法院申请，对方 15 日内不提异议即生效，可申请强制执行。
6. **起诉（慢但终局）**：管辖=被告住所地或合同履行地；可申请**财产保全**；可主张违约金、逾期利息、实现债权的费用（如有约定）。

### 风险红线
- 无对方签收的送货单 + 无对账 → 证据薄弱，提醒客户"先补签/先对账再诉讼"。
- 超过 3 年且无中断证据 → 有败诉风险，提示尽快行动。
- 公司濒临注销/失联 → 提示关注"未决债务与股东责任"边界。

## 二、劳动纠纷

### 核心链条
```
劳动关系认定 → 争议类型 → 协商/仲裁(前置) → 诉讼
```

### 分步要点
1. **劳动争议必须先仲裁（仲裁前置）**：向劳动人事争议仲裁委申请，不服裁决 15 日内再起诉（劳动争议调解仲裁法）。
2. **仲裁时效 1 年**（劳动争议调解仲裁法第 27 条，条文号联网核实）：从知道或应当知道权利受损起算；拖欠劳动报酬不受该 1 年限制（劳动关系存续期间；终止后 1 年内）。
3. **高频争议点**：
   - 未签书面劳动合同 → 第二倍工资（最长 11 个月）；未签满 1 年视为订立无固定期限合同。
   - 试用期：上限随合同期限递增、同一单位同一岗位不得重复约定。
   - 解除：协商一致 / 劳动者主动 / 有过错解除 / 无过错解除（提前30书面+经济补偿）/ 违法解除（2倍赔偿金）。
   - 经济补偿 N vs 赔偿金 2N 的适用甄别。
   - 竞业限制：限高管/高知/保密义务人，期限≤2年，单位需付经济补偿。
   - 社保/公积金未缴 → 补缴+工伤/医疗待遇风险。

### 风险红线
- 提醒客户：口头约定解除无书面证据很被动；"自动离职"不是免责法宝。
- 涉及工伤：企业 30 日内申请，超期员工可 1 年内自行申请。
- 竞业限制协议未付补偿：员工可主张解除，对企业不利。

## 三、股东纠纷

### 核心链条
```
出资 → 权利(知情/分红) → 转让 → 决议 → 僵局/退出
```

### 分步要点（重点提示"现行公司法=2023年修订、2024-07-01 施行"）
1. **注册资本**：认缴制，但**自 2024-07-01 起新设公司须 5 年内缴足**；存量公司有其过渡安排（联网核实具体口径）。
2. **加速到期**：公司不能清偿到期债务时，已到期但仍未缴的出资可能被要求提前缴纳——提示客户注意对外债务风险。
3. **股东出资瑕疵 / 抽逃出资**：补足 + 违约责任，可能影响表决/分红比例。
4. **知情权（查账权）**：可书面要求查阅会计账簿，公司无正当理由不得拒绝；可诉。
5. **盈余分配（分红）**：按约定或实缴比例；有利润不分可起诉，但商业判断有边界。
6. **股权转让**：有限责任公司股东转让股权，其他股东有**优先购买权**；程序瑕疵可致转让争议。
7. **决议瑕疵**：股东会/董事会决议无效（内容违法）/可撤销（程序·表决方式违法或章程违规）/不成立——起诉时效分别有规定。
8. **公司僵局 → 司法解散**：持续两年以上无法召开股东会/表决，经营管理严重困难，可通过诉讼解散（公司法，条文号联网核实）。

### 风险红线
- 提示"认缴≠不用出"——现在法院对未实缴/加速到期抓得严。
- 股权代持：内部效力不等于对抗第三人，客户要心中有数。
- 一人公司股东与公司财产混同 → 对债务承担连带责任。

> 编制纪律：以上"风险红线"为执业要点提示，凡涉具体金额/期限/条文号一律以联网核实的现行法为准；拿不准就并列"建议人工核实"。
