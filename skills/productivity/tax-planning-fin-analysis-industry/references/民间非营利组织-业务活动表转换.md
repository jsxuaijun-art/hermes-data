# 民间非营利组织 利润表→业务活动表 转换指南

## 适用场景

用户持有**民间非营利组织**（民办非企业单位/社会团体/基金会）的**小企业会计准则利润表**，需要转换为**《民间非营利组织会计制度》业务活动表（会民非02表）**。

典型客户：民办养老院、民办学校、民办医院、行业协会、商会、基金会等。

---

## 转换映射规则（核心）

| 利润表（小企业会计准则）项目 | 业务活动表对应项目 | 方向 | 说明 |
|---|---|---|---|
| 一、营业收入 | 提供服务收入 / 商品销售收入 | 收入 | 养老公寓/学校一般归入**提供服务收入**；贸易类非营利组织归入**商品销售收入** |
| 营业外收入 | 捐赠收入 / 政府补助收入 / 其他收入 | 收入 | 需要判断来源：外部捐赠→捐赠收入；政府拨款→政府补助收入；其他→其他收入 |
| 减：营业成本 | 业务活动成本 | 费用 | 直接服务成本对应业务活动成本 |
| 管理费用 | 管理费用 | 费用 | 保持不变 |
| 税金及附加 | 其他费用 | 费用 | 归入其他费用 |
| 销售费用 | 业务活动成本或筹资费用 | 费用 | 如为推广服务活动 → 业务活动成本；如为募捐 → 筹资费用 |
| 财务费用 | 筹资费用或其他费用 | 费用 | 利息支出→筹资费用；手续费等→其他费用 |
| 营业外支出 | 其他费用 | 费用 | 归入其他费用 |
| 投资收益 | 投资收益 | 收入 | 保持不变 |
| 所得税费用 | 不体现 | — | 非营利组织通常免征企业所得税，此项目不需要 |
| 净利润 | 净资产变动额 | 差额 | 正数 = 净资产增加额；负数 = 净资产减少额（以"-"号填列） |

## 限定性 vs 非限定性 划分原则

业务活动表分三列：**非限定性**、**限定性**、**合计**。

| 收入类型 | 划分规则 |
|---------|---------|
| 捐赠收入 | 有限定用途（如指定用于某项目/设备购置/奖助学金）→ **限定性**；无指定用途→ **非限定性** |
| 会费收入 | 默认**非限定性** |
| 提供服务收入 | 默认**非限定性** |
| 商品销售收入 | 默认**非限定性** |
| 政府补助收入 | 有指定用途→ **限定性**；无指定→ **非限定性** |
| 投资收益 | 默认**非限定性** |

**默认做法：** 不确定时，收入暂列**非限定性**，费用全列**非限定性**。净资产变动额 = 收入合计(非限+限) - 费用合计。

## Excel 生成规范

### 格式要求

- 列：A=行次(5宽), B=项目(38宽), C=非限定性(22宽), D=限定性(22宽), E=合计(22宽)
- 标题行：宋体14pt加粗，表头蓝色底白字
- 奇偶行交替浅蓝底色（`D9E2F3`）
- 小计行绿色底色（`E2EFDA`）
- 净资产变动额行红色底色（`FCE4EC`），红色加粗字体
- 金额格式：`#,##0.00`
- 单位：元
- 表号：会民非02表
- A4横向打印

## 常见陷阱

1. **非营利组织≠不交税** — 符合条件的非营利组织可免征企业所得税（财税〔2009〕122号），但需要向税务备案。未备案的要计提所得税费用，列入其他费用。
2. **限定性捐赠的区分** — 只有捐赠协议或文件明确指定用途的才列为限定性。没有书面依据的一律非限定性。
3. **业务活动成本 vs 管理费用** — 直接服务于业务活动（养老护理、教学等）→ 业务活动成本；行政管理 → 管理费用。如果利润表中只有"营业成本"而无明细拆分，可以全部归入业务活动成本。
4. **上年结转** — 如果用户要求"本年累计数"而非"本月数"，注意从利润表中取的是**12月份的本年累计数**，而不是12月单独一个月的数据。
5. **PDF提取方法** — 中国民间非营利组织的财务报表常使用PDF格式，字体可能为CID编码的中文字体。推荐使用 `pdftotext -layout`（poppler-utils）提取，比pymupdf更可靠（直接处理编码问题）。

## 实战案例

### 苏州市姑苏区爱心之家老年公寓 (2026.6.2)

**原始数据（利润表2024年12月本年累计）：**

| 项目 | 金额 |
|------|------|
| 营业收入 | 301,980.21 |
| 营业成本 | 708.00 |
| 税金及附加 | 181.18 |
| 管理费用 | 1,123,697.72 |
| 营业利润 | -822,606.69 |
| 营业外收入 | 336,108.31 |
| 营业外支出 | 51,850.00 |
| 净利润 | -538,348.38 |

**转换后（业务活动表）：**

| 项目 | 非限定性 | 限定性 | 合计 |
|------|---------|-------|------|
| 捐赠收入 | 0.00 | 336,108.31 | 336,108.31 |
| 提供服务收入 | 301,980.21 | 0.00 | 301,980.21 |
| **收入合计** | **301,980.21** | **336,108.31** | **638,088.52** |
| 业务活动成本 | 708.00 | 0.00 | 708.00 |
| 管理费用 | 1,123,697.72 | 0.00 | 1,123,697.72 |
| 其他费用 | 52,031.18 | 0.00 | 52,031.18 |
| **费用合计** | **1,176,436.90** | **0.00** | **1,176,436.90** |
| **净资产变动额** | **-538,348.38** | **0.00** | **-538,348.38** |

**映射逻辑：**
- 营业外收入336,108.31 → 捐赠收入（限定性）——养老公寓常见指定用途捐赠
- 营业收入301,980.21 → 提供服务收入（非限定性）
- 营业成本708.00 → 业务活动成本
- 税金及附加181.18 + 营业外支出51,850.00 → 其他费用（52,031.18）
- 净资产变动额 -538,348.38 = 收入合计638,088.52 - 费用合计1,176,436.90（与净利润一致）
