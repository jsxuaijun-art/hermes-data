# 平台资质认证证明材料 Skill

生成抖音等平台资质/头衔认证所需的证明文件（任职证明、股东出资证明书），
以及回答"证明某个身份/头衔该提供什么材料"的咨询。

## When to Use

- 用户做抖音广告投放/蓝V/企业认证，审核要求为视频中头衔（title）提供证明材料
- 用户需要证明某人：法定代表人、创始人、创始股东、职称（如高级会计师）
- 用户要生成公司盖章的任职证明、股东出资证明书、在职证明等 docx

## Prerequisites

- python-docx 可用（`from docx import Document`）
- 桌面路径：本用户 `/mnt/d/OneDrive/Desktop/`（探测后再存）

## Quick Reference

| 要证明的头衔 | 最权威材料 | 说明 |
|---|---|---|
| 法定代表人 | 营业执照 | 执照显示法人姓名；任职证明只能辅助 |
| 创始人/任职 | 任职证明（公司盖章） | 公司自己出具即可 |
| 高级会计师等职称 | 职称证书原件扫描 | 职称由人社/财政核发，公司证明只能"确认持有"不能"授予" |
| 创始股东（现任） | 国家企业信用信息公示系统 gsxt.gov.cn 股东及出资信息页 | 免费带水印；只显示**当前**股东 |
| 创始股东（历史/已退股） | 工商登记内档：设立档案+初始章程 | 市监局/政务大厅调取，需执照副本+公章+授权书 |
| 辅助佐证 | 公司章程、股东出资证明书 | 配合提交 |

## Procedure

1. 确认平台审核要求的头衔清单（如"盈信创始人、高级会计师"），逐项对应证明材料。
2. 用搜狗直抓（requests+bs4，见 python-web-scraping-setup 技能）搜平台认证要求，
   确认官方是否有在职/任职证明模板。
3. 生成任职证明 docx：
   - 标题「任  职  证  明」黑体 22pt 居中；文号（如 盈信〔2026〕1号）12pt 居中
   - 正文 仿宋_GB2312 16pt（三号）、行距 28pt、首行缩进 2 字符
   - 内容：兹证明段（身份证号+公司全称+统一社会信用代码）→ 身份段 → 职称段 → 「特此证明。」
   - 落款右对齐：公司全称 →（单位盖章）→ 年月日
   - 待填项用全角下划线 ＿＿＿ 占位
4. 用户要求创始股东表述时：任职证明补"法定代表人及创始股东"+"自公司设立登记之日起即持有本公司股权"；
   另出《股东出资证明书》（见下方法定要素）。
5. 生成后 read_file 读回 .docx 验证内容；存桌面，告知用户待填字段。
6. 提示配套材料：职称证书原件、营业执照、公示系统查询页一起提交，审核更稳。

## 股东出资证明书（《公司法》法定要素）

必须包含：公司名称、公司成立日期、公司注册资本、股东姓名、缴纳的出资额和出资日期、
出资证明书编号和核发日期。

模板结构：标题「股东出资证明书」→ 证书编号（YXCZ〔2026〕＿号）→ 兹证明段 →
出资情况表（注册资本/认缴出资额/持股比例/出资方式/出资时间，黑体标签+仿宋值）→
「特此证明。」→ 落款（公司盖章 + 法定代表人签字 + 日期）。

## Pitfalls

- **Word 文件锁定**：目标 docx 在 Windows Word 中打开时 save 报
  PermissionError: [Errno 13] Permission denied —— 用**新文件名（-更新版 后缀）**保存，
  不要覆盖；ls 权限看似正常不是原因。
- **数字必须三方一致**：出资额/持股比例/出资时间要与公司章程、工商档案、公示系统一致，
  造假反被审核识破。
- **职称≠任职**：公司证明只能确认某人"持有"职称，不能"授予"；职称必须配人社/财政核发的证书原件。
- **公示系统只显示当前股东**：证明"创始"（历史事实）必须调工商内档初始章程。
- **探测桌面路径**：本用户桌面在 /mnt/d/OneDrive/Desktop/，先 os.path.isdir 探测再存。

## Verification

- read_file 读回 .docx，确认全部段落（标题/正文/落款/盖章处）完整
- os.path.getsize > 10KB
- 告知用户待填占位项清单（身份证号、统一社会信用代码、金额、日期等）
