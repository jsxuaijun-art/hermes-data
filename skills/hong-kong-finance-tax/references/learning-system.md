# 香港财税“五大三粗六流”学习系统

## Level 1 — 五大
1. 登记与经营/税务设置
2. 发票、税务文件与业务凭证
3. 付款与资金
4. 利得税、雇主报税/薪俸税相关义务、印花税及其他适用香港税务申报与处理
5. 年度关账、年度税务和持续合规

## Level 2 — 三粗
### A. 采购 / 国际贸易 / 转口 / 转运
要求画六流并形成税务、会计、申报、证据 Checklist。

### B. 跨境服务 / 非贸付款 / Royalty / Interest
要求分析业务实质、合同、文件、税务、会计、付款、关联交易和协定。

### C. 资本投入 → 融资 → 利润 → 股息 / 再投资
要求分析资本流、利润形成、公司治理、税务、会计、银行和多国衔接。

## Level 3 — 综合案例
每个案例必须回答：
Facts → 五大 → 三粗 → 六流 → Tax → Accounting → Compliance → Risk → Evidence → Action

## Level 4 — 考试
- 初级：五大和系统入口
- 中级：税务 + 会计 + 文件 + 申报
- 高级：三粗 + 六流 + 跨境
- 专家：多年度 + 规则变化 + 协定 + 关联交易 + 证据链
