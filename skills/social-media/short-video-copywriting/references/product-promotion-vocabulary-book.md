# 教育类产品（词汇默写本）短视频推广 — 实战记录

## 产品背景
江姐为女儿设计的**高考英语词汇艾宾浩斯默写本**（词根版v3），基于255+ Membean词根库，含6轮艾宾浩斯复习法。产品已固化到 `vocab-memory-book` skill 和 `scripts/build_root.py`。

## 目标人群
- 高中生家长（尤其苏沪地区，与盈信客户群体重叠）
- 高考生本人
- 关注学习方法的家长群体

## 核心卖点（按优先级）
1. **科学性**：基于艾宾浩斯遗忘曲线（1885年发现），精确设计6个复习时间窗口（1天/2天/4天/7天/15天/30天）
2. **词根分组**：255+ Membean词根，不是字母顺序的笨办法
3. **6轮复习设计**：英译汉→汉译英→音标→英译汉→汉译英→综合，逐级加深
4. **制作背景**：妈妈给女儿亲手设计的（真实故事，最强信任背书）
5. **可定制**：高考3875词/上海中考词汇/其他定制需求

```

说实话，我一开始也挺崩溃的。😅

我女儿背单词，就跟大多数孩子一样——
背了忘，忘了背，背了再忘。
每天晚上背到十一点，第二天听写照样错一半。
你说她不努力吧，冤枉。
问题出在哪儿？方法在跟她的大脑对着干。

艾宾浩斯记忆法，搞教育的都听过。

遗忘不是匀速的——学完后的第1小时，崩得最快。
所以最佳复习时间点，不是"等你有空的时候"，
而是：1天、2天、4天、7天、15天、30天。
抓住这六个节点复习一遍，
记忆留存率能从20%拉到90%以上。
不是玄学，是神经科学。

我就按这个规律，给她做了套默写本。
高考一套，中考一套。
每组50个词，六轮闭环：
第一轮：英译汉——初次接触

第六轮：综合测验——收网

每一轮都踩在大脑快忘的临界点上，拉回来一次。
同样背100个词，别人忘掉80个，你记住85个。
差距不在智商，在方法。

说真的，我不知道这方法对你家孩子管不管用。
要不拿回去试一个月？
好用你就留着，不好用……你来找我。😄

需要的评论区扣「方法」，我把电子版发你。
```

**搜索注意事项（2026.7.6 本session实测）：**
- 抖音话题标签/BGM排行榜没有公开API
- 爬虫：Bing.cn JS渲染拿不到 → 搜狗第一次能拿到但链接不可达 → 不能连续搜第二次
- **最有效的做法：** 让用户自己在抖音App搜 `#高考英语` `#背单词` → 看点赞过万的视频 → 抄他们的标签和BGM歌名 → 手动发给我们

## BGM建议（教育类/知识类）
- **开头（0-3秒）**：节奏感强的钢琴切入或轻快节奏
- **中间（3-50秒）**：轻钢琴/知识点舒缓BGM（如《The Truth That You Leave》纯音乐）
- **结尾（50-60秒）**：励志渐进型，带渐强氛围

抖音搜关键词：「学习BGM」「知识分享配乐」「轻钢琴 知识分享」
（同上：让用户手机端搜，我们搜不到）
