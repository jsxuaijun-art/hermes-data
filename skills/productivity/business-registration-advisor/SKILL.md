### 3.1 公司设立（场景A）

| 子场景 | 关键审查点 | 参考法规 |
|--------|-----------|----------|
| 公司名称预先核准 | 字号是否重名、是否含禁用词 | 《企业名称登记管理规定》 |
| 经营范围规范表述 | 前置审批/后置备案、许可经营项目 | 《经营范围登记管理规定》 |
| 注册资本认缴 | 出资期限（新公司法5年）、特殊行业实缴要求 | 《公司法》第47条 |
| 住所/经营场所证明 | 各地场地要求不同（商住、住宅、集群注册） | 各地市场主体住所登记规定 |
| 法定代表人任职资格 | 失信被执行人限制、公务员禁业 | 《公司法》第178条 |
| 股东资格审查 | 外资准入限制、一人公司限制 | 《外商投资准入负面清单》 |
| 董事监事高管任职 | 信用记录、曾任公司破产责任 | 《公司法》第146条 |
| 章程定制 | 个性化条款设计（出资期限、表决权、利润分配） | 《公司法》 |
| **特殊：一人有限公司** | 限制一个自然人只能设立一个 | 《公司法》第58条 |
| **特殊：分公司设立** | 总公司经营范围覆盖、负责人任职 | 《公司法》第173条 |
| **来料加工/委托加工** | 系统无"来料加工"独立条目，用对应制造/加工条目覆盖 | 见本节下方「经营范围规范表述查询」 |

#### 经营范围规范表述查询操作流程

**当客户问具体经营范围怎么写时，必须上 jyfwyun.com 实时查，不依赖模型记忆。**

操作步骤：
1. 打开 https://jyfwyun.com 并选择业务所在省份（如江苏省）
2. 在搜索框输入客户业务的核心关键词（如"服装加工""食品销售""运输"）
3. 查看匹配结果，重点关注 **条目代码**、**许可情况**（一般事项/前置许可/后置许可）和 **说明**
4. 点击条目名称可查看详细对应行业及更精确的说明
5. 如有多个相关条目，可点击"添加"按钮选入右侧列表→"生成结果"

**已知的常见经营模式 ↔ 规范条目对照（已验证）：**

| 客户描述的业务 | 规范条目（代码） | 说明 |
|--------------|----------------|------|
| 来料加工服装（面料辅料客户提供，只提供劳务） | 服装制造（C6001）— 一般事项 | 系统无"来料加工"独立条目，服装制造已涵盖 |
| 服装辅料生产 | 服装辅料制造（C6006）— 一般事项 | 范围较窄，只做辅料时用 |
| 帽子/手套/围巾/袜子等小件加工 | 服饰制造（C6002）— 一般事项 | 对应行业183 |

**重要规则：**
- 经营范围系统里 **没有** "来料加工""委托加工"作为独立经营范围条目——来料加工是一种业务形式（结算方式），不是经营范围类别。直接用对应制造/加工条目即可
- 所有结果以 jyfwyun.com 实时查询为准，上述对照表仅作参考，每次仍须核实

### 3.2 公司变更（场景B）

| 子场景 | 关键审查点 | 参考法规 |
|--------|-----------|----------|
| 名称变更 | 新名称合规性同新设 | 《企业名称登记管理规定》 |
| 经营范围变更 | 新增许可项目需先取得许可证 | 《市场主体登记管理条例》第29条 |
| 住所变更 | 跨区域变更（同区vs跨区vs跨市） | 各地规定 |
| 法定代表人变更 | 新旧任交接时间节点 | 《公司法》第10条 |
| 注册资本变更（增资） | 认缴vs实缴、引入新股东 | 《公司法》第43条 |
| 注册资本变更（减资） | 登报公告45天、债权人通知 | 《公司法》第177条 |
| 股东变更 | 股权转让+税务完税前置 | **详见`suzhou-equity-transfer-guide`** |
| 董事/监事/经理变更 | 备案制，市场监管局 | 《市场主体登记管理条例》第24条 |
| 公司类型变更 | 有限公司↔股份公司 | 《公司法》第9条 |
| **特殊：减资（新公司法生效后）** | 形式减资vs实质减资、简易减资条件 | 2024年《公司法》第225条 |

| 子场景 | 关键审查点 | 参考法规 |

### 3.4.1 子模块 D3·食品经营许可/小餐饮备案（江苏 · 面积分水岭60㎡）★

> 设备设施清单（餐饮店/小作坊/小餐饮要买哪些设备）：见 references/食品经营-各业态必要设备设施清单.md（【网络来源】客户问办证要买哪些设备时优先调用）。

**核心结论：江苏餐饮服务经营者面积≤60㎡ = 小餐饮，实行【备案管理】（小餐饮信息公示卡），不办食品经营许可证。** 客户问"XX平米能不能办食品经营许可证"时，先判面积。

| 业态 | 面积 | 路径 | 依据 |
|------|------|------|------|
| 餐饮 ≤60㎡ | 小餐饮 | 营业执照 + 备案 → **小餐饮信息公示卡**（无需许可证） | 江苏省人大《关于加强小餐饮管理的决定》（2020通过，2025.1.14修正） |
| 餐饮 >60~≤500㎡ | 中型餐饮 | 食品经营许可证 | 苏市监规〔2024〕2号附件1 |
| 餐饮 >500~≤3000㎡ / >3000㎡ | 大型/特大型 | 食品经营许可证 | 同上 |
| 食品销售 ≤60㎡ | 小食杂店 | 备案管理 | 同上 |
| 食品销售 >60~<200㎡ / ≥200㎡ | 食杂店/商场超市 | 食品经营许可证 | 同上 |

**小餐饮做外卖（关键）：**
- 持公示卡并**标注网络经营** → 可从事网络餐饮服务（《决定》第八条）
- 平台必须接受公示卡入网（常州《网络餐饮服务食品安全管理若干规定》第四条为江苏通行口径）
- 小餐饮禁项：生食类食品、冷加工糕点、自制以生鲜乳为原料的饮品；面条浇头只要热制（卤/烧/爆炒）即合规，冷荤类浇头（白切鸡、凉拌菜）需专间、小面积店办不了
- 备案与营业执照一窗受理；备案不收费不验资

**"必须堂食"是误传——政府和平台都没这规定：**
- 市监总局令第36号《网络餐饮服务食品安全监督管理办法》（2018.1.1）第四条：入网只需【实体经营门店 + 食品经营许可证】——实体门店≠堂食座位
- 市监总局令第123号《网络餐饮服务经营者落实食品安全主体责任监督管理规定》（2026.6.1施行，史上最严）：**允许无堂食**，但必须显著标"无堂食"标识；网店名=门面招牌；主页公示证照/地址/门店实景；平台实地核查+每6个月核验；假冒堂食最高罚10-20万
- 平台（美团/饿了么/京东/淘宝闪购）：纯外卖店可入驻，须真实标注，用"一镜到底"视频审核
- 客户话术：做外卖必须有实体门店（非虚拟地址/黑作坊），无堂食合法但要亮明身份

> 详细速查（含法规文号、15㎡面条店案例、客户话术）：`references/食品经营许可-小餐饮备案-外卖监管.md`

| 变化点 | 旧法 | 新法 | 实操影响 |
|--------|------|------|---------|
| 出资期限 | 无上限 | **全体股东认缴出资自公司成立起5年内缴足** | 存量公司也受过渡期约束（3年过渡+5年期限） |
| 董事催缴义务 | 无 | **董事有催缴出资义务，未催缴承担赔偿责任** | 董事个人风险上升 |
| 丧失股东资格 | 无 | **未按期出资→催缴→失权通知→丧失未出资部分股权** | 股东出资刚性约束 |
| 简易减资 | 仅一般减资 | **增设简易减资制度**（仅减少注册资本弥补亏损） | 无债权人通知程序，但须公示 |
| 股份公司一人制 | 须2人以上 | **允许1人股份公司** | 一人公司选择更多 |
| 法定代表人 | 董事长/执行董事/经理 | **代表公司执行事务的董事或经理** | 范围变化 |
| 关联交易 | 有限规定 | **强化关联交易规则**（必须报告+决议+回避） | 关联交易合规要求提高 |
| 简易注销 | 有个别试点 | **明确写入法律**（公示时间缩短） | 全国统一标准 |

> **注意：** 新公司法2024年7月1日起施行。存量公司（2024年7月1日前设立）有3年过渡期（至2027年6月30日）调整出资期限至5年内。**截至2026年7月，距过渡期截止仅剩约1年**（苏州政务网已发布倒计时提醒），这是目前客户咨询最多的问题。

### 5.6 苏州"企业注销"操作路径（来源：sz.jszwfw.gov.cn → 法人服务 → 注销专区）

**简易注销（适用条件：未开业或无债权债务）：**
1. 国家企业信用信息公示系统公告 — 公示期20天
2. 公告期满无异议 → 提交简易注销申请
3. 税务部门自动核查（无欠税/未结事项→即时通过）
4. 市场监管局核准注销
5. ✕ 不适用情形：有未结税务事项、有债权债务、有行政处罚未履行

**一般注销流程：**
1. 成立清算组 → 企业信用信息公示系统公告45天
2. 清算组备案（线上可办）
3. 税务注销 → 取得《清税证明》（或符合即办条件）
4. 社保/公积金账户注销
5. 海关报关单位备案注销（如有进出口业务）
6. 缴销营业执照（线上缴销或窗口缴销）
7. 银行账户注销（客户自行到银行办理）

**非正常户处理（常见客户痛点）：**
- 未经营的公司长期不报税 → 税务变成非正常户
- 必须先解除非正常户 → 补申报 → 补缴罚款 → 才能启动注销流程
- 各地税务窗口对解除非正常户的口径有差异

## 七、常见陷阱与注意事项

| # | 陷阱 | 说明 | 应对 |
|---|------|------|------|
| 1 | 经营范围写得太窄 | 客户只写当前要做的业务，不预留发展空间 | 建议多写1-2个预见方向 |
| 2 | 地址不合规 | 住宅改商用、违章建筑、口袋地址过期、宅基地用途限制 | 确认场地性质 + 街道办备案文件；**宅基地注册先查实战经验库**（纯贸易可/加工+许可不可） |
| 3 | 出资期限写得不合理 | 新公司法5年上限，写太长无法备案 | 跟客户说明新法要求 |
| 4 | 注册资本过高 | 写1000万撑面子，到减资时麻烦 | 建议客户量力而行 |
| 5 | 分公司经营范围越界 | 分公司经营总公司经营范围以外业务 | 分公司不能超出总公司经营范围 |
| 6 | 简易注销不满足条件 | 有未结税务事项、有债权债务、有被处罚 | 先查税务状态再走简易 |
| 7 | 许可证前置vs后置搞混 | 以为先注册后办证，但许可项目需先拿许可证 | 前置许可→先办证后注册；后置许可→先注册后办证 |
| 8 | 外商投资行业误判 | 以为没有外资方，但穿透后关联方有外资背景 | 核查股东结构+负面清单 |
| 9 | 香港公司在内地直接经营 | 部分客户以为注册了香港公司就能在内地做业务 | 需要WFOE或代表处 |
| 10 | ⚠️ **使用过时法规** | 2024年公司法刚改，很多网上文章还是旧法内容 | 每次回答前官方源核实 |
| 11 | ⚠️ **以为"来料加工"要单独写进经营范围** | 客户描述来料加工/委托加工模式，觉得需要在经营范围里写"来料加工" | 经营范围系统无"来料加工"独立条目，用对应制造/加工条目（如"服装制造"）即可覆盖；来料加工是结算方式不是经营范围类别 |

### 经营范围查询工作流

2. 在搜索框输入经营活动关键词（如"服装加工""食品""运输"）
3. 查看搜索结果 → 确认条目代码 + 许可情况（一般事项/前置/后置）
4. 点击条目查看详细说明和对应行业
5. 多条可添加后拖动排序 → 点击"生成结果"查看规范表述
6. 如不确定 → 建议向当地市场监管部门咨询
