# 城市破播 — 苏州参考手册

> 同层级第五大类型。城市招商 × 财税获客，苏州当主角，生意做钩子。
> 徐总 2026.9.20 确立。

## 一、本类型定位速记

- 信任源 = 苏州（城市实力），不是"我做了多少年"
- 每一条 = 一个真实苏州事实（政策/数据/效率/举措）+ 拆给创业者听 + 落回自家生意
- 目标人群：在苏州 / 计划来苏州 / 外省迁苏 / 外资来华的中外创业者
- 四门生意：公司注册登记、代理记帐、财务外包、合规账

## 二、黄金三段（40s）节奏

```
0-5s   砸真实苏州数字/政策（热点第一句，不慢热）
5-18s  拆这条政策：对"想在苏州开公司的人"意味着啥、怎么落地
18-28s 映射观众：你是不是该注册苏州 / 你是外来创业者 / 公司要不要迁苏
28-30s 自然CTA：你来苏我带你办 / 评论区问我苏州政策 / 私信帮你算
```

## 三、政策链条（都可做文案，文号必查证）

国家 → 江苏 → 苏州市 → 各县级市/区（昆山/张家港/常熟/太仓/吴江/吴中/园区/高新）。
凡落实到苏州的，都可入文。引用标注官方文号，宁缺勿错，严禁AI幻觉。

## 四、可直接用的开篇钩子（2026 素材库底稿）

1. **低空经济**（钩子）：「苏州要开 3-5 条到周边机场的短途航线了——不是北上广，是苏州。」→ 拆：低空经济实施方案 2024-2026 + 促进条例 → 落点：想进低空赛道的公司，注册+资质+财务合规，会计帮你捋
2. **营商环境 9.0 版**（钩子）：「苏州营商环境又升级了，这版 28 个方面 90 项具体举措。」→ 拆：一窗受理、集成办理、整治吃拿卡要 → 落点：办执照不跑断腿，正规合规我敢跟你签
3. **创业补贴**（钩子）：「苏州创新创业领军人才，最高给 500 万项目资助 + 200 万购房补贴。」→ 拆：分档、申报窗口 → 落点：人才落地要开公司，账要合规才拿得到补贴→财务外包
4. **外企利润再投资**（钩子）：「苏州留外资，利润再投资有政策——三年要占投资超 25%。」→ 拆：资金/荣誉/涉税服务 → 落点：外资来苏设公司/再投资，涉外账务我熟
5. **个体工商户 200 万户**（钩子）：「苏州个体户破 200 万户了。」→ 拆：开店门槛、税负、灵活用工 → 落点：注册个体户/转公司，账怎么做，本地创业者
