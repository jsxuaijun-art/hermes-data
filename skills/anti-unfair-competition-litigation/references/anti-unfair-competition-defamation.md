# 反不正当竞争 · 商誉诋毁（商业诋毁 / 虚假宣传）诉讼研判 知识库

适用：客户（多为经营者）被同业在官网/短视频/自媒体上发"测评""对比""排行榜"类内容贬损，
问"能不能告赢""赔多少""公证费谁出"。也适用于**起草或复核**此类起诉状/代理词。

---

## 一、第一道坎：2025 修订已重编条文号（旧编号文书会被挑瑕疵）

- 2025-06-27 第十四届全国人大常委会第十六次会议**第二次修订**，**2025-10-15 施行**，全文 41 条（旧法 33 条）。
- 判断口径：**侵权行为发生在 2025-10-15 之后 → 必须用新编号**；之前的可引旧编号（或注明"行为时法"）。

| 主张 | 2019 旧 | 2025 新 |
|---|---|---|
| 混淆行为 | 第6条 | 第7条 |
| 商业贿赂 | 第7条 | 第8条 |
| 虚假宣传 | 第8条 | **第9条**（新增"虚假评价"、"帮助其他经营者"） |
| 侵犯商业秘密 | 第9条 | 第10条 |
| 有奖销售 | 第10条 | 第11条 |
| **商业诋毁** | 第11条 | **第12条**（对象由"竞争对手"扩为"其他经营者"；新增"**指使他人**编造、传播"入责） |
| 互联网专条 | 第12条 | 第13条（新增数据/算法/平台规则、非法获取数据） |
| **民事赔偿 + 合理开支** | 第17条 | **第22条** |
| 商业诋毁行政罚则 | 第23条 | 第28条（10万–100万；情节严重 100万–500万） |

新第 12 条原文：**"经营者不得编造、传播或者指使他人编造、传播虚假信息或者误导性信息，
损害其他经营者的商业信誉、商品声誉。"**

⚠️ 新第 22 条的**法定赔偿上限（500万）字面只列第 7 条混淆、第 10 条商业秘密**。
商业诋毁/虚假宣传能否类推适用，取决于修订后的司法解释——引用前必须核对现行司法解释，
别照搬旧法时代的类推结论。

全文权威来源：国家知识产权局转载中国人大网 `https://www.cnipa.gov.cn/art/2026/5/20/art_104_206437.html`
（可直接 `web_extract` 拿到全部 41 条原文）。

## 二、商业诋毁四要件（2025 新法下的司法认定标准）

1. **实施主体是经营者** —— 新法已**不要求**"竞争对手"关系，同业之外亦可。
2. **编造、传播虚假信息或误导性信息** —— 无样本、无方法、无来源的百分比/排名/投诉率数字即典型。
3. **指向特定经营者** —— **可识别即可，不要求指名道姓**（见第四节）。
4. **已经或可能损害商业信誉、商品声誉** —— **不要求实际损失**；公开网络传播即推定"足以造成损害"
   （虎牙诉斗鱼、网易诉灵犀等采"可能"标准）。

## 三、最高法典型案例 = 裁判文书网不可爬时的最佳"类案"来源

年度典型案例有最高法背书、带案号、可 extract，比零散律所文章强得多。

**渠道（按好用程度）：**
1. `cclp.sjtu.edu.cn`（上海交大竞争法研究中心）——转载**全文 + 案号 + 典型意义**，最好用
2. `ipc.court.gov.cn`（最高法知识产权法庭）——发布通稿
3. `csrc.gov.cn` / 地方法院网转载页

**《2026年人民法院反不正当竞争典型案例》（2026-09-10 发布，9件）**——"测评类诋毁"三件直接可用：

- **案例六 利用AI虚构他人产品测评文章搭车引流构成不正当竞争**（江苏无锡新吴区法院）
  以同行产品为词根 → AI 批量生成标题、AI 自动生成"介绍点评"文章 → 发在自有官网 →
  前后植入自家产品链接 → 靠搜索引擎自然检索引流。认定构成不正当竞争。
  → **"AI生成竞品测评 + 植入自家链接 + SEO引流"型案件的镜像判例。**
- **案例八 恶意剪辑他人产品测评视频贬损竞争对手构成商业诋毁**
  一审：重庆自由贸易试验区人民法院（2026）渝0192民初19081号。
- **案例九 能够识别对比商品来源的不实比较广告构成商业诋毁**
  山东东营中院一审、山东高院二审维持，**判赔 30 万**。视频**已遮盖**对比品牌标识，
  但消费者凭外包装识别出指向对象；宣称"含量都不达标""是淀粉做的"**无权威检测、
  行业标准等专业依据支撑** → 构成虚假信息、超出正常评论合理限度 → 商业诋毁成立。
  → **"指而不名 / 打码"仍构成诋毁的第一顺位依据。**

**《2025年人民法院反不正当竞争典型案例》**：以"震虎价"为名的低价营销活动中，编造、传播原告为
不良市场经营主体的虚假/误导性信息 → 商业诋毁成立（上海闵行法院一审），判赔 500 万（含合理开支）。

## 四、"指而不名"仍构成诋毁 —— 论证模板

- **核心命题**：商业诋毁只要求"相关公众能够识别出指向对象"，不要求指名道姓（案例九）。
- **识别证据清单**：
  ① 商号唯一性（同城无第二家同名同业）——查"国家企业信用信息公示系统"；
  ② 原告**开票记录**证明实际主营（对抗"主行业非同业"抗辩）；
  ③ 文章把该主体与**真实存在的机构并列**作评测/对比对象（公众明显识别为真实市场机构）；
  ④ 平台"大家都在搜"提示、评论区用户点名（案例九采信）。
- **反向加分**：故意采用"指而不名 / 遮盖标识"的写法，本身可作为**主观恶意**的论据。

## 五、常见抗辩与回应

| 被告抗辩 | 回应 | 依据 |
|---|---|---|
| 没点名，针对的是不特定对象 | 可识别即特定；指而不名反证恶意 | 案例九 |
| 内容由 AI / 第三方生成，我们只是平台 | 发布者即经营者，AI 生成不豁免；新法第12条"指使他人编造传播"亦担责 | 新反法第12条 |
| 属正当商业评论 / 消费者监督 | 无权威依据的否定性**事实陈述** + 超出合理限度 = 诋毁 | 案例九 |
| 原告主行业非同业、无竞争关系 | 按实际经营范围与开票认定；新法已不要求竞争关系 | 新反法第12条 |
| 未造成实际损失 | 不要求实际损失，公开传播即推定 | 多地"可能"标准 |
| 仅是转载 / 已删除 | 删除不免除既往传播责任，可减赔不脱责 | 反法第22条 |

## 六、合理开支（公证费 / 律师费 / 存证费）主张方法

- **依据**：新反法**第22条第2款**"赔偿数额还应当包括经营者为制止侵权行为所支付的**合理开支**"
  —— **特别法授权**，优于普通民事案"律师费各自承担"。
- **支持率高的三条件**：①已**实际办理**并取得正式发票/收费票据 **+ 付款凭证**；
  ②金额合理（网页保全公证常见 **1000–3000 元/件**）；③在诉请中**单列**为"合理开支"，并附服务合同。
- **正面案例**：最高法公报"某安居门业"案，公证费 **172,528.28 元全额支持**。
- **反面教训**：上海知识产权法院某案，取证费因**未提供实际支付证据**而不予支持。
- **诉讼受理费**：依《诉讼费用交纳办法》**第29条**由败诉方负担（部分胜诉按比例）。
  行为保全/证据保全费同理可列。
- 电子存证（时间戳/哈希固证 SHA256、沪E存类平台）成本低但权威性弱于公证：可作为诉前快速固证，
  **最终仍要办正式公证并留票据**，否则可能被酌减。

## 七、竞合与"重复评价"风险

- 同一行为常同时落入**虚假宣传（第9条）**与**商业诋毁（第12条）**。
- 上海知识产权法院判例指出：认定商业诋毁后又认定虚假宣传**存在重复评价**问题。
- **建议**：以**商业诋毁为主案由**，虚假宣传作补充/择一；诉请金额与合理开支**只主张一次**，
  不按案由各算一份。

## 八、立案前的程序硬伤清单（务必先核，否则先输在程序上）

1. **被告法定代表人真实姓名** —— 文书里若出现占位符/AI 生成的姓名，会导致无法送达、
   可能不予立案。查"国家企业信用信息公示系统"。
2. **关联被告是否为独立法人**、与操盘主体的股权/人员/地址混同证据 —— 决定**连带责任**成立与否
   （主管主体单独判责不受影响）。
3. **商号唯一性查询 + 原告主营开票记录** —— "指而不名"要件的核心证据。
4. **管辖**：涉不正当竞争民事案件由**知识产权法庭集中管辖**（如苏州知识产权法庭/苏州中院）。
5. **诉讼时效**：3 年，自知道或应当知道之日起算；持续发布的从行为终了起算。

## 九、胜诉概率与开支支持概率的研判框架（客户口径）

把结论**拆成四问**分别给区间 + 依据，不要只丢一个笼统数字：

1. **侵权认定概率**（判停止侵害 + 消除影响）—— 看四要件是否踩满、有无对应最高法典型案例。
   实务参考值：要件齐备 + 有对口典型案例时约 **80–85%**。
2. **判赔金额预期** —— 实际损失几乎无法举证，多走"合理开支 + 法院酌定"；中小经营主体案常见
   **数万至数十万**区间（对口案例九判 30 万），巨额酌定只出现在重大/知名品牌案件。
3. **各项开支支持概率**（公证费/律师费/存证费）—— 看票据齐全度与金额合理性；票据齐全时
   公证费支持率约 **85–90%**，缺凭据则显著下降。
4. **程序风险**（主体信息、送达、管辖、竞合、时效）—— 单独拉低整体胜算，须单列提示。

**必须写进交付物的免责与提醒**：本研判非代理意见；**法条序号、主体信息、赔额区间请在正式起诉前
由执业律师最终确认**。

## 十、交付格式（本用户偏好）

- 结论**先给两个数**（胜诉概率 / 公证费由被告承担概率），再展开理由——用户明确要的是概率判断
  而非法理综述。
- 单列一节"**必须先改的东西**"（法条序号、被告主体信息），因为客户手上已有的起诉状常引旧法编号。
- 风险点要**诚实列出**（含会拉低胜率的项），并配"操作路线图（按周排序）"。
- 成品落 .docx，交付到案件材料所在目录（本用户惯例：`D:\OneDrive\Desktop\名誉侵权（商业诋毁）\`），
  终端里同步给要点摘要。
- 生成 .docx 时注意：Python 字符串里嵌中文引号会引发 SyntaxError——脚本先 `write_file` 到
  `/tmp/*.py` 再执行，正文里的引号用替换函数（如 `<<`→“、`>>`→”）处理。

## 十二、改稿/重生成阶段（研判交付后的"第二轮"任务）

研判交付后用户几乎总会直接说："根据你上面的文字，尤其是'会拉低胜诉概率、必须提前处理的风险'，
重新生成民事起诉状 / 诉讼策略与抗辩应对预案。" 这不是重复任务，而是**从"分析"转入"按风险点改稿"**
的第二阶段，有独立的工作流：

1. **逐字段审计原稿**：把当事人信息（法定代表人姓名、统一社会信用代码、住所地、金额、案号/时间）
   分成"已核实可引用"与"占位/AI 生成"两堆。典型占位形态：脱敏值（`TT`）、AI 假名（"赵帅甲"）、
   全角下划线 `__________`。
2. **新稿另存新名**（`_修订稿v3`），落原稿同目录，**不覆盖原件**。
3. **未定项写 `__________` + 同行 `⚠` 标注**，写明核实渠道（国家企业信用信息公示系统等）。
4. **生成后回读核对**（本类任务最贵的实操课）：本次重生成时，原稿原告法定代表人"TT"这个脱敏占位
   被原样照搬进新起诉状的抬头和具状人两处——回读 .docx 才发现并修正。教训：**linter 只查语法，
   不查内容**；必须 `read_file` 读成品全文，逐字段核对抬头人、具状人、落款、诉请金额、证据清单条数。
5. **敌方信息升级写入诉请与证据清单**：新确认的侵权 URL（本次 7416972〔2026-06-06〕、
   8052852〔2026-06-26〕、71so.cn 8052894 镜像）同时进"诉讼请求第1项"与"证据清单第6项"，
   别只在一处更新。
6. **双案由主辅化**：以商业诋毁（第12条）为主案由、虚假宣传（第9条）备位/补充，诉请金额只主张一次，
   并明确写出"不分别计算赔偿"，堵住"重复评价"质疑。
7. **终端交付末尾单列"提交法院前你必须亲手补的 N 处"清单**（打卡式，不给用户留"漏填"空间）。

本次 v3 起诉状实际改动（可作改稿 checklist）：
①法条全部换新编号（9/12/22/28）；②双案由主辅；③三处 URL 写入诉请+证据清单；
④新增"指而不名"专段 + 引用最高法 2026 典型案例（案例六/九）与 2025"震虎价"案；
⑤新增"共同被告的选择"节（被告二无混同证据则撤回，聚焦主被告，不拖累立案）；
⑥"AI 生成免责"封堵（自有官网发布=经营者责任）；⑦赔额表述改为"按第22条实际损失/侵权获利+
合理开支+法院酌定"，不冒称 500 万上限；⑧证据清单 12 项（新增商号唯一性、开票记录、参保公示、
类案打印件、三落点公证）。

**python-docx 生成技术坑（本次实测报错）**：
- 循环变量名与表格 cells 赋值变量同名：
  `for a,b,c in rows:` 内写 `c = table.add_row().cells` → `TypeError: 'in <string>' requires
  string as left operand, not _Cell`。cells 变量改个名（如 `cc`）即好。
- 中文引号/长文本建议先 `write_file` 到 `/tmp/*.py` 再执行（沿用第十节做法）。
- 表格样式用 `table.style='Light Grid Accent 1'` 自带边框，比手画网格省事。
