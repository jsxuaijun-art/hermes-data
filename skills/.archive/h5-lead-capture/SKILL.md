# H5 留资页 / 落地页获客链路

> 场景：客户从公众号菜单（或短视频/朋友圈/二维码）进入 H5 表单页，填写姓名+电话+需求，
> 提交后通过企微推送到**内部群**，团队跟进成交。用户（徐总/盈信）已确认此链路，2026.8 设计定稿。

## When to Use

- 用户要搭「留资页/落地页/免费咨询表单/H5 表单」打通获客链路
- 用户说「客户点菜单填信息，我在企微收到」这类需求
- 从抖音/视频号/公众号/朋友圈把意向客户承接进企微私域的收口页

## 架构（已验证可行）

```
客户 → 公众号菜单「免费咨询」(跳转网页, 需已认证+备案域名)
        ↓
   H5页面 (ECS nginx, 手机端表单: 姓名/电话/需求)
        ↓ 提交
   Python后端 (ECS, 复用企微API)
        ↓
   企微内部群收到: 📩 新客户咨询「姓名/电话/需求」+ 跟进提示
        ↓
   团队跟进 → 成交
```

注意：H5 落地页 ≠ 微信小程序（financial-mini-program skill）。
小程序需微信审核、受微信生态限制；H5 落地页是普通网页，nginx 托管即可、部署快、无需审核。
抖音/视频号场景如需「留资」也可用 H5 链接承接。

## 运营引导策略（让客户愿意填）

1. **降门槛**：只问 3 个字段（姓名/电话/需求），绝不问公司名/税号等敏感信息；
   需求做**选择题**（□注册公司 □代理记账 □税务合规 □财务外包 □其他）比填空好点。
2. **利益前置**：留资即送《企业税务风险自查清单》PDF 或一次免费一般性咨询；或「24h 内顾问回电」制造紧迫感。
3. **内容引流**：公众号文章尾部 CTA 加一句引导（「不确定情况？点菜单免费咨询，3分钟说清需求，顾问免费诊断」）；
   短视频/朋友圈同步话术。
4. **企微群承接**：留资通知发到专门的「客户咨询」内部群（非全员群），配跟进话术模板 + 跟进结果登记。
5. **数据复盘**：每周看留资量（优化菜单位置/话术），每月看留资→成交转化率。

## 待确认清单（开工前必须问清）

1. 公众号类型 + 是否认证（订阅号已认证 = 菜单可跳网页 ✅）
2. H5 的域名/备案情况（跳转网页必须合法 HTTPS 地址）——**最关键前提**
3. 内部群通知方式：chatid（自建应用）还是 webhook key（群机器人）
4. 需求字段格式（若用户已让 WorkBuddy 设计，要设计稿文件或截图）
5. 留资奖励具体送什么
