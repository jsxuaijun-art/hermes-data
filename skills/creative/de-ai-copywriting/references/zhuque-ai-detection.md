# 朱雀AI检测（腾讯）— 实测数据与降AI率手法

## 定位
- 朱雀AI = 腾讯 AI 内容**检测**工具（不是"去除"工具）。官网：https://matrix.tencent.com/ai-detect/
- 免费在线，每次约5次检测额度；自动化访问触发**交互式滑块/点选验证码**。
- 主模型（deepseek）无 vision，无法自动过朱雀验证码 → 检测环节由用户手动操作。正确流程：备好纯文本 → 用户贴进朱雀 → 用户手动过滑块 → 用户把 AI率/报告 发回 → 按结果决定精修。

## 工作流（徐总确立 2026-08-21，本会话实测两轮）
1. 写稿 → 去AI味（必须结构层+语言层双层，见下）
2. 出两版：①原稿 + ②去AI味版，存「公众号素材」+ 桌面（docx）
3. 给链接+纯文本 → 用户检测（手动过验证码）→ 发回 AI率 或 报告文件路径
4. 按 AI率 决定是否再精修；达标才配图发布

## 用户文件路径默认（徐总确立 2026-08-21）
- 用户只给一个文件名 → 完整路径默认 = `D:\OneDrive\Desktop\<文件名>`（WSL: `/mnt/d/OneDrive/Desktop/`），不要猜其他路径。
- 用户说"检测结果/修改后文本见路径 X" → X 就是朱雀检测结果文件，直接 read_file 读取（PDF 会自动转文本）。

## 报告单解析（PDF 转文本格式）
- 抬头：《朱雀AI生成检测报告单》，含检测时间（如 2026/8/21 17:10:28）
- 表格：每片段 → 占全文比例 / 占字符数 / AIGC值
- 阈值：AIGC 0-0.5 人工特征；0.5-0.99 疑似AI；0.99-1 AI特征
- 表后附每个片段实际命中文字，可核对是哪段被判 AI
- 0.9+ ≈ 整篇判 AI，必须结构性重写，不要只换词再交差

## 实测数据（2026-08-21，《税收洼地返税叫停》公众号文）
- **V1（仅换词+拆句+口语化）**：片段1 AIGC **0.9116**（占59%），片段2 **0.9969**（占41%）→ 失败，整篇判 AI。
- 结论：表层措辞改写过不了朱雀；它看的是句法节奏、篇章结构、词汇分布。
- V2（结构层改写：场景对话开头+打破排比/对称+口语感叹+数字口语化）：已交付待用户实测，**结果未回传前不得宣称已达标**。

## 降AI率手法（V2 方向；每轮必须再实测，AI率说话）
- 开头：用**真实场景 + 老板原话对话**（如"江姐，XX园区说我去注册，税能返我四成，靠谱不？"），不要宣言式直开。
- **打破 `①②③④` 整齐排比** → 口语"一是…二是…三是…"。
- **打破"一方面…另一方面…"对称句** → "第一…第二…"+ 插入感叹（"你品品，833件啊"）。
- 口语感叹词/口头禅：你品品、你猜怎么着、我给你翻译、说白了、那才叫…
- **数字口语化+自我纠正**：129万户 → "一百二十九万户" 再补一句"对，129万户，不是129家"。
- 短句独立成段 + 长短句交错；避免全文句长均匀。
- 若结构层改写后仍不过（隐形机器痕迹，下一轮重点）：反问句过密、句子长度过于均匀、情绪递进太整齐。
