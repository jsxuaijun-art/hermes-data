# 中国政府网站检索/抓取 实操 (WSL+China 网络)

2026-08 实测。目标场景：定位地方财政局/政府的通知公文（如"代理记账行业自查""专项整治"等），
寻找原文链接。结论按可靠程度排序，避免重复踩坑。

## 一、搜索引擎在国内政务检索的现状（WSL，无代理）

| 通道 | 结果 | 备注 |
|------|------|------|
| **cn.bing**（curl 和浏览器均试） | ❌ 中文政务长查询基本不可用 | 分词错乱：把"代理记账""超出胜任能力"等拆错位，返回 bilibili/豆包等完全无关结果；加引号、`&ensearch=0/1`、`cc=cn` 等参数也不修复。**别浪费时间在这上面。** |
| Baidu / Google / DuckDuckGo | ❌ 不可达 | DNS/网络层 |
| **搜狗 sogou.com**（requests+bs4 可抓） | ✅ **能用，中文政务检索第一选择** | `https://www.sogou.com/web?query=<urlencode>` requests 返回 200 全文。**注意**：浏览器打开会触发 antispider 人机验证页，但 requests 直抓能拿到结果。 |
| **360 so.com**（requests+bs4 可抓） | ✅ **能用，并列第一选择** | `https://www.so.com/s?q=<urlencode>` requests 返回 200 全文。支持 `site:czj.sh.gov.cn 关键词` 站点限定，可精确定位某 gov 域名内的公文。 |

**关键结论**：通用搜索引擎里只有 **sogou + 360 能稳定抓中国政务**。cn.bing/百度/Google 别试了。
两个都能 requests+bs4 直接解析 `.vrwrap/.rb`（sogou）或 `li.res-list`（360）里的标题+摘要+来源域名。

### 360/搜狗 抓取要点
- 360 结果解析：`li.res-list` 里的 `h3 a` 标题、`cite` 来源域名、整条文字摘要。**摘要（S 段）常直接含公文原文片段**，能据此判断命中与否，不必每条都点开。
- 搜狗结果解析：`.vrwrap/.rb` 里的 `h3 a` 标题 + 整条文字。摘要同样含原文片段。
- ⚠️ **sogou/360 的页面标题链接是带签名跳转**（so.com/link?m=... 或 /link?url=...），**requests 直接 GET 该跳转通常返回 400**（需浏览器 cookie/JS 上下文），不要尝试 requests 解链。
- **拿真实目标 URL 的办法**：给 360/搜狗结果末尾加 `site:目标域名 关键词` 命中后，用**浏览器**打开该搜索页，`browser_navigate` 后**点击结果标题**，再用 `browser_console` eval `window.location.href` 取到真实落地 URL（如 czj.sh.gov.cn 的文章页）。这是从搜索引擎跳转链还原 gov 原文 URL 的可靠路径。
- 360 结果页会在顶部给出 `http://www.czj.sh.gov.cn`、`https://www.czj.sh.gov.cn/jqreport/` 等**站点快捷链接**（"为您推荐/相关搜索"区），可直接导航到官方入口。

## 二、上海市财政局 czj.sh.gov.cn（requests 可直抓，部分限制）

- **首页/文章详情页能 requests 直抓**（`r.encoding = r.apparent_encoding or "utf-8"` 后 BeautifulSoup 解析可行）。
- ⚠️ **栏目列表页（如 `…/gsgg_8929/index.html`、`…/hj_9035/dljz_9042/index.html`）返回的是一段 freemarker 模板错误**：
  `Template not found for name "json://{\"siteId\":\"0017\",\"category\":\"channel\",...}"`，无任何 `<a>`。
  这类列表路由不是 `index.html`，requests/浏览器都拿不到列表。**定位新公文靠「首页最新公告」+「搜狗/360 site: 限定」两个入口，别硬啃列表页。**
- ⚠️ **站内搜索接口 `was5/web/search?channelid=209150` 返回 404**（首页 form action 指向它，但后端失效/被拦）。别指望它。`www.czj.sh.gov.cn/jmreport/search...` 这类 jmreport 接口也一样基本废。
- **文章 URL 模式**：`https://czj.sh.gov.cn/zys_8908/zcfg_8983/zcfb_8985/hj_9035/dljz_9042/<YYYYMMDD>/xxfboswf000000<N>.html`
  其中 `hj_9035`=会计专栏，`dljz_9042`=代理记账子栏。首页能提取到最新公告的真实文章 URL，是找最新通知的最快入口。
- 首页搜索框 form action 指向 http（`http://czj.sh.gov.cn/was5/...`），非 https，也 404。

## 三、上海市政府统一检索 search.sh.gov.cn（推荐，政务权威聚合）

这是上海市官方全站搜索，聚合"办事事项 + 信息公开/政策发布"，是定位地方公文的**首选**。

用法要点（实测）：
- **必须用浏览器工具**（结果区 JS 渲染，requests 只能拿到 198KB 的壳、不含结果）。
- `browser_navigate("https://search.sh.gov.cn/search?text=<urlencode关键词>")` 能带 query 直达。
- 结果按"办事事项/要闻动态/信息公开"分类 tab 混排；要公文就重点看**信息公开**类；可用"时间排序"拉最新的。
- 结果链接是加密 token 的 detail 页（`/detail?token=...`），同一条会重复出现多次，去重按标题+来源 URL 判。
- ⚠️ 它的**索引不全/对新政策滞后**：测过多组关键词，能返回历年《上海市财政局关于加强代理记账机构事中事后综合监管的相关措施》《推进代理记账行政审批事项改革》等，但**搜不到当年新发的专项自查通知**。此时改用「sogou/360 site: 限定」或人工补位（见下），不要无限加关键词硬搜。

## 四、gov.cn 子域（财政部 sousuo.gov.cn、财政部官网等）

- DNS 不可达 / 被 WAF 拦截，政策原文无法可靠实时抓取。不要依赖。
- **例外**：`app.gjzwfw.gov.cn`（国家政务服务平台）子域部分页面可访问。

## 五、这类"行业自查/专项整治通知"的现实规律（重要判断）

- 中国的地方"行业自查通知"（代理记账、会计师事务所等）常由**市级财政部署、各区财政分别下发**，
  或直接**定向发到机构**（纸质/企微/行业协会群），**未必有公开网页**。
- 特征判断法帮你把范围缩小：文号、发文机关（市/区财政局）、"虚假承诺""超出胜任能力""XX月XX日前提交自查报告"
  这类标准化措辞，往往就是财政部统一部署的专项。原文抓不到时，**向用户要红头文件（PDF/Word）**来提炼要点，
  比无限搜索高效得多（用户偏好"先试、不行就方案B"，数据/原文质量第一）。
- **市级定向通知的旁证**：区财政局在官网发布的"开展XX专项整治工作"工作动态（如宝山 2026-01 的文章）常写明
  "针对**市局下发的 XX 家无证经营清单**"——这就是"市局部署→区局执行→报市局"模式的直接证据。
- **官方法规依据总能在官网公开找到**：即使当年的专项自查通知不发公开页，其**上位依据**（如《代理记账
  行政审批事项告知承诺实施办法》沪财发〔2025〕8号，含"虚假承诺"法律责任）会在市财政局官网政策发布区公开。
  用 sogou/360 `site:czj.sh.gov.cn` 搜"告知承诺 实施办法"即可拿到文号齐全的官方页面，用作权威引用。

## 五·B、上海市各区财政局站点地图（2026-08 全 16 区实测）

市级代理记账自查通知不发公开页时，区级站点是旁证来源。16 区财政局官网 reachability 与栏目结构实测：

| 区 | 站点 | requests 可达 | 代理记账/通知栏目路径（规律） |
|----|------|--------------|------------------------------|
| 嘉定 | **caizheng.jiading.cn**（独立财政官网，非区政府域） | ✅ http（https 443 连不上，只走 http） | 代理记账 `/hjgl/dljz`；通知公告 `/publicity/fdzdgknr/gg/zwgg`；政务动态/详情 `/zwdt/content_<N>` |
| 青浦 | www.shqp.gov.cn/fina/（区政府域下财政栏目） | ❌（WAF/超时，仅浏览器可访问） | 公示公告 `/fina/hjgsgg/`；代理记账子栏 `/fina/fgzd/index.html` |
| 浦东/徐汇/长宁/静安/虹口/金山/松江/奉贤/崇明 | 各自政府域下 | ✅ requests 可达 | 多用 `/czj/` 或政务公开栏目 |
| 杨浦/闵行/黄浦 | 政府域下 | ❌ requests 连不上（WAF/超时） | 用浏览器 + sogou/360 site: 限定 |

要点：
- **部分区有独立财政官网**（嘉定 caizheng.jiading.cn 最典型，栏目完整可爬），多数区财政信息挂在区政府域下 `/fina/` `/czj/` 里。
- **嘉定详情页 URL 用 `/zwdt/content_<数字>` 模式**（如发布 2026 会计监督检查公示 /zwdt/content_970940），代理记账栏目 `/hjgl/dljz` 可 requests 直抓列表。
- **历年专项整治/自查通知原文在区站可留存**：青浦 2023 专项整治通知带完整原文 URL
  `https://www.shqp.gov.cn/fina/hjgsgg/20230814/1129998.html`（引沪财会〔2023〕31号，要求告知承诺机构对照《代理记账管理办法》《上海市代理记账管理实施办法》自查\"资格申请时及执证经营期间是否符合承诺内容\"，8/31 前报自查报告盖章，电话 59729311）——可作为新版自查通知的**结构范式**。
- **区级 2026 监督检查公示**是当年对代理记账机构检查的公开实证（嘉定 2026-06-16 公示：2026年6-10月对区内代理记账机构检查，依据财会〔2023〕27号《代理记账基础工作规范（试行）》，公布被查机构名单）。
- 同一市级通知，各区执行节点/报送时间**可能不同**（如公众号称市级汇总到会计处 9/10，但某区可能要求 7/31 前报），**以辖区财政局转发的书面通知为准**。
