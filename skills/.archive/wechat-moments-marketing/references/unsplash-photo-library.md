```bash
# 注册资本主题
curl -L -o /tmp/img_01.jpg "https://images.unsplash.com/photo-1486406146926-c627a92ad1ab?w=800&q=80"
curl -L -o /tmp/img_02.jpg "https://images.unsplash.com/photo-1554224155-6726b3ff858f?w=800&q=80"

cp /tmp/img_01.jpg "/mnt/c/Users/Administrator/Desktop/主题_01_场景.jpg"
cp /tmp/img_02.jpg "/mnt/c/Users/Administrator/Desktop/主题_02_场景.jpg"
cp /tmp/img_03.jpg "/mnt/c/Users/Administrator/Desktop/主题_03_场景.jpg"
```

## 注意事项

- 文件命名用英文+数字，不用中文（WSL→Windows cp 中文名可能失败）
- 拷贝命令后加 `ls -la` 验证文件确实到达桌面
- 文件路径必须完整写出来，不能说「在桌面上」
- 图片尺寸 `?w=800&q=80` 即可，文件约40-100KB，朋友圈不压缩严重
