## 尾部结构规范（2026.7.28 确定）

完整尾部按以下顺序排列，不可缺项：

1. `---` 分隔线
2. 话题标签（`#标签1 #标签2 #标签3 #标签4 #标签5 #标签6 #标签7 #标签8`）
3. `---` 分隔线
4. 公司介绍（**[关于XXX]**）
5. 核心业务（**[核心业务]** + 短横线分隔）
6. 二维码图片（`![长按识别添加XXX](http://127.0.0.1:8080/images/qr_xuaijun.jpg)`）
7. 二维码操作引导在图片**下方**（`**长按 → 识别图中二维码 → 添加到通讯录**`）
8. 免费资料引导（`📥 **免费领资料：** ...`）
9. 电话（`电话（微信）：XXX`）
10. CTA（**盈信标准版=三个动作**，2026.8.6 定稿）：收藏 / 转发 / 关注（标题「觉得有用？请点屏幕右下角：」红色加粗加大）

**注意：** 话题标签在分隔线之上，公司介绍在分隔线之下。二维码图片路径更新时，服务器上替换同名文件即可。

## ⭐ CTA 标准文案（盈信，2026.8.6 用户定稿，所有新文章以此为准）

> **「请点屏幕右下角：」必须加粗 + 红色(#FF2941) + 加大两号(font-size:19px)。**

```
觉得有用？<span style="color:#FF2941; font-size:19px; font-weight:bold;">请点屏幕右下角：</span>

❶ **收藏** — 随时翻出来对照，不怕找不到

❷ **转发** — 转给朋友，ta可能正在踩坑

❸ **关注** — 推送财税干货，老板少踩雷
```

**规则：**
- 盈信文章 CTA 固定为**三个动作**（收藏/转发/关注），不再有「❹ 咨询」项。
- 标题行固定为 **「觉得有用？请点屏幕右下角：」**，其中「请点屏幕右下角：」用红色(#FF2941)、加粗、19px（加大两号）。
- ❷ 是「转给朋友」，❸ 是「关注」（**不带公众号名**）。
- 措辞照抄上面定稿版，不要改词（"随时"不改"需要的时候"、"转给朋友"不加字、"推送财税干货"不加"每周"）。
- 此 CTA 对**新发布的文章**从下次起生效；已在草稿箱/已发布的旧稿不强制回改。
