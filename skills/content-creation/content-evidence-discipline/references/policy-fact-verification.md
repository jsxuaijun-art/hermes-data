# 低空条例"立法层面"核实记录 + 可复用命令

> 案例日期：2026-09-21。用途：本文件是 `content-evidence-discipline` 的正反例原始素材，也是政策类文案核实的可复用操作手册。

## 事件经过（次序违规的完整链条）

1. 苏州政策监控（anysearch 8路关键词）推来线索：《苏州市低空经济促进条例》标题 + 政务网 URL
2. 写城市破播文案时直接用了这句："苏州把低空经济写进条例了——这是立法层面的事"
3. 徐总追问：这句话的依据是什么？——公司纪律要求讲话必须有依据、严禁 AI 幻觉/凭空臆断/捏造
4. 拉取那个 URL：**返回苏州政务网首页壳，不是条例正文**（正文 URL 链接漂移/JS 渲染）
5. 暴露事实：从未逐字核对过正文，依据只是搜索引擎返回的标题+URL
6. 事后做了完整核实 → 结论属实 → 但"先引用后核实"的**次序**本身违规

**教训：监控推的是线索不是事实；写成文案前必须核实原文。**

## 核实全过程（可复用命令）

### Step 1 — anysearch 拿官方链路
```bash
python3 ~/.hermes/skills/anysearch/scripts/anysearch_cli.py batch_search \
  --queries '[{"query":"苏州市低空经济促进条例 人大常委会 通过 施行","max_results":6},{"query":"苏州 低空经济 促进条例 地方性法规","max_results":5}]'
```
命中关键源：
- 苏州政务网《关于〈苏州市低空经济促进条例〉的说明》——"已由苏州市十七届人大常委会第二十二次会议于2025年6月25日通过"
- 2500sz 新闻"获省十四届人大常委会第十六次会议批准，将于今年10月1日起施行"
- 中共江苏省委新闻网《条例施行》——"2025年10月1日起正式施行，有法可依"
- 人民网《无锡苏州促低空经济法规同日获批、同日施行》
- 司法部官网《苏州创新机制举行低空经济立法推介会》——"纳入苏州市人大常委会2025年立法计划正式项目"

### Step 2 — web_extract 拉正文逐字核对
```bash
web_extract urls=["http://www.suzhou.gov.cn/szsrmzf/gbdfxfg/202509/69b369ede5ea4961915f726d.shtml"]
```
核对第一条："第一条 为了加快发展新质生产力，促进低空经济高质量发展……根据有关法律、法规，结合本市实际，制定本条例。"

⚠️ **坑**：正文 URL 的直接拉取曾返回首页壳（`gbdfxfg` 分类 URL 飘移）。此时回退用 anysearch 搜出的**多个独立源**交叉印证，而不是死磕单 URL。

### Step 3 — 多源交叉成结论
| 事实 | 来源 |

| 市十七届人大常委会通过 | 苏州政务网《说明》(2025-06-25) |
| 省人大常委会批准 | 2500sz / 人民网 (省十四届人大常委会第十六次会议, 2025-07-30) |
| 2025-10-01 施行 | 省委新闻网 (2025-10-02) / 2500sz |

## 合规表述（先核实后成文）

✅ "《苏州市低空经济促进条例》经市十七届人大常委会通过、省人大常委会批准，已于2025年10月1日起施行。"（依据：政网正文+说明、省委新闻网、人民网，多源交叉）

## 违反后的正确动作（AI 行为规范）

1. 如实承认：依据是标题+URL，未核对正文，次序违规
2. 立即按 Steps 1-3 核实（不狡辩、不找补）
3. 核实属实也照样把反面案例写进纪律文件（次序错即违规）
4. 交付物补"依据清单"区块（每条结论：出处+URL+核验日期）
5. 后续所有交付先核原文再成文
