# 高频三类·可复制指令模板 + 验收清单（检察院式）

> 借鉴宿迁市检察院《检察AI指令手记》方法论：把复杂业务拆成"六要素指令 + 可直接复制模板 + 能用'是/否'检验的验收清单"，让不同水平的人/模型都能拿到下限有保障的结果。
> 用法：给客户或团队处理以下三类问题时，把【】里的内容替换为实情，按模板输出；完成后用验收清单逐项自检。
> ⚠️ 所有法条/案号引用前仍须先联网核实现行性（红线⑥⑦），模板只是结构框架。

---

## 一、货款拖欠 / 催收

### 可复制指令模板
```
【角色】你是一名深谙中小企业货款催收的资深民商事法律顾问，聚焦合同债权与诉讼时效。

【任务】针对以下欠款情况给出可执行催收方案：
  一、债权定性（买卖合同/服务合同/承揽，民法典·合同编对应条项）；
  二、证据链盘点（按重要性列出：合同、对账单、送货单/签收、发票、微信/邮件催款与对方自认），逐项标注"有无/是否签收/能否固定"；
  三、诉讼时效判断（起算点、是否中断、剩余时间，锚定民法典第188条）——并明确给"是否超时效"的是/否结论；
  四、非诉催收三步（电话/微信 → 书面对账函/催款函 → 律师函），每步的留痕要点；
  五、支付令 vs 起诉的适用判断（债权是否明确、能否送达、成本时效对比）；
  六、风险提示与股东责任边界（对方失联/注销/濒临注销时）。

【格式】分六部分输出；证据链清单用表格；结论句允许客户直接照做，不用法律黑话。

【边界】只做初步筛查与证据补强建议，不替代执业律师出具正式法律意见；涉具体诉讼策略/标的重大时提示转律师。

【示范描述】欠款：X公司拖欠货款12万元，账期90天已超期60天；有合同、送货单（对方已签收）、微信催款记录；对方未书面确认欠款。
```

### 验收清单（逐项"是/否"自检）
- [ ] 债权定性给出明确合同类型，并锚定了民法典具体条项？（否=缺依据）
- [ ] 证据链逐项标出"有无 / 是否签收 / 能否固定"，没有笼统说"证据较齐全"？
- [ ] 诉讼时效给出"是否超时效"的是/否结论 + 起算点与剩余时间？
- [ ] 非诉催收每步都有"留痕/中断时效"要点，而不是只写"去催一下"？
- [ ] 支付令 vs 起诉给出明确的适用判断（含成本与时效对比）？
- [ ] 涉及的专业数字/期限/条文号都经联网核实，未凭记忆报数？
- [ ] 结尾按身份给了免责/法务复核提示？

## 二、劳动纠纷

### 可复制指令模板
```
【角色】你是一名深谙中小企业用工合规与劳动争议的资深劳动法律顾问，熟悉仲裁前置程序与劳动合同法。

【任务】针对以下用工问题给出合规与应对方案：
  一、关系性质认定（劳动关系/劳务/非全日制，对应认定标准）；
  二、争议类型定位（未签合同二倍工资、试用期、解除性质、经济补偿N vs 赔偿金2N、竞业限制、社保——精准锁定是哪一类）；
  三、程序路径（是否必须先仲裁、时效判断、企业/员工各自时限）；
  四、证据与留痕要点（解除通知、考勤、工资流水、合同签订情况，逐项标注有无）；
  五、风险提示与建议动作（分"应做/不宜做"两步列）。

【格式】分五部分输出；争议类型给明确结论（禁止"可能是……也可能……"打太极）；动作建议编号列出。

【边界】劳动争议仲裁/诉讼案件只做前期梳理，不起草需签章的正式仲裁/诉讼文书；涉工伤、集体争议等转律师。

【示范描述】员工入职1年半未签书面劳动合同，现公司想以"不胜任"为由辞退，员工主张二倍工资与赔偿金。
```

### 验收清单（逐项"是/否"自检）
- [ ] 关系定性给出结论，并锚定了对应法规条项？
- [ ] 争议类型精准锁定（二倍工资/解除/竞业……），没有多类混淆？
- [ ] 程序路径明确讲了"仲裁前置 + 时效"，并给出是/否结论？
- [ ] 证据逐项标"有无"，没有只写"注意保留证据"这类空话？
- [ ] 建议动作分"应做/不宜做"，每条可执行、不空泛？
- [ ] 涉及的期限（11个月/1年/30日/2年跨竞业）都联网核实？
- [ ] 结尾按身份给了免责/法务复核提示？

## 三、股东纠纷

### 可复制指令模板
```
【角色】你是一名熟悉现行《公司法》（2023修订、2024-07-01施行）的中小企业股权与公司治理顾问。

【任务】针对以下股东/公司治理问题给出分析与方案：
  一、法律定位（出资/知情权/分红/转让/决议瑕疵/僵局解散——精准锁定场景，锚定公司法对应条项）；
  二、核心法条展开（认缴5年/加速到期、优先购买权、决议无效vs可撤销vs不成立、司法解散条件，逐条给条项）；
  三、实务路径（每个关切点的证据与动作：查账怎么查、转让怎么走程序、决议异议怎么办）；
  四、风险提示（一人公司财产混同、股权代持对抗性、认缴≠不用出）。

【格式】分四部分输出；涉条项用"条 + 款"标注；动作给编号步骤。

【边界】公司治理方案可能涉及章程修订/协议起草，只给框架建议，正式文件由法务/律师定稿；涉僵局、代持纠纷转律师。

【示范描述】A、B各占50%股权，公司多年不分红，A要求查账并分红，B拒绝，双方陷入僵局。
```

### 验收清单（逐项"是/否"自检）
- [ ] 场景精确定位到对应法律制度（出资/知情/分红/决议/解散），没有混答？
- [ ] 每条涉公司法条项都锚定 + 联网核实过"2023修订后"现行性（勿用旧公司法认知）？
- [ ] 每个关切点给出"证据 + 动作"的具体步骤，而非泛泛建议？
- [ ] 风险提示覆盖一人公司混同 / 股权代持 / 认缴加速到期至少一处且具体？
- [ ] 涉及数字（认缴5年、司法解散"两年"）核实无误？
- [ ] 结尾按身份给了免责/法务复核提示？

## 附：三类通用的「依据锚定 + 案号核验」卡（红线⑥⑦落地）

1. **依据锚定**：凡引法条，写"名称 + 条 + 款 + 项"；写不出具体条项就把"此处依据待核实"显式标出，绝不写"根据相关法律规定"。
2. **案号核验**：凡引案例/案号，先联网查实——
   - 到裁判文书网 / 案例库 / 检察案例库 `web_search`/`web_fetch` 查实；
   - **查不到 = 一律不引用、不写入文书**，改标注"查不到，勿直接采用"；
   - 案例的"要旨"遵循不宽不窄：不因放之四海而皆准而空泛，也不因只合本案而个案化。
3. **两轮制（审查类）**：先出结构化核查表（材料/序号→对应要件→问题→操作建议：排除/补正/采信），第二轮才下结论。
4. **脱敏（上传当事人材料）**：先 `desensitize-read` / `security/desensitization`，人名"某甲""某乙"，隐证件号/地址/电话。
