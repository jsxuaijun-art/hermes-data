# 研发费用加计扣除申报全流程

> 定位：从「判定适用」到「申报享受 + 留存备查」的端到端操作。路径A高企与路径B非高企均走本流程，区别只在是否另填 A107041。
> 复算：`python scripts/gxrd_engine.py calc --json-text '<json>'`；测算额度不要凭心算。

## 一、前置过滤（先做，别急着算）

1. **主体**：会计核算健全、查账征收、能准确归集研发费用的居民企业（事业单位亦可；核定征收、非居民不适用）。
2. **行业**：6 类负面清单；兼营按 `该业务收入 ÷ (收入总额 − 不征税收入 − 投资收益) > 50%` 判定。
3. **活动**：7 类不适用活动反列举；须满足「明确创新目标/系统组织形式/结果不确定」三要点。
4. **证据**：立项文件 + 辅助账；**无辅助账不得加计**。

## 二、可加计研发费用归集范围（6 类，正列举）

| # | 类别 | 关键细目与边界 |
|---|------|----------------|
| 1 | 人员人工 | 直接从事研发人员工资薪金、五险一金、外聘研发人员劳务费；股权激励支出；兼岗按工时分摊 |
| 2 | 直接投入 | 直接消耗材料/燃料/动力；模具工艺装备开发制造费、不构成固定资产的样品样机购置费、试制产品检验费；仪器设备租赁费；研发与生产共用水电须合理分摊，划分不清不得加计 |
| 3 | 折旧费用 | 用于研发的仪器设备折旧；共用按工时/机时分摊；加速折旧按税收口径 |
| 4 | 无形资产摊销 | 用于研发的软件、知识产权、非专利技术摊销；共用分摊 |
| 5 | 新产品设计费等四项 | 新产品设计费、新工艺规程制定费、新药研制临床试验费、勘探开发技术现场试验费 |
| 6 | 其他相关费用 | **正列举**：技术图书资料费、资料翻译费、专家咨询费、高新科技研发保险费、研发成果检索/分析/评议/论证/鉴定/评审/评估/验收费、知识产权申请/注册/代理费、差旅费、会议费、职工福利费、补充养老/医疗（含年金）。**未列明费用不得计入** |

**明确不得加计**：法律行政法规规定不得税前扣除的费用；**研发用房屋的折旧费和租赁费**；已计入无形资产但不属加计范围的项目摊销。

> 新旧政策差异：现行口径新增外聘研发人员劳务费、试制产品检验费、专家咨询费、高新科技研发保险费、差旅费、会议费、职工福利费、补充养老/医疗保险费；**房屋折旧与租赁费仍未放开**。

## 三、其他相关费用限额（最高频算错点）

**现行公式（2021年度起，全部项目统一计算）**
```
其他相关费用限额 = 全部项目「人员人工等五项费用之和」× 10% / (1 − 10%)
可加计的其他相关费用 = min(实际发生额, 限额)
```
- **2021年第28号**：由按每一项目分别计算改为全部项目统一计算，不同项目限额可相互调剂；资本化项目费用在形成无形资产的年度统一纳入。
- 旧口径（2015年第97号，2020.12.31前）：逐项目计算，项目间不能调剂。

**算例（书 p110-111）**：A 前五项 88万+其他12万、B 92万+8万。新口径 `(88+92)×10%/(1-10%)=20万`，实际 20 万全额可加计，且只需算一次。

## 四、应冲减/剔除的特殊情形

| 情形 | 处理 |
|------|------|
| 下脚料、残次品、中间试制品等特殊收入 | 在**确认收入当年**从归集研发费中扣减；不足扣减按零计算 |
| 研发直接形成产品对外销售 | 对应材料费用不得加计；跨年度的在销售当年冲减，不足结转以后年度 |
| 政府补助作不征税收入 | 用于研发形成的费用/资产不得加计/摊销 |
| 政府补助作应税收入 | 可按规定加计 |
| 会计净额法冲减研发费、税务未确认应税收入 | 按冲减后余额计算加计 |

> 算例：研发支出200万+补助50万 → 不征税：150×100%=150万；应税：200×100%=200万。**企业可择优**。
> ⚠️ 风险实例（书 p114）：某高企大批量试制品对外销售未冲减，多列加计基数1500万，按15%补税 **225万**。

## 五、不同研发形式的税务处理

| 形式 | 加计规则 | 必备要件 |
|------|---------|---------|
| 自主研发 | 按归集范围全额计入 | 企业内部有权部门立项决议；无须事前鉴定/备案 |
| 委托境内机构/个人 | 实际发生额 **80%** 计入委托方，受托方不得再加计；按独立交易原则 | 合同经科技部门登记；委托个人凭发票；关联方须提供实际发生费用明细 |
| 委托境外机构 | 按 **80%**，且不超过境内符合条件研发费 **2/3** | 技术开发合同，委托方到科技部门登记；关联方提供明细；不含委托境外个人 |
| 合作研发 | 各方按各自实际承担的费用分别归集加计 | 合同经科技部门登记；各方独立核算 |
| 集中研发 | 按合理方法分摊，各方就分摊部分加计 | 集团决算表、分摊明细、关联申报 |

> **关联方明细易错点**：委托方支付100万、受托方实际发生90万，应提供**实际发生90万**的明细（非80万）。委托非关联方无需明细。
> **合同登记易错点**：未到科技部门登记 → **无法加计**（国科发政字〔2000〕63号第六条）。

## 六、加计比例与特殊主体

| 对象 | 比例 | 摊销 | 备注 |
|------|------|------|------|
| 一般企业 | **100%**(2023.1.1起制度性) | 无形资产 **200%** | 2023年第7号 |
| 集成电路/工业母机 | **120%**(2023–2027) | **220%** | 2023年第44号；清单管理；资本化按摊销时点 |
| 企业出资基础研究 | 100% | — | 2022年第32号 |
| 创意设计活动 | 100% | — | — |
| 科技型中小企业 | 100% | — | 需入库登记编号 |

**疑难口径**：加计可形成/扩大亏损（高企10年、一般5年）；符合条件未享受可**追溯3年**；资本化时点税收与会计一致；研发失败、跨年度项目当年费用化部分均可加计；与高企15%/小微择一关系见 hte_certification.md。

## 七、申报流程（SOP）

1. **预缴三时点**（2023年第11号）：7月可选上半年、10月可选前三季度、汇算清缴统一享受；前时点未选可在后续统一享受（非作废）。
2. **汇算填报** A107012 → A107010 → A105000 → A100000；高企另填 A107041。
3. **填表基础**：《研发支出辅助账汇总表》；辅助账/专项审计/申报表三处口径一致。
4. **留存备查**：2018年第23号「自行判别、申报享受、资料留存备查」。
5. **后续管理**：税务机关核查、异议鉴定（国科发政〔2017〕211号，转请科技部门鉴定）。

**A107012 关键行（完整见 auxiliary_ledger.md §七）**：
- 1 本年可享受加计扣除项目数量
- 2 自主研发·合作·集中 = 3+7+16+19+23+**34**
- 34 （七）**经限额调整后**的其他相关费用（⚠️非实际发生额）
- 35 委托研发 = 36+37+39
- 36 委托境内（实际×**80%**）
- 37 委托境外（按80%且≤境内2/3）
- 38 其中允许加计的委托境外（经2/3限额后）
- **40 年度研发费用小计 = 2 + 36×80% + 38**
- 41/42 本年费用化/资本化；43/44 本年及以前年度形成无形资产摊销额
- 45 允许扣除研发费用合计（41+43+44）
- 46–49 特殊收入与研发产品材料冲减
- 50 加计比例；51 本年加计扣除总额；52 结转以后年度
> 34 填限额调整后数、28 填实际发生数，两者差额即调增。34/38 两个独立限额。表版本每年可能调整，以电子税务局当年表样为准。

## 八、留存备查资料

→ 完整清单与签收单见 `assets/留存备查资料清单与签收单.md`。三类必备：①项目计划书+立项决议+项目组与研发人员名单 ②研发支出辅助账及汇总表 ③人员/材料/设备/无形资产分配说明（含工时）。委托/合作加合同登记证明；集中加决算表与分摊明细；委托境外加合同、发票、2/3测算；创意设计加活动说明。

## 九、常见错误速查

| 错误 | 后果 |
|------|------|
| 限额按项目分别算（未用28号统一口径） | 少加计或算错 |
| 其他费用塞入未列举项目 | 被调增 |
| 特殊收入/试制品材料未冲减 | 补税+滞纳金 |
| 不征税收入用于研发仍加计 | 不得加计 |
| 委托合同未登记/委托个人无发票 | 不得加计 |
| 关联方只提供部分费用明细 | 资料不合规 |
| 房屋折旧、租赁费计入加计 | 不得加计 |
| 事后补建辅助账 | 不得加计 |
