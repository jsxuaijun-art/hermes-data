# 热点类比型公众号文章创作工作流

> 版本：v1.0 · 2026-10-27 · 基于"人民日报痛批集采极端低价"实战案例萃取

## 适用场景（When to Use）

用户说"借热点写代账""热点类比文章""社会事件类比财税"或提供热点新闻链接要求类比创作时触发。

- 社会上出现与"低价内卷、质量塌方、恶性竞争"相关的热点事件（不限行业）
- 需要借热点为代理记账行业发声，反制低价同行
- 需要将销售skill中的话术体系融入内容创作，实现"内容即弹药"

## 核心原则

1. **热点是壳，话术是核**——热点只负责吸引注意力，销售话术才是文章的灵魂
2. **不贬低同行，只立专业标准**——用"我们坚持专业路线"替代"他们低价没质量"
3. **让读者能自查**——必须给出可操作的自查清单/验钞机
4. **所有事实可溯源**——引用政策/数据必须标注来源，不编造

## 工作流七步法

### 第1步：热点筛选与匹配度判断

| 判断维度 | 合格标准 | 本次案例 |
|---------|---------|---------|
| 事件权威性 | 人民日报/央视/部委发文等官方信源 | ✅ 人民日报人民时评 |
| 逻辑同构性 | 低价→成本击穿→质量塌方→用户买单 | ✅ 集采止血夹7.4元 vs 代账超低价 |
| 情绪共鸣度 | 大众对"便宜没好货"有普遍认知 | ✅ 药品安全人人关心 |
| 时效性 | 近1-2周内热点最佳 | ✅ 2025年7月评论，10月仍在发酵 |

**不合格热点特征：**
- 与"低价竞争"无关（如纯技术突破、娱乐八卦）
- 逻辑无法映射（如垄断定价高价，非低价内卷）
- 敏感政治话题（避开）

### 第2步：销售skill话术素材调取

**必须调用的核心话术模块（来自 sales-communication / price-negotiation / compliant-accounting）：**

| 话术模块 | 来源skill | 用途 |
|---------|---------|------|
| 服务费=买断工作时间 | `price-negotiation` | 文章核心逻辑锚点 |
| 五大省工信号 | `sales-communication` | 自查清单章节 |
| 行业类比法 | `sales-communication` | 类比章节素材 |
| 低价机构不可持续数学论证 | `compliant-accounting` | 算账章节 |
| 公道自在人间价格自有公理 | 徐总口述（2026-10-27） | 结尾升华章节 |
| AI做账的边界 | 徐总口述（2026-10-27） | 第四条低价路径 |

**调取原则：**
- 先全文检索 skill 中所有相关论述，确保不遗漏
- 优先使用用户最新口述的话术（比skill文件更新）
- 用户提供的原话 > skill现有文本 > 自行改写

### 第3步：文章结构设计

**标准结构（8段式）：**

```
1. 开头钩子（三句话公式：S1让我看见自己 → S2让我发现可能想错了 → S3让我知道有回报）
2. 数字冲击对比表（热点事件 vs 代账行业，5-6个维度对比）
3. 把热点概念翻译成代账场景（如"断供"→会计换人/账套不交/跑路）
4. 低价机构不可持续：数学问题（成本算账，3-4条活路含AI）
5. 服务费=买断工作时间（完整杀伤链）
6. 行业类比法（3个客户熟悉行业 + 代账映射）
7. 五大省工信号自查清单（5条，每条对比健康vs省工）
8. 公道自在人间，价格自有公理（升华 + 品牌态度）
9. 一句话总结
10. 尾部模板（话题标签/公司介绍/二维码/CTA/免费资料）
```

**结构变体：**
- 热点事件较小时，可合并2-3段
- 热点事件较大时，可在第3段后加"事件回顾"段
- 需要分割受众时（新手/老手），可按 wechat-publish 模式A上下篇

### 第4步：关键话术融入检查清单

**文章完成后必须逐条检查：**

- [ ] 服务费=买断工作时间逻辑是否完整呈现（含"上帝对每个人唯一公平的就是24小时"）
- [ ] 五大省工信号是否全部5条（①每月主动要银行流水②问真实业务③年终主动移交账册④会计是老师傅⑤两年换了几个会计）
- [ ] 行业类比是否至少3个行业（建筑/餐饮/电商/物流等）
- [ ] 低价机构活路是否含AI做账（含"AI是利器但医院暂时无法取代医生"的类比）
- [ ] "公道自在人间，价格自有公理"是否出现
- [ ] "贪图便宜使用7.4元止血夹将危害健康甚至危及生命"是否出现
- [ ] 是否无贬低同行表述（检查"他们低价没质量"类措辞，替换为"我们坚持专业路线"）
- [ ] 所有政策/数据是否有来源或标注"待核实"

### 第5步：配图制作

**必配图清单：**

| 位置 | 类型 | 制作方式 |
|------|------|---------|
| 封面 | 与主题相关的实景图 | Unsplash下载或AI生成 |
| 正文1 | 热点事件配图 | **优先：真实新闻截图**；备选：自制模拟图（PIL/WeasyPrint渲染） |
| 正文2 | 场景配图（如跑路/空办公室） | Unsplash下载 |
| 正文3 | 概念配图（如时间分配/沙漏） | Unsplash下载 |
| 正文4 | 清单配图（如自查清单） | Unsplash下载 |

**自制热点配图规范（本次案例验证）：**
- 用PIL直接绘制，900×1200px
- 风格：模仿人民日报红头版式（顶部红线+红色报头+黑色标题+红色副标题+粉色高亮框+灰色引用框）
- 必须含：核心事实数字（红色放大）、官方回应引用、来源落款
- 视觉验收：无乱码、排版正常、红色数字突出

### 第6步：发布与交付

**发布流程：**
1. 文章写入 `/tmp/article_xxx.md`
2. 图片上传服务器 `/var/www/html/images/`（用 `cat file | ssh ...` 方式避免scp超时）
3. wenyan发布：`NODE_OPTIONS='--experimental-require-module' node ... publish -f /tmp/article.md --server http://127.0.0.1:3000 -c /etc/wenyan/themes/01-anxinbojun.css`
4. 记录Media ID

**企微朋友圈交付（双重交付）：**
1. 生成文案（企微精炼版≤100字 + 个人微信完整版）
2. 配图打包ZIP：`python3 zipfile`（WSL无zip命令）
3. ZIP放桌面：`C:\Users\Admin\Desktop\`
4. 企微API推送：先发text（3套文案+说明），再逐张发image（4张图）
5. `safe: 0` 参数确保消息不保存到会话存档，需用户手动点击发送

### 第7步：复盘与skill更新

**每次完成后记录：**
- 热点事件与代账行业的映射点（新增到本skill案例库）
- 用户新提供的话术原话（补充到话术素材清单）
- 配图制作中的新Photo ID或新技术（更新配图规范）

## 案例库

### 案例1：人民日报痛批集采极端低价（2026-10-27）

**热点事件：** 人民日报评论《极端低价不通吃》，内镜止血夹报价7.4元，正常出厂价26-30元，低价药断供、不合格

**映射点：**
| 集采药械 | 代理记账 |
|---------|---------|
| 7.4元止血夹 | 超低价代理记账 |
| 低价药断供 | 会计换人/账套不交/跑路 |
| 患者健康风险 | 企业财税风险/罚款/倒闭 |
| 反安慰剂效应（患者不信任低价药） | 老板不信任低价账（每次风吹草动心跳加速） |
| 医保局"反内卷"划边界 | 先比资质再比价格 |

**关键话术融入：**
- 服务费=买断工作时间（含"做了这个就不能做那个"）
- 五大省工信号（5条完整自查清单）
- 行业类比（建筑/餐饮/电商）
- 低价机构4条活路（压人工/省流程/用AI做账/跑路）
- AI做账边界（"AI是利器但医院暂时无法取代医生"）
- 公道自在人间价格自有公理

**自制配图：** PIL绘制人民日报风格图（900×1200，红色报头+核心事实红框+引用灰框）

**产出：** 公众号文章1篇 + 企微朋友圈文案3套 + 配图4张 + ZIP打包推送

## 关联技能

- `wechat-publish` — 公众号写作→排版→发布主流程
- `sales-communication` — 销售话术母skill（9阶段全链路）
- `price-negotiation` — 价格谈判专项（服务费=买断工作时间）
- `wechat-moments-marketing` — 朋友圈运营（发布节奏/配图规范）
- `content-evidence-discipline` — 内容有依据纪律（不编造政策/数据）

## 使用纪律

1. **不编造政策文号**——引用人民日报/医保局文件时，如果没有原文，标注"据公开报道"或留白让用户核实
2. **不贬低同行**——全文检查"他们低价没质量"类措辞，用"我们坚持专业路线"替代
3. **用户原话优先**——徐总口述的话术（如"公道自在人间"）优先于skill现有文本
4. **AI做账表述审慎**——肯定AI价值（利器/提质增效），但强调边界（无法取代医生/专业判断）
5. **企微推送需确认**——API发送前必须得到用户明确批示
