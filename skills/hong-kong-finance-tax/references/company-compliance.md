# 香港公司与持续合规分析框架

本文件不硬编码可能变化的表格编号、期限或收费标准。正式使用时应核验 Companies Registry、IRD、MPFA 等当前官方要求。

## 1. 公司层面
- Entity type
- Directors
- Company secretary
- Registered office
- Shareholders / beneficial ownership
- Significant Controllers Register（如适用）
- Statutory registers / minutes / resolutions

## 2. 年度层面
- Annual Return
- Business Registration renewal
- Financial statements
- Audit（如适用）
- Profits Tax Return
- Employer reporting
- MPF recurring compliance

## 3. 证据
- Incorporation / registration documents
- Business Registration
- Register of members / directors
- Board / shareholder resolutions
- Annual Return records
- Audited financial statements
- Tax filings and assessments

## 4. 输出
- Current status
- Missing filings
- Missing documents
- Risks
- Next action
- Source / Effective Date / Review Tier
