# Vlog 想法 → 发布包 流水线

## 适用场景
用户只有一句/一段口头想法（某天见闻、感悟、纪念日话题），需要快速变成可拍摄、可发布的短视频文案包。典型输入如："9月18号苏州试鸣防空警报，我们无感，可前推七八十年听闻者多恐惧，和平有国家顶着，居安思危"。

## 一次性交付物
1. 三版口播文案
   - A 原意润色版：最贴近用户原话，仅做口语化打磨（约150–200字），附画面建议
   - B 情感升华版：加历史纵深/情绪转折，更有感染力（约250–350字），附画面建议
   - C 极简有力版：快节奏短视频，约80–120字，附画面建议
2. 浓缩版：按用户要求将 B 压到与 C 相近字数，保留升华感与核心金句
3. 主标题 2–3 个（简短、带钩子）
4. 引流副标题 2–3 个（情绪向、制造好奇/共鸣，放标题下或评论区）
5. 话题标签 8 个（# 开头，凝练吸睛；抖音/视频号用空格分隔，不用逗号）

## 执行步骤
1. 解析用户原始意思，提炼核心信息点：事件 / 对比 / 观点 / 落点。
2. 判断基调：
   - 庄重纪念类（九一八、抗战、国耻纪念日等）须克制、不戏谑、不煽情过头；历史表述准确，年份用"九十多年前"等稳妥表述，绝不编造数字或事件。
   - 生活 / 营销类可活泼。
3. 产出三版文案（A/B/C），每版附一句画面建议（机位 / 空镜 / 字幕落点）。
4. 如用户要求"把B浓缩成C长度"，将 B 压到 C 字数，保留升华感与金句。
5. 产出主标题、引流副标题、话题标签。
6. 全部写入一个 .txt 交付（桌面路径按环境：优先 C:\Users\Admin\Desktop，实际多为 C:\Users\Administrator\Desktop），并附选用建议。

## 注意事项
- 不主动生成 md 文件；交付用 txt（可在对话直接呈现 + 落盘）。
- 历史 / 政策类内容严禁 AI 幻觉，不确定的不写；涉及具体年份/事件以官方口径为准。
- 话题标签之间用半角空格分隔，不用逗号或顿号。
- 用户偏好结论先行、不废话；成稿直接给"版本 + 选用建议"，少解释。

## 调用示例
用户："9月18号苏州试鸣防空警报，我们无感，可前推七八十年听闻者多恐惧，和平有国家顶着，居安思危"
→ 走本流水线：产出 A/B/C 三版 + 浓缩版B + 主标题×3 + 引流副标题×3 + 话题×8，落盘 txt 并给选用建议。
