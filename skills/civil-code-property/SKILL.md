# 物权编（第二编）结构化 Skill

## 任务目标

把用户的物权纠纷定位到「所有权 / 用益物权 / 担保物权 / 占有」哪一分支、哪一章，给出
"权利归属、变动要件、能否对抗第三人、如何救济"的结构化结论与处置步骤。

## 物权编结构（路由索引，5 分编 20 章）

- **第一分编 通则**
  - 一般规定（第205—208条）
  - 物权的设立、变更、转让和消灭（第209—232条）：不动产登记（209—219）/ 动产交付（224—232）/ 其他规定（233—232 衔接）
  - 物权的保护（第233—239条）：返还原物、排除妨害、消除危险、修理重作更换、损害赔偿
- **第二分编 所有权**
  - 一般规定（第240—245条）；国家/集体/私人所有权（246—270）
  - 业主的建筑物区分所有权（第271—287条）；相邻关系（288—296）；共有（297—310）
  - 所有权取得的特别规定（第311—322条）：善意取得、遗失物、漂流物等
- **第三分编 用益物权**
  - 一般规定（第323—329条）；土地承包经营权（330—343）；建设用地使用权（344—361）
  - 宅基地使用权（第362—365条）；居住权（第366—371条）；地役权（第372—385条）
- **第四分编 担保物权**
  - 一般规定（第386—393条）；抵押权（394—424：一般抵押权 / 最高额抵押权）
  - 质权（425—446：动产质权 / 权利质权）；留置权（第447—457条）
- **第五分编 占有**（第458—462条）

## 重点制度速查表

| 主题 | 核心条文 | 要点 |
|------|---------|------|
| 不动产登记生效 | 第209、214条 | 不动产物权变动经依法登记生效；自记载于登记簿时发生效力 |
| 区分原则（合同≠物权） | 第215条 | 物权合同自成立生效，未登记不影响合同效力（可追究违约责任） |
| 动产交付生效 | 第224条 | 动产物权设立/转让自交付时生效（汽车/船舶/航空器未登记不得对抗善意第三人，225） |
| 物权请求权的行使 | 第235、236条 | 无权占有→返还原物；妨害/可能妨害→排除妨害或消除危险（不适用诉讼时效，类推人格权995） |
| 善意取得 | 第311条 | 无处分权人转让，受让人善意+合理价格+已登记/交付→取得所有权；原权利人向无处分权人索赔 |
| 遗失物 | 第312、314—319条 | 权利人2年内向受让人请求返还；受让人可向无处分权人追偿 |
| 业主共有与共同管理 | 第271—278条 | 专有部分外共有；车位（275/276）；筹集维修资金/改建等重大事项需"双三分之二参与+双四分之三同意"（278） |
| 相邻关系 | 第288—296条 | 有利生产方便生活、团结互助、公平合理；通行/排水/采光/通风等 |
| 按份/共同共有 | 第297—310条 | 处分共有物需2/3以上份额同意（301）；按份共有人优先购买权（305） |
| 居住权 | 第366—371条 | 依合同/遗嘱设立，登记生效（368）；满足生活居住需要，原则不得转让继承（369） |
| 土地承包经营权 | 第330—343条 | 承包期届满继续承包（332）；可流转（334—339）；三权分置 |
| 建设用地使用权 | 第344—361条 | 出让/划拨；住宅自动续期（359） |
| 抵押权 | 第394—424条 | 不转移占有担保；可抵押财产（395）；不得抵押（399） |

| 抵押权清偿顺序 | 第414条 | 已登记优先于未登记；同顺位按债权比例；未登记按债权比例 |
| 质权 / 留置权 | 第425—446 / 447—457条 | 动产/权利质权；留置须合法占有且债权与动产属同一法律关系（企业除外，448） |

## 高频场景 → 处置步骤 → 条文

1. **"买了二手房，钱付了没过户，卖房人又抵给第三人/被查封"**
   - 不动产变动登记生效（第209条），未登记不发生物权效力→你未取得所有权。
   - 但买卖合同有效（区分原则第215条）：可要求卖方承担违约责任、赔偿损失，或依合同主张继续履行（若未过户障碍可排除）。
   - 若第三人已善意取得并登记（第311条）→你只能向卖方索赔，不能要回房。
   - 步骤：①查是否网签/预告登记（221可预告登记防一房二卖）；②确认第三人是否善意且已登记；③向卖方主张违约/赔偿，必要时解除合同。

2. **"抵押的房子能不能卖？卖了抵押权还在吗？"**
   - 第406条：抵押期间**可以转让**抵押财产；当事人另有约定从其约定；转让的，**抵押权不受影响**。
   - 抵押人应通知抵押权人；若转让可能损害抵押权，抵押权人可请求提前清偿或提存。
   - 步骤：卖前看合同有无"不得转让"约定；通知抵押权人（银行）；过户后抵押权继续附着，买方"带押受让"。

3. **"小区车位到底归谁？物业说卖给我合法吗？"**
   - 第275条：车位分"规划内车位"（可约定归属）、"占用业主共有道路/场地的车位"（属业主共有）。
   - 第276条：规划内车位/车库应首先满足业主需要。
   - 步骤：看规划图与合同；占用共有地的车位属于全体业主，物业无权出售；重大事项由业主共同决定（278）。

4. **"邻居占道、漏水、挡采光"**
   - 相邻关系第288—296条：通行、排水、通风、采光、日照等按有利生产、方便生活、公平合理处理。
   - 妨害物权→请求排除妨害/消除危险（第236条）；造成损害的请求赔偿。
   - 步骤：先协商留证（照片/视频）；协商不成可请求基层组织调解或起诉。

5. **"借/租出去的东西被承租人卖了，能要回吗？"**
   - 善意取得第311条：受让人善意+合理价格+已交付/登记→取得所有权，原权利人只能向无处分权人（承租人）索赔。
   - 若受让人非善意（明知无处分权）或无偿取得→不发生善意取得，可返还原物（第235条）。
   - 遗失物第312条：2年内可向受让人请求返还。

6. **"想给父母在自家房子设居住权"**
   - 第366—371条：居住权依合同（书面）或遗嘱设立，向登记机构申请登记（第368条）时设立；原则不得转让、不得继承，原则上无偿（371）。

## 重点条文摘录（原文见 references/物权编全文.md）

- 第209条：不动产物权经依法登记发生效力；未经登记不发生效力（法律另有规定除外）。
- 第215条：当事人之间订立有关设立、变更、转让和消灭不动产物权的合同，自合同成立时生效；未办理物权登记的，不影响合同效力。
- 第224条：动产物权的设立和转让，自交付时发生效力（法律另有规定除外）。
- 第235条：无权占有不动产或者动产的，权利人可以请求返还原物。
- 第278条：下列事项由业主共同决定……（筹集/改建维修资金等需参与表决双三分之二、同意双四分之三）。
- 第311条：无处分权人将不动产或者动产转让给受让人的，所有权人有权追回；符合善意+合理价格+已登记/交付的，受让人取得所有权。
- 第366条：居住权人有权按照合同约定，对他人的住宅享有占有、使用的用益物权，以满足生活居住的需要。
- 第394条：为担保债务履行，不转移财产占有将该财产抵押给债权人的，债务人不履行到期债务或发生约定情形，债权人有权就财产优先受偿。
- 第399条：不得抵押的财产（土地所有权、宅基地等集体土地使用权原则上不得、公益设施、权属不明、被查封扣押监管的财产等）。
- 第406条：抵押期间，抵押人可以转让抵押财产；抵押财产转让的，抵押权不受影响。

## 注意事项

- 物权编解决"物的归属与利用"；若纠纷源于合同（如房屋买卖违约），可能构成责任竞合（民法典第186条，见 civil-code-general 总则编），可择一请求。
- 登记是物权变动核心要件，但**合同效力独立于登记**（第215条区分原则）是实务易错点。
- 担保物权与合同编"保证合同"（第681—702条）不同：前者支配物，后者是人保；二者可并用（混合担保）。
- 司法解释口径（担保制度解释、物权编解释）属外部规定，引用时注明"需结合司法解释"，不混入民法典正文。
