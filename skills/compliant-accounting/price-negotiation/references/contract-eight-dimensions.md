# 底层框架：代理记账"服务契约"八大维度（独立推导，不依赖五信号）

> **方法**：不靠"五大信号"从结果反推（有天花板），改从**源头推导**——先问"代理记账这份契约的本质是什么"，
> 再把违反契约的每一种路径穷举出来。框架可复用，遇到任何新"低价玩法"都能对号入座、持续扩库。
>
> **契约本质**：法定存续期内，按会计准则、按税法，把企业真实商业活动准确记录、申报、报告，
> 并守住风险、尽到保密。凡是让这份契约打折扣的，都是"省出来的"。

## 八大维度

- **① 工作量维度**：省做事的功夫——票据/核算/对账/申报各环节砍工（见 `bookkeeping-shortcut-catalog.md` 30条）。
- **② 时限维度**：压线、拖延、漏节点——申报拖最后一天、结账拖下月中、汇缴草草、年报让人自己记。→ 逾期滞纳金+罚款。
- **③ 质量标准维度**：错账、科目乱、口径错、不按准则、不复核。"能做出来"≠"做得对"，低价图前者。
- **④ 合规/法定义务维度**：凭证不附原始单据、账册不按法定年限保管（凭证/账册30年、年报永久）、期末不核对、无证经营/挂靠/不备案。这不是偷懒，是直接违规。
- **⑤ 责任与兜底维度 ★谈判杀手锏**：不签正式委托协议、责任条款模糊、不投保职业责任险、无赔偿能力。账做错漏报，一句"你自己提供的东西有问题"甩锅，追责无门。→ **反击问句："他敢不敢给你签'因他过错导致的损失由他兜底'的条款？"**
- **⑥ 职业操守·反向迎合维度 ★最阴最反直觉**："便宜"的另一种代价不是做少了而是**做坏了**——为留住客户主动迎合做违规：虚开、虚增成本票、隐瞒收入、两套账、配合"避"税避成逃税。表面为你省税，实则把你送进刑法一条街。→ **反醒句："便宜的会计越对你'好'，越要警惕——他今天帮你虚一张票，明天稽查就是你的虚开发票罪。"**
- **⑦ 安全保密维度**：进货价、成本、利润、客户底细全在代账手里。无保密机制、随手转发、离职不交接清物。→ **反醒："您公司的底细，比压价那点钱值钱不是一星半点——攥在谁手里更要紧。"**
- **⑧ 透明可追维度**：不给查询权限、账务黑箱、服务不留痕。出事说不出"当时怎么做的"，账在你掌控之外=命脉交出去。

## 谈判/验钞机用法

- **⑤⑥⑦ 三招为增量杀手锏**，最能砸死低价同行：
  - ⑤ → 问"他敢签兜底条款吗"，把便宜变成"你连兜底都没有"。
  - ⑥ → 把"便宜+殷勤"变成"正在送你上刀口"，升级版认知炸弹。
  - ⑦ → 用"底细攥在谁手里"点老板的痛。
- **按客户情景挑**：谈价格 → 用①③（量少质低）抛砖；谈保障 → 用⑤⑦；客户显露出"图便宜找会来事的" → 用⑥当头棒喝。
- 收尾恒 "先比专业再比价格" 给台阶。
