# 事前培育：从普通企业到「够格认定」高企的 0→1 路径

> 定位：`service_workflow.md` S4（认定/复审）的**前置培育阶段**。回答「这家企业现在不是高企、想变成高企，怎么一步步规范到够格」。认定八条件、指标口径、程序细节见 `hte_certification.md`（本文件只讲"怎么爬上去"）。
> 核心心智：高企资格不是"申报那一刻"的事，是**申报前 1–3 年就要按认定口径养成账务与证据习惯**。临时补只会在复审/复核时翻车。

## 0. 关键认知（先纠三个错）

- ❌「高企认定是申报窗口期突击准备的事」→ 错。三项硬指标（研发占比/高新收入/科技人员）都看**申报前 1 年、近三年**的口径数据，临时做只会失真或翻车。
- ❌「先有研发投入，认证跟你没关系」→ 错。**认证期的账务/立项/工时规范度，直接决定复审顺不顺**。会做加计的客户是天然的高企种子。
- ❌「知识产权是老三样凑够就行」→ 错。Ⅱ类（实用新型/软著/外观）**仅能用一次**，重复用会在复审被抓；要有意识地布局Ⅰ类（发明/集成电路布图）与年度新增。

## 1. 第一阶段：资格预诊断（能不能 / 值不值）

承接"普通企业想走高企"客户，**先用 audit 诊断做资格预判**：
```bash
python engine/rnd_engine.py audit <预诊断实例.json>
```
- 看五大维度里「高企资格维持指标」得分 + 三项硬指标是否已在达标临界
- **不达标但有研发实质** → 进入培育（本流程）
- **负面清单行业 / 核定征收 / 无研发实质** → 直接劝退，转 tax-incentive-policy 找其他优惠
- **已达标的存量企业（此前走 B 路径只做加计）** → 提示"你其实够格了，转路径 A 认定享 15%"，这是重要增量机会

## 2. 第二阶段：立项与账套动工（第 1 年，地基）

必须在申报年度**前一年就开始**，因为近三年指标是滚动的：

| 动作 | 要点 | 产出 |
|------|------|------|
| 研发项目立项 | 按八领域匹配真实研发活动，立项书/决议/项目计划 | 立项档案 |
| 设「研发支出」科目 | 费用化/资本化分设，按 RD 项目辅助核算 | 科目结构 |
| 建**两套辅助账** | ①加计 2021 简化版 ②高企认定专用账（表7-8，近三年分年按RD项目）——从立项时就设，**不得事后补** | 辅助账 |
| 定分配方法 | 兼岗工时、共用材料/设备分摊规则，写进会计政策 | 分配办法 |
| 科技人员台账 | 名单、岗位、在职/兼职/临时、183 天佐证 | 人员台账 |
| 高新收入科目 | 设「高新产品(服务)收入」明细科目，按税法口径拆分 | 收入明细 |
| 知识产权布局 | 有核心知识产权（Ⅰ类优先），与高新产品对应 | IP 对应表 |

## 3. 第三阶段：三项硬指标滚动静养（第 1–3 年，蓄力）

**每年 3 月**用 `rnd_calc.py`（或 audit 的资格指标判定）滚动测算，缺口提前预警：

```
研发费用占比 = 近三年研发费 ÷ 近三年销售收入  分档按【最近一年销售收入】
  ≤5000万 → ≥5% ；5000万–2亿 → ≥4% ；>2亿 → ≥3%   （境内研发费占比 ≥60%）
高新收入占比 = 高新产品(服务)收入 ÷ 总收入 ≥60%    （总收入=收入总额−不征税收入）
科技人员占比 = 科技人员 ÷ 职工总数 ≥10%          （累计实际工作 ≥183 天）
```

**培育期调控杠杆**（合法合规内）：
- 研发占比不足 → 增加真实研发投入归集、剔除伪研发（不是硬凑）
- 高新收入不足 → 产品/服务技术含量梳理，拆分符合领域的高新收入明细
- 科技人员不足 → 完善研发岗位定编、做足 183 天工时（不是挂名）
- 知识产权不足 → 布局发明/软著，但必须真实对应产品
> ⚠️ 杠杆是"规范归集 + 真实投入"，**不是造假调数字**。培育的价值在于让企业真实情况反映到口径里，而非拔苗助长。

## 4. 第四阶段：申报期（达标后）

- 对照 `hte_certification.md` 五节认定程序提材料包
- 高新技术产品(服务)收入、研发费用金额、科技人员**三处口径一致**（会计/加计/高企），这是被约谈/复核的命门
- 专项审计/鉴证由有资质中介出具（乙方不出具），乙方负责口径对齐
- `audit` 在申报前再跑一次，确认达标 + 出《指标达标与风险提示函》

## 5. 培育期的坑（实战）

1. **立项与指标不同步**：项目立项了但费用没进辅助账、人员没进工时表 → 证据链断。立项、归集、证据必须同月起开。
2. **两套辅助账只建一套**：用加计 2021 版顶替高企认定专用账 → 复审专项审计不认（R006/G 已断言）。
3. **营业收入当高企收入口径**：高企「总收入 = 收入总额 − 不征税收入」（税法口径），不是会计营业收入 → 占比算错。
4. **Ⅱ类知识产权重复用**：复审时旧 IP 已用一次不能再计 → 提前布局新增。
5. **忽视 183 天**：兼职/临时研发人员累计不足 183 天计入 → 科技人员占比虚高被复查。
6. **证书管理缺失**：不按期更名、不报年度发展情况报表 → 累计两年未报取消资格。
