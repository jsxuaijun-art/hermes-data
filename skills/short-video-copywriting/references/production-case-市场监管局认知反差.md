# 生产案例：市场监管局认知反差（2026.7.26）

## 背景

携程被罚51.79亿热点仍在发酵，江姐提出新角度：从「市场监管局不只是办营业执照的」切入，做认知反差类短视频。

## 素材来源

- 监管总局对携程的反垄断罚单事件
- 江姐个人经验：做公司注册二十年
- 市场监管局内设科室：价格监督、反垄断、质量监督、食品安全、知识产权、广告监管等

## 角度发散

| # | 角度 | 一句话钩子 |
|:-:|:-----|:-----------|
| A | 认知反差（*选中*） | 你以为市场监管局就是办执照的？携程51.79亿就是他们罚的 |
| B | 权力对比 | 办营业执照，是市场监管局最小的权力 |
| C | 老板必修课 | 市场监管局有20多个内设科室，至少一半能管到你 |
| D | 历史演变 | 从"工商局"到"市场监管局"，改的不只是名字 |
| E | 反常识 | 市场监管局其实是你最大的"保护伞"，不是"对头" |

## 脚本一开头的修正过程

**原始开头（被否）：**
> "我做了二十年公司注册，以前也以为市场监管局就是打印执照的…"

**江姐纠正后的开头（采用）：**
> "市场监管总局罚了携程51亿。这说明一个事——市场监管局不只是办执照的，它管的事多了去了。"

**修正原因：** 热点必须放第一句，不然观众3秒就划走了。先扔炸弹再讲故事。

## 最终节奏结构

```
0-3s  → 砸热点：市场监管总局罚了携程51亿
3-6s  → 抛观点：说明不只是办执照的
6-12s → 自报资历：做了二十年公司注册
12-25s→ 列科室：价格监督、反垄断、质量监督…
25-35s→ 升华：它管的是整个市场的公平和秩序
35-40s→ CTA：评论区聊聊
```

## 复用规则

当热点事件涉及「政府/监管部门」时：
1. 第一句必须是热点数字/结论，不是个人经历
2. 个人经历放第二段（作为论据，不是开头）
3. 先扔炸弹 → 再讲故事 → 再升华 → 再CTA
