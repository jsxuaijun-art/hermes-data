# 中文学校官方表格 Word 文档生成

当用户要为孩子（中国小学/初中/高中）生成官方表格类文档时加载本技能：
少代会提案登记表、入队/入团申请书、社会实践表、家委会登记表、开学/报名表、中考/升学相关表格等。

用户背景：徐总的孩子就读上海闵行区 上海交通大学附属第二中学，现初二升初三（冲刺中考）。

## 核心：python-docx 中文处理

生成 `.docx` 时若直接写中文，Word 里字体可能错乱。**必须**给每个 run 显式设置中文字体：

```python
from docx.shared import Pt, Cm
from docx.oxml.ns import qn
# Normal 样式
style = doc.styles["Normal"]
style.font.name = "宋体"
style.element.rPr.rFonts.set(qn("w:eastAsia"), "宋体")
# 每个 run
r.font.name = "宋体"
r.element.rPr.rFonts.set(qn("w:eastAsia"), "宋体")
```

关键点：`rFonts` 的 `w:eastAsia` 属性控制中文字体，`style.font.name` 只设西文字体。**必须两个都设**，否则中文可能默认显示。仿宋/宋体是公文常用字体，字号 12pt（小四）。

## 页面与表单布局

- A4：`page_width=Cm(21.0)`, `page_height=Cm(29.7)`，边距 `Cm(1.8~2.0)`
- 常见布局 = **两列表格** `Table Grid`：左列为字段名（加粗，宽约3.2cm），右列为内容（宽约13.8cm）
- 字段名单元格可用 `\n` 放多行标签（如"提案附议\n（4人，填姓名及身份）"）
- 单元格内容多行：逐行 `p.add_run()`，行间用 `r.add_break()`，不要用 `cell.text=`（会丢弃格式）
- 待用户手填的个人信息（姓名、班级、民族、附议人等）用下划线留空：`＿＿＿` / `性别：______`
- 标题行：宋体 16pt 加粗居中

通用写法：把生成逻辑封装成 `para()` 和 `set_cell()` 两个辅助函数，参数化内容，方便用户换主题时30秒出一版新文档。见 `scripts/generate_form.py`。

## 少代会提案登记表（特殊结构）

提案需按登记表七个部分撰写，总字数约300字，一事一议、切入点要小：
提案题目（"关于……的提案"）、提案主题/类别、提案关键词（2-3个，分号分隔）、提出缘由（为什么）、主要内容（是什么）、意见建议（怎么办，具体可行）、附议人员（≥4人，写姓名和身份）。

主题/类别三选一：
1. 队员自身成长发展（①学习生活 ②身心健康 ③权益维护）
2. 少先队组织建设（①制度创新 ②组织创新 ③活动创新 ④评价激励）
3. 校园环境设施治理和学校发展（①校园文化 ②校园公共安全 ③科技创新 ④校园环境保护）
4. 其他

参考提案示例（话题 + 归类）：
- 心理健康/中考减压 → 1.② 身心健康
- 手机/电子产品管理 → 1.① 学习生活
- 校园垃圾分类/节电 → 3.④ 校园环境保护
- 开设科创社团 → 3.③ 科技创新

## 输出位置

用户要求在"桌面"时，保存到 `/mnt/c/Users/jiangmin/Desktop/<文件名>.docx`（Windows路径 `C:\Users\jiangmin\Desktop\...`）。文件名带上主题后缀便于用户区分多个候选题材。

## 验证

- 改完生成后务必用 `read_file` 或 python-docx 重新读一遍确认中文、字段、下划线都正确渲染
- 需用户手填的字段（姓名/班级/附议人）在最终交付文本里明确列出，方便用户逐项补填
- 如用户要打印可提示可导出PDF（LibreOffice `soffice --convert-to pdf`）
