# 研发支出辅助账建账实操

> 定位：高企账务与加计扣除的**地基**。无辅助账 = 不得加计 = 高企复核不达标。
> 配套：`assets/研发支出辅助账_2021简化版.csv`、`assets/辅助账模板说明.md`、`assets/研发工时记录表.csv`。
> 复算：`python scripts/gxrd_engine.py calc --json-text '<json>'`。

## 一、四条硬要求

1. **按项目设账**：对享受加计扣除的研发费用，按研发项目设置辅助账；一个纳税年度内多项研发活动的，分别归集。
2. **立项时设账**：研发项目立项时即设置辅助账，留存备查；**不得事后补建**。
3. **分别核算**：研发费用与生产经营费用分别核算；划分不清的不得加计（水电费、共用设备、兼岗人员须按合理方法分摊）。
4. **部门协同**：涉及公司决议、研发合同、会计账簿、科技成果资料，研发/人事/财务/行政任一断链即影响优惠。

## 二、辅助账样式三选一

| 样式 | 构成 | 适用 |
|------|------|------|
| 2015 版（97号） | 4 类辅助账（自主/委托/合作/集中）+ 1 张汇总表 | 项目多、审计/IPO要求高；继续有效 |
| **2021 版（28号）** | 1 类辅助账 + 1 张汇总表 | 中小微企业主力（推荐） |
| 自行设计 | 参照上述样式 | 须含 2021 版必填数据项且逻辑一致 |

**2021 版三大变化**：①简并样式（4 类合并为 1 类，多形式项目只建一套账）②精简信息（只填六大类费用合计，删借方/贷方）③调整口径（增加委托境外列次、体现其他相关费用限额统一计算）。

### ⚠️ 高企客户要另设「高企认定专用辅助账」

**两套账，不是一套账**。高企与加计口径不同，不能拿 2021 版加计辅助账直接充当高企申报底稿：

| | 加计扣除辅助账 | 高企认定专用辅助账 |
|---|---|---|
| 依据 | 2021年第28号样式 | 认定工作指引 + 《企业年度研究开发费用结构明细表》(表7-8) |
| 计量 | 按研发项目设辅助账，六大类费用 | 以单个研发活动为基本单位，按近三年每年分别填报，列 RD01/RD02… |
| 费用科目 | 人员人工/直接投入/折旧/无形资产摊销/新产品设计费等/其他相关 | 内部研发：人员人工、直接投入、**折旧与长期待摊**、无形资产摊销、**设计费用**、**装备调试费与试验费**、其他；另列委托外部研发(80%) |
| 其他费用上限 | 10%（全部项目统一计算） | 一般 ≤ 研究开发总费用 **20%**（按全部研发项目汇总） |
| 交付 | 随 A107012 留存备查 | 由有资质中介专项审计/鉴证，填认定申请书结构明细表 |

> 落地：高企客户在 `研发支出` 项目辅助核算下**分设两栏/两套台账**，共用原始凭证但按各自口径归集，年末出两张汇总表。

## 三、科目设置与分录

```
研发支出
├─ 费用化支出 — 项目A
│   ├─ 人员人工费用          ┐
│   ├─ 直接投入费用          │
│   ├─ 折旧费用              │ 六大类（加计口径）
│   ├─ 无形资产摊销          │
│   ├─ 新产品设计费等四项    │
│   └─ 其他相关费用          ┘ ← 单列，卡 10%(加计)/20%(高企)
├─ 费用化支出 — 项目B ...
└─ 资本化支出 — 项目C（开发阶段符合资本化条件）
```

| 环节 | 分录 |
|------|------|
| 研究阶段/开发阶段不符合资本化条件 | 借 `研发支出—费用化支出`，贷 银行存款/应付职工薪酬/累计折旧 等 |
| 期末结转 | 借 `管理费用—研发费用`，贷 `研发支出—费用化支出` |
| 开发阶段符合资本化条件 | 借 `研发支出—资本化支出`，贷 相应科目；资产负债表列「开发支出」 |
| 达到预定用途 | 借 `无形资产`，贷 `研发支出—资本化支出`；按 200%（120%企业220%）税前摊销 |

**资本化时点税收与会计一致**：按《企业会计准则第6号》判断，税收无另行规定。

**共用对象分摊方法**：
- 完全用于生产经营的仪器/设备/建筑物折旧 → 不得归集计入研发。
- 既研发又生产经营/多项目 → 按工时或工作量等合理方法分摊。
- 在用建筑物 → 按「研发占用面积÷总面积」分摊折旧，再按工作量在各项目间二次分摊（仅高企口径可计）。
- 多项目无形资产 → 按工作量分摊。
- 分摊方法一经确定不得随意变更，须留存计算证据。

**装备调试费边界**：研制特殊专用生产机器、改变生产和质量控制程序、制定新方法及标准等可计；**为大规模批量化/商业化生产的常规工装准备、工业工程费用不得计入**。

## 四、四类口径并列表（建账时分列）

| 维度 | 会计核算 | 高企认定 | 加计扣除 | IPO |
|------|---------|---------|---------|-----|
| 房屋折旧/租赁费 | 含 | 按指引 | **不含** | 按准则 |
| 其他费用上限 | 按准则 | ≤20% | ≤10%(统一) | — |
| 人员范围 | 研发人员 | 科技人员(≥183天) | 直接研发+外聘 | 全时/非全时须工时佐证 |
| 委托研发 | 按实际 | 境内符合条件部分 | 80%(境外另限2/3) | 委外单列核查 |

> 辅助账**单列「其他相关费用」并同时标注高企口径占比与加计口径占比**，三套数字能解释差异是 IPO/专项审计过关关键。

## 五、标准归集 SOP

1. **立项**：项目计划书 + 立项决议（企业内部有权部门即可，无须科技部门事前鉴定/备案）+ 项目组与研发人员名单 + 预算。
2. **设账**：按项目设辅助核算，选样式（推荐 2021 简化版），定分摊方法（工时/机时/面积，一经确定不得随意变更）。
3. **日常归集**：人员人工（工时记录）、直接投入（领料单/出库单）、折旧摊销（使用记录）；多用途按合理方法分配；委托/境外单列。
4. **月末结转**：费用化→管理费用；资本化→保留余额列「开发支出」。
5. **年末汇总**：编《研发支出辅助账汇总表》→ 与总账、A107012、专项审计三处核对 → 随财报/申报留存备查。

- [ ] 内部研发机构/项目组编制（含研发人员名单）

- [ ] 直接投入领料单/出库单（与项目对应，生产领料不得混入）
- [ ] 仪器设备使用记录（多用途按机时分摊）

- [ ] 委托/合作研发合同科技部门登记证明

## 七、例 4-1 全链填表示范（辅助账→汇总表→A107012）

**背景**：甲公司 2023 年三个项目。A 自主费用化未完成，研发费 200 万（人员人工100=工资80+五险一金20、直接投入50、折旧10、专利权摊销5、新产品设计费5、其他相关30=差旅20+会议10）。B 自主资本化，2023.1.1 起资本化、7.10 结转无形资产、直线法10年，研发费100万。C 委托研发 100 万（境内70+境外30）。

**各项目前五项合计**：A=170万，B=95万，C=0。

**① 其他相关费用限额（2021年第28号，全部项目统一算）**
```
= (170万 + 95万 + 0) × 10%/(1−10%) = 294,444.44
实际发生 35万 > 限额 → 按 294,444.44
   A = 294,444.44 × 30/35 = 252,380.95
   B = 294,444.44 ×  5/35 =  42,063.49
```
复算 `other_limit(2650000, 350000)` → 限额 294,444.44、超限 55,555.56。

**② 委托研发**：境内 70×80%=560,000；境外 30×80%=240,000（未超境内2/3）→ C 可加计 800,000。

**③ 年度研发费用小计（A107012 40行）**
```
40行 = 2(2,944,444.44) + 36×80%(560,000) + 38(240,000) = 3,744,444.44
```
（2 行 = 170万+95万+294,444.44 = 2,944,444.44）

**④ 允许扣除研发费用合计**
```
费用化 = 1,700,000 + 252,380.95 + 800,000 = 2,752,380.95
资本化 =   950,000 +  42,063.49 = 992,063.49（本年留以后年度摊销）
本年形成无形资产摊销额 = 992,063.49 ÷ 10 × 6/12 = 49,603.17
允许扣除研发费用合计 = 2,752,380.95 + 49,603.17 = 2,801,984.12
```

**⑤ 加计扣除总额** = 2,801,984.12 × 100% = 2,801,984.12。

**A107012 关键行**：1行项目数3；2行 2,944,444.44；28行其他实际 350,000；34行经限额调整 294,444.44；35行委托 1,000,000；36/37/38行 700,000/300,000/240,000；40行 3,744,444.44；41行费用化 2,752,380.95；42行资本化 992,063.49；43行摊销 49,603.17；45行允许扣除 2,801,984.12；51行加计总额 2,801,984.12。

> ⚠️ **40行 = 2 + 36×80% + 38**，不是 35×80%：境外委托已在 38 行体现限额后金额，勿把 37 行再乘 80%。34/38 是两个独立限额。表版本每年可能调整，以电子税务局当年表样为准。

## 八、常见错误速查

| 错误 | 后果 |
|------|------|
| 事后补建辅助账 | **不得加计**（红线） |
| 一个项目按研发形式分设多套账 | 2021 版无需分设，徒增不一致风险 |
| 自设样式缺必填项/逻辑不一致 | 归集不被认可 |
| 研发与生产划分不清、水电未分摊 | 划分不清部分不得加计 |
| 领料单与项目 BOM 不匹配 | 稽查穿透（黄金案） |
| 限额仍按项目分别计算 | 少加计或算错（2021 起统一计算） |
| 辅助账、专项审计、A107012 三处不一致 | 高企复核/汇缴被质疑 |
