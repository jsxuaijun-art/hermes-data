# 高考英语词汇默写本生成器

## 定位
副业工具。非主营业务，仅在有闲时调用。

## 调用方法
用户说「调用词汇默写本」时，执行以下流程：
1. 询问词汇文件路径（默认桌面 `高考英语词汇表3817词.txt`）
2. 询问每组单词数量（默认50）
3. 询问版本偏好（词根版/前缀版/精简版）
4. 运行脚本生成文档放桌面

## 拓展用法：提取考试词汇\n\n无需人工提供词库。利用英文词频数据 + 高考词汇表交集筛选特定级别词：\n- **中考词汇（苏/沪）**：取频次排名前1800词，与源词汇表取交集 → 约1200词\n- 脚本见 `scripts/build_suzhou.py`（该脚本已内嵌频率筛选逻辑，修改SRC和WPG即可适配其他级别）\n- 调用时：告知词汇级别（中考/高考/四级/考研），由脚本自动交集提取即可\n\n## 用户偏好（经验法则）
- `#` 列宽必须压到0.2cm（绝对最小值），节余宽度**均分**给其他列。用户曾反复纠正此宽度。
- 鼓励语必须 **每组必有**、**10pt加粗红色**、**不可留白**。用户发现前版本部分组空白后要求修正。
- 音标填空区必须**分行**：「英＿___」一行、「中＿___」下一行，不可合并在一行内。
- 内容必须**铺满整页**，底部不得留空。若行高过大导致溢出下一页，说明行高值算错（正确值600dxa）。
- `序号`统一替换为 `#`。
- 封面元素间要有足够间距，不可堆叠。ctr()的before/after参数不可过小。

## 已知坑点
- **行高值容易算错**：25行填满A4页的正确行高是**600 dxa**（≈1.06cm），不是2977 dxa。2977 dxa=5.25cm会导致25行需要131cm，严重溢出。
- **鼓励语可能因为百分比门槛不触发**：里程碑从5%开始，前几组累计不到5%时不显示。修复方案：配「通用加油语」后备，每组必出。
- **词根列表解析**：`RAW_ROOTS` 字符串必须**每行一个 `root|meaning`**，一行放多个词根用`|`分隔会导致后续词根丢失。

### 江姐文案风格特征（2026.7.6 从用户原稿+对话中萃取）

以下特征稳定出现，未来写文案**必须遵守**，不要改成「AI口吻」：

1. **自嘲+真实感开场**：用「说实话」「搞的」「挺崩溃的」开头，不装权威，先示弱建立信任
2. **具体数字**：背100个 → 忘80个 / 记住85个，不用笼统描述
3. **科学锚点**：艾宾浩斯1885年 → 精确到年份和人名，增加可信度
4. **产品作为「副产品」出现**：核心叙事是她如何帮女儿，产品只是「顺便做出来的」
5. **口语化收尾**：「不好用你来找我」「需要的评论区扣XX」→ 指令清晰，不装客气
6. **不用AI套路句**：避免「你是否曾经」「这是一个值得深思的问题」「开启你的...之旅」
7. ⚠️ **不要重写用户初稿**：用户发来的草稿保留90%原文，只做结构微调+收藏率钩子增强

### 推广文案修改规则（基于江姐原稿的优化记录）
- **黄金三秒**：避免铺垫型开场（「辅导过孩子的家长」），改用冲突型开场（「说实话，我一开始也挺崩溃的」）
- **收藏率钩子**：把六轮步骤写得可截屏可保存，增加收藏价值
- **口语化**：减少书面语，增加「搞得」「管用」「你来找我」等聊天感表达
- **互动引导**：避免半封闭问题（「你认一认同」），改用明确行动指令（「评论区扣方法」）
- **信任锚**：公开真实动机（给女儿做的），降低广告味
- **结尾钩子**：用「不好用你来找我」替代「回来汇报成果」，显示底气
- **⚠️ 用户自写初稿的黄金法则**：用户（江姐）自己写的草稿有不可替代的真实感。如果她发来初稿让改，保留90%原文，只做结构微调+收藏率钩子增强。不要重写——她的「辅导孩子」经历是最强信任锚，AI润色过度会破坏真实感。
