# 公司注销完整流程与最新政策（2024-2026）—— 调研全稿

调研时间：2026-08 | 覆盖：流程顺序与材料、税务注销最新政策（简易/即办）、税务注销查什么、纳税工商银行衔接、苏州上海代办收费。

## 1. 完整流程各环节核心要点与时限

| 环节 | 关键动作 | 法定时限 | 核心材料 |
|---|---|---|---|
| ① 成立清算组 | 股东会决议解散，确定清算组成员 | 解散事由出现之日起15日内 | 股东会解散决议、清算组成员名单 |
| ② 清算组备案/公告 | 国家企业信用信息公示系统公告清算组信息 | 清算组成立之日起10日内 | 清算组信息(名称/成员/负责人) |
| ③ 债权人公告 | 通知已知债权人+免费发布公告 | 60日内发布；公告期45日(个独无法通知60日) | 债权人公告、债权申报期限说明 |
| ④ 开展清算 | 清财产、编资产负债表和财产清单、清缴税款 | 清算期(45日公告届满+申报期) | 清算方案、资产负债表、财产清单 |
| ⑤ 税务注销(清税) | 结清税款/滞纳金/罚款、缴销发票税控、申报清算所得 | 一般纳税人10个工作日;小规模5个工作日;即办情形即时办结 | 《清税申报表》、经办人身份证、董事会/主管批复决议、发票领用簿、税控设备、法院裁定(破产/强清) |
| ⑥ 工商注销 | 提交经确认的清算报告+清税证明 | 清算结束后,公告期满后 | 《公司注销登记申请书》、股东会决议、清算报告、清税证明、营业执照正副本 |
| ⑦ 社保/公积金注销 | 结清社保欠费后注销 | 工商注销之日起30日内 | 社保注销申请、社保欠费结清凭证 |
| ⑧ 银行账户销户 | 先销一般/专用/临时存款户,资金转基本户后再销基本户 | 须完成税务注销手续后方可销户 | 工商注销证明、营业执照、法人身份证、公章/财务章/法人章 |
| ⑨ 印章缴销 | 到公安机关指定地点缴销公章 | — | 营业执照注销证明、法人身份证 |

### 税务注销材料清单（权威口径）
- 《清税申报表》(一照一码户) 或《注销税务登记申请审批表》(非一照一码户)
- 经办人身份证件原件(实名办税可免)
- 条件报送：董事会/上级主管部门决议、法院破产/强清裁定书、吊销营业执照决定、发票领用簿、税控设备、项目完工/验收证明(非居民承包工程)等
- 已实名办税/信息共享可获取的可取消复印件报送

## 2. 政策文件沿革（引用依据）

1. **税总发〔2018〕149号**《关于进一步优化办理企业税务注销程序的通知》——首次推出清税证明免办、承诺制容缺、即时办结。
2. **税总发〔2019〕64号**《关于深化"放管服"改革 更大力度推进优化税务注销办理程序工作的通知》——扩大即办范围；明确"办理过涉税事宜但未领票、无欠税滞纳金罚款的主动清税,资料齐全即时出,资料不齐承诺制容缺"；破产即时出文书核销死欠（**该条已废止，见下**）。
3. **国市监注发〔2021〕45号**《关于进一步完善简易注销登记 便捷中小微企业市场退出的通知》(市场监管总局+税务总局)——简易注销公示期45→20天；拓展适用范围；个体工商户免承诺书免公示；税务部门对三类情形不提异议。
4. **市场监管总局等六部门 2025年第52号公告**《企业注销指引（2025年修订）》(2025-12-12)——现行总纲；明确决议解散→清算分配→注销登记；清算组成立/公告/债权人公告时限(10日/60日/45日)、清算职责(清缴税款、缴销发票税控、办理企业所得税/土增清算、结清出口退免税)、法律责任。
5. **税务总局+最高法 2025年第24号公告**《关于企业破产程序中若干税费征管事项的公告》(2025-11-27)——破产企业**持终结破产程序裁定书即申请税务注销、即时出具清税文书、核销"死欠"**；税款/社保单独申报、滞纳金利息按普通债权；重整和解中未获清偿的滞纳金罚款**不影响注销**；依法解除财产保全、中止强制执行；**废止**税总发〔2019〕64号第一条第三项及2019年48号公告第四条。

## 3. 三类注销路径判定细则

### 路径A：免办清税证明（直接向市场监管部门简易注销）
- 未办理过涉税事宜的纳税人；
- 办理过涉税事宜但未领用发票(含代开)、无欠税(滞纳金)及罚款的纳税人；
- 简易注销公告期届满之日前已办结缴销发票、结清应纳税款等清税手续的。

### 路径B：即办/承诺制容缺即时办理
1. 办理过涉税事宜但未领用发票(含代开)、无欠税(滞纳金)及罚款，主动清税；
2. 未处税务检查状态、无欠税、已缴销专票税控，且属下列之一：
   - 纳税信用 A级和B级；
   - 控股母公司纳税信用A级的 M级；
   - 省级政府引进人才/省级以上行业协会认定行业领军人才创办企业；
   - 未纳入纳税信用级别评价的定期定额个体工商户；
   - 未达到增值税纳税起征点的纳税人；
   - 由总机构汇总缴纳增值税/所得税、不就地预缴或分配的分支机构。
3. 经法院裁定宣告破产或强制清算的，持终结破产/强清程序裁定书即时出文书核销"死欠"；
4. 未办涉税事宜的纳税人主动清税，凭营业执照即时出文书。

### 路径C：一般注销（必须走）
有欠税滞纳金罚款、处税务检查/稽查状态、发票税控未缴销、被列经营异常名录/严重违法失信、未申报纳税处非正常户(须先解非+补申报)、被特别纳税调查期间、或符合即办条件但不愿承诺的。税务机关出具《税务事项通知书》告知未结事项，办结后办理。

### 市场监管简易注销程序（253号文+45号文）
- 适用：未发生债权债务或已将债权债务清偿完结的有限责任公司/非公司企业法人/个独/合伙企业(上市股份公司除外)。
- 公示期20天(原45天)，公示届满20天内申请，可延长最长30天。
- 材料简化为《全体投资人承诺书》等，不再提交清算报告/投资人决议/清税证明/清算组备案/登报样张。
- 不适用：被列经营异常名录/严重违法失信、股权被冻结/出质/动产抵押、非法人分支机构未注销、正在被立案调查/行政强制/司法协助/行政处罚、曾终止简易注销、注销前需经批准、外商投资准入特别管理措施等。

## 4. 税务注销查什么（预检清单）

1. 有无未办结涉税事项；
2. 账务与清算所得：企业所得税就清算所得申报缴纳；未办土增清算先办；出口企业结清出口退(免)税；
3. 发票与税控设备：缴销发票和其他税务证件、注销防伪税控信息；
4. 欠税欠费：结清应纳税款、多退(免)税款、滞纳金和罚款；
5. 异常状态：非正常户先解非+补办申报；被特别纳税调查期间原则上不予注销；是否处税务检查/稽查状态；
6. 社保及银税划缴：已登记社保费信息须办注销；银税三方(委托)划缴协议税务注销办结后自动终止。

## 5. 衔接顺序
**税务注销→工商注销→银行销户**。税务注销须早于工商(持清税证明)；银行销基本户凭工商注销证明、须先完成税务注销；社保注销在工商注销后30日内。

## 6. 代办收费行情（苏州/上海）

| 类型 | 苏州参考 | 说明 |
|---|---|---|
| 简易注销(税务正常) | 约2000元起 | 固定打包价 |
| 一般注销(账目清晰) | 约5000元起(常见3000-8000元) | 按工作量评估 |
| 疑难注销(异常/非正常户/黑名单/股东失联) | 约10000元起 | 含补申报、罚款缴纳、异常移除、解黑 |
| 税务注销单项代办 | 视情况数百至数千元 | 账务清晰即办情形便宜 |

- 全程正常公司注销实务常见3000-8000元，异常公司6个月-1年并大幅加价。
- 上海与苏州接近，常见4000-8000元区间，简单可低至2000元，疑难/异常大幅上浮。
- 影响变量：纳税人类型、票量、行业复杂度(电商/建筑/外贸加价)、账务混乱度、是否需补账补税罚款。
- 比价要"同口径比总成本"，正规机构敢把"因会计失误导致罚款滞纳金由机构承担"写进合同。
