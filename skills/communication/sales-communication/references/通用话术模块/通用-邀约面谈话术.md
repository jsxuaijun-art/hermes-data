# 通用话术模块 · 邀约拜访与面谈话术

> 来源：代帐促单培训材料。邀约5步+6方法；面谈准备+5步面谈思路。

## 一、邀约话术

**邀约成功的核心：** 让客户明白你不会占用太多时间，且上门拜访有客户不容拒绝的好处。

### 邀约5步流程
1. **约定时间：** 刘总，明天上午10点左右你在公司吗？我带着会计去见你。
2. **体现价值：** 刘总，我过去见你不光是聊合作，还会给你分享一些政策信息，包括最新优惠政策、近期稽查重点、同行省钱方案，这些信息对你一定有用。
3. **降低防备：** 刘总，我上门拜访，合不合作是你的选择，我把这里面的细节一次性讲清楚，给你做个对比分析，你做选择的时候也更方便，节省时间和精力。
4. **让客户知道不占用太多时间：** 这次过去，你给我留30分钟时间就可以了。
5. **多次拜访：** 每个客户都要发起3次以上的拜访，哪怕客户没答应，也要确认下次沟通时间，争取更多机会。

### 6种邀约方法

| 方法 | 适用客户 | 操作要点 | 参考话术 |
|------|---------|---------|---------|
| 直接邀约法 | 有意向、直爽配合的客户 | 开门见山直接约见 | 刘总，电话里也说不清具体细节，也没办法展示。我们见面花几分钟详细介绍一下，您是今天上午还是下午方便，我去拜访您？ |
| 假设合作法 | 有意向或对代账感兴趣的客户 | 假设客户已想合作，自然切入见面 | 刘总，新客户合作的活动马上就结束了，我先给你保留了一个名额。你今天上午还是下午方便，我去拜访你？ |
| 同行刺激法 | 对见面犹豫不决的客户 | 举例合作客户，让客户有从众心理 | 刘总，你看光是这个月跟我们合作的建材公司就有七八家，比如XX公司，非常看重专业和服务，你就放心交给我们吧。这样你看上午还是下午方便，我去拜访您？ |
| 随机拜访法 | 对见面犹豫不决的客户 | 用提问方式试探客户感受 | 刘总，你看巧不巧，我有个客户刚好在附近，我顺便去拜访一下你，你看下午3点还是4点时间方便呢？ |
| 试探邀约法 | 比较强势或意向不明确的客户 | 充分尊重和耐心 | 刘总，咱们沟通了这么久，你感觉我们公司怎么样呢？要不这样，我们具体面聊，我给你做个分析和对比，你看怎么样？ |
| 同情邀约法 | 拒绝见面但对代账感兴趣的客户 | 用业绩等个人困难激发同情心 | 刘总，咱们沟通了这么久，感觉你也是一个非常真诚的人。我这个月就差1个单子就能完成任务了，年轻人创业/工作也不容易，就当支持我一下，也给你多一个选择考察的机会。我们见面聊一下，等你了解完了再做决定也不晚，你看上午还是下午方便？ |

## 二、面谈话术

### 1) 面谈前的准备
- **《客户信息分析表》**：客户姓名/身份(法人/合伙人/实际经营者)、企业背景、类型(个体户/个独/有限公司/合伙/股份)、经营范围、阶段(初创/发展/转型/成熟)、财税意识、代账需求点、反对意见及解决方案、逼单关键点。
- **网上背景调查：** 经营范围、主营产品、行业状况，预估自己已有的资源。
- **判断客户阶段**（初创期不了解财税/发展期较重视但关注价格/成熟期很重视价格还好）。
- **切入方式：** 成功签单案例，或从客户需求点切入。
- **方案准备：** 想给的方案、套餐如何包装、如何设逼单点。
- **判断逼单点：** 客户短期内做决策的速度、有何硬性需求。
- **自我演练：** 和主管/同事一对一情景模拟演练，检视不顺畅处。

### 2) 面谈5步思路
1. **破冰：** 自我介绍、寒暄赞美、道明来意（破冰开场白见获客破冰话术）。
2. **确认需求：** 把之前谈的需求再确认一次，若有新异议或新需求，现场深入了解挖掘确认，找到最本质的需求点。只有找到痛点，才能对症下药。
3. **强调优势：** 结合客户需求，告诉客户我们能解决他的问题。话术模板（特征-优点-利益-证据）：
   - 特征：因为我们的产品跟别的公司有哪些不一样的地方……
   - 优点：所以，我们有哪些亮点/功能/作用……
   - 利益：对您而言，我们的产品能给您带来什么利益或好处……
   - 证据：比如说我们的某个客户，跟我们合作前后有哪些变化……
4. **疑虑解决：** 常见疑虑见《通用-疑虑处理话术》，这里不重复。
5. **试探成交：** 提前准备好合同，只要聊得差不多了，就瞄准机会递合同，不要等客户问。只要客户没有反对意见，就默认成交、现场收款。
   > 刘总，没其他问题的话，咱们今天就把事情定下来，我们也能第一时间安排人手做后续服务，特别是工商注册，需要准备的材料挺多的、流程时间也很久，我把对公账户发你。
   **（整个环节前提：一定要敢递、多递合同。）**
