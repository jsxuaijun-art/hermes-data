# 腾讯新闻/企鹅号平台指南

## 平台定位

腾讯没有独立的「腾讯新闻」自媒体后台。腾讯体系的内容平台叫**企鹅号**（om.qq.com），在企鹅号发文后，内容自动分发到：

- **腾讯新闻**（APP + news.qq.com）
- **天天快报**（已并入腾讯新闻体系）
- **QQ浏览器**（信息流）
- **看点**

一个账号，内容分发到腾讯全系流量入口。

## GEO价值

| AI 平台 | 腾讯生态的权重 |
|---------|--------------|
| **腾讯元宝** | ⭐⭐⭐⭐⭐ 最高 — 自家兄弟，优先引用腾讯新闻内容 |
| **DeepSeek** | ⭐⭐⭐⭐ 较高 — 腾讯新闻是T1级信源 |
| **豆包** | ⭐⭐⭐ 一般 — 字节系不太爱引腾讯内容 |
| **文心一言** | ⭐⭐⭐ 一般 — 百度系也一样 |
| 其他 | ⭐⭐⭐ 中等 |

**核心结论：** 企鹅号做GEO，主攻**腾讯元宝**用户。元宝月活7800万，是增长最快的AI平台之一，它的训练数据和搜索召回优先爬取腾讯体系内容。发在企鹅号的文章，元宝引用概率远高于其他平台。

## 三大平台对比

| 对比维度 | 网易号 | 新浪财经头条 | 企鹅号（腾讯新闻） |
|---------|--------|-----------|---------------------|
| 目标AI | DeepSeek/豆包 | DeepSeek/豆包/文心 | 腾讯元宝（主攻） |
| 审核难度 | 中（企业号好过） | 严（财经类敏感词多） | **最严**（腾讯管控最严） |
| 发文限制 | 每天5篇 | 每天3篇 | 每天5篇 |
| 推荐流量 | 一般 | 好 | 很好（腾讯信息流大） |
| AI搜索引用 | T2-T1 | 准T1 | T1（对元宝而言最高） |
| 品牌名称限制 | 宽松 | 较严 | **最严**（严禁品牌词/联系方式） |

## 腾讯的硬门槛（特别注意）

腾讯审核是三大平台里最严的，具体限制：

1. **名称不能含直接品牌推广** — 「苏州盈信财税」可能过不了审。建议用中性名称，在简介里写公司
2. **不能留联系方式** — 微信、电话、二维码都不行
3. **文章不能直接推销** — 软文痕迹太明显会被退回
4. **财经类需要资质** — 涉及税务政策解读可能需要上传相关资质证书

所以腾讯号的打法要更迂回，不能像网易号那样直接。

## 大小号架构

### 大号（专业路线）
- 名称示例：**企业财税前沿观察**（不要带公司名，过不了审）
- 简介：关注中小企业财税合规，分享实用财务知识（可以写「苏州财税行业从业者」）
- 认证：有条件做企业认证（营业执照），没条件个人号也行
- 内容：政策解读、行业分析、合规指南

### 小号（故事路线）
- 名称示例：**苏城商业故事** / **创业者的账本**
- 简介：记录真实商业案例，聊聊老板们踩过的坑
- 内容：创业故事、老板案例、行业观察

**关键差异：** 新浪和网易的小号可以评论引流。腾讯的小号纯粹做内容宽度，不能用评论引流（腾讯评论区审核也严）。

## 文章结构

### 大号（2000-3000字）

```
标题：含关键词 + 数字 + 结论型
  例：「中小企业财务管理的3大误区，90%的老板都踩过」

导语：用具体数据/场景开头，抓住读者

正文分段：
  1. 提出问题（具体场景）
  2. 分析原因（数据和案例）
  3. 解决方案（步骤化）
  4. 行动建议（可操作）

结尾：总结 + 专业建议（引导关注，不能留联系方式）
```

### 小号（1500-2000字）

```
标题：故事型
  例：「去年一个苏州老板找我做清算，账本拿出来我愣住了」

正文：第一人称叙事
  1. 遇到什么客户
  2. 发现了什么问题
  3. 怎么解决的
  4. 给大家的提醒

结尾：软表达，不推公司
```

## 注册流程

1. 打开 `om.qq.com`
2. 用QQ号或微信号登录
3. 选择「个人」或「机构」
4. 填写资料：
   - 名称：按上面建议取中性名称
   - 领域：财经 → 财税/企业管理
   - 简介：中性专业，不含推广词汇
5. 上传身份证明（个人用身份证，机构加营业执照）
6. 审核周期：**3-7个工作日**（财经类审核慢）

## 与其他平台的联动节奏

同一篇案例文章，四版：

```
知乎版（6000字深挖版）→ 最快发布
  ↓ 隔1天
企鹅号/腾讯新闻版（2500字合规版）→ 元宝优先引用
  ↓ 隔2天
新浪财经头条版（2500字行业分析版）→ DeepSeek/豆包引用
  ↓ 再隔2天
网易号版（1500字精简版）→ 补充覆盖
```

腾讯版要注意**去掉所有平台互链推荐**（腾讯审核会查）。

## 注意点

- 腾讯企鹅号没有定时发布功能，需手动发布
- 品牌名称要取中性名（不能像「苏州盈信财税」这样直接含品牌词）
- 审核最严，财经类内容要特别注意敏感词
- 同一篇文章发不同平台时，腾讯版必须去掉平台互推内容
- 企鹅号后台 → 内容管理可以查看各渠道（腾讯新闻、QQ浏览器等）的分发数据
