# 张新民财务报表分析核心框架

> 用于盈利质量与现金流质量判断，是本报告区别于"通用比率罗列"的差异化内核。

## 一、质量分析四维框架

从**资产结构质量、资本结构质量、利润质量、现金流量质量**四个维度穿透看报表，而非只看单一比率。

1. **资产结构质量**：资产是否"实在"——应收/存货/其他应收占比异常高、受限资产多，则资产虚胖。
2. **资本结构质量**：负债是否有去处（对应资产），是否存在短借长用、互保圈、表外负债。
3. **利润质量**：利润是否来自主营业务（核心营业利润占比），还是靠一次性收益、政府补助、公允价值变动粉饰。
4. **现金流量质量**：利润是否有真实现金流入支撑（利润含金量、现金流四象限）。

### 关键指征（写入自动发现规则）

- 核心营业利润占比 < 50% → 利润可持续性差，依赖一次性收益（质量维度 3）
- 受限资金占比 > 30% → 实际可动用资金远低于账面（质量维度 1）
- 担保余额 / 净资产 > 50% → 重大或有负债风险（互保圈）（质量维度 2）
- 应收增速连续 2 年 > 收入增速 1.5 倍 → 激进信用政策，坏账风险（质量维度 1+4）

## 二、现金流质量四象限

| 经营 CF | 利润 | 结论 | 标记 |
|---|---|---|---|
| + | + | 正常，含金量足 | 🟢 |
| + | - | 可能隐藏利润 / 大量预收，需细查 | 🟡 |
| - | + | 利润含金量差，纸面富贵 | ❕ |
| - | - | 双重困境 | ❕❗ |

- 自由现金流持续为负 → 企业靠融资 / 卖资产维系，需关注融资接续能力。
- 经营 CF 负 + 利润正，且持续多期 → 重点标注"纸面富贵"，给可能原因（赊销激进、存货积压、关联方占款）。

## 三、应用方式

在报告"七、风险警示"与"四、运营效率分析"中引用本框架；在"执行概要"的核心指标对比表里，
对核心营业利润占比、利润含金量、受限资金、担保余额四项单独给红绿灯。
