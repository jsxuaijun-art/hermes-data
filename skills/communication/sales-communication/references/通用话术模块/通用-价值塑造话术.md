# 通用话术模块 · 价值塑造话术

> 来源：代帐促单培训材料。核心公式：**因为什么特点，所以有什么优势，对您而言有什么好处（配证据）**。

## 一、公司优势（用数字和硬资质强调）

- **品牌口碑：** 我们在当地成立多少年？目前多少客户？其中70%来源于客户转介绍。**用数字说话。**
- **持证上岗：** 会计部有几位专职会计、考取哪些证书。证书最有说服力（如高级会计师、中级会计师、税务师）。
- **定期培训：** 定期专项培训（个体户/汇算清缴/进出口/税务稽查专项等）。
- **定期考核：** 每月考核主办会计、沟通会计、外勤会计、会计助理，都要有扎实专业知识。
- **专家资源：** 财税专家资源库，处理财税合规、税务稽查等问题有人脉和资源，让企业和老板放心。
- **价格透明：** 专业代账公司做口碑，价格公开透明，后期没有隐形收费。

## 二、分工明确
- **会计分行业：** 会计分不同行业，合作后有专门负责的会计团队（如某会计专做电商贸易行业，对行业账务、政策、资源都很了解）。
- **部门协作：** 专业财税公司除代理记账事业部，还有财税合规事业部、稽查应对事业部，多部门协作，根据财务数据出具报表、分析经营风险。

## 三、超值服务
- **服务保障：** 配备专职客户服务经理 + 智能做账系统（内置税务风控模型，对企业税务/发票/工商数据多角度分析，出具税务风险检测报告）。
- **政策学习：** 提供财税政策学习渠道，让企业无忧、老板无忧——不单单是财税服务，而是企业成长服务。

## 四、特点-优势-好处-证据 模板（价值塑造核心公式）

> 切记：塑造价值一定要围绕客户能得到的好处。

| 特点 | 优势 | 好处 | 证据 |
|------|------|------|------|
| 品牌口碑 | 在当地一点一点做起来的 | 认真负责 | 在当地成立X年；拥有X客户；X%转介绍 |
| 持证上岗 | 主办会计X年经验，会计经理精通5个以上行业账务，能处理疑难账税 | 经验丰富不易出错，不让企业多交冤枉税糊涂税 | 岗位资格证书/证书/客户好评截图/账本账套 |
| 定期培训 | 定期专项培训 | 确保企业财务安全 | 学习培训照片 |
| 定期考核 | 各岗位都要有扎实专业知识 | 后续服务专业高效 | 考核照片 |
| 专家资源 | 有财税专家资源库、人脉资源 | 最大程度让企业和老板放心 | 专家团队形象照/讲课照片/客户好评 |
| 价格透明 | 专业代账公司，价格公开透明 | 后期没有隐形收费 | 价格表 |
| 会计分行业 | 会计分行业专人负责 | 熟知不同行业政策资源，账务更安全不交冤枉钱 | 会计团队形象照/朋友圈截图 |
| 部门协作 | 代理记账+财税合规+稽查应对多部门协作 | 出具报表、分析经营风险，助力稳步发展 | 公司照片/报告展示 |
| 服务保障 | 专职客户经理+智能做账系统+税务风控 | 定期税务风险检查，提前预警，规避解决 | 功能展示、报告展示 |
| 政策学习 | 提供财税政策学习渠道 | 不单单是财税服务，而是企业成长服务，安心省心 | 线上线下培训会照片/客户反馈 |

**举例（完整套用）：** 因为我们合作后会有专门的会计团队负责（特征）→ 所以对不同行业的政策、资源都非常了解，账务更安全（优势）→ 对您而言就是不用多交冤枉钱、账更放心（好处）→ 您可以看看我们XX行业客户的反馈（证据）。
