# 盈信品牌标语 / 口号 / 企微签名 创作

## 适用场景
- 用户要「标语、口号、宣传语、slogan、签名」类短文案
- 用户要「企业文化、企业精神、价值观、信仰追求、道德规范、行为准则」标语体系
- 企业微信朋友圈「签名素材库存」多版本口号
- 文化墙、名片背面、公司简介页脚、招聘宣讲、服务手册的定稿标语

## 模型路由铁律（不可违反）
- **短文案/标语/口号/签名 → 豆包 Doubao-Seed-2.1-Pro（telecom-doubao）出稿**，主会话只做编排、校准、事实校验
- 调用器 = skill `llm-longform-generation/scripts/stream_chat.py`（stream=true，密钥走环境变量名传入，勿内联）
- 主会话绝不直接写短文案（违规 = 失效交付）

## 已核实事实白名单（唯一可用的背书，喂给豆包防编造）
- 盈信企业管理（苏州），2009 年成立，苏州+上海双城，专注中小微企业
- 主营：公司注册、代理记账、税务合规咨询、高端会计服务
- 团队：徐爱军（负责人，上海交大管理硕士）；江敏（苏州本地高级会计师）；注册税务师 CTA；注册会计师 CPA
- 资质：涉税专业服务机构信用等级 TSC 五级（最高等级）
- 沉淀：十七年财税实务，上千家客户，转介绍比例高
- 精确数字/占比/客户数一概以确认口径为准，无据不得写；宁缺口号张力也不编

## 企业文化标语 五维框架
按 5 个维度组织，每维 3 条候选，每条 = 「标语 —— 一句话注解（落点/适用场景）」：
- A 企业精神（盈信信什么、是什么）
- B 核心价值观念（做人做事最看重什么）
- C 信仰追求 / 使命（为什么做、达成什么）
- D 道德规范 / 操守底线（怎么对客户负责）
- E 行为准则（日常服务与作业的落地标准）

标语硬约束：4~14 字为主，最长 ≤16 字；对仗工整但避开"空壳四字连排"；庄重不端着、不说教、不空喊；可嵌入「盈信」二字段落；无促销、无数字。
收尾补一个「主标语三件套」（精神 + 使命 + 操守）供对外一锤定音。

## 企微朋友圈签名 创作
角度八法：①专业实力 ②稀缺资质 ③陪伴成长 ④踏实放心 ⑤正向价值观 ⑥行业沉淀 ⑦团队背书 ⑧留口子（万能收尾）。
每条 = 适用场景（配哪类正文）+ 主句 + 备选。③⑤⑧重人情与低门槛；②⑦是差异化"重武器"但别每条都贴（用多像自夸，一周 1-2 次进正文更有效）。
原则：口语、有温度、不硬广、价值观正、点到留口子。

## 企业藏头诗（诗歌体标语 —— 融合五维 + 藏头「盈信」）
需求形态：把 企业精神/核心价值观/信仰追求/道德规范/行为准则 五维融进诗里，藏头连读成品牌词。
四种格式按用途选：**四言**（四句 16 字 / 八句 32 字 —— 最凝练、读两遍就背下来，最宜进人设文件与文化墙）／四句五言（名片、桌牌）／四句七言绝句（宣传册、文化墙边角）／八句七言（主文化墙、简介开篇，内容最全，首推）。
- 藏头从「盈」「信」起，后 2~4 字自定短词（守正 / 行稳 / 致远 / 敦慎 / 守正行稳致远 …），八句版宜两段各四字
- 押韵：偶数句押韵，长短版都追求一韵到底，不强调平仄格律（用户明示「不强求」）
- 每句都要落到某一维，交付时附「维度对应」一句话注解；别为凑字堆意象
- 流程：豆包出候选 → 主会话机械核验（见下节）→ 桌面 Word 交付（沿用本文档的 python-docx 小节）
- 出稿后按 A/B/C 三种格式各给 3 首 +「首推」标记，让用户挑；末尾附《校准说明》

## 藏头诗机械核验（交付前必跑，不可省）
**LLM 自报的「藏头连读」和「每句字数」都不可信。** 实测豆包把实际藏头为「盈信敦慎」的诗标成
「盈信敦行」（第 4 句首字是「慎」不是「行」）。读着顺 ≠ 格式对。
核验三件事：
1. 藏头 = 每句**首字**逐个拼接，与模型标注比对 —— 必程序化
2. 每句字数（去标点后）**整首齐整**且落在常见诗体字数 4/5/6/7（四言/五言/六言/七言）—— 必程序化；要锁死某一诗体时用 `--line-len N`（如 `--line-len 4` 只收四言）
3. 押韵（偶数句韵母一致/通押）—— 脚本只打印每句末字，靠人读
```bash
python3 scripts/verify_acrostic.py --file draft.txt --split-blank --expect 盈信守正,盈信行稳
```
不符即 exit 1，可当交付门禁；改句后必须重跑。

**首字生造的固有难点**：藏头被「盈」「信」框住，开头两字之外的词容易生造（盈程/盈邻/盈舱/盈畔/盈畴）。
交付时主动说明这点并留「你看中哪首、我按原意重拟更自然的起句」的口子 —— 别装作每句都自然。

## 融入人设文件（identity-anchor / 产品手册）

标语、藏头诗定稿后，用户常追问「这些要不要融进人设 md？」——**值得，但守 4 条纪律**：

1. **只进「理念层」，每项只定一版。** `canonical-identity-anchor.md` 自带「一次性定稿、引用不得改写」纪律，融进去的必须唯一版；备选/多首只留在本 skill 的 references，**不上墙、不进引用源**（多版本进引用源 = 对外口径混乱）。七言长版留给海报/文化墙，不进人设 md。
2. **按文件定去留：**
   - `canonical-identity-anchor.md`（品牌身份锚点）← **首选落点**。现装硬背书＋话术＋数据、缺理念层 → 新增「企业文化 · 品牌资产」章节，建议放「三、标准表述」之后、编号顺延。
   - `03-产品手册.md`（compliant-accounting/references）← 开头「核心定位」下加**一行使命**即可，别整章塞。
   - `SOUL.md` ← **不是盈信人设**，是 Hermes 人格模板（136 字节空壳），勿放。
3. **五份副本全同步**（★ sales-communication 那份**有意**多一段「反挂靠三连问」，同步时保留、只在其后追加，**勿用其余四份覆盖它**）。源文件 CRLF，比对 `diff <(tr -d '\r' < A) <(tr -d '\r' < B)`，改完核 md5。
4. **先提案后动手。** 理念/文化属「品牌宣传类」内容，写进核心人设文件前必须列方案请用户拍板，未获同意不落笔。

**可主动提的增值角度**（用户认过这种"顺带发现"）：产品手册第六章「合规/保密/时效/响应承诺」就是操守「不越红线，不谋虚利」的**落地版** —— 理念（虚）与承诺（实）互引成闭环，比单摆标语有说服力。

完整底账（五副本路径 + md5 + 提案稿 + 四言定稿）见 `references/identity-anchor-integration-2026-10.md`。

## 交付规范
1. 桌面 .md 先行，回复里给出完整 Windows 路径（如 C:\Users\Administrator\Desktop\…）
2. 用户要 Word 时用 python-docx 生成（本机已装 1.2.0；pandoc 未装）——见下节
3. 一任务全部产物先入同名文件夹再压 zip 留桌面（见 content-evidence-discipline 交付铁律）

## Word 生成（python-docx，本机已验证）
- 本机环境：pandoc 未安装，python-docx 1.2.0 已装 → 直接用 python-docx，无需纯 stdlib 手搓 OOXML
- 中文字体必须同时设置 Normal 样式与每个 run 的 eastAsia，否则 Word 里中文回退宋体：
  - Normal：`style.element.rPr.rFonts.set(qn("w:eastAsia"), "宋体")`
  - 每个 run：`run._element.rPr.rFonts.set(qn("w:eastAsia"), "黑体"/"宋体"/"楷体")`
  - 深蓝 RGBColor(0x1F,0x3B,0x73) 做节标题、#C00000 红做待核对标注
- 两个部分之间用 `add_page_break()` 分页
- 验证：`read_file` 会自动抽取 .docx 文本，逐条核对内容完整性（无需 soffice/pandoc）

## Pitfalls
- 豆包标语偶尔会混入与盈信无关的地名/数字/头衔——主会话必须逐条读一遍，只保留在事实白名单内的表述
- 「待核对」红标只能用于真实存在的不确定点，写完就直接改对，别把占位注当交付
- 交付 Word 前先问清是合并成一份（多主题分 part + 分页）还是分开多份
- **藏头诗/对联/字谜等有硬格式约束的稿子：豆包自报的「藏头」「字数」必错漏，交付前跑 `scripts/verify_acrostic.py`，别凭读感放过**（本坑已实测踩到一次）
- 阶段性产物别只留 .md 散在桌面：一任务全部产物入同名文件夹再压 zip（见 content-evidence-discipline 交付铁律）；但用户明确说「word 放桌面」时，Word 本体留桌面，只提示可收拢源文件，勿擅自删

## Verification
- 交付前逐条核对：无编造数值/法条/奖项/头衔（只用白名单）
