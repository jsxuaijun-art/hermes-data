# 强反爬平台（抖音/小红书）取数路线

## 结论（2026-08-04 与用户确认拍板）
抖音等强反爬平台，在当前环境（WSL 共享出口IP、无住宅代理、用户为财税合规行业）下直接爬取性价比极低，且触碰个人信息合规红线。**用户已拍板：不搞"改网络身份"硬爬。** 取数一律走替代路线（见下），不要再向用户推销代理/指纹浏览器方案。

## 网络身份四层模型（为什么"只换IP"不够）
抖音风控同时核查四层，任何一层露馅都会被识别：
1. **IP 出口** — 公网IP类型（机房/住宅/移动/运营商段）
2. **设备指纹** — Canvas/WebGL/字体/时区/UA/显卡拼出的"设备长相"
3. **Cookie/登录态** — 抖音账号身份 + 权重与行为历史
4. **账号信誉** — 是否养号、IP是否多人共用、行为是否像真人

## 改变网络身份的方案盘点（成本/有效性/风险）
| 方案 | 成本 | 对抖音有效性 | 主要风险 |
|------|------|------------|---------|
| 普通机房代理池 | 便宜 | 低（IP早被标记） | 易封 |
| 海外住宅代理 | 贵（按GB） | 低（地区不匹配） | 慢+贵，中国IP另计费 |
| 国内住宅代理 | 极贵且稀少 | 中 | 大量IDC伪装 |
| 移动4G/5G代理 | 贵 | 较高（抖音信移动） | 需实名通道 |
| 指纹浏览器+代理 | 订阅费 | 高（组合拳） | 封号/合规 |
| 家用宽带PPPoE重拨换IP | 低成本 | 高（真住宅） | IP数有限 |
| 养号+登录态 | 时间成本 | 关键（配合IP） | 封号 |

## 为什么不建议本用户折腾
1. 财税行业，非反爬专业，配齐=烧钱烧时间养技术
2. 合规雷区：批量注册/养号/抓取触《个人信息保护法》，与"税务合规"人设冲突（这是劝退第一理由）
3. 用户要的是数据不是爬虫——有更便宜合规的路
