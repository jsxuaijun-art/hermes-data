# 按张付费全包（印量包）专章

建立于 2026-10。触发场景：用户拿回一份本地服务商的"按张付费、全包"报价，
问"要不要换方案 / 怎么谈"。或用户是服务型乙方，想把该模式打包成客户产品。

## 1. 判定：全包 vs 买断，怎么比才不跑偏

**唯一正确的比法：`全包元/张` vs `买断路线的单页综合成本`。**

```
买断单页综合成本 = (购机价 ÷ 生命周印量)
                 + 单页耗材（已按覆盖率折算的实际页产量，见 high-volume-toner-economics.md）
                 + 单页维修摊销
                 + 单页其他（不含纸张；纸张两种模式都自付）
```

❌ 不要拿"全包元/张"去和"购机价"比 —— 量纲不同，结论必然错。
❌ 不要把买断路线的耗材年费按**标称页产量**算 —— 会低估 2～3 倍，导致误判成"全包贵"。

## 2. 实测总账（财税代理，年印量 7.68 万张，不含纸，3 年期）

| 方案 | 首期投入 | 3 年总支出 | 机器归属 | 维修/停机风险 | 加粉管理 |
|---|---|---|---|---|---|
| **印量包 0.03 元/张** | ¥0 | **≈ ¥6,912** | 供应商 | 供应商承担，坏了换机 | 无 |
| 买断·奔图 P3301DN + 大粉盒 | ≈¥1,500 | ≈ ¥7,300 | 买方 | 自行承担 | 需管理 |
| 买断·兄弟 HL-B2080DW + 自加粉 | ≈¥1,650 | ≈ ¥7,920 | 买方 | 自行承担 | 需管理 |
| 买断·佳能 LBP243dw + 兼容件 | ≈¥3,080 | ≈ ¥9,350 | 买方 | 自行承担 | 需管理 |
| 对照：市场常规租赁 0.05 元/张 | ¥0 | ≈ ¥11,520 | 供应商 | 供应商承担 | 无 |

纸张（两模式都不含）：3 年约 ¥5,760（¥0.025/张 × 7.68 万 × 3），默认双面可降至约 ¥4,000。

## 3. 印量敏感性（结论稳健性证明）

| 年印量 | 印量包 3 年 | 买断自加粉 3 年 | 谁更省 |
|---|---|---|---|
| 5 万张/年 | ¥4,500 | ≈ ¥5,910 | 印量包 |
| 7.68 万张/年（当前） | ¥6,912 | ≈ ¥7,920 | 印量包 |
| 10 万张/年 | ¥9,000 | ≈ ¥9,660 | 印量包 |

**三档全包都更省 → 该结论不依赖印量估得准不准。** 这一点必须明确讲给用户，
因为它把"印量估错会不会翻盘"这个顾虑直接消掉。用 `scripts/compare_buyout_vs_perpage.py`
重算，保证口径统一。

## 4. 全包额外消掉的三件事（价值常被低估，要单独讲）

1. **维修与停机风险转移** —— 机器不归买方，坏了供应商换机。对"申报期绝对不能停"的
   财税/审计/开票业务，这比省的那点钱更值钱。
2. **加粉管理成本归零** —— 不用记着买粉、加粉、备货、找文印店，也不承担漏粉脏手、加粉报错。
3. **"粉盒虚标 / 覆盖率口径"问题自动消失** —— 所有品牌标称页数都按 ISO/IEC 19752 的
   **5% 覆盖率**计，而财税凭证/报表实际覆盖率远高于 5%，所以买断模式下备货永远算不准。
   改按张付费后，粉盒能打多少页是供应商的事，与买方无关。
   **这是把前面几轮最费劲的问题一次性消掉，要主动指出来。**

## 5. 决策维度收缩表（换方案时必须显式给这张表）

| 作废（与买方无关） | 仍成立（改为向供应商"要求"） |
|---|---|
| 鼓粉分离 / 可自加粉 / 加粉生态 | 月负荷 ≥ 峰值 2～3 倍 |
| 粉盒容量 / 换粉频次 | 速度（决定申报期会不会排队） |
| 单页耗材成本 | 纸盒容量、出纸容量 |
| 兼容耗材单价与保修风险 | 复印 / 扫描 / 输稿器需求 |
| —— | 打印语言（GDI vs PCL/PS，见 network-shared-printing-compat.md） |
| —— | 系统兼容（Win7 等），可转为供应商责任 |
| —— | 纸张成本（一般不含纸，双面可省约 30%） |

## 6. 三条反直觉动作

1. **单价固定 → "压配置"，不是"压价"。** 同样 0.03 元/张，机器越快、纸盒越大、
   功能越全，买方越划算。主动要更好的机器。
2. **低于行情约 40% 时不要继续压价。** 压太狠，服务商会用低配机器或放慢响应把成本找回来。
   火力转到合同条款。
3. **A3 要翻案。** 早期方案常以"A3 更贵、用不上"砍掉 A3；按张付费下该理由不成立 ——
   A3 黑白复合机能打 A4，通常速度更快（25～40ppm）、纸盒更大（1000 页起）、月负荷更高、
   标配双面 + 复印 + 扫描 + 输稿器。**同价或小幅加价就该争 A3。**

## 7. 合同 12 项必查清单（本模式的核心价值就在这张纸上）

| # | 条款 | 为什么关键 |
|---|---|---|
| 1 | **月最低印量 / 最低消费** | **唯一能让低价变贵的条款。** 月最低 8,000 张而实际只用 6,400 张 → 三年白付约 5.76 万张 × 单价 ≈ ¥1,728。要求：无最低，或 ≤ 实际月均的 80% |
| 2 | 超印单价 | 不能 ≤ 合同单价就要问清，旺季超量不能被高价补差 |
| 3 | 锁价年限 | 三年锁价，白纸黑字，防中途调价 |
| 4 | 是否含彩色 + 彩色单价 | 另行报价并锁定，避免日后被高价 |
| 5 | 是否含纸张 | 一般不含，确认清楚（纸由买方自购） |
| 6 | 响应 / 修复时效 | 建议 4 小时响应 / 24 小时修复；申报期停机容忍度极低 |
| 7 | **备机条款** | 修不好须提供备用机 —— **印量包最大的价值点** |
| 8 | 设备归属 + 中途解约 + 残值买断 | 服务变差时留退路，用得好可留下 |
| 9 | 服务不达标退出 / 换机条款 | 供应商服务变差时的退路 |
| 10 | 是否含税开票 | 财务入账需要 |
| 11 | **系统兼容责任转移** | 写"供应商负责接入局域网并确保所内全部电脑（含 Win7）可正常打印及使用金蝶/用友凭证打印；不能满足须无偿调整或更换设备" |
| 12 | **现场试打** | 用真实凭证纸 + 金蝶/用友凭证 + 电子税务局申报表；参数表替代不了试打 |

## 12. 副产品：把该模式反向打包成客户产品（服务型乙方适用）

若用户是**服务型乙方**（财税代理 / 咨询 / 代账），这套采购经验本身可变成一项
卖给客户的产品："办公设备全包，客户只按张付费，什么都不用管。"

**产品设计要点：**

| 形态 | 对客户报价（参考） | 适合客户 |
|---|---|---|
| 按张全包（推荐） | 0.05～0.06 元/张（黑白） | 月印 1,000～5,000 张 |
| 月租 + 含基础印量 | 月 200～400 元（含 3,000 张） | 印量稳定的小微 |
| 打包赠送（绑定主服务） | 作为主服务包的加值项 | 新签 / 续约客户 |

**⚠ 必须做的期望值管理（诚实）：** 打印差价很薄 —— 每张约 2 分，月印 3,000 张的客户
一年毛利才约 ¥720。**定位应是"增援型产品"**：
① 每月固定接触点，强化客户关系；② 提升主服务签约率与客单价；③ 制造转介绍钩子。
**不是独立利润线。** 期望值定在这里就划算，定成"新利润中心"必然失望。

**落地只需一步：** 向服务商问一句"如果我把客户介绍给你们，渠道价 / 分润怎么算？" ——
零成本，产品线就打通了。

**渠道洞察：** 品牌**区域总代理 / 授权维修站本身就有自己的分销体系**，且最缺的是
**稳定的小微客户流量** —— 与持有大量小微客户的服务型乙方天然互补。
不必从零搭供应链，可直接谈渠道合作："我这边有几百家客户，办公设备这块你们有没有渠道合作政策？"

**必须提前划的边界：**

| 风险 | 应对 |
|---|---|
| 售后责任归属（客户先找乙方，但乙方解决不了） | 合同明确乙方为推荐/代理方，服务由上游承担；建快速转交机制 |
| 服务商质量拖累乙方品牌 | 只与品牌官方授权服务商合作；协议中约定响应时效与考核，不合格可更换 |
| 服务商跑路 | 要求设备产权清晰、抄表数据可转移；对接 2 家备选 |
| 进价被吃 | 同时向 3 家以上询价；争取书面渠道价或改固定分佣制 |
| 数据合规 | 明确抄表仅涉及页数计数、不涉及内容；上门人员须签保密约定 |

## 13. 诚实的残留不确定性

- **0.03 元/张的成本可持续性存疑。** 按 7.68 万张/年、机器 ¥3,000 三年摊销、
  兼容耗材按市价估算，该价位对供应商利润极薄。属让利价，**必须以书面锁价对冲中途调价风险**。
- 机型与最终报价均以**供应商书面答复 + 现场试打**为准，本文件中的参数与价格是参考量级。
