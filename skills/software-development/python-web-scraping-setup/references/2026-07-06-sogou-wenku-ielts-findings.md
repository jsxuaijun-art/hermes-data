## 搜狗搜索 curl_cffi「一次失效」律

| 尝试 | 目标 | 工具 | 关键词 | 结果 |

**结论**：搜狗的 curl_cffi 只有 **第一次请求** 有效。之后 IP/会话 被永久标记。不可重试，不可换参数重试，不可换工具重试。首次拿到的链接必须一次用到位。

## 经验教训

1. **搜狗第一次为金色窗口** — 必须一次把拿到的链接全部记录并利用
2. **百度文库搜索页可自动化**，但文档页的完整内容和下载必须由用户自己 VIP 操作
3. **「相关文档集」比多次搜索更高效** — 一次点击获得15篇同类文档
4. **搜索关键词一定要带品牌+书名** — 「新东方」「俞敏洪」「绿宝书」这类出版商名比泛搜有效得多
5. **本 session 用户明确有百度文库 VIP** — 终端用户有此条件时优先走此路，节省爬虫调试时间
