# 企业名称登记 · 核名实操要点（法规一手依据）

> 依据两份现行/有效文件整理，代办注册「核名一次过」的差异化价值点：
> 1. 《企业名称登记管理规定实施办法》（国家市场监督管理总局令第82号，2023-10-01施行，替代2004年总局令第10号）
> 2. 《企业名称禁限用规则》《企业名称相同相近比对规则》（工商企注字〔2017〕133号，2017-07-31）
> 核名的本质是：结构对 + 避开禁限 + 不与同行业相同/近似 + 自主申报承诺自负其责。

---

## 一、企业名称结构（四要素，依次排列）

```
行政区划名称 + 字号 + 行业或经营特点 + 组织形式
例：苏州（行政区划）+ 盈信（字号）+ 企业管理（行业）+ 有限公司（组织形式）
```

- 行政区划 = 企业所在地县级以上行政区划名称；**市辖区的名称不能单独用作行政区划**（实施办法§9；133号§11）。
- 商号放到字号之后、组织形式之前时，要**加括号**：如「XX（上海）科技有限公司」（实施办法§9）。
- 字号 = **2个以上汉字**，字/词或其组合；**行政区划、行业、组织形式不得用作字号**（实施办法§10；133号§12）。自然人投资人姓名可作字号。
- 行业 = 按**主营业务 + 国民经济行业分类标准**确定；无标准的可参照行业习惯或专业文献（实施办法§11）。
- 组织形式 = 与组织结构/责任形式一致（实施办法§12）：
  - 公司：「有限责任公司」「有限公司」「股份有限公司」「股份公司」
  - 合伙企业：「（普通合伙）」「（特殊普通合伙）」「（有限合伙）」
  - 个人独资企业：「（个人独资）」
  - **不得使用可能使公众误以为其他组织形式的字样**。

## 二、禁限用规则（核名踩坑高频区）

### 禁止性规则（133号§4-§14，绝对不能出现）
1. **与同一登记机关已登记/核准的同行业企业名称相同**，包括：已登记、已核准未登记仍在有效期、已申请未核准、注销未满1年、变更名称未满1年的原同行业名称、被撤销/吊销未注销的同行业名称（§4）。
2. 有损国家/社会公共利益：消极政治影响、恐怖分裂极端主义、殖民文化、歧视、封建糟粕、毒品淫秽色情暴力赌博等（§5）。
3. 对公众欺骗或误解：领导人/革命家/烈士/模范姓名、非法组织/反动人物姓名、宗教组织名或显著宗教色彩（§6）。
4. 外国国家（地区）名称、国际组织名称（§7）。
5. 政党名称、党政军机关名称、群团组织名称、社会组织名称、部队番号（§8）。
6. **不得用外文、字母、阿拉伯数字**，须用规范汉字（§9）。
7. 法律行政法规禁止的其他内容（§10）。

### 限制性规则（133号§15-§29，有条件才可用）
1. 不得与同行业企业名称**近似**，但有投资关系除外（§15）。
2. 企业法人名称中**不得含有其他非营利法人名称**（除投资/授权用其简称、且简称有其他含义）（§16）。
3. **不得含有另一个企业名称**（除投资/授权用简称）（§17）。
4. 不得明示/暗示为非营利组织或超设立目的（§18）。
5. **「中国/中华/全国/国家/国际」**：除国务院决定设立的企业外，不得冠以；中间使用须是行业限定语；外资可用「（中国）」。冠名三类需总局核准（§19）。
6. **不含行政区划**（§20）：须国务院批准 / 总局登记 / 注册资本≥5000万 / 总局另有规定。
7. 字号不得用语句、句群、段落，但具显著识别性或短句除外（§22）。
8. 字号不得含「国家级/最高级/最佳」等误导性文字（§23）。
9. 字号不得用外国国家/地区所属辖区、城市名及简称（§24）。
10. 行政区划不得作字号，但县以上地名有其他含义除外（§25）。
11. 字号不得用职业/职位/学位/职称/军衔/警衔，但其他含义除外（§26）。
12. **不得用工商总局曾给驰名商标保护的规范汉字作同行业字号**（除获授权）（§27）。
13. 行业不得与主营业务不一致（§28）；符合以下可不用国民经济行业类别表述：①经济活动属5个以上大类；②注册资本≥1亿或为集团母公司；③与同登记机关同类别企业字号不相同。

### 集团名称（实施办法§17-§18，2023新规）
- 控股3家以上企业法人，可在组织形式前用「集团」或「（集团）」。
- 集团名称应与母公司行政区划、字号、行业/经营特点一致；子公司/参股公司经母授权可冠集团名称。

## 三、相同 / 相近比对（133号比对规则）

### 提示「相同」（不能通过，三条）
1. 与已登记/核准企业名称**完全相同**。
2. 行政区划、字号、行业、组织形式**排列顺序不同但文字相同**（如：北京红光酒业发展有限公司 vs 红光（北京）酒业发展有限公司）。
3. 字号+行业文字相同但行政区划/组织形式不同（如：北京红光酒业有限公司 vs 红光酒业有限公司 / 北京红光酒厂）。

### 提示「相近」（能报，但有审核不通过/侵权/被强制变更风险，五条）
1. 同行业字号相同，行业表述不同但含义相同（万青地产 vs 万青房地产/万青置业）。
2. 同行业字号字音相同，行业表述相同或内容相同（牛栏山 vs 牛兰山；牛栏山 vs 牛蓝山白酒）。
3. 字号**包含或被包含**同行业字号（阿里巴巴 vs 阿里巴巴巴巴）。
4. 字号与同行业字号**部分字音相同**（阿里巴巴 vs 马云阿理巴巴）。
5. 不用国民经济行业表述（实业/发展等）时，含/被含同类别字号，或字音相同（牛兰山 vs 金牛栏山；全聚德 vs 荃巨得/宏荃聚德）。

**核名结论要诀**：只要**同行业 + 相同或近似的组合**都会触发风险。避开：同行业相同字、同音不同字、包含关系、拆字重组。

## 四、自主申报制度（2023实施办法第三、四章）

- 企业名称由**申请人自主申报**，通过申报系统或窗口提交，**对材料真实性/合法性/有效性负责**（§21-§22）。
- 申报时承诺：因其名称与他人近似侵权的，**依法承担法律责任**（§22）。
- **保留期：2个月**；设立需批准或经营范围有登记前须批项目的，保留期**1年**（§25）。
- 保留期内名称**不得用于经营活动**；届满前须办理登记（§25）。
- 登记机关发现保留期名称不合规，不予登记并书面说明（§26）。

### 不得申报的行为（§23，违法有罚则§48）
1. 不以自行使用为目的，**恶意囤积名称**占用名称资源。
2. 提交虚假材料或欺诈手段申报。
3. 故意申报与他人在先有影响名称近似。
4. 故意申报法律禁止的名称。

## 五、使用、转让与争议裁决（要点）

- 印章、银行账户、法律文书所用名称须与营业执照一致（§28）。
- **名称可转让**：签书面合同 + 办名称变更登记 + 公示（§29）。
- 授权使用名称：双方分别公示授权信息（§30）。
- 已登记名称不合规 → 责令变更；不立即变更可能严重损害公共利益的，可用**统一社会信用代码代替**（§31-§32）。
- 责令变更后30日内办理，逾期列入**经营异常名录**（§32）。
- 争议裁决：可向法院起诉或请求登记机关处理（§34）；裁决考量显著性/独创性、持续使用时间、知悉程度、申报承诺、混淆误认、商誉（§41）。不服可行政复议或诉讼（§47）。

## 六、核名实操速查（给客户/自用口诀）

1. **先结构**：区划+字号+行业+组织形式排好，字号≥2汉字不撞要素词。
2. **再避禁**：扫禁限清单（领导人/宗教/政治敏感/党政军/国家大词/外文数字字符）。
3. **后比对**：同行业是否相同/近似——重点查同音、包含、拆字。（企业名称申报系统会自动比对并提示）
4. **多备名**：核名多备3-5个（字号不同、排列不同），防撞同行业。
5. **自主申报**：提交时勾选承诺自负其责。
6. **盯保留期**：2个月（有审批项目1年），期限内办登记，逾期失效。
7. **开票/经营**：名称定了再用，保留期内不得经营。
