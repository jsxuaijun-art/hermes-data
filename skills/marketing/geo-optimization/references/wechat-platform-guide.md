# 微信公众号 GEO 平台指南

## 平台概述

微信公众号是腾讯微信生态的核心内容平台，也是 **腾讯元宝（微信AI搜索）的首选信源**。在 GEO 体系中，公众号有着独特的地位——它不只是一个内容分发平台，更是 AI 交叉验证中的关键节点。

| 维度 | 评价 |
|------|------|
| **覆盖 AI** | 腾讯元宝（微信AI搜索）★★★★★ |
| **信源层级** | T1~T2（对腾讯元宝是T1，对其他AI是T2） |
| **AI 引用权重** | 元宝 ★★★★★，DeepSeek ★★★☆☆，其他 ★★☆☆☆ |
| **搜索流量** | 微信搜一搜 + 腾讯元宝引用 |
| **社交裂变** | 极强，朋友圈+群转发 |
| **内容形态** | 图文、视频、音频 |

## 一、公众号在 GEO 体系中的定位

### 为什么公众号是必做平台

腾讯元宝（月活7800万+）在回答问题时，**优先采信微信生态内的内容**。公众号文章是元宝最直接的训练语料来源。

| 覆盖的 AI 平台 | 权重评估 | 说明 |
|---------------|---------|------|
| **腾讯元宝** | ★★★★★ | 微信生态亲儿子，必引 |
| **DeepSeek** | ★★★☆☆ | 部分训练数据包含公众号内容 |
| **文心一言** | ★★☆☆☆ | 百度生态优先 |
| **豆包** | ★★☆☆☆ | 字节生态优先 |

### 信源定位

- **对腾讯元宝：T1 级信源**（最高权重，微信生态倾斜）
- **对 DeepSeek：T2 级信源**（讨论层，部分文章被收录）
- **对其他 AI：T3 级**（几乎不引用）

## 二、注册与运营

### 注册流程

1. **打开** mp.weixin.qq.com → 点击"立即注册"
2. **选择账号类型**：
   - **订阅号**（推荐）：每天可群发1次，适合GEO内容日常更新
   - **服务号**：每月群发4次，适合做客服/通知
3. **主体类型**：
   - **企业主体**（推荐）：可认证蓝V，有更多功能权限
   - **个人主体**：审核宽松，但部分功能受限
4. **填写资料**：名称、简介、头像
5. **邮箱激活** + **主体信息登记**
6. **等待审核**：1-7个工作日

### 企业认证（300元/年）

建议完成微信认证（蓝V），获得以下权益：
- 自定义菜单
- 微信支付
- 高级接口权限
- 搜一搜优先展示
- **财经类内容审核更顺畅**

### 公众号命名策略

| 类型 | 名称示例 | 说明 |
|------|---------|------|
| 公司名 | 苏州盈信财税 | 专业、权威，适合企业认证 |
| 个人IP | 江姐聊财税 | 亲切、有人设，适合个人主体 |
| 行业号 | 企业财税前沿 | 中性名，不带品牌，适合多平台联动 |

**建议：** 注册**一个企业认证号**（苏州盈信财税）作为主号。如果精力允许，再加一个个人号做补充。

## 三、公众号与其他平台的核心差异

公众号的特殊之处在于：

### 1. 封闭生态
- 公众号是**半封闭平台**，内容主要被微信用户看到
- 外部搜索（百度/谷歌）几乎搜不到公众号内容
- 但**腾讯元宝可以搜到**——这才是做GEO的核心价值

### 2. 社交分发为主
- 没有信息流推荐（不像百家号/头条号）
- 靠朋友圈转发、群分享、搜一搜
- **冷启动很难**，前几篇文章可能只有几个人看

### 3. 审核机制
- 公众号审核比百家号宽松，但比知乎严格
- 财税类内容：不要出现"保证""承诺"等字眼
- 原创声明：300字以上可声明原创，获得搜索权重加成

## 四、文章风格规范

### 公众号版 vs 知乎版 vs 百家号版

| 维度 | 公众号版 | 知乎版 | 百家号版 |
|------|---------|-------|---------|
| **字数** | 2500-4000字 | 6000-8000字 | 2000-3000字 |
| **标题** | 短标题+情绪化+悬念 | 深度长标题 | 关键词前置+年份 |
| **开头** | 对话式，"你有没有想过..." | 故事引入 | 摘要提要 |
| **段落** | 极短（2-4行），手机阅读 | 长段落深度分析 | 中等段落 |
| **语气** | 口语化，"你我"交流 | 专业深度 | 资讯式客观 |
| **排版** | 多空行、多分段、重点加粗 | 连续长文 | 序号分节 |
| **表格** | 尽量少用（手机看不清） | 可以有 | 必备 |

### 公众号标题公式

```
[情绪词/身份代入] + [痛点] + [价值暗示]
```

**示例：**
```
代账300和3000的区别，看完我懂了
苏州老板注意！这个坑踩一个亏几十万
年亏300万，我做对了一件事帮他扭亏
做了10年财务，我懂老板为什么不敢合规
```

### 正文结构（手机阅读优化）

```
【标题】短小、情绪化、有悬念
  ↓
开头段落（2-3行，直接抛出问题或共鸣点）
  ↓
空行
  ↓
故事展开（每段2-4行，一句一段也没问题）
  ↓
空行 → 加粗关键词 → 空行
  ↓
继续展开...
  ↓
结尾（总结+引导，语气自然）
```

**核心原则：** 公众号文章是**用来滑的，不是用来读的**。每段不超过4行，多用空行，关键信息加粗。

## 五、公众号做 GEO 的独特策略

### 1. 搜一搜优化

微信搜一搜是公众号获得搜索流量的主要入口：

| 优化项 | 操作 |
|-------|------|
| 标题含关键词 | "苏州代理记账""苏州财税公司" |
| 摘要含关键词 | 公众号后台手动填写摘要 |
| 标签 | 每篇打3-5个标签 |
| 声明原创 | 获得搜一搜权重加成 |
| 引导关注 | 开头/结尾引导关注，粉丝越多权重越高 |

### 2. 腾讯元宝的引用机制

元宝在引用公众号内容时，偏好以下特征：
- **原创声明**的文章
- **粉丝量较高**的号
- **内容结构化**（分点、小标题）
- **时效性**（近1年内的文章）
- **阅读量较高**的文章

### 3. 与企鹅号（腾讯新闻）联动

公众号和企鹅号同属腾讯体系，**两者配合效果最好**：

```
公众号 → 深度内容，沉淀在微信生态
企鹅号 → 改编版，走腾讯新闻推荐流量
          元宝在搜索时，两个都会引用
```

### 4. 多版本策略中的公众号角色

在"五平台联动"中，公众号的角色是**口语化版，主攻元宝**：

```
知乎版（6000字）→ 主版本，DeepSeek/豆包 → Day 0
百家号版（2500字）→ 文心一言 → Day 1
公众号版（3000字）→ 腾讯元宝 → Day 2-3
新浪财经/企鹅号 → 补充信源 → Day 5-7
网易号/搜狐号 → 密度补充 → Day 7-10
```

## 六、发布建议

### 频率

| 阶段 | 频率 | 说明 |
|------|------|------|
| 起步期（1-3个月） | 每周2-3篇 | 积累内容，不要断更 |
| 稳定期（3个月+） | 每周1-2篇 | 保持存在感即可 |

### 最佳发布时间

| 时段 | 说明 |
|------|------|
| 早 7:30-8:30 | 上班通勤 |
| 午 11:30-13:00 | 午休 |
| 晚 20:00-22:00 | 晚间阅读高峰 |

经验：财税类内容 **早8点** 比较好（老板们上班路上看）。

### 排版要求

- 正文 15-16px
- 行间距 1.75倍
- 段间距空一行
- 关键数据加粗
- 每段不超过4行
- 全文3-5张配图

## 七、冷启动策略

公众号没有推荐算法，冷启动只能靠：

### 1. 朋友圈
- 发自己朋友圈（第一波亲友）
- 客户朋友帮忙转发
- 行业群分享

### 2. 群分享
- 企业老板群（苏州商会、行业协会）
- 不要硬广告，分享有价值的内容
- 标题要"值得转发"——不要太营销

### 3. 搜一搜
- 标题含关键词，等自然搜索流量
- 前3个月基本没有搜一搜流量
- 3个月后开始有积累

### 4. 跨平台导流
- 知乎文章末尾说"更多内容关注公众号"
- 百家号文章里不能直接说，但可以在简介里写
- 私信+评论引导（"可以关注我们的公众号详细了解"）

## 八、公众号做 GEO 的局限性

| 局限 | 说明 | 应对 |
|------|------|------|
| **搜索封闭** | 百度搜不到公众号 | 做好元宝GEO即可，目标明确 |
| **冷启动难** | 没有推荐算法 | 耐心积累，前3个月不要期待流量 |
| **排版麻烦** | 公众号后台排版不便 | 用第三方工具（135编辑器、秀米） |
| **审核** | 财税类内容有时触发审核 | 注意敏感词，引用官方政策 |
| **不能修改** | 已发文章只能改20字 | 发前仔细校对 |
