# 合同编（第三编）结构化 Skill

## 任务目标

把用户关于合同的法律问题，定位到具体分编/章/条文，给出可精确引用的结论与操作建议；
复杂场景给出"警惕信号 + 处置步骤 + 条文依据"。

## 合同编结构（路由索引）

- **第一分编 通则**（第463—594条，8章）：一般规定、订立、效力、履行、保全、变更和转让、权利义务终止、违约责任。
- **第二分编 典型合同**（第595—978条，19章→共29种有名合同）：
  买卖合同(9)、供用电水气热力(10)、赠与(11)、借款(12)、保证(13)、租赁(14)、融资租赁(15)、
  保理(16)、承揽(17)、建设工程(18)、运输(19)、技术(20)、保管(21)、仓储(22)、委托(23)、
  物业服务(24)、行纪(25)、中介(26)、合伙(27)。
- **第三分编 准合同**（第979—988条，2章）：无因管理(28)、不当得利(29)。

## 通则重点制度速查

| 主题 | 核心条文 | 要点 |
|------|---------|------|
| 合同定义/身份协议参照 | 第464条 | 合同是设立变更终止民事法律关系的协议；婚姻/收养/监护等身份协议依身份法，无规定可参照本编 |
| 合同效力（成立即受保护、相对性） | 第465条 | 依法成立的合同受法律保护，仅对当事人具有法律约束力（法律另有规定除外） |
| 合同条款争议解释 | 第466、142条 | 按第142条第1款确定争议条款含义；多语种文本同等效力时推定为同义，不一致按相关条款/性质/目的/诚信解释 |
| 合同形式（书面/口头/数据电文） | 第469条 | 数据电文可随时调取查用的视为书面形式 |
| 格式条款提示说明义务 | 第496条 | 提供方须采取合理方式提示免责/减轻责任等有利害关系条款，按要求说明；未尽义务致对方未注意/理解的，对方可主张该条款不成为合同内容 |
| 格式条款无效 | 第497条 | 三种情形无效：法定无效情形；不合理免除/减轻己方责任、加重对方责任、限制对方主要权利；排除对方主要权利 |
| 全面履行 + 诚信附随义务 | 第509条 | 按约定全面履行；遵循诚信履行通知/协助/保密等义务；履行中避免浪费资源、污染环境、破坏生态（绿色原则） |
| 违约责任（继续履行/补救/赔偿） | 第577条 | 不履行或履行不符合约定，承担继续履行、采取补救措施或赔偿损失等 |
| 损失赔偿范围（可预见规则） | 第584条 | 相当于违约造成的损失，含合同履行后可获利益，但不得超违约方订约时预见到或应预见到的损失 |
| 违约金过高/过低调整 | 第585条 | 约定违约金；过分高于损失的，可请求法院/仲裁酌减；低于损失的，可请求增加 |
| 定金罚则 | 第587条 | 给付方违约致不能实现合同目的，无权返还定金；收受方违约，双倍返还 |
| 定金与违约金择一 | 第588条 | 既约定违约金又约定定金，一方违约对方择一适用；定金不足弥补损失的，可请求赔偿超过部分 |
| 减损义务 | 第591条 | 违约后对方应采取适当措施防损扩大；未采取不得就扩大部分请求赔偿，防损合理费用由违约方负担 |
| 借款利息不得预扣 | 第670条 | 利息不得预先在本金中扣除；预扣的按实际借款数额返还并计算利息 |
| 禁止高利放贷 | 第680条 | 禁止高利放贷，利率不得违反国家规定；未约定利息视为无息；自然人之间利息约定不明视为无息 |

## 高频场景 → 处置步骤 → 条文

1. **"我签的协议里有一堆小字格式条款，能免责吗？"**
   - 警惕信号：提供方未提示、未说明免责/限责条款 → 第496条，对方可主张不成为合同内容。
   - 即使成为内容，若不合理免除己方责任/排除对方主要权利 → 第497条无效。
   - 步骤：①确认是否尽提示说明义务；②审查是否属第497条三种无效情形；③主张不成为内容或无效。

2. **"对方违约了，我能要多少赔偿？"**
   - 依据第577条（违约责任）、第584条（可预见规则，含可得利益但受限）、第591条（减损）。
   - 步骤：算实际损失+可得利益→核对是否超出订约时可预见→审查守约方是否减损→主张。

3. **"交了定金又约定了违约金，能同时要吗？"**
   - 第588条：只能择一；定金不足弥补损失的，可就不足部分再索赔。

4. **"借钱给朋友，先扣了利息，合法吗？"**
   - 第670条：不得预扣，预扣按实际出借额算本息。第680条：禁止高利贷，自然人借贷无息约定不明视为无息。

5. **"买的货在运输中坏了，谁承担？"**
   - 交付前风险由出卖人担（买卖合同第604—606条风险随交付转移）；买受人原因致迟延受领的，自违反约定时起担风险（第608条）。具体核对 references/合同编全文.md 第595—647条。

6. **"物业收了费不干活，能拒交物业费吗？"**
   - 物业服务合同第937—950条：业主按约定支付物业费；物业服务人未按约定提供服务，业主可要求其承担继续履行、采取补救措施或赔偿损失等违约责任，但一般不能直接拒交全部物业费（依合同与司法解释具体判断）。

## 注意事项

- 合同编通则（第463—594条）可参照适用于非合同之债（第468条）及身份协议无规定时（第464条第2款）。
- 借款利率"违反国家有关规定"指最高法规定的一年期LPR四倍等红线，属司法解释口径，需结合最新规定。
- 保证合同区分一般保证与连带责任保证：未约定或约定不明，按**一般保证**（《民法典》第686条第2款，区别于原《担保法》推连带）。
- 所有条文以 `references/合同编全文.md` 为准；引用务必核对该文件原文，勿凭记忆改字。
