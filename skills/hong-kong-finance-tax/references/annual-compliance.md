# 香港年度财税与公司合规框架

## 年度检查至少覆盖
- Financial close
- Financial statements
- Audit status（如适用）
- Profits Tax Return
- Tax assessment / payment status
- Employer reporting
- MPF compliance
- Annual Return
- Business Registration renewal
- Related-party / TP documentation
- Board / shareholder records
- Dividend / capital events
- Outstanding regulatory items

所有截止日期和表格编号在执行时必须核验当前官方来源。
