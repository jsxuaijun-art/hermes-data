# 自动发现规则（重排去重后 22 条）

> 由 `scripts/report_generator.py` 依据解析 JSON 逐条判定，分级标注 🔴高 / 🟡中 / 🟢低 / ❕关注。
> 每条异常在报告中给"可能原因"，不下断言。原 Hermes 规格 30 条中 15-20（税务稽查应对）已移除，
> 不属于报表分析范畴；其税务合规内容并入 `tax-compliance.md` 作为报告板块五指引。

## 一、基础 / 结构（R1-R8）

- **R1 🔴 资产负债表不平衡**：资产总计 -（负债合计 + 所有者权益）差额 > 0.01。
  可能原因：未分配利润未结转、外币折算差额、减值未计提、期初错、口径不一。要求核平。
- **R2 🔴 期初数 ≠ 上期期末数**：本期期初与上年末不一致。要求会计核实（未结转或录入错）。
- **R3 🟡 个人借款 / 关联方资金往来**：其他应收/应付挂个人 or 关联方大额。税务风险（视同分红 / 账外）。
- **R4 🔴 应收集中度过高**：前 1 大客户占应收 > 70%。高风险，单一客户依赖。
- **R5 🟡 应收集中度偏高**：前 1 大客户占应收 40-70%。中风险。
- **R6 🟡 存货增速 > 收入增速 1.5 倍**：积压风险，关注跌价。
- **R7 🚨 净利润 > 0 但所得税 = 0**：质疑，要求会计解释（免税资质 / 递延 / 漏计）。
- **R8 🚨 实际税率 < 5%**：确认是否享优惠，避免少计提引发风险。

## 二、盈利质量 / 张氏框架（R9-R12）

- **R9 ❕ 应收增速连续 2 年 > 收入增速 1.5 倍**：激进信用政策，坏账风险累积。
- **R10 🟡 受限资金占比 > 30%**：实际可动用资金远低于账面，流动性被锁定。
- **R11 ❕ 担保余额 / 净资产 > 50%**：重大或有负债风险（互保圈），关注代偿。
- **R12 🟡 核心营业利润占比 < 50%**：利润可持续性差，依赖一次性收益 / 政府补助。

## 三、资金链 / 流动性（R13-R15）

- **R13 🔴 资金链三信号叠加**：现金比率 < 10% 且 应收周转天数恶化 且 短期借款上升 → 资金链高风险。
- **R14 🔴 应收周转天数超赊账账期 60 天以上**：回款停滞，资金链承压。
- **R15 🟡 存贷双高**：货币资金充足但短期借款同时高企，资金被占用 / 体外循环，需核查。

## 四、资产 / 往来异常（R16-R17）

- **R16 🟡 其他应收款占流动资产 > 20%**：关联方占用 / 抽逃资金嫌疑，税务风险。
- **R17 🟡 其他应付款余额大**：未入账收入 / 账外资金，需核实。

## 五、费用 / 盈利质量（R18-R21）

- **R18 🔴 销售费用率大幅偏离行业**：过高疑回扣 / 虚列，过低疑隐藏收入。
- **R19 🟡 毛利率连续 3 期下滑**：竞争力削弱 or 成本失控。
- **R20 🟡 经营现金流持续为负但利润为正**：纸面富贵，利润含金量差。
- **R21 🟡 存货增速远高于收入且期末余额巨大**：跌价风险，需计提减值。

## 六、期限结构（R22）

- **R22 🟡 期限错配**：长期借款用于短期用途 / 短期借款滚存，流动性风险。

## 判定优先级

行业细分阈值 > 资金链专项阈值 > 通用默认值。每个命中项在报告"七、风险警示"中按
🔴高 / 🟡中 / 🟢低 分级，结构：标题 → 数据支撑 → 后果 → 建议。
